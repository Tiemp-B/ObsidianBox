# Summary

OpenClaw(구 Clawdbot, Moltbot)은 오스트리아 개발자 피터 슈타인베르거(Peter Steinberger)가 만든 **자유-오픈소스 자율 AI 에이전트 플랫폼**이다. 사용자의 로컬 기기에서 상시 실행되며, 이미 사용 중인 메신저(WhatsApp, Telegram, Discord 등)를 인터페이스로 삼아 LLM(Claude, GPT 등)을 통해 실제 작업을 자율 수행한다. 2026년 1월 말 폭발적으로 바이럴되며 GitHub 역사상 가장 빠르게 성장한 오픈소스 프로젝트 중 하나가 되었다.

<aside>핵심 개념 — "Local-First AI Agent"</aside>

OpenClaw는 단순 챗봇이 아닌 **에이전트 런타임(Agentic Runtime)**이다.

- **클라우드 AI 어시스턴트**: 제공자 서버의 샌드박스 내에서만 동작 → 로컬 파일 접근 불가
- **OpenClaw**: 사용자의 로컬 기기에서 Gateway 프로세스가 실행 → 로컬 환경에 직접 접근 가능

슈타인베르거는 이를 "실제로 무언가를 수행하는 AI"로 정의하며, 텍스트를 생성하는 것이 아니라 **작업을 실행하는 AI**임을 강조했다.

---

<aside>아키텍처</aside>

OpenClaw는 4계층 구조로 동작한다.

```
[ CHANNEL ]  <---->  [ GATEWAY ]  <---->  [ LLM BRAIN ]
(Telegram 등)        (Node.js)            (Claude/GPT/Ollama)
                          |
                   [ SKILLS / TOOLS ]
                   (Shell, Browser, Files)
```

- **Gateway**: WebSocket 서버 (기본 포트 18789). 모든 클라이언트·채널·툴의 허브
- **Channel**: 사용자가 이미 쓰는 메신저 (WhatsApp, Telegram, Discord, iMessage, Slack 등 20+개)
- **LLM Brain**: Claude, GPT-4o, DeepSeek, Ollama 등 외부 LLM API 연동
- **Skills/Tools**: 브라우저 자동화, 파일 시스템 접근, 쉘 실행, Cron 스케줄링 등

---

<aside>Skills & ClawHub</aside>

**Skills**는 OpenClaw 에이전트의 기능을 확장하는 모듈이다. `SKILL.md` 마크다운 파일로 정의되며, 에이전트가 필요할 때 해당 스킬을 로드해 실행한다.

**ClawHub**는 Skills의 공개 마켓플레이스로, npm과 유사한 구조다.

- 현재 3,500개 이상의 스킬 등록
- 가입 1주일 이상의 GitHub 계정이면 누구나 배포 가능
- 임베딩 기반 벡터 검색으로 스킬 탐색 지원
- 코드 서명·필수 보안 심사 없음 → **보안 리스크**

스킬 종류: 코딩(PR 요약, 배포 트리거), 생산성(메일 팔로업, 회의 요약), CRM, DevOps, 개인 일정 관리 등

<aside>주요 보안 이슈</aside>

OpenClaw는 시스템 수준 접근 권한을 가지는 만큼 보안 위협이 현실적이다.

- **ClawHavoc 캠페인 (2026년 1월)**: ClawHub에 수백 개의 악성 스킬 유포. API 키 탈취, 키로거 삽입, MEMORY.md에 악성 콘텐츠 주입
- **ClawJacked 취약점**: 악성 웹사이트가 WebSocket을 통해 로컬 OpenClaw 에이전트를 하이재킹
- **CVE-2026-25253**: Gateway를 탈취해 임의 명령 실행 가능
- **가짜 설치 파일**: Bing AI 검색 결과에 가짜 GitHub 설치 파일이 노출되어 인포스틸러 및 GhostSocks 프록시 악성코드 유포
- 연구자들은 ClawHub 스킬의 **12~20%가 악성**으로 추정

**보안 권고:**

- 신뢰할 수 없는 스킬 설치 금지 (스킬 = 서드파티 코드 실행과 동일)
- Docker 컨테이너 또는 격리된 샌드박스 환경에서 운영
- 스킬 권한(permissions) 반드시 확인 후 최소한만 허용
- OpenClaw 전용 API 키 사용 및 일일 지출 한도 설정
