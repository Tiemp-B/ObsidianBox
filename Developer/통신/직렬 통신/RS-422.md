# Summary

RS-422는 [[차동 신호(Differential Signaling)|차동 신호]]를 써서 긴 거리(최대 ~1km)·고속 전송이 가능한 직렬 통신 규격으로, 1쌍의 송신선에 여러 수신기를 다는 1:N(멀티드롭 수신) 구조다.

# Notes

<aside>전기적 특성</aside>

- [[차동 신호(Differential Signaling)|차동 신호]] 방식 → 최대 약 **1km**, 신호 전압 **±2V~6V**
- 송신에 **2가닥**(한 쌍), **전이중**이면 **4가닥**(송신쌍 + 수신쌍)

<aside>속도와 거리 (반비례)</aside>

- ~12m: **10 Mbps**
- 1200m: **100 kbps**
- 거리가 멀수록 속도가 비례적으로 감소

<aside>연결성</aside>

- 1쌍의 송신선에 **수신기 10개** 연결 가능 → **1:N** (송신 1, 수신 다수)

<aside>구조</aside>

- **꼬인 케이블(twisted pair)**
- **[[종단 저항(Termination Resistor)|종단 저항]] 100~120Ω** → [[신호 반사(Signal Reflection)|신호 반사]] 방지

<aside>용도</aside>

- 한 곳에서 여러 기기로 전송 (예: 공장)

---

<aside>핵심 정리</aside>

- RS-422 = 차동 신호, ~1km, 1:N(수신 다수), 꼬인 케이블 + 종단저항 100~120Ω
- 거리↑ → 속도↓ (12m 10Mbps ~ 1200m 100kbps)
