# Summary

RS-485는 1:N인 [[Developer/통신/직렬 통신/RS-422|RS-422]]를 보완해 **모든 기기가 송수신**(멀티드롭 양방향)할 수 있게 한 차동 직렬 통신 규격으로, 공장 자동화 필드버스의 물리 계층으로 널리 쓰인다.

# Notes

<aside>버스 구조도</aside>

![[RS-485 버스.excalidraw]]

<aside>RS-422와의 관계</aside>

- 1:N(수신만 다수)인 RS-422를 보완 → **모든 기기가 송수신** 가능(멀티드롭)
- 1쌍의 선에 다수 장치를 [[네트워크 토폴로지(Network Topology)|데이지 체인]]으로 연결

<aside>버스 구성</aside>

- 양 끝단에 **[[종단 저항(Termination Resistor)|종단 저항]]**
- Float(미구동) 상태의 신호를 보정하기 위한 **바이어스 저항**
- 표준 수신기 **32대**, 저부하 칩 사용 시 **256대**

<aside>속도와 거리 (반비례)</aside>

- 최대 **~10 Mbps**, 최대 거리 **~1.2km** (거리↑ → 속도↓)

<aside>트랜시버 (MCU ↔ 트랜시버)</aside>

- **TX / RX**: 송·수신 데이터
- **DE (Driver Enable)**: 송신 모드 활성
- **RE (Receiver Enable)**: 수신 모드 활성
- 반이중이라 DE/RE로 송·수신 방향을 전환

<aside>신호 전압</aside>

- 출력: **±1.5V ~ ±5V**
- 수신: **±200mV 이상**(차동 전압 기준)

<aside>페일세이프 (Fail-safe)</aside>

- 단선되거나 송신 신호가 없을 때 라인을 **HIGH로 고정**해 오동작 방지
- **바이어스 저항**으로 이 페일세이프를 구현(대체)

<aside>주 사용처</aside>

- 공장 내 로봇, 인버터, 전력 감시, 컨트롤러 등

---

<aside>핵심 정리</aside>

- RS-485 = RS-422 보완, 모든 기기 송수신(멀티드롭), ~10Mbps·~1.2km
- 양 끝 종단저항 + 바이어스 저항(페일세이프), 트랜시버 DE/RE로 방향 전환
- 표준 32대(저부하 칩 256대)
