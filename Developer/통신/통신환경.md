# Summary

통신 방식을 가르는 기초 개념 — 직렬/병렬, 동기/비동기, 전이중/반이중, 싱글엔드/차동 — 과 전송 속도 지표(bitrate·baudrate), 거리에 따른 신호 열화(둔화·반사)를 정리한다.

# Notes

<aside>직렬 vs 병렬</aside>

- **직렬(Serial)**: 하나의 선으로 비트를 순차 전송. 선이 적어 **저렴**하고 배선이 단순.
- **병렬(Parallel)**: 여러 선으로 여러 비트를 동시 전송. 선이 많아 **비싸고**, **고속에서 선 간 신호 도착 시간 차(skew)로 오차가 발생**해 장거리·고속에 불리.

<aside>동기 vs 비동기</aside>

- **동기(Synchronous)**: 송수신이 **공유된 클럭선**으로 타이밍을 맞춤.
- **비동기(Asynchronous)**: 별도 클럭 없이 **사전에 설정된 속도(baudrate)**로 타이밍을 맞춤.

<aside>전이중 vs 반이중</aside>

- **전이중(Full-duplex)**: 두 기기가 **송신과 수신을 동시에** 수행.
- **반이중(Half-duplex)**: 두 기기가 **번갈아** 송수신(동시 불가).
- 상세: [[전이중·반이중(Duplex)]]

<aside>싱글엔드 vs 차동</aside>

- **싱글엔드(Single-ended)**: **통신선과 GND**의 전압 차로 신호를 판별. 선이 적지만 공통 접지 잡음에 취약.
- **차동(Differential)**: **두 선의 전압 차이**로 신호를 판별. 공통으로 실린 잡음이 상쇄되어 **노이즈에 강함** → **[[CAN(Controller Area Network)|CAN]]** 등에서 사용.
- 상세: [[차동 신호(Differential Signaling)]]

<aside>bitrate와 baudrate</aside>

- **bitrate(비트레이트)**: 초당 전달되는 **비트 수**. `bitrate = baudrate × 심볼당 비트 수`
- **baudrate(보드레이트)**: 초당 **신호(심볼) 변화 횟수**. `baudrate = 1 / Ts`
  - **심볼(symbol)**: 일정 시간 동안 유지되는 하나의 신호 상태
  - **Ts**: 심볼 주기(한 심볼이 유지되는 시간)
- 한 심볼이 1비트만 실으면 bitrate = baudrate, 여러 비트를 실으면 bitrate가 더 크다.
- 상세: [[보드레이트와 비트레이트(Baud Rate·Bit Rate)]]

<aside>속도와 거리 (속도 ∝ 1/거리)</aside>

전송 속도는 대체로 거리에 반비례한다. 선 길이가 길어지면:

- **신호 값 변경이 둔해짐**: 선의 기생 저항·정전용량 때문에 엣지가 뭉개진다(짧은 선은 뚜렷한 사각파, 긴 선은 둥글게 무뎌진 파형) → 고속 전송이 어려워짐.
- **[[신호 반사(Signal Reflection)|반사(reflection)]] 발생**: 신호의 일부가 끝까지 도달하지 못하고 **되돌아오는 현상**. **임피던스 불연속성**이 원인이며, 종단 저항으로 [[임피던스 매칭(Impedance Matching)|임피던스를 맞춰]] 억제한다.

---

<aside>핵심 정리</aside>

- 직렬 = 저렴·단순, 병렬 = 고속이나 비싸고 skew로 장거리에 불리
- 차동 전송은 두 선의 차이를 보므로 잡음에 강함(CAN)
- bitrate = baudrate × 심볼당 비트 / baudrate = 1/Ts
- 선이 길수록 신호가 둔해지고 임피던스 불연속으로 반사가 생겨 속도가 제한됨
