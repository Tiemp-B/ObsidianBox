# Summary

<summary>동적 계획법(DP)은 복잡한 문제를 간단한 여러 개의 하위 문제로 나누어 푸는 최적화 기법이다. 이미 계산한 결과를 저장하여 재사용함으로써 중복 계산을 피하고 효율성을 높인다.</summary>

DP의 핵심은 '최적 부분 구조'와 '중복되는 부분 문제'를 파악하는 것이며, Bottom-up(타뷸레이션)과 Top-down(메모이제이션) 두 가지 접근법이 있다.

---

# Notes

동적 계획법은 분할정복과 비슷하지만, 부분 문제들이 서로 겹치는 경우에 사용하는 최적화 기법이다.

<aside>DP의 조건</aside>

**최적 부분 구조 (Optimal Substructure)**: 문제의 최적해가 부분 문제의 최적해로부터 구성될 수 있어야 한다.

**중복되는 부분 문제 (Overlapping Subproblems)**: 같은 부분 문제가 여러 번 반복되어 계산된다. 이를 저장하여 재사용하는 것이 DP의 핵심이다.

<aside>구현 방법</aside>

**Top-down (메모이제이션)**: 재귀를 사용하며, 계산 결과를 메모리에 저장. 필요한 부분만 계산하므로 직관적이다.

**Bottom-up (타뷸레이션)**: 반복문을 사용하며, 작은 문제부터 차례로 해결. 재귀 스택 오버플로우가 없고 일반적으로 더 빠르다.

<aside>대표적인 문제들</aside>

**피보나치 수열**: DP의 가장 기본적인 예시. 재귀로 구현하면 O(2^n)이지만 DP로 O(n)으로 최적화 가능.

**배낭 문제 (Knapsack)**: 제한된 용량에서 가치의 합을 최대화하는 문제. 0-1 배낭과 분할 가능 배낭이 있다.

**LCS (Longest Common Subsequence)**: 두 문자열의 최장 공통 부분 수열을 찾는 문제. 편집 거리와 유사한 점화식을 사용한다.

**LIS (Longest Increasing Subsequence)**: 주어진 수열에서 증가하는 부분 수열 중 가장 긴 것을 찾는 문제. O(n²) 또는 이진 탐색으로 O(n log n) 해결 가능.

**점화식 세우기**: DP 문제의 핵심은 현재 상태를 이전 상태들로 표현하는 점화식을 찾는 것이다.
