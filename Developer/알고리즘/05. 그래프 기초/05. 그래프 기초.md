# Summary

<summary>그래프는 정점(Vertex)과 간선(Edge)으로 이루어진 자료구조로, 네트워크 관계를 표현한다. DFS와 BFS는 그래프를 순회하는 가장 기본적이고 중요한 탐색 알고리즘이다.</summary>

그래프는 인접 행렬 또는 인접 리스트로 표현하며, DFS는 깊이 우선, BFS는 너비 우선으로 탐색한다.

---

# Notes

그래프 알고리즘은 소셜 네트워크, 지도, 웹 크롤링 등 실생활의 다양한 문제를 해결한다.

<aside>그래프 표현 방법</aside>

**인접 행렬 (Adjacency Matrix)**: 2차원 배열로 표현. 간선 존재 여부를 O(1)에 확인 가능하지만 O(V²) 공간 필요.

**인접 리스트 (Adjacency List)**: 연결된 정점만 저장. O(V+E) 공간으로 효율적이며, 대부분의 경우 선호된다.

<aside>DFS (깊이 우선 탐색)</aside>

**동작 원리**: 한 방향으로 끝까지 탐색한 후 되돌아와 다른 경로 탐색. 스택 또는 재귀로 구현.

**시간 복잡도**: O(V+E)

**활용**: 사이클 탐지, 위상 정렬, 강하게 연결된 컴포넌트(SCC), 백트래킹

<aside>BFS (너비 우선 탐색)</aside>

**동작 원리**: 현재 정점에서 가까운 정점부터 탐색. 큐를 사용하여 구현.

**시간 복잡도**: O(V+E)

**활용**: 최단 경로(가중치 없는 그래프), 레벨별 순회, 최소 스패닝 트리

<aside>추가 개념들</aside>

**연결 요소 (Connected Component)**: 연결된 정점들의 집합. DFS/BFS로 개수 파악 가능.

**사이클 탐지**: 방향/무방향 그래프에서 사이클 존재 여부 확인. DFS 중 back edge 발견 시 사이클 존재.

**이분 그래프 (Bipartite Graph)**: 정점을 두 그룹으로 나눌 수 있는 그래프. BFS로 색칠하며 판별 가능.
