# Summary

<summary>Write a concise summary here</summary>
노드 단위로 데이터를 저장하고 포인터로 서로 연결한 선형 자료구조.
포인터를 사용한 연결을 통해 동적 크기 조정이 가능하며 메모리가 연속적이지 않다.
탐색은 O(N), 삽입, 삭제는 O(1)이다.

---

# Notes

노드의 구조는 데이터, 포인터로 이루어져 있다. 단방향의 경우 1개, 양방향의 경우 2개의 포인터를 가진다. 

<aside>노드</aside>

```
[c++]
struct node{
	int data;
	node* next;
	node* prev; // 양방향의 경우
};
```

<aside>탐색</aside>

```
[c++]
node* searchLL(int target){
	node* ptr = head;
	while(ptr){
		if(ptr->data == target) return ptr;
		ptr = ptr->next;
	}
}
```

<aside>삽입, 제거</aside>

```
void addNode(int data, node* loc){
	node* newNode = new node;
	newNode->data = data;
	if(loc == head){
		loc
	}
}
```
