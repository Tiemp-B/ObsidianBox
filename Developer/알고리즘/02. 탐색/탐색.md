# Summary
<summary>탐색(Search)은 데이터 집합 내에서 원하는 값을 찾는 과정으로, 선형 탐색과 이진 탐색이 대표적이다.</summary>
선형 탐색은 단순하지만 느리고, 이진 탐색은 정렬된 자료에서 빠른 성능을 보인다. 자료구조의 특성에 따라 해시 탐색, 트리 탐색 등 다양한 형태로 확장된다.

# Notes

<aside>정의</aside>

탐색(Search)은 **데이터 집합 내에서 특정 값을 찾는 연산**이다.  
입력된 키(key)에 해당하는 데이터를 효율적으로 찾기 위해 다양한 방법이 존재하며,  
탐색 알고리즘의 성능은 **자료구조의 형태와 정렬 여부**에 따라 달라진다.

---

<aside>선형 탐색(Linear Search)</aside>

- 배열이나 리스트 등 순차 자료구조에서 사용.  
- 첫 번째 원소부터 순서대로 비교하여 일치하는 값을 찾는다.  
- 데이터가 정렬되어 있지 않아도 사용 가능.  
- 시간 복잡도: `O(n)`

---

<aside>이진 탐색(Binary Search)</aside>

[[이진 탐색]]
- **정렬된 배열**에서만 사용 가능.  
- 중간값을 기준으로 탐색 범위를 절반씩 줄여 나간다.  
- 시간 복잡도: `O(log n)`

---

<aside>해시 탐색(Hash Search)</aside>

[[해시 탐색]]
- 키를 **해시 함수(Hash Function)** 에 입력하여 인덱스를 직접 계산.  
- 평균 탐색 시간 `O(1)`로 매우 빠르다.  
- 단, 해시 충돌(Collision) 발생 시 체이닝(Chaining) 또는 개방 주소법(Open Addressing)으로 처리 필요.

---

<aside>트리 탐색(Tree Search)</aside>

[[트리 탐색]]
- **이진 탐색 트리(BST)** 또는 **균형 트리(AVL, Red-Black Tree)** 에서 사용.  
- 키 값을 비교하며 좌/우 서브트리로 이동.  
- 평균 시간 복잡도 `O(log n)`이지만, 트리가 불균형하면 최악의 경우 `O(n)`까지 증가.

---

<aside>그래프 탐색(Graph Search)</aside>

[[그래프 탐색]]
- 노드 간 연결 관계를 따라 탐색.  
- **DFS(깊이 우선 탐색)**: 스택 또는 재귀로 깊게 탐색.  
- **BFS(너비 우선 탐색)**: 큐로 인접 노드를 순서대로 탐색.  
- 시간 복잡도: `O(V + E)`

---

<aside>탐색 방법 비교</aside>

| 탐색 방법 | 전제 조건 | 평균 시간 복잡도 | 특징 |
|------------|-------------|------------------|------|
| 선형 탐색 | 정렬 불필요 | O(n) | 단순하지만 느림 |
| 이진 탐색 | 정렬 필요 | O(log n) | 효율적이지만 정렬 필요 |
| 해시 탐색 | 해시 함수 필요 | O(1) | 매우 빠르지만 충돌 가능 |
| 트리 탐색 | 트리 구조 필요 | O(log n) | 균형 유지가 중요 |
| 그래프 탐색 | 노드 연결 필요 | O(V + E) | 경로 탐색, 순회에 사용 |
