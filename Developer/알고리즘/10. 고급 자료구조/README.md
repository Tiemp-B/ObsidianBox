## 📝 Notes (필기 영역)

### 1. 세그먼트 트리 (Segment Tree)

#### 개념
구간에 대한 쿼리를 효율적으로 처리하는 트리 구조. 배열의 구간 합, 최솟값, 최댓값 등을 빠르게 구할 수 있습니다.

#### 특징
- 구간 쿼리: O(log N)
- 값 업데이트: O(log N)
- 공간 복잡도: O(4N)

#### 활용
- 구간 합 쿼리
- 구간 최솟값/최댓값 쿼리
- Lazy Propagation으로 구간 업데이트 최적화

---

### 2. 펜윅 트리 (Fenwick Tree / Binary Indexed Tree)

#### 개념
세그먼트 트리보다 간단하고 메모리 효율적인 구간 쿼리 자료구조. 주로 누적 합과 업데이트에 사용됩니다.

#### 특징
- 구간 합 쿼리: O(log N)
- 값 업데이트: O(log N)
- 공간 복잡도: O(N)
- 구현이 세그먼트 트리보다 간단

#### 핵심 연산
```
- update(i, delta): i번째 원소에 delta 더하기
- query(i): 1~i까지의 누적 합
- rangeQuery(l, r): query(r) - query(l-1)
```

---

### 3. 트라이 (Trie)

#### 개념
문자열 집합을 효율적으로 저장하고 검색하는 트리 자료구조. 각 노드가 문자를 나타냅니다.

#### 특징
- 문자열 삽입: O(M) - M은 문자열 길이
- 문자열 검색: O(M)
- 접두사 검색: O(M)

#### 활용
- 자동 완성
- 사전 구현
- IP 라우팅 테이블
- 문자열 집합에서 XOR 최댓값 찾기

---

### 4. 서로소 집합 (Disjoint Set / Union-Find)

#### 개념
서로 겹치지 않는 집합들을 효율적으로 관리하는 자료구조입니다.

#### 핵심 연산
- **Find:** 원소가 속한 집합 찾기
- **Union:** 두 집합을 하나로 합치기

#### 최적화 기법
- **경로 압축 (Path Compression):** Find 연산 시 경로상의 모든 노드를 루트에 직접 연결
- **Union by Rank/Size:** 작은 트리를 큰 트리 아래에 합치기

**시간 복잡도:** O(α(N)) - 거의 상수 시간 (α는 아커만 함수의 역함수)

#### 활용
- MST (Kruskal 알고리즘)
- 네트워크 연결성 판단
- 동적 연결성 문제

---

### 5. 균형 이진 탐색 트리

#### AVL 트리
- 모든 노드의 왼쪽/오른쪽 서브트리 높이 차이가 최대 1
- 회전 연산으로 균형 유지
- 검색/삽입/삭제: O(log N)

#### Red-Black 트리
- 모든 노드가 빨강 또는 검정 색상
- 루트는 검정, 빨강 노드의 자식은 검정
- 모든 리프까지의 검정 노드 수 동일
- AVL보다 삽입/삭제가 빠름

## 🔑 Cue (핵심 질문)

| 질문 | 답변 위치 |
|------|-----------|
| 구간 쿼리에 가장 적합한 자료구조는? | 세그먼트 트리 또는 펜윅 트리 |
| 펜윅 트리 vs 세그먼트 트리? | 펜윅이 더 간단하고 메모리 효율적 |
| 문자열 집합 저장에 최적인 것은? | 트라이 (Trie) |
| Union-Find의 시간 복잡도는? | O(α(N)) - 거의 상수 시간 |
| 경로 압축이란? | Find 시 경로의 모든 노드를 루트에 연결 |
| AVL vs Red-Black? | Red-Black이 삽입/삭제 더 빠름 |

## 📌 Summary (요약)

고급 자료구조는 특정 문제를 효율적으로 해결하기 위한 전문화된 도구입니다. 세그먼트 트리와 펜윅 트리는 구간 쿼리에, 트라이는 문자열 검색에, Union-Find는 집합 관리에, 균형 이진 탐색 트리는 동적 정렬 데이터에 최적화되어 있습니다. 각 자료구조의 특성과 시간 복잡도를 이해하고 상황에 맞게 선택하는 것이 중요합니다.
