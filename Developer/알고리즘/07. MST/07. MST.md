# Summary

<summary>최소 신장 트리(MST)는 그래프의 모든 정점을 연결하면서 간선 가중치의 합이 최소가 되는 트리입니다. 크루스칼(간선 기준, Union-Find 활용)과 프림(정점 기준, 우선순위 큐 활용) 알고리즘으로 O(E log E), O(E log V)에 구할 수 있습니다.</summary>

# Notes

<aside>MST 기본 개념</aside>

**최소 신장 트리(Minimum Spanning Tree)**는 가중치가 있는 무방향 연결 그래프에서 모든 정점을 포함하면서 간선 가중치의 합이 최소인 트리를 말합니다.

**신장 트리의 조건:**
- 그래프의 모든 정점을 포함
- 정점이 N개일 때 간선은 정확히 N-1개
- 사이클이 존재하지 않음
- 모든 정점이 연결되어 있음

<aside>크루스칼 알고리즘</aside>

**간선 중심 접근 방식**으로 가중치가 낮은 간선부터 선택합니다.

**알고리즘 과정:**
1. 모든 간선을 가중치 기준 오름차순 정렬
2. 가중치가 낮은 간선부터 선택
3. 해당 간선이 사이클을 만들지 않으면 MST에 포함
4. N-1개의 간선을 선택할 때까지 반복

**핵심 자료구조:** Union-Find (Disjoint Set)
- 사이클 감지를 위해 두 정점이 같은 집합에 속하는지 확인
- Find 연산: 정점이 속한 집합의 대표 찾기
- Union 연산: 두 집합을 하나로 합치기

**시간 복잡도:** O(E log E)

<aside>프림 알고리즘</aside>

**정점 중심 접근 방식**으로 하나의 정점에서 시작하여 트리를 확장합니다.

**알고리즘 과정:**
1. 임의의 시작 정점 선택
2. 선택된 정점들과 연결된 간선 중 가중치가 최소인 간선 선택
3. 해당 간선으로 새로운 정점을 트리에 추가
4. 모든 정점이 포함될 때까지 반복

**핵심 자료구조:** 우선순위 큐 (Min Heap)

**시간 복잡도:** O(E log V)

<aside>Union-Find 최적화</aside>

**1. 경로 압축 (Path Compression)**
- Find 연산 시 경로상의 모든 노드를 루트에 직접 연결
- 트리의 높이를 감소시켜 이후 연산 속도 향상

**2. Union by Rank/Size**
- 항상 작은 트리를 큰 트리 아래에 합치기
- Rank: 트리의 높이 기준
- Size: 트리의 노드 수 기준

**최적화 효과:** O(α(N)) - 거의 상수 시간
