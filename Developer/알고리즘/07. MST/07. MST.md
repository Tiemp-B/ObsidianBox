# Summary

<summary>최소 신장 트리(MST)는 그래프의 모든 정점을 최소 비용으로 연결하는 트리이다. 크루스칼과 프림 알고리즘이 대표적이며, 네트워크 설계 등 실용적인 문제에 광범위하게 활용된다.</summary>

크루스칼은 간선 중심으로 Union-Find를 사용하고, 프림은 정점 중심으로 우선순위 큐를 사용한다.

# Notes

MST는 네트워크 구축, 도로 건설, 회로 설계 등에서 비용을 최소화하는 핵심 알고리즘이다.

<aside>신장 트리의 개념</aside>

**신장 트리 (Spanning Tree)**: 그래프의 모든 정점을 포함하면서 사이클이 없는 부분 그래프. V개의 정점을 V-1개의 간선으로 연결.

**최소 신장 트리**: 여러 신장 트리 중 간선 가중치의 합이 최소인 트리.

**특성**: 
- 사이클이 없음
- 정점 개수가 V면 간선은 V-1개
- 항상 연결 그래프

<aside>크루스칼 (Kruskal) 알고리즘</aside>

**동작 원리**: 간선을 가중치 순으로 정렬한 후, 사이클을 만들지 않는 간선부터 선택.

**시간 복잡도**: O(E log E) - 주로 정렬에 소요

**Union-Find 자료구조**: 
- Find: 원소가 속한 집합 찾기
- Union: 두 집합 합치기
- 경로 압축과 union-by-rank로 최적화하면 거의 O(1)

**장점**: 간선이 적은 희소 그래프에 유리

<aside>프림 (Prim) 알고리즘</aside>

**동작 원리**: 시작 정점에서 출발하여 트리를 확장하며, 트리와 연결된 간선 중 최소 가중치 간선을 추가.

**시간 복잡도**: O(E log V) - 우선순위 큐 사용 시

**구현**: 
- 우선순위 큐에 (가중치, 정점) 저장
- 방문하지 않은 정점 중 최소 비용 선택
- 다익스트라와 유사한 구조

**장점**: 간선이 많은 밀집 그래프에 유리

<aside>실전 활용</aside>

**네트워크 설계**: 최소 비용으로 모든 노드를 연결하는 통신망 구축

**클러스터링**: MST를 이용한 데이터 군집화

**근사 알고리즘**: TSP(외판원 문제)의 근사해 구하기
