# Summary

<summary>재귀는 함수가 자기 자신을 호출하는 프로그래밍 기법이며, 분할정복은 큰 문제를 작은 문제로 나누어 해결하는 알고리즘 설계 패러다임이다. 이 두 개념은 밀접하게 연관되어 있으며 많은 고급 알고리즘의 기초가 된다.</summary>

재귀의 핵심은 base case와 recursive case를 명확히 정의하는 것이며, 분할정복은 분할-정복-결합의 3단계로 이루어진다.

---

# Notes

재귀와 분할정복은 복잡한 문제를 단순하게 해결할 수 있는 강력한 도구다.

<aside>재귀 함수의 기본</aside>

**재귀의 정의**: 함수가 자기 자신을 호출하는 프로그래밍 기법. 반복문으로 표현 가능한 모든 것은 재귀로도 표현 가능하다.

**필수 요소**:
- Base case (종료 조건): 재귀를 멈추는 조건
- Recursive case (재귀 단계): 문제를 더 작은 문제로 만드는 과정

**스택 오버플로우**: 재귀 깊이가 너무 깊어지면 발생. 메모이제이션이나 반복문 전환으로 해결 가능.

<aside>분할정복 (Divide and Conquer)</aside>

**3단계 프로세스**:
1. **분할 (Divide)**: 문제를 더 작은 부분 문제로 나눔
2. **정복 (Conquer)**: 부분 문제를 재귀적으로 해결
3. **결합 (Combine)**: 부분 문제의 해답을 합쳐 원래 문제의 해답 도출

**대표적인 예시**: 병합 정렬, 퀵 정렬, 이진 탐색, 카라츠바 곱셈 알고리즘

<aside>백트래킹 기초</aside>

**백트래킹**: 해를 찾는 도중 막히면 되돌아가서 다른 경로를 탐색하는 기법. DFS와 유사하지만 가지치기(pruning)를 통해 불필요한 탐색을 줄인다.

**대표 문제**: N-Queens, 스도쿠, 미로 찾기, 부분집합 합

**하노이의 탑**: 재귀의 아름다움을 보여주는 고전 문제. n개의 원판을 옮기려면 2^n - 1번의 이동이 필요하다.
