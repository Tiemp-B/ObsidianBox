# Summary

<summary>정렬과 탐색은 알고리즘의 가장 기본이 되는 개념으로, 데이터를 효율적으로 정리하고 원하는 값을 빠르게 찾는 방법을 다룬다. 시간 복잡도 분석을 통해 각 알고리즘의 효율성을 평가할 수 있다.</summary>

정렬은 O(n²)부터 O(n log n)까지, 탐색은 O(n)부터 O(log n)까지 다양한 시간 복잡도를 가진 알고리즘들이 존재한다.

# Notes

정렬과 탐색 알고리즘은 프로그래밍의 가장 기초가 되는 필수 개념이다.

<aside>기본 정렬 알고리즘</aside>

**버블 정렬 (Bubble Sort)**: 인접한 두 원소를 비교하여 정렬하는 가장 간단한 방법. 시간 복잡도 O(n²)로 비효율적이지만 구현이 쉽다.

**선택 정렬 (Selection Sort)**: 매 단계마다 최솟값을 찾아 앞으로 보내는 방식. 마찬가지로 O(n²)의 시간 복잡도를 가진다.

**삽입 정렬 (Insertion Sort)**: 각 원소를 이미 정렬된 부분의 적절한 위치에 삽입. 거의 정렬된 데이터에서는 효율적이다.

<aside>고급 정렬 알고리즘</aside>

**퀵 정렬 (Quick Sort)**: 피벗을 선택하여 분할 정복 방식으로 정렬. 평균 O(n log n), 최악 O(n²)의 시간 복잡도를 가진다.

**병합 정렬 (Merge Sort)**: 배열을 반으로 나누어 재귀적으로 정렬 후 병합. 안정적으로 O(n log n)을 보장한다.

**힙 정렬 (Heap Sort)**: 힙 자료구조를 이용한 정렬. O(n log n)의 시간 복잡도와 O(1)의 공간 복잡도를 가진다.

<aside>탐색 알고리즘</aside>

**순차 탐색 (Linear Search)**: 처음부터 끝까지 순서대로 찾는 방법. O(n)의 시간 복잡도.

**이진 탐색 (Binary Search)**: 정렬된 배열에서 중간값과 비교하여 범위를 절반씩 줄여가며 탐색. O(log n)으로 매우 효율적이다.

**핵심 포인트**: 정렬과 탐색은 상호보완적 관계. 정렬된 데이터는 이진 탐색으로 빠르게 찾을 수 있으므로, 여러 번 탐색할 데이터는 먼저 정렬하는 것이 유리하다.
