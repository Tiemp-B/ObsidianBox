# 위상 정렬 (Topological Sort)

## 📝 Notes (필기 영역)

### 위상 정렬이란?
방향 비순환 그래프(DAG)에서 정점들을 선형으로 정렬하는 것. 모든 간선 (u, v)에 대해 u가 v보다 앞에 오도록 정렬합니다.

### 주요 알고리즘

#### 1. Kahn의 알고리즘 (진입 차수 활용)
- 진입 차수가 0인 정점을 큐에 삽입
- 큐에서 정점을 꺼내고 결과에 추가
- 해당 정점과 연결된 간선 제거 (진입 차수 감소)
- 새롭게 진입 차수가 0이 된 정점을 큐에 삽입
- 큐가 빌 때까지 반복

**시간 복잡도:** O(V + E)

#### 2. DFS 기반 위상 정렬
- 각 정점에서 DFS 수행
- DFS가 끝나는 순서의 역순이 위상 정렬 결과
- 스택을 사용하여 구현

**시간 복잡도:** O(V + E)

#### 3. 순환 그래프 탐지
- 위상 정렬 결과의 정점 수가 전체 정점 수보다 적으면 사이클 존재
- DFS에서 방문 중인 정점을 다시 방문하면 사이클 존재

### 활용 사례
- 작업 스케줄링 (선행 조건이 있는 작업들)
- 컴파일러의 의존성 해결
- 수강 신청 순서 결정
- 빌드 시스템

## 📌 Summary (요약)

위상 정렬은 DAG에서 정점들을 선형으로 나열하는 알고리즘입니다. Kahn의 알고리즘(진입 차수 기반)과 DFS 기반 방법이 있으며, 둘 다 O(V+E) 시간에 동작합니다. 사이클이 있으면 위상 정렬이 불가능하며, 이를 통해 사이클 탐지도 가능합니다. 작업 스케줄링, 의존성 해결 등에 활용됩니다.
