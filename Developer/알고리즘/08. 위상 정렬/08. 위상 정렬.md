# Notes

<aside>위상 정렬 기본 개념</aside>

**위상 정렬(Topological Sort)**은 방향 그래프의 정점들을 선형으로 나열하는 것으로, 모든 방향 간선 (u, v)에 대해 정점 u가 정점 v보다 앞에 오도록 정렬합니다.

**핵심 조건:**
- 방향 비순환 그래프(DAG)에서만 가능
- 사이클이 존재하면 위상 정렬 불가능
- 위상 정렬 결과는 유일하지 않을 수 있음

<aside>Kahn의 알고리즘</aside>

**진입 차수 기반 BFS 접근법**

**알고리즘 과정:**
1. 모든 정점의 진입 차수를 계산
2. 진입 차수가 0인 정점들을 큐에 삽입
3. 큐에서 정점을 하나 꺼내 결과에 추가
4. 연결된 간선 제거 (인접 정점 진입 차수 감소)
5. 새롭게 진입 차수가 0이 된 정점을 큐에 삽입
6. 큐가 빌 때까지 반복

**사이클 감지:** 결과 정점 개수 < 전체 정점 개수

**시간 복잡도:** O(V + E)

<aside>DFS 기반 위상 정렬</aside>

**깊이 우선 탐색 활용**

**핵심 아이디어:** DFS 완료 순서의 역순이 위상 정렬 결과

**알고리즘 과정:**
1. 미방문 정점에서 DFS 시작
2. 인접 정점들을 재귀적으로 방문
3. DFS 완료 시 스택에 삽입
4. 모든 정점 방문까지 반복
5. 스택을 pop하면서 결과 생성

**사이클 감지:** 방문중 상태의 정점을 다시 만나면 사이클

**시간 복잡도:** O(V + E)

<aside>실전 활용</aside>

**문제 유형:**
- 작업 스케줄링 (선행 작업)
- 수강 신청 (선수과목)
- 빌드 시스템 (파일 의존성)
- 교착 상태 감지
