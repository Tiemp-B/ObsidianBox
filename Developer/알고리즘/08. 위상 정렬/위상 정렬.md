# Summary

<summary>위상 정렬은 방향 비순환 그래프(DAG)의 정점들을 선형으로 나열하되, 모든 간선 (u,v)에 대해 u가 v보다 앞에 오도록 정렬하는 것입니다. Kahn(진입 차수 기반 BFS)과 DFS 기반 두 가지 방법이 있으며, O(V+E) 시간에 동작합니다. 사이클이 있으면 위상 정렬이 불가능합니다.</summary>

# Notes

<aside>위상 정렬이란?</aside>

**위상 정렬(Topological Sort)**은 방향 그래프의 정점들을 선형으로 나열하는 것으로, 모든 방향 간선 (u, v)에 대해 정점 u가 정점 v보다 앞에 오도록 정렬합니다.

**핵심 조건:**
- 방향 비순환 그래프(DAG, Directed Acyclic Graph)에서만 가능
- 사이클이 존재하면 위상 정렬 불가능
- 위상 정렬 결과는 유일하지 않을 수 있음

**실생활 예시:**
- 대학 선수과목 체계 (미적분학 → 선형대수)
- 빌드 의존성 (A.java → A.class → program.jar)
- 프로젝트 작업 순서 (설계 → 개발 → 테스트)

<aside>Kahn의 알고리즘</aside>

**진입 차수(Indegree) 기반 BFS 접근법**

**진입 차수:** 한 정점으로 들어오는 간선의 개수

**알고리즘 과정:**
1. 모든 정점의 진입 차수를 계산
2. 진입 차수가 0인 정점들을 큐에 삽입
3. 큐에서 정점을 하나 꺼내 결과 리스트에 추가
4. 해당 정점과 연결된 모든 간선을 제거 (인접 정점들의 진입 차수 감소)
5. 새롭게 진입 차수가 0이 된 정점들을 큐에 삽입
6. 큐가 빌 때까지 3-5 반복

**사이클 감지:**
- 결과 리스트의 정점 개수 < 전체 정점 개수 → 사이클 존재
- 진입 차수가 0이 되지 않는 정점들이 사이클을 형성

**시간 복잡도:** O(V + E)
- 모든 정점 방문: O(V)
- 모든 간선 확인: O(E)

**공간 복잡도:** O(V)
- 진입 차수 배열: O(V)
- 큐: 최대 O(V)

**장점:**
- 직관적이고 이해하기 쉬움
- 사이클 감지가 자연스럽게 이루어짐
- BFS 특성상 레벨별 처리 가능

<aside>DFS 기반 위상 정렬</aside>

**깊이 우선 탐색을 활용한 접근법**

**핵심 아이디어:**
- DFS에서 각 정점의 탐색이 완료되는 순서의 역순이 위상 정렬 결과

**알고리즘 과정:**
1. 방문하지 않은 정점에서 DFS 시작
2. 인접한 정점들을 재귀적으로 방문
3. 현재 정점의 DFS가 완료되면 스택에 삽입 (또는 리스트 앞에 삽입)
4. 모든 정점을 방문할 때까지 반복
5. 스택을 pop하면서 결과 생성 (또는 리스트를 역순으로)

**사이클 감지:**
- 방문 상태를 3가지로 관리: 미방문(0), 방문중(1), 방문완료(2)
- 방문중(1) 상태의 정점을 다시 만나면 사이클 존재

**시간 복잡도:** O(V + E)
- DFS: O(V + E)

**공간 복잡도:** O(V)
- 재귀 호출 스택: 최대 O(V)
- 방문 상태 배열: O(V)

**장점:**
- 구현이 간결함
- 사이클 감지가 명확함
- 연결 요소별로 독립적으로 처리 가능

<aside>Kahn vs DFS</aside>

**Kahn 알고리즘:**
- ✅ 더 직관적이고 이해하기 쉬움
- ✅ 레벨별 처리 가능 (같은 레벨의 정점들을 그룹핑)
- ✅ 반복문 기반이라 스택 오버플로우 없음
- ❌ 진입 차수 배열 추가 필요

**DFS 기반:**
- ✅ 구현이 더 간결함
- ✅ 추가 자료구조 최소화
- ✅ 강연결 요소 찾기 등 다른 그래프 알고리즘과 통합 용이
- ❌ 재귀 깊이 제한 가능성

**선택 기준:** 
- 일반적으로 Kahn 추천 (직관적이고 안정적)
- 메모리가 제한적이면 DFS
- 다른 DFS 기반 알고리즘과 함께 사용 시 DFS

<aside>실전 활용</aside>

**전형적인 문제 패턴:**

**1. 작업 스케줄링**
- 선행 작업이 있는 작업들의 실행 순서 결정
- 예: 컴파일 순서, 프로젝트 Task 순서

**2. 수강 신청**
- 선수과목 제약이 있는 과목들의 이수 순서
- 예: 백준 2252번 - 줄 세우기

**3. 빌드 시스템**
- 파일 의존성을 고려한 빌드 순서
- Makefile, Gradle 등의 빌드 도구

**4. 교착 상태 감지**
- 자원 할당 그래프에서 사이클 → 교착 상태

**최적화 기법:**
- 진입 차수가 0인 정점이 여러 개일 때, 특정 우선순위 적용 가능
- 우선순위 큐 사용하여 사전순, 가중치 순 등 정렬 가능

**주의사항:**
- 위상 정렬이 불가능한 경우(사이클) 처리 필수
- 여러 개의 유효한 정렬이 존재할 수 있음
- DAG가 아닌 경우 에러 처리 필요

**관련 알고리즘:**
- 강연결 요소 (Strongly Connected Components)
- 최장 경로 문제 (DAG에서는 DP로 해결 가능)
- Critical Path Method (CPM)
