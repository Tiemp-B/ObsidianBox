## 📝 Notes (필기 영역)

### 네트워크 플로우란?
용량이 있는 간선으로 이루어진 방향 그래프에서 출발점(source)에서 도착점(sink)으로 보낼 수 있는 최대 유량을 구하는 문제입니다.

### 핵심 개념
- **용량(Capacity):** 간선에 흐를 수 있는 최대 유량
- **유량(Flow):** 실제로 흐르고 있는 양
- **잔여 용량(Residual Capacity):** 용량 - 유량
- **증가 경로(Augmenting Path):** 출발점에서 도착점까지 잔여 용량이 양수인 경로

### 주요 알고리즘

#### 1. 포드-풀커슨 (Ford-Fulkerson)
- 증가 경로를 찾아 유량을 보내는 과정을 반복
- DFS 또는 BFS로 증가 경로 탐색
- 역간선을 활용하여 유량 조정 가능

**시간 복잡도:** O(E × |max flow|) - 유량 값에 의존

#### 2. 에드몬드-카프 (Edmonds-Karp)
- 포드-풀커슨의 개선 버전
- BFS를 사용하여 최단 증가 경로 탐색
- 유량 값에 무관한 시간 복잡도 보장

**시간 복잡도:** O(VE²)

#### 3. 디닉 (Dinic's Algorithm)
- 레벨 그래프 구축 (BFS)
- 레벨 그래프에서 블로킹 플로우 찾기 (DFS)
- 매우 효율적인 알고리즘

**시간 복잡도:** O(V²E)

#### 4. 이분 매칭 (Bipartite Matching)
- 이분 그래프에서 최대 매칭을 찾는 문제
- 최대 유량 문제로 변환하여 해결
- 각 간선의 용량을 1로 설정

**시간 복잡도:** O(VE)

### 최대 유량 - 최소 컷 정리
네트워크의 최대 유량 값은 최소 컷의 용량과 같습니다.

### 활용 사례
- 네트워크 최적화
- 매칭 문제 (구직자-회사, 학생-프로젝트)
- 항공편 스케줄링
- 이미지 세그멘테이션

## 🔑 Cue (핵심 질문)

| 질문 | 답변 위치 |
|------|-----------|
| 증가 경로란? | 잔여 용량이 양수인 경로 |
| 역간선의 역할은? | 유량 조정 가능하게 함 |
| 가장 효율적인 알고리즘은? | 디닉 알고리즘 O(V²E) |
| 이분 매칭과의 관계는? | 최대 유량으로 변환 가능 |
| 최대 유량 = ? | 최소 컷의 용량 |

---

## 📌 Summary (요약)

네트워크 플로우는 용량이 있는 그래프에서 최대 유량을 구하는 문제입니다. 포드-풀커슨(기본), 에드몬드-카프(BFS 사용), 디닉(레벨 그래프)의 세 가지 주요 알고리즘이 있으며, 디닉이 가장 효율적입니다. 이분 매칭 문제는 최대 유량으로 변환하여 해결할 수 있으며, 최대 유량은 최소 컷과 같다는 중요한 정리가 있습니다.
