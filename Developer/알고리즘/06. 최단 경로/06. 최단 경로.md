# Summary

<summary>최단 경로 알고리즘은 그래프에서 두 정점 사이의 가장 짧은 경로를 찾는 문제를 해결한다. 간선 가중치의 특성과 필요한 정보에 따라 적절한 알고리즘을 선택해야 한다.</summary>

다익스트라는 단일 출발점에서 양의 가중치, 벨만-포드는 음의 가중치 처리, 플로이드-워셜은 모든 쌍 최단 경로를 구한다.

---

# Notes

최단 경로는 내비게이션, 네트워크 라우팅, 게임 AI 등에서 핵심적으로 사용된다.

<aside>다익스트라 (Dijkstra)</aside>

**동작 원리**: 출발점에서 가장 가까운 미방문 정점을 선택하며 최단 거리를 갱신. 그리디 알고리즘의 일종.

**시간 복잡도**: 우선순위 큐 사용 시 O((V+E) log V), 배열 사용 시 O(V²)

**제약 조건**: 음의 가중치를 가진 간선이 없어야 함

**구현 팁**: 최소 힙(우선순위 큐)을 사용하여 최적화

<aside>벨만-포드 (Bellman-Ford)</aside>

**동작 원리**: 모든 간선을 V-1번 완화(relaxation)하여 최단 거리 계산.

**시간 복잡도**: O(VE)

**장점**: 음의 가중치 처리 가능, 음의 사이클 탐지 가능

**단점**: 다익스트라보다 느림

<aside>플로이드-워셜 (Floyd-Warshall)</aside>

**동작 원리**: 동적 계획법으로 모든 정점 쌍 사이의 최단 거리를 계산. 중간 경유점을 고려하며 거리 갱신.

**시간 복잡도**: O(V³)

**활용**: 모든 쌍 최단 경로, 경로 복원, 그래프의 지름 계산

**공간**: O(V²)의 2차원 배열 사용

<aside>A* 알고리즘</aside>

**휴리스틱 탐색**: 목표 지점까지의 예상 거리(휴리스틱)를 활용하여 탐색 효율 향상.

**평가 함수**: f(n) = g(n) + h(n), 여기서 g(n)은 실제 거리, h(n)은 휴리스틱 거리

**활용**: 게임 AI, 경로 찾기 최적화
