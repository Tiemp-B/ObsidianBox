# Summary
분할 정복(Divide and Conquer)은 큰 문제를 더 작은 하위 문제로 나누어 해결한 뒤,  
그 결과를 결합해 전체 문제의 해답을 구하는 알고리즘 설계 기법이다.  
대표 예시는 병합 정렬, 퀵 정렬, 이진 탐색, 거듭제곱 계산 등이 있다.

# Notes

분할 정복은 문제의 구조를 분석하여 재귀적으로 해결하는 강력한 알고리즘 설계 방법이다.  
복잡한 문제를 단순한 하위 문제로 나누어 효율적 계산을 가능하게 한다.

<aside>정의</aside>

분할 정복(Divide and Conquer)은 주어진 문제를 더 작은 하위 문제(subproblem)로 **분할(Divide)** 하고,  
각각을 독립적으로 **정복(Conquer)** 한 후, 결과를 **병합(Combine)** 하는 과정을 통해 전체 문제를 해결하는 방식이다.

---

<aside>3단계 구조</aside>

1. **분할(Divide)** — 문제를 동일한 형태의 하위 문제로 나눈다.  
2. **정복(Conquer)** — 하위 문제를 재귀적으로 해결한다.  
3. **병합(Combine)** — 하위 문제의 결과를 결합하여 최종 해답을 만든다.

---

<aside>특징</aside>

- **재귀적 구조(Recursive Structure)** 를 가진다.  
- 하위 문제가 서로 독립적이어야 효율적으로 병렬 처리 가능하다.  
- 각 단계에서 동일한 패턴이 반복되며, 전체 수행 시간은 주로 `T(n) = aT(n/b) + f(n)` 형태로 표현된다.  
- 마스터 정리를 통해 복잡도를 분석할 수 있다.

---

<aside>시간 복잡도 예시 (Master Theorem)</aside>

문제의 크기를 n, 하위 문제의 개수를 a, 분할 비율을 b, 병합 비용을 f(n)이라 할 때:

`T(n) = aT(n/b) + f(n)`

- **Case 1:** `f(n) = O(n^(log_b(a) - ε))` → `T(n) = Θ(n^(log_b(a)))`  
- **Case 2:** `f(n) = Θ(n^(log_b(a)))` → `T(n) = Θ(n^(log_b(a)) * log n)`  
- **Case 3:** `f(n) = Ω(n^(log_b(a) + ε))` → `T(n) = Θ(f(n))`

---

<aside>대표 알고리즘</aside>

- **정렬:** 병합 정렬(Merge Sort), 퀵 정렬(Quick Sort)  
- **탐색:** 이진 탐색(Binary Search)  
- **수학:** 거듭제곱 계산(Fast Exponentiation), Karatsuba 곱셈  
- **그래프:** 최근접 점 쌍 찾기(Closest Pair of Points)  
- **행렬:** Strassen 행렬 곱셈 알고리즘  

---

<aside>활용 및 한계</aside>

- 문제의 크기를 분할하기 쉽고, 하위 문제가 독립적인 경우에 매우 효과적이다.  
- 하위 문제가 서로 의존적이면, 분할 정복보다는 **동적 프로그래밍(DP)** 이 적합하다.  
- 재귀 호출이 많기 때문에 **스택 오버플로우**나 **오버헤드 증가**에 주의해야 한다.  
- 병렬 처리 및 분산 계산 구조에 적합하다.
