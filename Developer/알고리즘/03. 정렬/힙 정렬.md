# Summary
힙 정렬(Heap Sort)은 완전 이진 트리 형태의 힙(Heap) 자료구조를 이용한 비교 기반 정렬 알고리즘이다.  
최대 힙을 구성해 루트(최대값)를 하나씩 꺼내 정렬하며, 제자리 정렬이지만 불안정 정렬이다.  
시간 복잡도는 `O(n log n)`으로 일정하다.

# Notes

힙 정렬은 힙 자료구조를 이용해 효율적으로 정렬을 수행한다.  
정렬 과정 전체에서 추가 메모리를 거의 사용하지 않아 공간 효율성이 높다.

<aside>정의</aside>

힙 정렬(Heap Sort)은 **완전 이진 트리 형태의 힙(Heap)** 을 이용해 정렬하는 알고리즘이다.  
최대 힙(Max Heap)을 구성한 뒤, 루트 노드(최대값)를 배열의 끝으로 이동시키고  
남은 구간에서 다시 힙을 재구성하여 정렬을 완료한다.

---

<aside>동작 과정</aside>

1. 주어진 배열을 **최대 힙(Max Heap)** 으로 만든다.  
2. 루트(가장 큰 값)를 마지막 원소와 교환한다.  
3. 힙 크기를 1 줄인 뒤, 다시 최대 힙을 재구성한다.  
4. 이 과정을 전체 크기가 1이 될 때까지 반복한다.

---

<aside>특징</aside>

- **비교 기반 정렬**  
- **불안정 정렬(Unstable Sort)**  
- **제자리 정렬(In-place Sort)**  
- 추가 메모리 사용이 거의 없음 (`O(1)`)  
- 항상 일정한 `O(n log n)`의 성능을 보임  
- 데이터의 초기 정렬 여부에 관계없이 동일한 성능  

---

<aside>시간 복잡도</aside>

| 경우 | 복잡도 |
|------|--------|
| 최선 | O(n log n) |
| 평균 | O(n log n) |
| 최악 | O(n log n) |

공간 복잡도: `O(1)`

---

<aside>활용 및 한계</aside>

- 메모리 제약이 있는 환경에서 효율적이다.  
- 데이터의 정렬 상태에 영향을 받지 않는다.  
- 하지만 안정 정렬이 아니므로, 같은 값의 상대적 순서를 유지할 수 없다.  
- 실무에서는 병합 정렬이나 퀵 정렬에 비해 덜 사용되지만,  
  **고정된 공간 내에서 일정한 성능을 요구할 때** 유용하다.

```c

int arr[SIZE]; // 루트가 1인 트리 배열 
static inline void swap(int *a, int *b){
	int t=*a; *a=*b; *b=t;
}
void heapify(int arr[], int n, int i){
	int largest = i;
	while(1){
		int l=2*i; // i노드의 좌측 아이
		int r=2*i+1; // r노드의 우측 아이
		int m=largest; // m= 
		
		if(l<=n && arr[l]>arr[m]) m=l; // 
		if(r<=n && arr[r]>arr[m]) m=r; // 
		if(m==largest) break;
		
		swap(&arr[largest], &arr[m]);
		i=largest=m; 
	}
}

void heap_sort(int arr[]){
	// 맥스 힙 구축
	for(int i=N/2; i>=1; --i)
		heapify(arr, N, i);
	
	// 하나씩 추출
	for(int end=n-1; end>0; --end){
		swap(&arr[1], &arr[end]);
		heapify(arr,end-1,1);
	}
}
```
