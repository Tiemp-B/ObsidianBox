# Summary
계수 정렬(Counting Sort)은 각 데이터의 등장 횟수를 세어 정렬하는 비비교 기반 정렬 알고리즘이다.  
정수형 데이터나 범위가 제한된 값에 매우 효율적이며, 시간 복잡도는 `O(n + k)`이다.  
안정 정렬(Stable Sort)이지만, 데이터 범위가 넓으면 비효율적이다.

# Notes

계수 정렬은 데이터 간의 비교를 수행하지 않고,  
각 값의 빈도수를 기반으로 위치를 계산해 정렬하는 방식이다.  
값의 크기보다는 “분포”에 집중한다.

<aside>정의</aside>

계수 정렬(Counting Sort)은 데이터의 범위를 기준으로 배열을 생성하고,  
각 값이 몇 번 등장하는지 세어 그 누적 결과를 이용해  
각 원소의 최종 위치를 결정하는 **비비교 기반 정렬 알고리즘**이다.

---

<aside>동작 과정</aside>

1. 데이터의 최댓값과 최솟값을 찾는다.  
2. 해당 범위를 가지는 **계수 배열(Count Array)** 을 만든다.  
3. 각 데이터의 등장 횟수를 계수 배열에 저장한다.  
4. 계수 배열을 누적하여 각 값의 정렬 후 위치를 계산한다.  
5. 입력 배열을 뒤에서부터 순회하며 결과 배열에 값을 채운다.  
6. 안정 정렬이 보장되며, 정렬된 배열이 생성된다.

---

<aside>특징</aside>

- **비교를 사용하지 않는 정렬 알고리즘**  
- **안정 정렬(Stable Sort)**  
- **정수형 데이터 또는 범위가 제한된 경우 효율적**  
- 데이터의 범위(`k`)가 입력 크기(`n`)보다 매우 크면 비효율적  
- 제자리 정렬이 아니며, 추가 메모리(`O(k + n)`)가 필요  

---

<aside>시간 복잡도</aside>

| 경우  | 복잡도      |
| --- | -------- |
| 최선  | O(n + k) |
| 평균  | O(n + k) |
| 최악  | O(n + k) |

공간 복잡도: `O(k + n)`

---

<aside>활용 및 한계</aside>

- **성적, 나이, 점수, 개수 등 정수형 데이터 정렬**에 적합.  
- 문자열 정렬 시 기수 정렬(Radix Sort)의 하위 루틴으로 사용된다.  
- 값의 범위가 큰 실수, 음수, 또는 문자열에는 직접 적용하기 어렵다.  
- 데이터 분포를 미리 알 수 있을 때 가장 효율적이다.

int ret[n];

void counting_sort(){
	for(int i=0; i<n; ++i) cnt[arr[i]]++;
	for(int i=1; i<k+1; ++i) cnt[i]+=cnt[i-1];

}
