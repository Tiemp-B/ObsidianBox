# Summary
퀵 정렬(Quick Sort)은 [[분할 정복]](Divide and Conquer) 원리를 이용한 비교 기반 정렬 알고리즘이다.  
피벗(Pivot)을 기준으로 작은 값은 왼쪽, 큰 값은 오른쪽으로 분할하며 재귀적으로 정렬한다.  
평균 시간 복잡도는 `O(n log n)`이지만, 피벗 선택이 나쁘면 최악의 경우 `O(n²)`이 된다.

# Notes

퀵 정렬은 평균적으로 매우 빠른 정렬 알고리즘이며, 대부분의 내장 정렬 함수의 기반이 된다.  
피벗 선택이 성능의 핵심이며, 제자리 정렬이지만 불안정 정렬이다.

<aside>정의</aside>

퀵 정렬(Quick Sort)은 배열에서 하나의 원소를 피벗(Pivot)으로 선택하고,  
피벗보다 작은 값은 왼쪽, 큰 값은 오른쪽으로 분할(Partition)한 뒤  
각 부분 배열을 재귀적으로 정렬하는 **분할 정복 기반 알고리즘**이다.

---

<aside>동작 과정</aside>

1. 배열에서 피벗을 선택한다.  
2. 피벗을 기준으로 작은 값과 큰 값으로 분할한다.  
3. 분할된 두 하위 배열에 대해 재귀적으로 퀵 정렬을 수행한다.  
4. 모든 하위 배열의 크기가 1이 되면 정렬이 완료된다.  

---

<aside>특징</aside>

- **비교 기반 정렬**  
- **불안정 정렬(Unstable Sort)**  
- **제자리 정렬(In-place Sort)**  
- 평균적으로 매우 빠르며, 대부분의 정렬 알고리즘보다 효율적  
- 피벗 선택이 성능을 결정: 중앙값 선택이 이상적  

---

<aside>시간 복잡도</aside>

| 경우 | 복잡도 |
|------|--------|
| 최선 | O(n log n) |
| 평균 | O(n log n) |
| 최악 | O(n²) |

공간 복잡도: `O(log n)` (재귀 호출 스택)

---

<aside>활용 및 한계</aside>

- **대규모 데이터 정렬**에 적합하며, **내부 정렬(in-place sort)** 로 자주 사용된다.  
- 데이터가 이미 정렬되어 있거나 피벗이 항상 한쪽에 치우치면 `O(n²)` 성능 저하 발생.  
- 안정성이 필요하지 않은 경우 가장 효율적인 선택 중 하나.  
- 하이브리드 정렬(예: introsort)은 퀵 정렬을 기반으로 구성된다.
