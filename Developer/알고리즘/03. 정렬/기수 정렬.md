# Summary
기수 정렬(Radix Sort)은 자릿수(Digit)를 기준으로 여러 번의 정렬을 수행하는 비비교 기반 정렬 알고리즘이다.  
각 자릿수별로 안정 정렬(주로 계수 정렬)을 적용하며, 전체 복잡도는 `O(d*(n + k))`이다.  
정수나 문자열 데이터 정렬에 적합하고, 안정 정렬이다.

# Notes

기수 정렬은 각 자릿수를 기준으로 낮은 자리부터 높은 자리 순으로 정렬을 반복한다.  
비교 연산 없이 정렬이 가능하며, 데이터의 구조적 규칙성을 이용한다.

<aside>정의</aside>

기수 정렬(Radix Sort)은 데이터를 자릿수 단위로 나누어  
각 자리값을 기준으로 안정 정렬을 반복 수행하여 전체를 정렬하는 알고리즘이다.  
각 자릿수의 정렬에는 일반적으로 **계수 정렬(Counting Sort)** 이 사용된다.

---

<aside>동작 과정</aside>

1. 데이터의 **최대 자릿수(d)** 를 확인한다.  
2. **가장 낮은 자릿수(1의 자리)** 부터 시작해 해당 자리 기준으로 안정 정렬을 수행한다.  
3. 정렬된 결과를 유지한 채 **다음 자릿수(10의 자리, 100의 자리, …)** 로 진행한다.  
4. 모든 자릿수 정렬이 끝나면 전체 데이터가 정렬된다.

---

<aside>기수 정렬의 종류</aside>

- **LSD (Least Significant Digit) 방식**  
  - 가장 낮은 자릿수부터 정렬 시작.  
  - 일반적인 정수 정렬에서 사용.  
  - 예: 1의 자리 → 10의 자리 → 100의 자리 순.  

- **MSD (Most Significant Digit) 방식**  
  - 가장 높은 자릿수부터 정렬 시작.  
  - 문자열이나 긴 숫자열 정렬에 사용.  
  - 재귀적 구조로 구현되며, 하위 자릿수로 세분화된다.

---

<aside>특징</aside>

- **비교를 사용하지 않는 정렬 알고리즘**  
- **안정 정렬(Stable Sort)**  
- **정수나 문자열 정렬에 적합**  
- 각 자릿수 정렬에는 보통 계수 정렬을 사용 (`O(n + k)`)  
- 데이터의 자릿수가 많을수록 성능이 저하됨 (`O(d*(n + k))`)  
- 실수나 부동소수점에는 직접 적용하기 어렵다.

---

<aside>시간 복잡도</aside>

| 경우 | 복잡도 |
|------|--------|
| 최선 | O(d*(n + k)) |
| 평균 | O(d*(n + k)) |
| 최악 | O(d*(n + k)) |

공간 복잡도: `O(n + k)`

---

<aside>활용 및 한계</aside>

- **학생 점수, 전화번호, 우편번호, 문자열 데이터** 등 자릿수가 일정한 데이터에 효과적이다.  
- 정수형 데이터에서 **값의 크기보다 자릿수(d)** 가 작은 경우 매우 빠르다.  
- 단, 데이터가 불균형하거나 자릿수가 큰 경우 **병합 정렬이나 퀵 정렬보다 비효율적**이다.  
- 일반적으로 **계수 정렬과 함께 사용**되어 대량의 정수 데이터 정렬에 널리 활용된다.
