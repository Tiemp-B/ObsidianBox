# Summary
병합 정렬(Merge Sort)은 분할 정복(Divide and Conquer) 방식을 사용하는 정렬 알고리즘이다.  
리스트를 절반으로 나누어 각각 정렬한 뒤 병합하여 전체를 정렬한다.  
안정 정렬이며, 시간 복잡도는 항상 `O(n log n)`이다.

# Notes

병합 정렬은 재귀적으로 리스트를 분할하고, 정렬된 하위 리스트를 병합하는 방식으로 동작한다.  
추가 메모리가 필요하지만, 일관된 성능을 제공하는 효율적인 정렬 알고리즘이다.

<aside>정의</aside>

병합 정렬(Merge Sort)은 배열을 반으로 나누고, 각 절반을 재귀적으로 정렬한 후 병합하여 전체를 정렬하는 **비교 기반 안정 정렬 알고리즘**이다.  
정렬 과정에서 새로운 배열을 만들어 병합하므로 **추가 메모리 공간이 필요**하다.

---

<aside>동작 과정</aside>

1. 리스트를 반으로 나눈다.  
2. 각 하위 리스트를 재귀적으로 정렬한다.  
3. 두 리스트를 비교하여 하나의 정렬된 리스트로 병합한다.  
4. 병합 결과를 상위 호출로 반환하며, 모든 분할이 병합될 때까지 반복한다.  

---

<aside>특징</aside>

- **분할 정복(Divide and Conquer)** 기반 알고리즘  
- **안정 정렬(Stable Sort)**  
- **비교 기반 정렬**  
- **추가 메모리 공간 O(n)** 필요  
- 데이터가 정렬되어 있더라도 모든 과정을 수행해야 함  
- 크기가 큰 데이터나 외부 저장장치 정렬(External Sorting)에 적합  

---

<aside>시간 복잡도</aside>

| 경우 | 복잡도 |
|------|--------|
| 최선 | O(n log n) |
| 평균 | O(n log n) |
| 최악 | O(n log n) |

공간 복잡도: `O(n)`

<aside>코드</aside>

```c++
int arr[];
int tmp[]; // 임시 배열

void merge(int arr[], int left, int mid, int right){
	int i=left;
	int j=mid+1;
	int k=left;
	
	while(i<=mid && j<=right){
		if(arr[i]<=arr[j])
			tmp[k++]=arr[i++];
		else
			tmp[k++]=arr[j++];
	}
	
	while(i<=mid) tmp[k++]=arr[i++];
	while(j<=right) tmp[k++]=arr[j++];
	
	for(int t=left; t<=right; ++t) arr[t]=tmp[t];
}

void merge_sort(int arr[], int left, int right){
	if (left>=right) return;
	int mid=(left+right)/2;
	
	merge_sort(arr, left, mid);
	merge_sort(arr, mid+1, right);
	merge(arr, left, mid, right);
}
```

---

<aside>활용 및 한계</aside>

- **대용량 데이터 정렬** 또는 **안정성이 필요한 경우**에 자주 사용된다.  
- 메모리를 추가로 사용하므로 **임베디드 시스템** 등 메모리 제약 환경에는 부적합하다.  
- **내부 정렬**보다 **외부 정렬(external sort)** 로서 강점을 가진다.  
- Python의 내장 정렬 알고리즘(Timsort)은 병합 정렬의 변형이다.
