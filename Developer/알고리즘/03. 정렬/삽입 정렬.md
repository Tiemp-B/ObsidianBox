
# Summary

삽입 정렬(Insertion Sort)은 정렬된 구간에 새로운 원소를 삽입하며 전체를 정렬하는 알고리즘이다.  
거의 정렬된 데이터에 효율적이며, 안정 정렬이자 제자리 정렬이다.  
평균 시간 복잡도는 `O(n²)`, 최선의 경우 `O(n)`이다.

# Notes

삽입 정렬은 카드를 한 장씩 올바른 위치에 끼워 넣는 방식처럼 작동한다.  
작은 데이터셋이나 정렬된 배열에서 빠르게 수행되지만, 큰 데이터셋에는 비효율적이다.

<aside>정의</aside>

삽입 정렬은 배열을 정렬된 부분과 미정렬 부분으로 나누고,  
미정렬된 원소를 하나씩 꺼내 정렬된 구간의 올바른 위치에 삽입하는 **비교 기반 정렬 알고리즘**이다.

---

<aside>동작 과정</aside>

1. 두 번째 원소부터 시작한다.  
2. 현재 원소를 앞의 정렬된 원소들과 비교한다.  
3. 자신보다 큰 원소들을 뒤로 이동시킨다.  
4. 비어 있는 자리에 원소를 삽입한다.  
5. 전체 데이터가 정렬될 때까지 반복한다.

---

<aside>특징</aside>

- **비교 기반 정렬**  
- **안정 정렬(Stable Sort)**  
- **제자리 정렬(In-place Sort)**  
- 거의 정렬된 데이터에 매우 효율적  
- 구현이 간단하고 직관적  

---

<aside>시간 복잡도</aside>

| 경우 | 복잡도 |
|------|--------|
| 최선 | O(n) |
| 평균 | O(n²) |
| 최악 | O(n²) |

공간 복잡도: `O(1)`

---

<aside>활용 및 한계</aside>

- 데이터가 이미 정렬되어 있거나 거의 정렬된 경우 빠르게 작동한다.  
- 데이터가 무작위로 섞여 있을 경우 비효율적이다.  
- 간단한 구조 덕분에 **부분 정렬**이나 **하이브리드 정렬**(예: Timsort)의 일부로 자주 사용된다.
