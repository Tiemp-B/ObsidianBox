# Summary
선택 정렬(Selection Sort)은 전체 데이터 중 최소값을 찾아 맨 앞 원소와 교환하는 방식의 정렬 알고리즘이다.  
단순한 구조를 가지지만, 비교 횟수가 많아 비효율적이다.  
시간 복잡도는 항상 `O(n²)`이며, 불안정 정렬(Unstable Sort)이다.

# Notes

선택 정렬은 데이터 중에서 가장 작은 값을 찾아 차례대로 앞으로 이동시키는 방식으로 동작한다.  
비교 연산은 많지만 교환 횟수는 적은 편이다.

<aside>정의</aside>

선택 정렬(Selection Sort)은 배열 전체에서 최소값을 찾아 현재 위치의 원소와 교환하는 **비교 기반 정렬 알고리즘**이다.  
정렬이 완료될 때까지 이 과정을 반복한다.

---

<aside>동작 과정</aside>

1. 배열에서 가장 작은 값을 찾는다.  
2. 해당 값을 첫 번째 위치의 원소와 교환한다.  
3. 다음 인덱스로 이동해 남은 구간에서 다시 최소값을 찾는다.  
4. 이 과정을 마지막 원소 전까지 반복한다.  
5. 전체 배열이 오름차순으로 정렬된다.

---

<aside>특징</aside>

- **비교 기반 정렬**  
- **불안정 정렬(Unstable Sort)**  
- **제자리 정렬(In-place Sort)**  
- 교환 횟수는 `n-1`회로 적지만, 비교 횟수는 `n(n-1)/2`로 많음  
- 단순하지만 효율성이 낮아 실무에서는 거의 사용되지 않음  

---

<aside>시간 복잡도</aside>

| 경우 | 복잡도 |
|------|--------|
| 최선 | O(n²) |
| 평균 | O(n²) |
| 최악 | O(n²) |

공간 복잡도: `O(1)`

<aside>활용 및 한계</aside>

- **소규모 데이터셋**이나 **정렬 과정 시각화 학습용**으로 사용됨.
