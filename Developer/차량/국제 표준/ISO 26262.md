# Summary

ISO 26262는 자동차 전자·전기 시스템의 **기능 안전(Functional Safety)** 을 보장하기 위한 국제 표준이다.  
안전 수명주기(Safety Lifecycle)를 정의하며, 위험 분석에서부터 시스템 개발·검증·유지보수까지 모든 단계를 포함한다.  
ASIL 등급 체계를 통해 안전 목표의 중요도를 정량적으로 평가하고, 이에 맞는 개발 프로세스를 요구한다.

# Notes

<aside>ISO 26262 개요</aside>  

ISO 26262는 **자동차 산업에 특화된 기능 안전 표준**으로, IEC 61508을 기반으로 한다.  
주요 목적은 **전자적 오류나 시스템 결함으로 인한 위험을 최소화**하여 운전자와 탑승자의 안전을 보장하는 것이다.  
적용 대상은 차량의 **E/E(Electrical/Electronic)** 시스템이며, 하드웨어·소프트웨어·시스템 레벨에서 모두 요구사항을 정의한다.

<aside>표준의 구조</aside>  

ISO 26262는 12개 파트로 구성된다.  
1. 용어와 정의  
2. 기능 안전 관리  
3. 개념 단계 (Hazard Analysis & Risk Assessment)  
4. 시스템 개발  
5. 하드웨어 개발  
6. 소프트웨어 개발  
7. 생산 및 운용  
8. 지원 프로세스  
9. 안전 분석 기법 (ASAM, FMEA, FTA 등)  
10. ISO 26262 가이드라인  
11. 세미트럭 및 버스 등 확장 적용  
12. 모터사이클 적용  

<aside>안전 수명주기 (Safety Lifecycle)</aside>  

ISO 26262는 개발 초기부터 폐기까지 **전체 수명주기**에서 안전을 고려한다.  
1. 위험 분석 및 안전 목표 도출  
2. ASIL 분류  
3. 시스템/하드웨어/소프트웨어 개발  
4. 검증(Verification) 및 검증(Validation)  
5. 운영 및 유지보수 단계 안전 보장  

각 단계는 트레이서빌리티(추적성)를 유지해야 하며, 상위 안전 요구사항이 하위 단계까지 구체적으로 연결되어야 한다.

<aside>ASIL (Automotive Safety Integrity Level)</aside>  

ASIL은 위험의 심각도(Severity), 노출도(Exposure), 제어 가능성(Controllability)을 조합하여 결정된다.  
등급: **QM < ASIL A < ASIL B < ASIL C < ASIL D**  
- **ASIL D:** 가장 높은 수준의 안전 무결성 필요 (예: 브레이크, 조향 시스템)  
- **ASIL A:** 상대적으로 낮은 안전 등급 (예: 계기판 표시)  
- **QM (Quality Management):** 기능 안전 요구 없음, 일반 품질 프로세스로 충분  

<aside>SW 개발과 ISO 26262</aside>  

소프트웨어 개발 단계에서는 다음을 중점적으로 관리한다.  
- 요구사항 검증 (Requirements Validation)  
- 코드 표준화 (MISRA-C 등)  
- 단위 테스트 및 커버리지 검증  
- 정적 분석 및 형식 검증(Formal Verification)  
- 오류 검출 메커니즘(Watchdog, Redundancy, ECC 등)  

ASIL 등급이 높을수록 코드 품질, 검증 강도, 리뷰 절차가 강화된다.

<aside>하드웨어 개발과 안전 메커니즘</aside>  

하드웨어는 기능 이상(Fault) 발생 시 안전 상태로 전환될 수 있어야 한다.  
주요 기법:  
- Redundancy (이중화 회로)  
- Fault Tolerance (결함 허용 설계)  
- Diagnostic Coverage (진단률 측정)  
- Failure Mode and Effect Analysis (FMEA)  
- Fault Tree Analysis (FTA)  

<aside>기능 안전 관리</aside>  

안전 관리자는 프로젝트 전반에서 ISO 26262 프로세스 준수 여부를 감독한다.  
- Safety Plan 수립  
- 역할 및 책임 정의  
- 독립적 검증(Independent Verification)  
- 변경 관리 및 형상 관리(Configuration Management)  

<aside>산업 적용 예시</aside>  

- **ADAS (Advanced Driver Assistance System):** 센서·제어기 간의 기능 안전 확보  
- **파워트레인 제어:** 엔진, 변속, 브레이크 제어  
- **자율주행 시스템:** 인식·판단·제어 모듈의 다중 안전 수준 설계  
- **MCU/SoC 개발:** ISO 26262 인증 IP, Safety Mechanism 내장  

<aside>핵심 요약</aside>  

- ISO 26262는 자동차 E/E 시스템의 기능 안전 표준  
- ASIL 기반으로 위험 수준 평가  
- 시스템·SW·HW 개발 단계별 안전 요구사항 적용  
- 트레이서빌리티와 검증이 필수  
- 자율주행, 전장 ECU, 반도체 설계까지 폭넓게 적용된다
