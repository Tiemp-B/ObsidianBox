# Notes
SW 개발을 위한 정의, 운용, 유지보수 등의 과정을 각 단계별로 나눈 것이다.

<aside>생명 주기</aside>

**SW 개발 단계**와 **각 단계 별 주요 활동**, 그리고 **활동의 결과**에 대한 산출물로 표현한다. 또한 개발 후에도 품질이 항상 최상의 상태를 유지할 수 있도록 관리하는 과정.
- 정의 단계(WHAT) : 계획, 요구 분석
	- 타당성 분석 -> 개발 계획 -> 요구사항 분석
- 개발 단계(HOW) : 설계, 개발, 테스트
	- 설계 -> 개발 -> 테스트
- 유지보수 단계(CHANGE) : 적용, 예방, 폐기
	- 유지보수 -> 폐기

<aside>SW 공학</aside>

개념
- 여러가지 방법론과 도구, 관리 기법들을 통하여 SW 품질과 생산성을 향상시키는 학문
- IEEE의 SW 공학 표준 용어 사전
	-> 개발, 운용, 유지보수, 폐기 처분에 대한 체계적인 접근 방안
- Fairley 
	-> 지정 비용과 기간 내에 SW를 체계적으로 생산, 유지 보수 관련 기술적 관리적 원리
- Boehm
	-> 과학적 지식을 SW 설계와 제작에 응용하는 것
원칙
- 현대적인 프로그래밍 기술을 계속적으로 적용
- 개발된 SW의 품질이 유지되도록 지속적으로 검증
- SW 개발 관련 사항 및 결과에 대한 명확한 기록 유지
