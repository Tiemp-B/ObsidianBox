# Notes

<aside>역사</aside>

C, C언어는 강력하고 성능은 좋으나 메모리 안정성 문제로 인한 버그와 취약점이 발생했다.
이를 보완하기 위해 시작한 프로젝트이다.

개발자는 모질라 연구소의 Graydon Hoare의 개인 프로젝트
목표는 시스템 프로그래밍 언어의 장점을 유지하며 메모리 안정성을 보장할 수 있는 언어 구상. 
컴파일 타임에 메모리 안전성을 보장하고, 동시성 프로그래밍을 쉽게 할 수 있는 언어를 목표

---

<aside>특징</aside>

철학: 안전성, 속도, 병행성
메모리 누수, 댕글링 포인터, 데이터 경합 등의 문제를 컴파일 타임에 미리 발견하고 방지를 목표

<aside> 안전성</aside>

메모리 누수, 댕글링 포인터, 데이터 경합 등의 문제를 원천적으로 차단.
방식: 소유권 시스템으로 관리
소유권, 빌림(borrowing), 참조(reference)규칙을 통해 할당, 해제를 진행
이를 통해 라이프타임 시스템으로 참조가 유효한 기간을 명확히 정의하여 관리

<aside>속도</aside>

C, C++과 같은 수준의 성능을 목표로 한다.
Zero-cost 추상화(고수준 언어의 추상화 기능을 저수준에서도 성능 저하 없이 구현)를 통해 고수준 추상화 기능을 제공하며 성능 보장
빌드 시스템은 성능 최적화에 초점을 맞춤

필요시 unsafe 블록을 사용하여 메모리 직접 조작을 구현하여 세밀한 성능 튜닝이 가능하다

<aside>병행성</aside>

안전한 병행을 위해 소유권과 빌림 규칙을 사용. std::thread 모듈이나 Rayon같은 외부 크레이트는 데이터 병렬 처리를 손쉽게 구현하도록 도와준다.
async/awiat 구문이 사용 가능하여 비동기 작업을 직관적으로 작업 가능
