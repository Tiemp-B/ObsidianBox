# Summary

보안 공격(Security Attacks)은 시스템·네트워크·사용자 데이터를 침해하기 위해 수행되는 다양한 공격 행위이다.  
대표적으로 **기밀성 위협, 무결성 위협, 가용성 위협**으로 분류되며,  
Malware, DoS, MITM, SQL Injection, XSS 등 수많은 공격 방식이 존재한다.  
현대 보안은 이러한 공격을 분석하고 방어하기 위한 기술과 정책을 포함한다.

# Notes

<aside>보안 공격 개요</aside>

보안 공격은 시스템, 네트워크, 애플리케이션의 취약점을 이용하여  
데이터 유출, 서비스 중단, 시스템 장악 등을 목적으로 수행되는 악의적 활동이다.  

공격은 다음 세 가지 보안 속성(CIA)을 위협한다:  
- **Confidentiality(기밀성)**  
- **Integrity(무결성)**  
- **Availability(가용성)**  

정보 보안은 이러한 위협으로부터 시스템을 보호하는 것을 목표로 한다.

<aside>주요 공격 유형</aside>

대표적인 보안 공격들은 다음과 같다.

1. **Malware(악성코드)**  
   - Virus, Worm, Trojan, Ransomware 등  
   - 시스템 파괴, 정보 탈취, 금전 요구 등 다양한 피해 유발  

2. **Phishing / Social Engineering**  
   - 사람의 심리를 이용한 정보 탈취  
   - 이메일, 문자, 가짜 로그인 페이지 등  

3. **Man-in-the-Middle Attack (MITM)**  
   - 통신 중간에서 데이터 가로채기/변조  
   - 암호화되지 않은 HTTP 환경에서 취약  

4. **DoS / DDoS 공격**  
   - 대량 트래픽으로 서비스 마비  
   - 봇넷 이용한 분산 공격이 일반적  

5. **Injection 공격 (SQL Injection, Command Injection 등)**  
   - 입력값 검증 취약점 악용  
   - 데이터베이스 노출 또는 시스템 명령 실행 유발  

6. **XSS (Cross-Site Scripting)**  
   - 악성 스크립트를 웹 페이지에 주입  
   - 쿠키 탈취, 가짜 입력 창 표시, 세션 탈취  

7. **Zero-day Attack**  
   - 아직 패치되지 않은 새로운 취약점 공격  

8. **Brute-force / Credential Stuffing**  
   - 무차별 암호 대입 또는 유출된 계정 정보 재사용 공격  

9. **Replay Attack**  
   - 패킷을 가로채 재전송하여 인증 우회  

<aside>네트워크 기반 공격</aside>

- **ARP Spoofing / ARP Poisoning**  
  동일 네트워크에서 트래픽 가로채기  
- **DNS Spoofing**  
  악성 사이트로 리다이렉트  
- **Port Scanning (Nmap)**  
  서비스 탐색 및 취약점 확인  
- **Session Hijacking**  
  세션 쿠키 또는 토큰 탈취  

네트워크 보안은 방화벽, IDS/IPS, TLS 암호화를 통해 방어한다.

<aside>웹 애플리케이션 공격</aside>

- SQL Injection  
- XSS  
- CSRF (요청 위조)  
- Directory Traversal  
- File Upload 취약점  
- SSRF(Server-Side Request Forgery)  

웹 보안의 핵심 원칙:  
입력 검증, 권한 확인, 세션 보호, 최소 권한 원칙.

<aside>시스템 공격</aside>

- Buffer Overflow  
  공격자가 스택을 덮어쓰고 셸코드를 실행  
- Privilege Escalation  
  루트 권한 탈취  
- Supply Chain Attack  
  소프트웨어 업데이트 또는 패키지에 악성코드 삽입  

커널 취약점, 권한 정책 오류를 통해 시스템 전체가 장악될 수 있다.

<aside>보안 공격의 방어 기술</aside>

- **암호화(TLS, HTTPS)**  
- **방화벽, IDS/IPS, WAF**  
- **정적 분석/동적 분석**  
- **패치 관리 및 취약점 스캐닝**  
- **Multi-Factor Authentication(MFA)**  
- **Zero Trust Architecture**  
- **로그/모니터링(SIEM)**  

보안은 기술적·관리적·물리적 요소로 다층적 접근이 필요하다.

<aside>핵심 정리</aside>

- 보안 공격은 CIA(기밀성·무결성·가용성)를 위협하는 모든 행위  
- Malware, MITM, Injection, XSS, DDoS 등 다양한 형태 존재  
- 네트워크, 웹, 시스템 전 영역에서 발생  
- 암호화· 접근 통제· 취약점 관리· 모니터링을 통한 방어가 필수
