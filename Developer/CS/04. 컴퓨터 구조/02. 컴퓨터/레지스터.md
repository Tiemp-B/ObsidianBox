# Summary

레지스터는 CPU 내부의 가장 빠른 저장 장치로, 명령 실행 과정에서 데이터와 주소, 상태 정보를 보관한다.  
일반 목적 레지스터와 특수 목적 레지스터로 구분되며, 명령 처리, 스택 관리, 분기 및 예외 처리에 필수적이다.

# Notes

<aside>레지스터의 개요</aside>  

레지스터는 CPU가 직접 접근할 수 있는 초고속 메모리다.  
명령어 페치/디코드/실행 과정에서 연산 데이터, 주소, 상태 값을 임시로 저장한다.  
레지스터의 수와 구조는 ISA(x86, ARM, RISC-V 등)에 따라 다르다.

<aside>레지스터 종류</aside>  

- **일반 목적 레지스터 (GPR)**  
  연산 및 임시 데이터 저장. 예: x86 rax, rbx / ARM x0~x30 / RISC-V x0~x31  
- **특수 목적 레지스터**  
  - PC(Program Counter): 다음 실행될 명령의 메모리 주소 저장  
  - IR(Instruction Register): 현재 명령 저장  
  - SP(Stack Pointer): 스택 최상단 위치  
  - BP/FP(Base/Frame Pointer): 스택 프레임 기준  
  - PSR/FLAGS: 조건 플래그(Z, N, C, V 등) 포함  
  - LR(Link Register, ARM): 함수 반환 주소  
  - ACC(Accumulator): 특정 연산 누산기 (레거시 구조에서 자주 사용)  

<aside>PC</aside>

다음 실행될 명령어의 메모리 주소 저장
한 개의 명령 인출(Fetch)이 끝나면 자동으로 다음 명령어 주소 저장

<aside>동작 및 의미</aside>  

레지스터는 CPU 파이프라인에서 데이터 경로 중심 역할을 한다.  
- 산술/논리 연산 수행(ALU와 직접 연결)  
- 함수 호출 시 인자 전달 및 반환 값 저장  
- 컨텍스트 스위칭 시 레지스터 상태 보존  
- 조건 플래그 기반 분기 실행 제어  
ISA 설계·컴파일러 최적화·스케줄링에 직접 영향 미친다.
