# 확장 분야

**분류:** 컴퓨터 과학 - 확장 분야

---

## 개요

컴퓨터 과학의 응용 영역으로, 다양한 산업과 기술 분야로 확장된다.

## 주요 분야

### 임베디드 시스템
- MCU (Microcontroller Unit)
- RTOS (Real-Time Operating System)
- 센서 및 액추에이터
- 디바이스 드라이버 개발
- IoT (Internet of Things)

### 클라우드 & DevOps
- Docker: 컨테이너화
- Kubernetes: 오케스트레이션
- AWS, Azure, GCP
- CI/CD 파이프라인
- Infrastructure as Code (IaC)

### 분산 시스템
- CAP 이론
- Consistency (일관성)
- Consensus 알고리즘: Paxos, Raft
- 분산 데이터베이스
- 마이크로서비스

### 고급 응용
- 컴퓨터 비전 (Computer Vision)
- 자연어 처리 (NLP)
- 음성 인식 (Speech Recognition)
- 로보틱스 (Robotics)

### 신기술
- 양자컴퓨팅 (Quantum Computing)
- 엣지컴퓨팅 (Edge Computing)
- HPC (High Performance Computing)
- 블록체인 (Blockchain)
