# 인공지능 & 데이터 사이언스

**분류:** 컴퓨터 과학 - AI & 데이터 사이언스

---

## 개요

AI와 데이터 사이언스는 데이터를 기반으로 패턴을 학습하고 예측하는 기술이다.  
머신러닝과 딥러닝을 통해 자동화된 의사결정 시스템을 구축한다.

## 주요 개념

### 기초 수학
- 선형대수: 벡터, 행렬, 고유값
- 확률과 통계
- 미적분

### 머신러닝
- 지도 학습: 회귀, 분류
- 비지도 학습: 군집화, 차원 축소
- 알고리즘: SVM, KNN, Decision Tree, Random Forest

### 딥러닝
- 신경망(Neural Networks)
- CNN (Convolutional Neural Networks)
- RNN (Recurrent Neural Networks)
- Transformer, Attention Mechanism

### 프레임워크
- TensorFlow
- PyTorch
- scikit-learn
- Keras

### 응용
- MLOps
- 모델 최적화
- Edge AI
- 자연어 처리(NLP)
- 컴퓨터 비전(Computer Vision)
