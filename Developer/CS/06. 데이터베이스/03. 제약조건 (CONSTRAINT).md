# Summary

# Notes

<aside>제약조건이란</aside>

제약조건(CONSTRAINT)은 테이블에 부적절한 데이터가 입력되는 것을 막아 무결성(Integrity)을 보장하는 규칙이다. 주로 `CREATE TABLE` 또는 `ALTER TABLE`에서 정의한다.

---

<aside>제약조건의 종류</aside>

- **PRIMARY KEY**: 기본키. 유일성 + NOT NULL을 동시에 만족하며 테이블당 하나만 지정
- **FOREIGN KEY**: 외래키. 다른 테이블의 기본키를 참조하여 참조 무결성을 보장
- **UNIQUE**: 유일성 보장. 단, NULL 값은 허용
- **NOT NULL**: NULL 값 입력 불가
- **CHECK**: 속성값이 특정 조건을 만족하도록 제한
- **DEFAULT**: 값이 입력되지 않을 때 사용할 기본값 지정

---

<aside>CONSTRAINT 키워드로 명명하기</aside>

`CONSTRAINT 제약조건이름` 형식으로 제약조건에 이름을 부여하면, 이후 `ALTER TABLE ... DROP CONSTRAINT 이름` 으로 관리하기 쉽다.

```sql
CREATE TABLE ORDERS (
    ORDER_ID  INT,
    CUST_ID   INT,
    AMOUNT    INT DEFAULT 0,
    CONSTRAINT PK_ORDER  PRIMARY KEY (ORDER_ID),
    CONSTRAINT FK_CUST   FOREIGN KEY (CUST_ID) REFERENCES CUSTOMER(ID),
    CONSTRAINT CHK_AMT   CHECK (AMOUNT >= 0)
);
```

---

<aside>참조 동작 옵션</aside>

외래키가 참조하는 부모 행이 삭제·변경될 때의 동작을 `ON DELETE` / `ON UPDATE`로 지정한다.

- **CASCADE**: 부모 행이 삭제/변경되면 자식 행도 연쇄적으로 삭제/변경
- **SET NULL**: 자식 행의 외래키 값을 NULL로 설정
- **SET DEFAULT**: 자식 행의 외래키 값을 기본값으로 설정
- **RESTRICT / NO ACTION**: 자식 행이 존재하면 부모 행의 삭제/변경을 제한
