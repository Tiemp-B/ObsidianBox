# Notes

<aside>SQL의 분류</aside>

SQL은 기능에 따라 네 가지로 분류된다.

- **DDL(Data Definition Language, 정의어)**: 스키마·테이블 구조 정의 — `CREATE`, `ALTER`, `DROP`, `TRUNCATE`
- **DML(Data Manipulation Language, 조작어)**: 데이터 조회·조작 — `SELECT`, `INSERT`, `UPDATE`, `DELETE`
- **DCL(Data Control Language, 제어어)**: 권한 제어 — `GRANT`, `REVOKE`
- **TCL(Transaction Control Language, 트랜잭션 제어어)**: `COMMIT`, `ROLLBACK`, `SAVEPOINT`

---

<aside>DDL</aside>

데이터베이스 객체의 구조를 정의한다.

- **CREATE**: 테이블·뷰·인덱스 등 객체 생성
- **ALTER**: 기존 객체의 구조 변경 (ADD / MODIFY / DROP)
- **DROP**: 객체를 구조까지 완전히 삭제
- **TRUNCATE**: 테이블의 모든 행을 삭제하되 구조는 유지 (DELETE보다 빠름, 롤백 불가)

```text
CREATE TABLE STUDENT (
    ID      INT PRIMARY KEY,
    NAME    VARCHAR(20) NOT NULL,
    DEPT    VARCHAR(20)
);
```

---

<aside>DML - SELECT</aside>

가장 많이 쓰이는 조회문이다. 논리적 처리 순서는 FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY 이다.

- **집계함수**: `COUNT`, `SUM`, `AVG`, `MAX`, `MIN`
- **GROUP BY**: 그룹으로 묶어 집계, **HAVING**: 그룹에 대한 조건
- **ORDER BY**: 정렬 (ASC 오름차순 / DESC 내림차순)

```text
SELECT DEPT, COUNT(*) AS CNT
FROM STUDENT
WHERE ID > 0
GROUP BY DEPT
HAVING COUNT(*) >= 2
ORDER BY CNT DESC;
```

---

<aside>DML - INSERT / UPDATE / DELETE</aside>

데이터의 삽입·수정·삭제를 담당한다.

```text
INSERT INTO STUDENT (ID, NAME, DEPT) VALUES (1, '홍길동', 'CS');
UPDATE STUDENT SET DEPT = 'EE' WHERE ID = 1;
DELETE FROM STUDENT WHERE ID = 1;
```

---

<aside>JOIN과 서브쿼리</aside>

여러 테이블을 결합하거나 쿼리를 중첩한다.

- **JOIN 종류**: EQUI(=), NON-EQUI, OUTER(LEFT/RIGHT/FULL), SELF, NATURAL
- **서브쿼리**: 단일행(연산자 `=`, `>`, `<` 등) / 다중행(`IN`, `ANY`, `ALL`, `EXISTS`)
- **집합 연산**: `UNION`(중복 제거), `UNION ALL`(중복 포함), `INTERSECT`(교집합), `EXCEPT`(=MINUS, 차집합)

**IN 연산자**: 컬럼값이 주어진 목록(값 리스트 또는 서브쿼리 결과) 중 하나와 일치하는지 판별한다. 여러 개의 `OR` 조건을 간결하게 대체한다.

```text
-- 값 리스트와 함께 (OR의 축약)
SELECT * FROM STUDENT WHERE DEPT IN ('CS', 'EE', 'ME');

-- 서브쿼리와 함께 (다중행 반환 가능)
SELECT NAME FROM STUDENT
WHERE ID IN (SELECT STUDENT_ID FROM ENROLL WHERE GRADE = 'A');

-- 목록에 없는 경우
SELECT * FROM STUDENT WHERE DEPT NOT IN ('CS', 'EE');
```

**다중행 서브쿼리 연산자**: 서브쿼리가 여러 행을 반환할 때 사용한다(단일행 연산자 `=`와 대비).

- **IN**: 결과 중 하나라도 일치하면 참
- **ANY (= SOME)**: 결과 중 하나라도 조건을 만족하면 참 — `> ANY(...)`는 최솟값보다 크면 참
- **ALL**: 결과 모두가 조건을 만족해야 참 — `> ALL(...)`은 최댓값보다 커야 참
- **EXISTS**: 서브쿼리 결과가 한 행이라도 존재하면 참(값 자체보다 존재 여부만 판단)

```text
-- CS 학과의 어떤 학생보다도 나이가 많은 학생
SELECT NAME FROM STUDENT
WHERE AGE > ALL (SELECT AGE FROM STUDENT WHERE DEPT = 'CS');
```

> ⚠️ **NULL 주의**: 서브쿼리 결과나 목록에 NULL이 포함되면 `NOT IN`은 아무 행도 반환하지 않을 수 있다(NULL 비교 결과가 UNKNOWN이 되기 때문). 이 경우 `NOT EXISTS`를 사용하는 것이 안전하다.

<aside>DCL과 TCL</aside>

권한과 트랜잭션을 제어한다.

- **GRANT**: 사용자에게 권한 부여, **REVOKE**: 권한 회수
- **COMMIT**: 트랜잭션 확정, **ROLLBACK**: 트랜잭션 취소, **SAVEPOINT**: 롤백 지점 지정

```text
GRANT SELECT, INSERT ON STUDENT TO user1;
REVOKE INSERT ON STUDENT FROM user1;
```

---

<aside>뷰(VIEW)와 인덱스(INDEX)</aside>

조회 편의와 성능을 위한 객체이다.

- **뷰(VIEW)**: 하나 이상의 테이블에서 유도된 가상 테이블. 물리적으로 저장되지 않으며, 논리적 독립성과 보안성을 높인다. 삽입·갱신·삭제에는 제약이 있다.
- **인덱스(INDEX)**: 검색 속도를 높이기 위한 자료구조. 조회 성능은 향상되나, 삽입·삭제·갱신 시 인덱스도 갱신해야 하므로 부하가 생긴다.
