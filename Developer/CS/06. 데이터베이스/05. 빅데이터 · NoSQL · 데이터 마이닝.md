# Notes

<aside>빅데이터의 특성 (V)</aside>

빅데이터는 기존 방식으로 저장·분석하기 어려운 대규모 데이터를 말하며, 특성을 V로 표현한다.

- **3V**: Volume(규모), Variety(다양성), Velocity(속도)
- **4V**: 3V + Veracity(정확성/신뢰성)
- **5V**: 4V + Value(가치)

---

<aside>NoSQL</aside>

NoSQL(Not Only SQL)은 관계형 모델을 벗어나 대용량·비정형 데이터를 유연하게 다루는 데이터베이스이다. 스키마가 유연하고 수평 확장에 유리하다.

- **Key-Value**: 키-값 쌍으로 저장 — Redis, DynamoDB
- **Document**: JSON/BSON 등 문서 단위 저장 — MongoDB
- **Column-family**: 컬럼 계열 단위 저장 — HBase, Cassandra
- **Graph**: 노드·간선으로 관계 표현 — Neo4j

---

<aside>CAP 이론</aside>

분산 시스템은 다음 세 가지를 동시에 모두 만족할 수 없으며, 최대 두 가지만 보장할 수 있다.

- **Consistency(일관성)**: 모든 노드가 같은 시점에 같은 데이터를 봄
- **Availability(가용성)**: 요청에 항상 응답
- **Partition tolerance(분단 허용성)**: 네트워크 분할이 있어도 동작

---

<aside>데이터 마이닝</aside>

대량의 데이터에서 의미 있는 패턴과 규칙을 발견하는 기법이다.

- **연관 규칙(Association)**: 항목 간 연관성 발견 (예: 장바구니 분석)
- **분류(Classification)**: 미리 정의된 범주로 데이터를 분류
- **군집화(Clustering)**: 유사한 데이터끼리 그룹으로 묶음
- **예측(Prediction)**: 과거 데이터로 미래 값을 추정

---

<aside>관련 개념</aside>

- **데이터 웨어하우스(DW)**: 분석을 위해 통합·축적한 주제 지향 데이터 저장소
- **OLAP**: 다차원 데이터를 대화식으로 분석하는 기술
- **ETL**: 추출(Extract)·변환(Transform)·적재(Load) 과정
- **하둡(Hadoop) / 맵리듀스(MapReduce)**: 대규모 데이터 분산 저장·병렬 처리 프레임워크
