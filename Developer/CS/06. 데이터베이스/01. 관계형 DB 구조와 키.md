# Notes

<aside>릴레이션 구성 요소</aside>

관계형 데이터베이스는 릴레이션(테이블)들의 집합으로 이루어진다.

- **릴레이션(Relation)**: 데이터를 저장하는 테이블 그 자체
- **튜플(Tuple)**: 릴레이션의 행(Row), 레코드. 하나의 개체 인스턴스에 해당
- **속성(Attribute)**: 릴레이션의 열(Column), 필드. 데이터의 항목
- **도메인(Domain)**: 하나의 속성이 가질 수 있는 원자값들의 집합(값의 범위)

---

<aside>차수와 카디널리티</aside>

릴레이션의 크기를 나타내는 두 지표이다.

- **차수(Degree)**: 속성(열)의 개수
- **카디널리티(Cardinality)**: 튜플(행)의 개수

세로(속성) = 차수, 가로(튜플) = 카디널리티로 기억한다.

---

<aside>키의 특성</aside>

키는 튜플을 식별하는 기준이며, 두 가지 특성으로 정의된다.

- **유일성(Uniqueness)**: 하나의 키 값으로 각 튜플을 유일하게 식별할 수 있음
- **최소성(Minimality)**: 튜플을 식별하는 데 꼭 필요한 최소한의 속성으로만 구성됨

---

<aside>키의 종류</aside>

포함 관계는 슈퍼키 ⊃ 후보키 ⊃ 기본키 이다.

- **슈퍼키(Super Key)**: 유일성은 만족하나 최소성은 만족하지 않는 키
- **후보키(Candidate Key)**: 유일성과 최소성을 모두 만족하는 키
- **기본키(Primary Key)**: 후보키 중 대표로 선정한 키. NULL 값과 중복을 가질 수 없음
- **대체키(Alternate Key)**: 후보키 중 기본키로 선정되지 못한 나머지 키
- **외래키(Foreign Key)**: 다른 릴레이션의 기본키를 참조하는 속성. 참조 무결성을 보장
