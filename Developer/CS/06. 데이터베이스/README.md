# 데이터베이스

**분류:** 컴퓨터 과학 - 데이터베이스

---

## 개요

데이터베이스(DB)는 대량의 데이터를 효율적으로 저장, 검색, 관리하는 시스템이다.  
SQL을 기반으로 하며, 트랜잭션과 정규화를 통해 일관성을 유지한다.

## 주요 개념

### 데이터베이스 모델
- 관계형(RDBMS): MySQL, PostgreSQL, Oracle
- 비관계형(NoSQL): MongoDB, Redis, Cassandra

### SQL 쿼리
- SELECT, JOIN, GROUP BY, INDEX
- 서브쿼리, 집계 함수

### 트랜잭션
- ACID 속성
- Lock, Deadlock
- MVCC (Multi-Version Concurrency Control)

### 정규화와 인덱싱
- 데이터 중복 제거
- 검색 성능 최적화

### 응용
- 분산 데이터베이스
- 샤딩(Sharding)
- 레플리케이션(Replication)
- 데이터 웨어하우스
