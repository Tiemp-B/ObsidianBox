# Summary

커널(Kernel)은 **운영체제의 핵심 부분으로, 하드웨어와 응용 프로그램 사이에서 시스템 자원을 관리하는 중심 구성 요소**다.  
CPU, 메모리, 파일 시스템, 입출력 장치 등의 자원을 효율적으로 제어하고,  
시스템 콜을 통해 사용자 프로그램에 서비스를 제공한다.

# Notes

<aside>커널의 개념</aside>

커널은 **운영체제의 핵심(Core)이며, 시스템 자원을 직접 제어하는 소프트웨어 계층**이다.  
응용 프로그램은 커널을 통해 하드웨어 자원에 접근하며,  
이때 사용자 모드(User Mode)에서 커널 모드(Kernel Mode)로 전환이 발생한다.

커널의 주요 역할은 다음과 같다.  
- **자원 관리:** CPU, 메모리, I/O, 파일 시스템 제어  
- **프로세스 관리:** 생성, 스케줄링, 동기화, 통신  
- **보호 기능:** 사용자 접근 제어, 메모리 보호, 권한 구분  
- **하드웨어 추상화:** 다양한 장치 드라이버와의 인터페이스 제공  

<aside>커널의 구조 종류</aside>

1. **모놀리식 커널 (Monolithic Kernel)**  
   - 모든 핵심 기능(프로세스 관리, 메모리, 파일 시스템, 드라이버 등)이 하나의 커널 공간에서 동작  
   - 장점: 빠른 수행 속도, 낮은 통신 오버헤드  
   - 단점: 오류 발생 시 전체 시스템에 영향  
   - 예시: Linux, Unix  

2. **마이크로커널 (Microkernel)**  
   - 최소한의 기능만 커널에 포함 (스케줄링, IPC, 메모리 관리 등)  
   - 나머지는 사용자 공간에서 실행  
   - 장점: 안정성, 유지보수 용이  
   - 단점: 커널-유저 모드 간 통신 비용 증가  
   - 예시: QNX, MINIX, L4  

3. **하이브리드 커널 (Hybrid Kernel)**  
   - 모놀리식 커널의 성능 + 마이크로커널의 안정성을 결합  
   - 예시: Windows NT, macOS (XNU)  

4. **모듈형 커널 (Modular Kernel)**  
   - 커널 기능을 모듈 형태로 동적 로드/언로드 가능  
   - 예시: 현대 Linux 커널 (Loadable Kernel Module, LKM)  

<aside>커널의 주요 구성 요소</aside>

- **프로세스 관리자(Process Manager):** 프로세스 생성, 스케줄링, 동기화 담당  
- **메모리 관리자(Memory Manager):** 가상 메모리, 페이징, 캐싱 담당  
- **파일 시스템 관리자(File System Manager):** 파일 입출력, 디렉터리, 권한 관리  
- **디바이스 관리자(Device Manager):** 장치 드라이버 관리, 인터럽트 처리  
- **시스템 콜 인터페이스(System Call Interface):** 사용자 요청을 커널 내부 기능과 연결  

<aside>커널 모드와 사용자 모드</aside>

운영체제는 시스템 안정성을 위해 두 가지 실행 모드를 구분한다.  
- **사용자 모드(User Mode):** 응용 프로그램 실행, 제한된 권한  
- **커널 모드(Kernel Mode):** 시스템 자원 제어, 모든 권한 보유  
시스템 콜 또는 예외 발생 시 사용자 모드에서 커널 모드로 전환된다.  

<aside>커널의 동작 방식</aside>

1. 응용 프로그램이 시스템 콜을 호출  
2. 트랩(Trap) 발생 → 커널 모드 전환  
3. 커널이 요청된 자원 작업 수행  
4. 작업 완료 후 사용자 모드로 복귀  

<aside>커널 스케줄링</aside>

커널은 CPU를 여러 프로세스에 분배하기 위한 스케줄러를 포함한다.  
- **선점형 스케줄링:** 커널이 실행 중인 프로세스를 강제로 중단 가능  
- **비선점형 스케줄링:** 실행 중인 프로세스가 스스로 CPU를 반환해야 함  
- **목표:** 처리량 향상, 응답 시간 단축, 공정성 유지  

<aside>커널의 보안 기능</aside>

- **메모리 보호:** 프로세스 간 메모리 접근 제한  
- **사용자 권한 분리:** 일반 사용자와 root 권한 구분  
- **시스템 호출 필터링:** 불법 접근 방지 (예: seccomp, AppArmor)  
- **드라이버 격리:** 장치 오류로부터 커널 보호  

<aside>커널의 발전과 응용</aside>

- **리눅스 커널:** 오픈소스, 다양한 아키텍처 지원, 모듈식 구조  
- **윈도우 NT 커널:** 하이브리드 구조, 안정성과 성능 병행  
- **임베디드 커널:** 실시간성 중심, 작은 메모리 공간 최적화  
- **RTOS 커널:** 태스크 우선순위 기반 실시간 응답 보장 (예: FreeRTOS, VxWorks)

커널은 운영체제의 심장으로,  
모든 시스템 동작의 기반을 제공하며 안정성과 성능을 결정짓는 핵심 요소이다.
