# Summary

파일 시스템(File System)은 **데이터를 저장장치(HDD, SSD 등)에 구조적으로 저장하고 접근할 수 있도록 관리하는 운영체제의 핵심 구성 요소**다.  
파일의 생성, 삭제, 접근, 권한 관리, 디렉터리 구조 유지 등을 담당하며,  
저장 효율과 데이터 무결성을 보장하는 것이 주요 목적이다.

# Notes

<aside>파일 시스템의 개념</aside>

파일 시스템은 **운영체제가 저장장치에 데이터를 저장·관리하는 방식**이다.  
파일은 이름(name), 속성(attribute), 데이터(data)로 구성되며,  
운영체제는 이를 블록 단위로 나누어 저장하고 접근한다.  

- **파일(File):** 사용자나 프로그램이 다루는 논리적 데이터 단위  
- **디렉터리(Directory):** 파일을 체계적으로 분류하고 관리하는 구조  
- **경로(Path):** 파일의 위치를 나타내는 문자열 (절대경로 / 상대경로)

<aside>파일 시스템의 주요 기능</aside>

1. **파일 관리:** 생성, 삭제, 열기, 닫기, 읽기, 쓰기  
2. **저장 공간 관리:** 빈 공간(Free Space) 관리, 블록 할당 및 회수  
3. **디렉터리 구조 관리:** 파일의 계층적 관리 및 탐색 기능 제공  
4. **보안 및 접근 제어:** 사용자 권한 및 접근 권한(읽기, 쓰기, 실행) 관리  
5. **데이터 무결성 보장:** 시스템 오류 시 복구(Journaling) 지원  

<aside>파일 속성과 접근 권한</aside>

파일에는 다양한 속성이 포함된다.  
- **이름(Name):** 파일 식별자  
- **유형(Type):** 텍스트, 실행 파일 등  
- **크기(Size):** 파일의 바이트 단위 크기  
- **소유자(Owner):** 파일의 관리자 정보  
- **접근 권한(Permission):**  
  - `r`: 읽기(Read)  
  - `w`: 쓰기(Write)  
  - `x`: 실행(Execute)
