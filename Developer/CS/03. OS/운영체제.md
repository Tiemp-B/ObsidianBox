# Summary

운영체제(OS)는 **하드웨어 자원을 효율적으로 관리하고 사용자와 하드웨어 간의 인터페이스 역할을 하는 시스템 소프트웨어**다.  
프로세스 관리, 메모리 관리, 파일 시스템, 입출력 제어, 동기화 등의 기능을 통해 컴퓨터의 전반적인 동작을 제어한다.

# Notes

<aside>운영체제의 개념</aside>

운영체제는 하드웨어와 소프트웨어의 중간 계층으로,  
프로그램 실행을 관리하고 시스템 자원(CPU, 메모리, 입출력 장치)을 효율적으로 분배한다.  
사용자는 운영체제를 통해 하드웨어를 직접 제어하지 않고 명령어 형태로 요청한다.

<aside>주요 기능</aside>

- **[[프로세스]] 관리:**  
  - 프로세스 생성, 스케줄링, 상태 전이 관리  
  - 컨텍스트 스위칭(Context Switching)  
  - 스레드(Thread) 기반 멀티태스킹  
- **메모리 관리:**  
  - 주소 공간 분할 및 보호  
  - 페이징(Paging), 세그멘테이션(Segmentation)  
  - 가상 메모리(Virtual Memory)  
- **파일 시스템:**  
  - 디스크 블록 관리, 디렉토리 구조, 접근 제어  
  - FAT, NTFS, ext4 등 파일 시스템 구조  
- **입출력 관리:**  
  - 디바이스 드라이버 관리, 버퍼링, 인터럽트 처리  
- **시스템 호출(System Call):**  
  - 커널과 사용자 프로그램 간의 인터페이스 제공  

<aside>프로세스 스케줄링</aside>

운영체제는 CPU를 효율적으로 활용하기 위해 스케줄링 알고리즘을 사용한다.  
- **비선점형:** FCFS, SJF  
- **선점형:** Round Robin, Priority, Multilevel Queue  
- **목표:** CPU 이용률 극대화, 응답시간 최소화, 처리량 향상  

<aside>동기화와 교착상태</aside>

- **동기화:** 여러 프로세스나 스레드가 공유 자원을 동시에 사용할 때 충돌을 방지  
  - 세마포어(Semaphore), 뮤텍스(Mutex), 모니터(Monitor)  
- **교착상태(Deadlock):**  
  - 원인: 상호배제, 점유대기, 비선점, 순환대기  
  - 해결: 예방(Prevention), 회피(Avoidance), 탐지(Detection), 복구(Recovery)  

<aside>메모리 관리 기법</aside>

- **연속 메모리 할당:** 고정 분할, 가변 분할  
- **비연속 메모리 할당:** 페이징, 세그멘테이션  
- **가상 메모리:** 페이지 교체 알고리즘(FIFO, LRU, LFU)  
- **캐시 메모리:** 지역성(Locality of Reference)에 기반한 빠른 접근  

<aside>프로세스 간 통신(IPC)</aside>

- **공유 메모리(Shared Memory):** 빠르지만 동기화 필요  
- **메시지 큐(Message Queue):** 커널을 통한 통신 방식  
- **파이프(Pipe):** 부모-자식 프로세스 간 데이터 스트림  
- **소켓(Socket):** 네트워크 기반 통신  

<aside>운영체제 구조</aside>

- **단일 구조(Monolithic):** 모든 기능이 커널에 포함  
- **계층 구조(Layered):** 기능을 계층적으로 분리  
- **마이크로커널(Microkernel):** 최소 기능만 커널에 포함, 나머지는 유저 모드에서 실행  
- **모듈식 구조:** 필요 기능을 동적으로 추가 가능  

<aside>응용 분야</aside>

- **데스크톱 OS:** Windows, macOS, Linux  
- **모바일 OS:** Android, iOS  
- **임베디드 OS:** FreeRTOS, Zephyr, VxWorks  
- **서버/클라우드 OS:** Linux (Ubuntu, CentOS), Windows Server  
- **가상화 및 컨테이너:** Docker, KVM, VMware, Kubernetes  

<aside>현대 운영체제의 발전 방향</aside>

- 멀티코어 및 병렬 처리 최적화  
- 전력 효율 중심의 스케줄링  
- 보안 강화 및 샌드박싱 구조  
- 클라우드 및 컨테이너 친화적 설계  
- 실시간성과 신뢰성을 중시한 RTOS 발전
