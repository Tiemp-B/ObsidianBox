# Summary

동적 프로그래밍(Dynamic Programming, DP)은 **복잡한 문제를 작은 하위 문제로 나누어 해결한 뒤, 그 결과를 저장하여 중복 계산을 피하는 알고리즘 설계 기법**이다.  
큰 문제를 작은 문제로 분할한다는 점에서 분할정복과 유사하지만, **부분 문제의 중복을 활용**한다는 점에서 다르다.

# Notes

<aside>동적 프로그래밍의 개념</aside>

동적 프로그래밍은 **최적 부분 구조(Optimal Substructure)** 와 **중복 부분 문제(Overlapping Subproblems)** 특성을 가진 문제에 적용된다.  
같은 계산을 반복하지 않고, **부분 문제의 해를 메모이제이션(Memoization)** 하여 효율적으로 문제를 해결한다.  

- **하향식(Top-Down):** 재귀 + 메모이제이션  
- **상향식(Bottom-Up):** 반복문 + 테이블 채우기  

<aside>적용 조건</aside>

1. **중복 부분 문제 (Overlapping Subproblems)**  
   - 동일한 부분 문제가 여러 번 등장  
   - 예: 피보나치 수열  

2. **최적 부분 구조 (Optimal Substructure)**  
   - 전체 문제의 최적 해가 부분 문제의 최적 해로부터 구해짐  
   - 예: 최단 경로 문제, 배낭 문제  

<aside>대표적인 예시</aside>

1. **피보나치 수열 (Fibonacci Sequence)**  
   - 점화식: F(n) = F(n-1) + F(n-2)  
   - DP 적용 시 O(n)으로 시간 단축 가능  

2. **최장 증가 부분 수열 (LIS)**  
   - 점화식: dp[i] = max(dp[j]) + 1 (단, arr[j] < arr[i])  
   - 시간 복잡도: O(n²), 이진 탐색 적용 시 O(n log n)  

3. **0/1 배낭 문제 (Knapsack Problem)**  
   - 점화식: dp[i][w] = max(dp[i-1][w], dp[i-1][w-wi] + vi)  
   - 한정된 무게에서 최대 가치 산출  

4. **최단 경로 (Floyd-Warshall, Bellman-Ford)**  
   - 여러 노드 간 최소 거리 계산  
   - DP 테이블을 이용하여 점진적으로 갱신  

5. **행렬 곱셈 최소 비용 (Matrix Chain Multiplication)**  
   - 점화식: dp[i][j] = min(dp[i][k] + dp[k+1][j] + cost)  
   - 괄호 배치 순서에 따른 최소 연산량 계산  

<aside>구현 방식</aside>

- **Top-Down (Memoization):**  
  재귀적으로 문제를 풀며, 이미 계산한 결과를 저장 후 재사용  

- **Bottom-Up (Tabulation):**  
  작은 문제부터 순서대로 테이블을 채워 올라감  

두 방법의 시간 복잡도는 같지만,  
Top-Down은 코드가 간결하고 Bottom-Up은 메모리 접근이 효율적이다.  

<aside>DP 테이블의 구조</aside>

- **1차원 배열:** 피보나치, 계단 오르기 등  
- **2차원 배열:** 배낭 문제, 최단 경로, 편집 거리 등  
- **3차원 이상:** 확률, 상태 전이 문제  

DP 테이블을 설계할 때,  
1. 상태 정의 (dp[i], dp[i][j])  
2. 점화식 수립  
3. 초기값 설정  
4. 순서 결정  

<aside>동적 프로그래밍과 분할정복의 차이</aside>

| 구분 | 동적 프로그래밍 | 분할 정복 |
|------|------------------|------------|
| 중복 문제 | 존재함 | 없음 |
| 계산 방식 | 결과 저장 후 재활용 | 독립적 계산 |
| 예시 | 피보나치, 배낭, LIS | 병합 정렬, 퀵 정렬 |
| 접근법 | 재귀 + 저장 or 반복 | 재귀 분할 |

<aside>복잡도 분석</aside>

- **시간 복잡도:** 하위 문제의 개수 × 각 문제 해결 비용  
- **공간 복잡도:** DP 테이블 크기에 비례  
- 대부분의 DP 문제는 O(n), O(n²), O(n³) 수준  

<aside>응용 분야</aside>

- **최적화 문제:** 최소 비용, 최대 이익, 최단 경로 등  
- **문자열 처리:** LCS, 편집 거리(Edit Distance)  
- **그래프 문제:** 최단 경로, 최대 유량  
- **게임 이론:** 승패 여부 계산, 전략 최적화  
- **AI/로보틱스:** 상태 기반 의사결정 (MDP, Reinforcement Learning)  

<aside>핵심 정리</aside>

동적 프로그래밍은 다음 단계로 구성된다.  
1. 문제를 하위 문제로 분할  
2. 점화식(Recurrence Relation) 정의  
3. 메모이제이션 또는 테이블 작성  
4. 최적 해 추출  

즉, **"문제를 나누고, 기억하고, 합치는 것"** 이 동적 프로그래밍의 본질이다.
