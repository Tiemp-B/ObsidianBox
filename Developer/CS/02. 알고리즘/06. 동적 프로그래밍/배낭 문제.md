# Summary

냅색(Knapsack) 문제는 **한정된 용량의 가방에 넣을 수 있는 물건들을 선택해 최대 가치를 얻는 조합 최적화 문제**다.  
대표적인 동적 프로그래밍(DP) 문제이며, 부분 문제의 최적 해를 이용해 전체 최적 해를 구한다.  
0/1 냅색, 분수 냅색, 다중 냅색 등 다양한 변형이 존재한다.

# Notes

<aside>문제 개념</aside>

냅색 문제는 다음과 같이 정의된다.  
- 가방 용량 W가 주어지고,  
- 각 물건 i의 무게 `wi`와 가치 `vi`가 주어질 때,  
- 용량을 초과하지 않으면서 **총 가치의 합을 최대화**하도록 물건을 선택한다.

즉, "제한된 자원으로 최대의 효율을 내는 선택 문제"이다.  
수학적으로는 다음과 같이 표현된다.  
Maximize Σ vi * xi  
subject to Σ wi * xi ≤ W,  
xi ∈ {0, 1}

<aside>문제 유형</aside>

1. **0/1 Knapsack**  
   - 각 물건을 한 번만 선택 가능  
   - DP로 대표되는 형태  

2. **Fractional Knapsack (분수 냅색)**  
   - 물건을 쪼개서 일부만 담을 수 있음  
   - 그리디(Greedy) 알고리즘으로 해결 (가치/무게 비율 기준 정렬)  

3. **Unbounded Knapsack (무한 냅색)**  
   - 같은 물건을 여러 번 선택 가능  
   - DP로 해결 (각 물건의 재사용 허용)  

4. **Multiple Knapsack (다중 냅색)**  
   - 각 물건의 개수가 제한되어 있음  
   - 0/1 냅색을 여러 번 수행하는 방식으로 해결  

<aside>0/1 냅색의 DP 접근</aside>

0/1 냅색은 하위 문제의 최적 해를 활용한다.  
dp[i][w] = i번째 물건까지 고려했을 때,  
가방 용량이 w일 때의 최대 가치.

점화식:  
dp[i][w] =  
- dp[i-1][w], if wi > w  
- max(dp[i-1][w], dp[i-1][w-wi] + vi), if wi ≤ w  

초기 조건: dp[0][*] = 0 (물건이 없을 때 가치 0)  

시간 복잡도: O(N × W)  
공간 복잡도: O(W) (1차원 DP로 최적화 가능)

<aside>예시</aside>

가방 용량 W = 10,  
물건:  
- A(무게 6, 가치 13)  
- B(무게 4, 가치 8)  
- C(무게 3, 가치 6)  

→ 최대 가치 = 14 (B + C 선택)

<aside>분수 냅색과의 차이</aside>

| 구분 | 0/1 냅색 | 분수 냅색 |
|------|-----------|------------|
| 선택 단위 | 물건 전체 | 물건 일부 가능 |
| 알고리즘 | 동적 프로그래밍 | 그리디 |
| 복잡도 | O(N × W) | O(N log N) |
| 예시 | 배낭 문제 | 자원 분배 문제 |

<aside>확장 문제</aside>

- **Subset Sum Problem:**  
  - 주어진 숫자 중 일부의 합이 특정 값이 되는지 판별  
  - 0/1 냅색의 특수한 형태  

- **배낭 문제 응용:**  
  - 자원 배분, 투자 최적화, 일정 계획, 로봇 부품 선택 등  
  - 산업·경제 분야에서 널리 활용  

<aside>핵심 요약</aside>

- 냅색 문제는 DP의 대표적 응용으로, "제한된 자원 하에서의 최적 선택" 문제이다.  
- 분할정복과 달리, 이전 계산 결과를 재활용한다.  
- 0/1 냅색은 DP로, 분수 냅색은 그리디로 해결한다.  
- 최적화 알고리즘, 인공지능, 경로 탐색 등에서도 기본 원리로 자주 응용된다.
