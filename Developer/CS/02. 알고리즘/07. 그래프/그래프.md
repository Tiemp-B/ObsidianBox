# Summary

그래프(Graph)는 **정점(Vertex)과 간선(Edge)으로 이루어진 데이터 구조**로,  
객체 간의 관계를 표현하는 데 사용된다.  
방향성, 가중치, 연결성 여부에 따라 다양한 유형으로 분류되며,  
탐색(DFS, BFS), 최단 경로(Dijkstra, Floyd), 최소 신장 트리(MST) 등 다양한 알고리즘의 기반이 된다.

# Notes

<aside>그래프의 기본 개념</aside>

그래프는 정점(Vertex)들의 집합 V와 간선(Edge)들의 집합 E로 구성된다.  
G = (V, E)

- **정점(Vertex):** 데이터나 객체를 나타냄  
- **간선(Edge):** 정점 간의 관계를 표현  
- **차수(Degree):** 한 정점에 연결된 간선의 수  

그래프는 트리(Tree)를 포함하는 더 일반적인 구조이다.  

<aside>그래프의 종류</aside>

1. **무방향 그래프 (Undirected Graph)**  
   - 간선에 방향이 없음  
   - (u, v)와 (v, u)는 동일  

2. **방향 그래프 (Directed Graph)**  
   - 간선에 방향이 있음  
   - (u, v) ≠ (v, u)  

3. **가중치 그래프 (Weighted Graph)**  
   - 각 간선에 가중치(비용, 거리, 시간 등)가 부여됨  

4. **연결 그래프 (Connected Graph)**  
   - 모든 정점이 서로 도달 가능한 그래프  

5. **비연결 그래프 (Disconnected Graph)**  
   - 일부 정점이 다른 정점으로 도달 불가능한 그래프  

6. **사이클 그래프 (Cyclic Graph)**  
   - 시작 정점으로 돌아오는 경로(사이클)가 존재  

7. **무사이클 그래프 (Acyclic Graph)**  
   - 사이클이 존재하지 않음 → DAG(Directed Acyclic Graph)  

<aside>그래프의 표현 방식</aside>

1. **인접 행렬 (Adjacency Matrix)**  
   - 2차원 배열로 간선 존재 여부 표현  
   - 공간 복잡도: O(V²)  
   - 장점: 특정 간선 존재 여부 O(1) 확인  
   - 단점: 희소 그래프에서는 비효율적  

2. **인접 리스트 (Adjacency List)**  
   - 각 정점이 연결된 정점 목록을 저장  
   - 공간 복잡도: O(V + E)  
   - 장점: 메모리 효율적, 탐색 빠름  

<aside>그래프 탐색 알고리즘</aside>

- **DFS (깊이 우선 탐색):**  
  - 한 경로를 끝까지 탐색 후 백트래킹  
  - 재귀 또는 스택 사용  
  - 경로 탐색, 사이클 탐지, 위상 정렬 등에 사용  

- **BFS (너비 우선 탐색):**  
  - 가까운 정점부터 탐색  
  - 큐(Queue) 사용  
  - 최단 거리 탐색에 활용 (가중치 없는 그래프)  

<aside>그래프의 응용 알고리즘</aside>

1. **최단 경로 (Shortest Path):**  
   - 다익스트라(Dijkstra): 단일 출발점 최단 경로 (양의 가중치)
