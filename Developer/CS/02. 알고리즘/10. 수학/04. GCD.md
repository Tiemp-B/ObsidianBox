# Notes

<aside>최대공약수란</aside>

두 정수 a, b를 동시에 나누어 떨어뜨리는 공약수 중 가장 큰 수를 최대공약수(Greatest Common Divisor)라 한다.
`gcd(a, 0) = a` 이며, 모든 수는 0을 약수로 나눌 수 없으므로 0은 자기 자신을 제외한 모든 수와의 GCD가 그 수 자신이 된다.
소인수분해로도 구할 수 있으나, 큰 수에서는 인수분해 비용이 커 유클리드 호제법을 주로 사용한다.

---

<aside>유클리드 호제법</aside>

`gcd(a, b) = gcd(b, a mod b)` 를 반복하여, 나머지가 0이 되는 순간의 나눈 수가 GCD이다.
원리는 `a = bq + r` 일 때 a와 b의 공약수 집합이 b와 r의 공약수 집합과 완전히 같다는 데에 있다. 어떤 수가 a와 b를 모두 나누면 `r = a - bq` 도 나누고, 역으로 b와 r을 나누면 `a = bq + r` 도 나누기 때문이다.
나머지가 매 단계 적어도 절반 수준으로 줄어들어 **O(log(min(a, b)))** 의 시간복잡도를 가진다. 최악의 경우는 인접한 피보나치 수를 입력했을 때이다.

```cpp
int gcd(int a, int b){
    if(b == 0) return a;
    return gcd(b, a % b);
}
```

---

<aside>반복 구현</aside>

재귀 호출의 스택 오버헤드를 피하기 위해 반복문으로 동일한 과정을 구현할 수 있다.
b가 0이 될 때까지 `(a, b)`를 `(b, a % b)`로 갱신한다.

```cpp
int gcd(int a, int b){
    while(b != 0){
        int r = a % b;
        a = b;
        b = r;
    }
    return a;
}
```

---

<aside>최소공배수(LCM)</aside>

두 수의 곱은 최대공약수와 최소공배수의 곱과 같다. 즉 `a * b = gcd(a, b) * lcm(a, b)` 이므로 `lcm(a, b) = a * b / gcd(a, b)` 로 구한다.
`a * b`를 먼저 계산하면 오버플로가 발생할 수 있으므로, GCD로 먼저 나눈 뒤 곱하는 순서가 안전하다.

```cpp
int lcm(int a, int b){
    return a / gcd(a, b) * b;
}
```

---

<aside>확장 유클리드 호제법</aside>

GCD를 구하는 동시에 `a*x + b*y = gcd(a, b)` 를 만족하는 정수 해 (x, y)를 함께 구하는 방법이다(베주 항등식).
모듈러 곱셈 역원 계산, 일차 부정방정식 풀이 등에 사용된다.
재귀의 바닥에서 `gcd(a, 0) = a` 이므로 `x = 1, y = 0` 이고, 상위 단계로 돌아오며 `x = y1`, `y = x1 - (a / b) * y1` 로 해를 갱신한다.

```cpp
int ext_gcd(int a, int b, int& x, int& y){
    if(b == 0){
        x = 1; y = 0;
        return a;
    }
    int x1, y1;
    int g = ext_gcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}
```

<aside>이진 GCD (스타인 알고리즘)</aside>

나눗셈(모듈러) 연산이 느린 환경에서 시프트와 뺄셈만으로 GCD를 구하는 방법이다.
2로 나누어 떨어지는지를 짝/홀로 판정해 공통 2의 거듭제곱을 분리하고, 남은 홀수끼리 뺄셈을 반복한다.

```textplain
1. a와 b가 모두 짝수면 공통 인수 2를 빼내고(shift), 카운트 증가
2. 한쪽만 짝수면 그 수를 2로 나눔(홀수는 2를 인수로 갖지 않으므로)
3. 둘 다 홀수면 큰 수에서 작은 수를 뺌
4. 한쪽이 0이 되면, 남은 수에 앞서 빼낸 2의 거듭제곱을 다시 곱함
```

```cpp
int gcd(int a, int b){
    if(a == 0) return b;
    if(b == 0) return a;

    int shift = 0;
    while(((a | b) & 1) == 0){   // 둘 다 짝수
        a >>= 1; b >>= 1; ++shift;
    }
    while((a & 1) == 0) a >>= 1; // a를 홀수로

    while(b != 0){
        while((b & 1) == 0) b >>= 1;
        if(a > b) std::swap(a, b);
        b -= a;
    }
    return a << shift;
}
```
