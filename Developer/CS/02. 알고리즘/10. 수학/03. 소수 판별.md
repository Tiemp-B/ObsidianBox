# Notes

<aside>단순 나눗셈</aside>

어떤 수에 대해 그 수보다 작은 수들을 나눠가며 나머지가 0이 되지 않는다면 소수이다.
간단한 조건으로 하여 O(n^2)의 시간복잡도를 가진다
```cpp
vector<int> prime;

void prime_checker(int n){
    for(int i=2; i<=n; ++i){
        bool flag = true;
        for(int j=2; j<n; ++j){
            if(i%j==0) {
                flag = false;
                break;
            }
        }
        if(flag)
            prime.push_back(i);
    }
}

```
