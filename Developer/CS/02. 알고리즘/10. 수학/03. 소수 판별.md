# Notes

<aside>단순 나눗셈</aside>

어떤 수에 대해 그 수보다 작은 수들을 나눠가며 나머지가 0이 되지 않는다면 소수이다.
간단한 조건으로 하여 O(n^2)의 시간복잡도를 가진다
```cpp
vector<int> prime;

void prime_checker(int n){
    for(int i=2; i<=n; ++i){
        bool flag = true;
        for(int j=2; j<n; ++j){
            if(i%j==0) {
                flag = false;
                break;
            }
        }
        if(flag)
            prime.push_back(i);
    }
}

```

<aside>에라토스테네스의 체</aside>

어떤 수의 배수들을 리스트에서 제외하는 방식이다.
O(N log(logN))의 시간복잡도와  O(N)의 공간복잡도를 가진다.
```cpp
vector<int> prime;

void prime_checker(int n){
    vector<bool> checker(n+1, true);
    for(int i=2 ; i<=n; ++i){
        if(!checker[i]) continue;
        prime.push_back(i);
        for(int t=i+i; t<=n; t+=i){
            checker[t] = false;
        }
    }
}
```
