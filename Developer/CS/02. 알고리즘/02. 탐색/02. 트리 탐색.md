# Summary
이진 탐색 트리(Binary Search Tree, BST)는 **왼쪽 서브트리에는 작은 값, 오른쪽 서브트리에는 큰 값**이 저장되는 이진 트리다.  
탐색, 삽입, 삭제 모두 평균 시간 복잡도 `O(log n)`이며,  
정렬된 데이터를 효율적으로 저장하고 검색할 수 있는 자료구조다.

# Notes

이진 탐색 트리는 트리 구조와 탐색 알고리즘의 결합 형태로,  
정렬된 데이터를 빠르게 탐색할 수 있는 핵심 구조다.

<aside>정의</aside>

이진 탐색 트리(Binary Search Tree)는 각 노드에 값(key)이 존재하며,  
- 왼쪽 자식의 키 < 부모 노드의 키  
- 오른쪽 자식의 키 > 부모 노드의 키  
라는 규칙을 만족하는 **이진 트리(Binary Tree)** 구조이다.

---

<aside>구조</aside>

각 노드는 다음 정보를 가진다:
- **Key (값)** — 노드의 데이터  
- **Left Child** — 자신보다 작은 값  
- **Right Child** — 자신보다 큰 값  

이 구조로 인해, 모든 노드에 대해 왼쪽은 작은 값, 오른쪽은 큰 값으로 정렬된 상태가 유지된다.

---

<aside>탐색 과정</aside>

1. 루트(Root) 노드에서 시작한다.  
2. 찾는 값이 현재 노드보다 작으면 왼쪽 서브트리로 이동한다.  
3. 크면 오른쪽 서브트리로 이동한다.  
4. 값이 일치하면 탐색 성공, 없으면 실패로 종료한다.  
→ 탐색 시간: 평균 `O(log n)`, 최악 `O(n)` (트리가 편향된 경우).

---

<aside>삽입 과정</aside>

1. 루트에서부터 비교를 시작한다.  
2. 삽입할 값이 현재 노드보다 작으면 왼쪽, 크면 오른쪽으로 이동한다.  
3. 비어 있는 위치를 찾으면 그 자리에 새 노드를 삽입한다.  
→ 삽입 시간: 평균 `O(log n)`  

---

<aside>삭제 과정</aside>

삭제는 세 가지 경우로 나뉜다:

1. **자식이 없는 노드 (단말 노드)**  
   → 그냥 제거.  

2. **자식이 하나인 노드**  
   → 부모가 자식을 직접 가리키게 변경.  

3. **자식이 둘인 노드**  
   → 오른쪽 서브트리의 최소값(또는 왼쪽 서브트리의 최대값)으로 대체 후, 해당 노드를 삭제.  

---

<aside>시간 복잡도</aside>

| 연산 | 평균 | 최악 |
|------|------|------|
| 탐색 | O(log n) | O(n) |
| 삽입 | O(log n) | O(n) |
| 삭제 | O(log n) | O(n) |

최악의 경우(정렬된 데이터 삽입)는 트리가 한쪽으로 편향되어 선형 구조가 된다.

---

<aside>균형 트리 (Balanced BST)</aside>

이진 탐색 트리의 단점은 **편향(Pivoting)** 에 의해 효율이 감소하는 것이다.  
이를 해결하기 위해 균형 유지 기능이 있는 변형 구조들이 개발되었다.

- **AVL Tree:** 노드의 균형 인수(왼쪽 높이 - 오른쪽 높이)가 -1, 0, 1을 유지.  
- **Red-Black Tree:** 색상 규칙을 이용해 균형을 유지.  
- **Splay Tree:** 자주 접근하는 노드를 루트로 이동.  
- **Treap:** 난수를 이용한 확률적 균형 유지.  

---

<aside>순회 방법 (Traversal)</aside>

- **중위 순회(Inorder):** 왼쪽 → 루트 → 오른쪽 → 오름차순 출력.  
- **전위 순회(Preorder):** 루트 → 왼쪽 → 오른쪽.  
- **후위 순회(Postorder):** 왼쪽 → 오른쪽 → 루트.  

중위 순회를 수행하면 항상 **정렬된 데이터**가 출력된다.

---

<aside>응용 분야</aside>

- **데이터 검색 및 정렬된 데이터 저장**  
- **사전(Dictionary) 및 집합(Set) 구현**  
- **데이터베이스 인덱스**  
- **자동완성 및 트리 기반 탐색 구조 (ex. 트라이, B-Tree)**
