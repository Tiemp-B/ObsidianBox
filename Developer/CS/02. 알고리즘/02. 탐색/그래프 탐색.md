# Summary
그래프 탐색(Graph Search)은 **그래프의 모든 정점(vertex)을 체계적으로 방문하는 알고리즘**이다.  
대표적인 방식은 **너비 우선 탐색(BFS)** 과 **깊이 우선 탐색(DFS)** 으로,  
BFS는 큐(Queue)를 이용해 가까운 노드부터 탐색하고,  
DFS는 스택(Stack) 또는 재귀(Recursion)를 이용해 깊은 노드부터 탐색한다.

# Notes

그래프 탐색은 노드 간의 연결 관계를 기반으로 경로를 찾거나, 전체 구조를 순회하는 데 사용된다.  
네트워크, 경로 탐색, 연결성 분석 등 다양한 문제의 기본이다.

<aside>정의</aside>

그래프 탐색(Graph Traversal)은 **시작 정점에서 시작하여 모든 정점을 한 번씩 방문하는 과정**이다.  
그래프는 노드(Vertex)와 간선(Edge)으로 구성되며, 방향성이나 가중치에 따라 탐색 방법이 달라질 수 있다.

---

<aside>그래프의 종류</aside>

- **무방향 그래프 (Undirected Graph):** 간선이 양방향 연결.  
- **방향 그래프 (Directed Graph):** 간선이 한쪽 방향으로만 연결.  
- **가중치 그래프 (Weighted Graph):** 간선마다 비용(가중치)이 존재.  
- **비가중치 그래프 (Unweighted Graph):** 간선의 가중치가 동일.

---

<aside>탐색 방식 개요</aside>

| 구분 | BFS (너비 우선 탐색) | DFS (깊이 우선 탐색) |
|------|----------------------|----------------------|
| 탐색 구조 | Queue (FIFO) | Stack / Recursion |
| 방문 순서 | 가까운 정점부터 탐색 | 깊은 경로를 우선 탐색 |
| 특징 | 최단 경로 보장 (비가중치 그래프) | 경로 탐색, 순환 탐지에 유용 |
| 구현 방식 | 반복문 기반 | 재귀 기반 가능 |
| 시간 복잡도 | O(V + E) | O(V + E) |

---

<aside>BFS (너비 우선 탐색)</aside>

1. 시작 노드를 큐에 넣고 방문 표시.  
2. 큐에서 노드를 꺼내어 인접 노드들을 차례로 탐색.  
3. 아직 방문하지 않은 노드를 큐에 추가.  
4. 큐가 빌 때까지 반복.  

- **특징:**  
  - 비가중치 그래프에서 **최단 거리 탐색**에 활용 가능.  
  - 트리 레벨 순회(Level Order Traversal)와 동일한 원리.  
  - 예시: 미로 탐색, 네트워크 거리 계산, 최소 이동 횟수 문제.

---

<aside>DFS (깊이 우선 탐색)</aside>

1. 시작 노드에서 출발.  
2. 방문하지 않은 인접 노드로 깊이 들어감.  
3. 더 이상 갈 곳이 없으면 이전 단계로 되돌아감 (Backtracking).  
4. 모든 노드를 방문할 때까지 반복.  

- **특징:**  
  - 재귀(Recursion) 또는 스택(Stack)으로 구현 가능.  
  - **경로 탐색, 순환(사이클) 탐지, 위상 정렬**에 유용.  
  - 탐색 순서가 깊이 중심적이므로 트리 구조 순회와 유사.

---

<aside>시간 복잡도</aside>

그래프의 정점(V)과 간선(E)에 따라 두 방식 모두 다음과 같다.  
- **BFS:** O(V + E)  
- **DFS:** O(V + E)  
→ 모든 정점과 간선을 한 번씩 방문하기 때문이다.

---

<aside>응용 분야</aside>

- **BFS:**  
  - 최단 경로 탐색 (비가중치 그래프)  
  - 레벨 탐색 (층별 탐색 문제)  
  - 네트워크 확산 시뮬레이션  

- **DFS:**  
  - 그래프 연결 요소 찾기 (Connected Components)  
  - 사이클 탐지(Cycle Detection)  
  - 위상 정렬(Topological Sort)  
  - 백트래킹 기반 문제 (예: 미로 탐색, 조합 탐색)

---

<aside>탐색 시 고려사항</aside>

- **방문 체크 (Visited 배열)** 필수 — 중복 방문 방지.  
- **그래프 표현 방식:**  
  - 인접 행렬(Adjacency Matrix): 공간 O(V²), 간단하지만 비효율적.  
  - 인접 리스트(Adjacency List): 공간 O(V + E), 일반적으로 효율적.  
- **연결 그래프 / 비연결 그래프:**  
  - 모든 노드를 방문하려면 비연결 그래프의 경우 모든 시작점에서 탐색 반복.
