# Summary

가장 많이 쓰는 방법은 CCW(Counter-Clockwise, 외적부호 판별)이다.

# Notes

<aside>외적부호</aside>

세 점 A, B, C에 대해 벡터 AB와 벡터 AC의 외적 성분을 구한다.
결과에 따라 다음과 같이 분류된다
- >0 : C가 선분 AB의 왼쪽에 존재한다.
- <0 : C가 선분 AB의 오른쪽에 존재한다.
- =0 : A, B, C가 한 직선 위에 존재한다.

```c++
CCW(A, B, C) = (B.x - A.x)(C.y - A.y) - (B.y - A.y)(C.x - A.x)
            = B.x * C.x +A.x*A.y - B.x*A.y - A.x*C.y
            - B.y*C.x -A.x*A.y + B.y*A.x + A.y*C.x
            = B.x*C.x 
```

---

<aside>선분 교차 아이디어</aside>

1. 직선 AB와 직선 XY의 교차는 CCW(A, B, X) * CCW(A, B, Y)가 0 이하일 때이다.
    - AB를 기준으로 점 X, Y가 서로 다른 영역에 있기 때문에
2. 선분은 직선보다 짧으므로 직선 XY에 대해서 A, B의 위치도 확인하여야 한다.

따라서 선분 AB와 선분 XY의 교차확인은 다음과 같다.
```
is_crosed(A, B, C) = (CCW(A,B,X)*CCW(A,B,Y)<=0) && (CCW(X,Y,A)*CCW(X,Y,B))
```
