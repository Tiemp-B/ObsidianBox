# Summary

프로그래밍(Programming)은 **논리적 사고를 코드로 표현하여 문제를 해결하는 과정**이다.  
언어 문법과 제어 구조를 활용해 알고리즘을 구현하고, 시스템이 이해할 수 있는 형태로 변환한다.  
즉, 프로그래밍은 “사고를 구현하는 기술”이자 소프트웨어의 기반이다.

# Notes

<aside>프로그래밍의 개념</aside>  
프로그래밍은 단순한 코딩이 아니라 문제 분석 → 설계 → 구현 → 테스트 → 유지보수로 이어지는 과정이다.  
컴퓨터가 수행할 논리적 절차를 정의하고 효율적으로 표현하는 것이 핵심이다.  
즉, 알고리즘을 코드로 구체화하여 실행 가능한 프로그램을 만드는 것이다.

<aside>언어와 패러다임</aside>  
- **주요 언어:** C, C++, Python, Java, Rust, Go  
- **패러다임:**  
  - 절차형(Procedural): 순차적 명령 수행 중심 (C)  
  - 객체지향(OOP): 객체 단위의 설계 (C++, Java)  
  - 함수형(Functional): 부작용 없는 함수 중심 (Haskell, Kotlin)  
  - 이벤트 기반(Event-driven): 입력·이벤트 중심 (JavaScript, Node.js)  
  - 선언형(Declarative): 수행 방식보다 목표 명시 (SQL, Prolog)  

<aside>핵심 구성 요소</aside>  
- **제어문:** if, for, while  
- **자료형:** 정수형, 문자열, 배열, 포인터  
- **함수/메서드:** 재사용 가능한 로직 단위  
- **클래스/객체:** 캡슐화·상속·다형성  
- **예외 처리:** 안정적 오류 제어  
- **메모리 관리:** 동적 할당, 가비지 컬렉션  

<aside>소프트웨어 설계 원칙</aside>  
- **추상화:** 복잡한 로직 단순화  
- **캡슐화:** 데이터 은닉  
- **모듈화:** 기능 단위 분리  
- **인터페이스 분리:** 독립적 구조 유지  
- **의존성 역전:** 상위 모듈의 독립성 확보  

<aside>실행 과정</aside>  
1. **작성:** 소스코드 작성  
2. **컴파일:** 고급 언어 → 기계어 변환  
3. **링킹:** 라이브러리 연결  
4. **로딩:** 메모리 적재  
5. **실행:** 명령어 순차 수행  

<aside>응용 분야</aside>  
- **시스템 프로그래밍:** OS, 드라이버, 커널  
- **네트워크 프로그래밍:** TCP/UDP, HTTP, gRPC  
- **임베디드 프로그래밍:** MCU, RTOS, 센서 제어  
- **웹·서버 개발:** Spring, Django, Node.js  
- **병렬처리:** 멀티스레드, 비동기 I/O  

<aside>성능 최적화</aside>  
- **시간 효율:** 불필요한 반복 최소화  
- **공간 효율:** 메모리 재활용  
- **캐시 활용:** 지역성(Locality) 극대화  
- **비동기 처리:** 이벤트 루프, 멀티프로세싱  
- **컴파일 최적화:** 인라인, 루프 언롤링  

<aside>협업 및 유지보수</aside>  
- **버전 관리:** Git, Branch 전략  
- **테스트:** 단위, 통합, 회귀 테스트  
- **CI/CD:** Jenkins, Docker, GitHub Actions  
- **코드 리뷰:** 품질 개선, 버그 감소  

<aside>확장 응용</aside>  
- AI·데이터 분야: Python, TensorFlow  
- 시스템·보안 분야: C/C++, Rust  
- 웹·서버 분야: JavaScript, TypeScript  
- 임베디드 분야: C, FreeRTOS  
- 클라우드 분야: Go, Python, Shell Script
