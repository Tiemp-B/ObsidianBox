# Summary

프로그래밍은 **문제를 논리적으로 분석하고, 이를 코드로 구현하여 컴퓨터가 수행할 수 있도록 만드는 과정**이다.  
언어 문법과 제어 구조를 통해 알고리즘을 표현하며, 효율성·유지보수성·확장성을 동시에 고려해야 한다.

# Notes

<aside>프로그래밍의 개념</aside>

프로그래밍은 문제 해결을 위한 논리적 사고를 코드로 구체화하는 과정이다.  
요구사항 분석 → 설계 → 구현 → 테스트 → 유지보수의 순환적 과정으로 진행되며,  
단순 명령어 작성이 아닌 **논리적 구조 설계와 최적화된 표현**이 핵심이다.

<aside>언어와 패러다임</aside>

- **주요 언어:** C, C++, Python, Java, Rust, Go  
- **패러다임 구분:**  
  - 절차형: 순차적 명령 실행 (C)  
  - 객체지향: 객체 단위의 설계 및 상호작용 (C++, Java)  
  - 함수형: 부작용 없는 함수 중심 (Haskell, Kotlin)  
  - 이벤트 기반: 이벤트 흐름 중심 (JavaScript, Node.js)  
  - 선언형: 수행 절차보다 결과 명시 (SQL, Prolog)

<aside>핵심 구성 요소</aside>

- **자료형**: 정수형, 실수형, 문자열, 배열, 포인터  
- **제어문**: 조건문(if), 반복문(for, while)  
- **함수**: 코드의 재사용 및 구조화  
- **클래스/객체**: 캡슐화, 상속, 다형성 구현  
- **예외 처리**: 오류 대응 및 복구  
- **메모리 관리** 동적 할당, 참조, 가비지 컬렉션  

<aside>설계 원칙과 최적화</aside>

- **추상화:** 복잡한 로직 단순화  
- **캡슐화:** 내부 데이터 보호  
- **모듈화:** 기능별 독립적 구성  
- **의존성 역전:** 상위 모듈이 하위에 종속되지 않음  
- **성능 최적화:** 반복 최소화, 메모리 효율 향상, 캐시 활용, 비동기 처리  

<aside>응용 및 확장</aside>

- **시스템 프로그래밍:** 운영체제, 드라이버, 커널  
- **네트워크 프로그래밍:** 소켓, TCP/UDP, HTTP, gRPC  
- **임베디드:** MCU, RTOS, 센서 제어  
- **웹/서버:** Spring, Django, Node.js  
- **AI 및 데이터:** Python, NumPy, TensorFlow  

<aside>협업과 품질 관리</aside>

- **버전 관리:** Git, Branch 전략  
- **테스트:** 단위, 통합, 회귀 테스트  
- **CI/CD:** Jenkins, Docker, GitHub Actions  
- **코드 리뷰:** 품질 향상, 유지보수성 확보
