# 소프트웨어 공학

**분류:** 컴퓨터 과학 - 소프트웨어 공학

---

## 개요

소프트웨어 공학은 대규모 시스템을 체계적으로 설계하고 유지보수하는 학문이다.  
개발 생명주기(SDLC)와 설계 원칙을 통해 안정적 품질을 보장한다.

## 주요 개념

### 설계 원칙
- 객체지향 프로그래밍 (OOP)
- SOLID 원칙
  - Single Responsibility
  - Open/Closed
  - Liskov Substitution
  - Interface Segregation
  - Dependency Inversion

### 디자인 패턴
- 생성 패턴: Singleton, Factory, Builder
- 구조 패턴: Adapter, Decorator, Proxy
- 행위 패턴: Observer, Strategy, Command
- 아키텍처 패턴: MVC, MVVM, DI

### 테스트
- 단위 테스트 (Unit Test)
- 통합 테스트 (Integration Test)
- 회귀 테스트 (Regression Test)
- TDD (Test-Driven Development)

### 개발 도구
- Git: 버전 관리
- Jenkins: CI/CD
- Docker: 컨테이너화
- Kubernetes: 오케스트레이션

### 응용
- 대규모 시스템 설계
- 마이크로서비스 아키텍처
- DevOps
- Agile/Scrum 방법론
