# Notes

.파일은 기본적으로 숨김처리가 되어 있다

<aside>.git</aside>

.git 파일은 이 폴더를 git에서 관측한다는 의미라 보면 된다. 해당 파일이 있기에 git이 주시하기 시작한다

<aside>.gitattributes</aside>

파일별 속성과 동작 방식을 제어하는 설정 파일이다.


<aside>.gitignore</aside>

여러 공간에서 파일을 공유, 수정을 하는 과정에서 서로 다른 공간의 환경적 차이로 인해 발생하는 일부 파일들이나 공개적 공간에 올리기 불안한 보안 파일 등 레포지토리로 공유되지 않는 파일들이 존재한다. 이를 .gitignore파일에 등록을 하면 더 이상 git이 대상을 추적, 공유하지 않게 된다.
