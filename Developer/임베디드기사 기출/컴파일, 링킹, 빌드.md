## [Q.15-1 / Q.22-16]
Q. 프로그램 실행 시, 실행 파일과 라이브러리가 연결되는 링크 방식은 무엇인가?
<details class="hoverbox">
  <summary>답안</summary>
  <div class="hover-content">
    동적 링킹 (Dynamic Linking)
  </div>
  <summary>해설</summary>
  동적 링킹 : 실행 가능한 목적 파일을 만들 때, 프로그램에서 사용되는 모든 라이브러리 모듈을 포함시키지 않고, 해당 모듈의 주소만 포함시킨다. 런타임에 실행파일과 라이브러리가 메모리에 위치될 때, 해당 모듈의 주소로 가서 필요한 함수를 실행시키는 방식. <br>
  정적 링킹 : 빌드 시 라이브러리 코드를 실행 파일에 복사.
</details>
## [Q.19-2 / Q.22-16]
Q. Makefile에서 타겟 오브젝트 파일을 나타내는 매크로 심볼은 무엇인가?
<details class="hoverbox">
  <summary>답안</summary>
  <div class="hover-content">
    $@
  </div>
  <summary>해설</summary>
  Makefile의 자동 변수<br>
  <li>$@ : 현재 타겟의 이름</li>
  <li>$^ : 현재 타겟이 의존하는 대상들의 전체 목록</li>
  <li>$? : 현재 타겟이 의존하는 대상들 중 변경된 것들의 목록</li>
</details>
