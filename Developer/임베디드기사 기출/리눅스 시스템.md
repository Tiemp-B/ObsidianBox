## [Q.24-11 / Q.20-5]
Q. 리눅스에서 Run Level을 설정하는 파일은?
<details class="hoverbox">
  <summary>답안</summary>
  <div class="hover-content">
    /etc/inittab
  </div>
  <summary>해설</summary>
  리눅스의 런 레벨:<br>
  0 : 시스템 종료(halt)<br>
  1 : 단일 사용자 모드(Single-user mode)<br>
  2 : 다중 사용자 모드(네트워크 미지원)<br>
  3 : 다중 사용자 모드(네트워크 지원)<br>
  4 : 사용자 정의 모드<br>
  5 : GUI 모드(3과 동일하나, X11 그래픽 환경 지원)<br>
  6: 시스템 재부팅(reboot)
</details>
