## [Q.22-14]
Q. 물리 주소와 1:1로 매핑되어 있는 구간의 페이지로, 커널에서 메모리를 할당할 때 가장 빠르게 할당해 줄 수 있는 영역은 무엇인가?
<details class="hoverbox">
  <summary>답안</summary>
  <div class="hover-content">
    ZONE_NORMAL
  </div>
  <summary>해설</summary>
  ZONE의 종류:<br>
  - ZONE_DMA: 하위 16MB의 메모리를 DMA 용도로 예약<br>
  - ZONE_HIGHMEM: 32비트 컴퓨터에서 작은 주소 공간으로 인한 제약 때문에 사용<br>
  - ZONE_MOVABLE: 쉽게 이동할 수 있는 페이지로만 구성된 존<br>
  - ZONE_DEVICE: 대용량의 메모리에 빠르게 접근할 때 사용하는 존
</details>


## [Q.24-12 / Q.20-1 / Q.15-11]
Q. 어셈블리어로 작성된 블록으로, 자동으로 포함되지 않으므로 프로그램 개발 시 이를 직접 조합하여 링커를 통해서 오브젝트 파일을 포함시켜야 하는 것은 무엇인가?
<details class="hoverbox">
  <summary>답안</summary>
  <div class="hover-content">
	Startup Code (스타트업 코드)
  </div>
  <summary>해설</summary>
  임베디드 시스템에서 전원을 켜거나 리셋된 후 가장 먼저 실행되어 하드웨어 초기화하고 메모리 환경을 설정한 뒤, main 함수가 실행될 수 있도록 준비하는 코드<br>
  스타트업 코드 동작 순서<br>
  1. Power-On Self-Test 수행(POST)<br>
  2. 인터럽트 벡터 테이블 셋업<br>
  3. 모든 인터럽트 실행 차단<br>
  4. 장치 초기화(GPIO, SDRAM, Clock, Watchdog emd)<br>
  5. 메모리 영역 초기화 (Stack, BSS 영역 등)<br>
  6. 부트로더를 SDRAM으로 복사<br>
  7. 부트로더 실행
</details>

## [Q.18-7]
Q. ROM에 저장된 압축된 커널 이미지를 램에 로딩하고 실행하는 기능을 수행하는 것은?
<details class="hoverbox">
  <summary>답안</summary>
  <div class="hover-content">
    부트로더
  </div>
  <summary>해설</summary>
  주기억장치에서 ROM 부분은 부트로더라고 불리는 초기화 프로그램을 저장하는데, 이 프로그램은 전원이 켜졌을 때 컴퓨터 SW를 가동시키는 역할을 한다. 이 프로그램은 OS의 일부분을 디스에서 주기억장치로 적재하고 제어를 OS로 옮겨준다.
</details>
