# Summary

RS-232는 컴퓨터와 주변 장치 간 **직렬 통신(serial communication)** 을 위한 전통적인 인터페이스 표준이다.  
단순한 구조와 높은 호환성으로 오랜 기간 사용되었으며,  
현재도 산업 장비, 계측기, 반도체 장비 통신 등에서 널리 활용된다.

# Notes

<aside>RS-232 개요</aside>

RS-232(Recommended Standard 232)는  
1960년대에 제정된 **직렬 통신 물리 계층 표준**이다.  
컴퓨터(DTE)와 모뎀·장비(DCE) 간 데이터 교환을 목적으로 설계되었다.

주요 특징:  
- 직렬 비동기 통신  
- 단방향 신호선 기반  
- 짧은 거리 통신에 적합  
- 단순하고 구현이 쉬움  

<aside>통신 방식</aside>

RS-232는 **비동기(Asynchronous)** 방식으로 동작한다.  

- 클록 신호 없음  
- 송수신 장치가 동일한 전송 속도(Baud Rate) 설정 필요  
- Start Bit, Data Bit, Parity Bit, Stop Bit 구조  

전송 예:  
- 8N1 (8 data bits, No parity, 1 stop bit)

<aside>전기적 특성</aside>

RS-232는 TTL/CMOS(LOW: 0~0.8V, HIGH: 2V~)와 다른 전압 체계를 사용한다.

- 논리 1 (MARK): −3V ~ −15V  
- 논리 0 (SPACE): +3V ~ +15V  
- ±25V 범위까지 허용  

이로 인해 MCU와 직접 연결 시 **레벨 변환기(MAX232 등)** 가 필요하다.

<aside>커넥터와 핀 구성</aside>

대표 커넥터:  
- DB9 (현재 가장 일반적)  
- DB25 (과거 표준)

DB9 주요 핀:  
- TXD (송신 데이터)  
- RXD (수신 데이터)  
- GND (신호 접지)  
- RTS / CTS (흐름 제어)  
- DTR / DSR (장비 제어)  

<aside>흐름 제어 방식</aside>

RS-232는 두 가지 흐름 제어를 지원한다.

1. **하드웨어 흐름 제어**  
   - RTS / CTS 신호선 사용  
   - 안정적, 배선 복잡  

2. **소프트웨어 흐름 제어**  
   - XON / XOFF 제어 문자 사용  
   - 배선 단순, 데이터 충돌 가능성 존재  

<aside>속도 및 거리 제한</aside>

- 일반 속도: 9,600 ~ 115,200 bps  
- 최대 거리: 약 15m (속도·환경에 따라 감소)  

고속·장거리 통신에는 RS-485, Ethernet 등이 더 적합하다.

<aside>RS-232의 장점</aside>

- 구현이 매우 단순  
- 디버깅 용이  
- 오랜 기간 검증된 안정성  
- 장비 간 높은 호환성  

특히 **산업 장비 초기 통신, 유지보수 포트**로 자주 사용된다.

<aside>한계와 대안</aside>

한계:  
- 낮은 속도  
- 짧은 통신 거리  
- 노이즈에 취약  
- 1:1 통신만 가능  

대안:  
- RS-485 (장거리·다중 노드)  
- USB (고속·범용)  
- Ethernet (네트워크 기반 통신)  

<aside>산업적 활용</aside>

- 반도체 장비 통신(SEMI 장비 초기 설정)  
- 산업용 컨트롤러  
- 계측기, PLC  
- 콘솔 디버깅 포트  
- 임베디드 시스템 초기 설정  

<aside>핵심 정리</aside>

- RS-232는 가장 오래된 직렬 통신 표준 중 하나  
- 비동기 방식, ±전압 신호 사용  
- 구현이 단순하고 호환성이 뛰어남  
- 현대 시스템에서는 보조·관리용 인터페이스로 주로 사용된다
