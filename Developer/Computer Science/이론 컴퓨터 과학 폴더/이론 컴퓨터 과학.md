# Summary

이론 컴퓨터 과학(Theoretical Computer Science)은 계산의 본질과 한계를 탐구하는 학문이다.  
알고리즘, 오토마타, 복잡도, 계산 가능성 등 컴퓨터 과학의 수학적 기반을 다루며,  
무엇이 계산 가능한가(Computability)와 얼마나 효율적으로 계산 가능한가(Complexity)를 연구한다.

# Notes

이론 컴퓨터 과학은 컴퓨터의 동작 원리와 계산의 논리적 구조를 수학적으로 분석하는 분야다.  
현대 컴퓨터 과학의 모든 응용 기술은 이 분야의 개념적 토대 위에 세워져 있다.

<aside>정의</aside>

이론 컴퓨터 과학(Theoretical Computer Science)은 **계산의 본질, 알고리즘의 한계, 문제의 복잡도**를 연구하는 컴퓨터 과학의 근간이다.  
컴퓨터를 ‘추상적 계산 모델’로 보고, 어떤 문제를 얼마나 효율적으로 해결할 수 있는지를 탐구한다.

---

<aside>핵심 연구 영역</aside>

1. **계산 이론 (Theory of Computation)**  
   - 계산 가능한 문제의 범위와 한계를 다룸.  
   - 튜링 기계(Turing Machine), 결정 문제(Decision Problem), 계산 가능성(Computability) 개념 연구.  

2. **오토마타 이론 (Automata Theory)**  
   - 형식 언어(Formal Language)를 인식하는 기계 모델을 연구.  
   - 유한 오토마타(DFA/NFA), 푸시다운 오토마타(PDA), 튜링 기계 등.  
   - 프로그래밍 언어 구문 분석(Parser) 설계의 기초가 된다.

3. **복잡도 이론 (Complexity Theory)**  
   - 문제를 해결하는 데 필요한 시간과 공간을 분석.  
   - P vs NP, NP-완전성, NP-난해성 문제를 다룸.  
   - 효율적 알고리즘의 존재 여부를 이론적으로 규명한다.

4. **알고리즘 이론 (Algorithm Theory)**  
   - 문제 해결 절차의 효율성 및 최적성 분석.  
   - 그래프 이론, 조합론, 최적화 문제와 밀접하게 관련.  
   - 근사 알고리즘, 랜덤화 알고리즘, 병렬 알고리즘 등도 포함된다.

5. **정보 이론 (Information Theory)**  
   - 데이터 표현과 전송의 효율성, 정보의 양을 정량화.  
   - 엔트로피(Entropy), 압축(Compression), 오류 정정(Error Correction) 개념 포함.

---

<aside>핵심 개념</aside>

- **계산 가능성(Computability):** 해결 가능한 문제와 불가능한 문제를 구분.  
- **튜링 완전성(Turing Completeness):** 임의의 계산이 가능한 시스템의 성질.  
- **복잡도 등급(Complexity Class):** 문제를 시간/공간 기준으로 분류 (P, NP, PSPACE 등).  
- **감소(Reduction):** 한 문제를 다른 문제로 변환해 난이도를 비교하는 방법.  
- **형식 언어(Formal Language):** 프로그래밍 언어와 컴파일러의 이론적 기반.

---

<aside>수학적 기반</aside>

- **이산수학 (Discrete Mathematics)** — 그래프, 트리, 집합, 관계  
- **논리학 (Logic)** — 명제 논리, 술어 논리, 증명 이론  
- **선형대수와 확률** — 랜덤화 알고리즘, 오류 확률 분석  
- **수론 및 조합론** — 암호학, 해시, 난수 생성 등에서 응용  

---

<aside>응용 분야</aside>

- **컴파일러 설계:** 오토마타와 문법 이론 기반  
- **암호학:** 복잡도 이론과 수론에 기반  
- **인공지능:** 탐색 및 최적화 알고리즘 이론  
- **데이터 압축 및 통신:** 정보 이론 기반  
- **형식 검증(Formal Verification):** 시스템의 정확성을 수학적으로 증명  

---

<aside>핵심 목표</aside>

이론 컴퓨터 과학의 목표는 단순한 프로그래밍 기술 습득이 아니라,  
**계산의 한계를 이해하고 효율적인 계산 방법의 존재 가능성을 탐구하는 것**이다.  
즉, “무엇을 계산할 수 있고, 얼마나 빠르게 계산할 수 있는가?”를 근본적으로 밝히는 학문이다.
