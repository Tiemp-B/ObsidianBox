# Summary
컴퓨터 구조(Computer Architecture)는 하드웨어와 소프트웨어 간의 상호작용을 정의하는 시스템의 내부 설계 원리를 다룬다.  
명령어 집합(ISA), CPU 구조, 메모리 계층, 입출력 시스템 등이 핵심 구성 요소이며,  
효율적인 계산 성능과 에너지 사용을 목표로 한다.

# Notes

컴퓨터 구조는 프로그램이 하드웨어에서 실행되는 과정을 이해하기 위한 이론적·실무적 기초다.  
소프트웨어 명령이 전자회로 수준에서 어떻게 처리되는지를 다룬다.

<aside>정의</aside>

컴퓨터 구조(Computer Architecture)는 **하드웨어 구성 요소의 설계와 이들 간의 상호작용 방식**을 연구하는 분야다.  
명령어가 CPU에서 해석되고 실행되는 과정을 중심으로, 성능, 비용, 전력 효율의 균형을 설계 목표로 한다.

---

<aside>핵심 구성 요소</aside>

1. **[[CPU]] (중앙처리장치: Central Processing Unit)**  
   - 명령어 해석 및 실행의 핵심 장치.  
   - 주요 구성:  
     - **ALU (Arithmetic Logic Unit)** — 산술 및 논리 연산 수행  
     - **Control Unit (제어 장치)** — 명령어 해석 및 제어 신호 생성  
     - **Registers (레지스터)** — 고속 임시 저장 장치  

2. **명령어 집합 구조 (ISA: Instruction Set Architecture)**  
   - 하드웨어가 이해할 수 있는 명령어의 집합.  
   - [[CISC]](복잡 명령어 집합) vs [[RISC]](축약 명령어 집합)  
   - ISA는 하드웨어와 소프트웨어의 **추상화 계층** 역할을 한다.  

3. **메모리 계층 구조 (Memory Hierarchy)**  
   - CPU에서 데이터 접근 속도의 차이를 줄이기 위한 구조.  
   - **레지스터 → 캐시 → 메인 메모리 → 보조 기억장치** 순으로 구성.  
   - 캐시(Locality of Reference)는 프로그램의 공간·시간적 지역성을 활용한다.

4. **입출력 시스템 (I/O System)**  
   - CPU와 주변 장치 간의 데이터 교환을 담당.  
   - 버스(Bus), DMA(Direct Memory Access), 인터럽트(Interrupt) 메커니즘을 포함한다.  

5. **파이프라이닝 (Pipelining)**  
   - 명령어를 단계별로 겹쳐 실행하여 처리 효율 향상.  
   - 각 단계가 동시에 실행되어 CPU 처리율(Throughput)을 높인다.  

---

<aside>성능 최적화 요소</aside>

- **병렬 처리 (Parallel Processing):** 다중 코어(Multi-Core), SIMD, MIMD 등 구조 사용.  
- **분기 예측 (Branch Prediction):** 명령 흐름의 예측을 통해 파이프라인 정체 최소화.  
- **Out-of-Order Execution:** 실행 순서를 동적으로 재조정하여 CPU 효율 향상.  
- **캐시 최적화 (Cache Optimization):** 데이터 접근 패턴에 따른 효율적인 캐시 관리.  
- **전력 효율 (Power Efficiency):** 모바일 및 임베디드 시스템에서 중요한 설계 지표.  

---

<aside>마이크로아키텍처 (Microarchitecture)</aside>

- ISA를 실제 하드웨어로 구현한 세부 설계 구조.  
- 파이프라인 단계, 실행 유닛 수, 캐시 크기 등 하드웨어 특성 정의.  
- 예: Intel x86, ARM Cortex, RISC-V 아키텍처 등.  

---

<aside>응용 분야</aside>

- CPU, GPU, FPGA 설계 및 최적화  
- 임베디드 시스템 및 마이크로컨트롤러 구조 설계  
- 고성능 컴퓨팅(HPC) 및 데이터센터 서버 아키텍처  
- 전력 효율 중심의 모바일 및 IoT 디바이스 설계  

---

<aside>핵심 목표</aside>

컴퓨터 구조의 목표는 **“더 빠르고, 더 효율적이며, 더 신뢰성 있는 계산”**을 구현하는 것이다.  
이를 위해 하드웨어의 병렬성, 메모리 효율, 명령어 처리 최적화가 균형 있게 설계되어야 한다.
