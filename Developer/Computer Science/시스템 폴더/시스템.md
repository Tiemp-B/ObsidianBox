# Summary

시스템(Systems)은 컴퓨터의 하드웨어와 소프트웨어 자원을 효율적으로 관리하고,  
안정적이며 확장 가능한 동작을 보장하는 분야다.  
운영체제, 네트워크, 데이터베이스, 분산 시스템 등이 핵심 영역이며,  
프로그램이 실제 하드웨어에서 동작하도록 하는 기반 역할을 한다.

# Notes

시스템 분야는 컴퓨터 자원의 효율적 관리, 병렬 처리, 네트워크 통신 등  
**실제 동작 환경을 설계·최적화하는 기술적 토대**를 다룬다.  
즉, 이론 컴퓨터 과학이 “계산의 원리”라면, 시스템은 “계산의 실행”에 해당한다.

<aside>정의</aside>

시스템(Systems)은 하드웨어와 소프트웨어 사이의 상호작용을 관리하고,  
프로그램이 자원을 효율적으로 사용하도록 제어하는 **컴퓨터 과학의 응용 영역**이다.  
운영체제(OS), 네트워크, 데이터 저장 구조, 분산 처리 등이 포함된다.

---

<aside>핵심 구성 영역</aside>

1. **[[운영체제]] (Operating System)**  
   - CPU, 메모리, 파일 시스템, 프로세스 관리 기능을 제공.  
   - 대표 구성 요소:  
     - 프로세스 스케줄러(Process Scheduler)  
     - 가상 메모리(Virtual Memory)  
     - 시스템 콜(System Calls)  
     - 동기화(Synchronization), 락(Lock), 세마포어(Semaphore)

1. **[[컴퓨터 구조]] (Computer Architecture)**  
   - 명령어 집합 구조(ISA), 캐시, 파이프라이닝, 병렬 연산 등.  
   - 하드웨어 성능과 소프트웨어 효율 간의 균형 설계.

1. **[[네트워크]] (Computer Networking)**  
   - 데이터 전송 프로토콜(TCP/IP, UDP, HTTP 등)을 정의하고 통신 흐름을 제어.  
   - OSI 7계층 기반으로 설계되며, 라우팅, 소켓 프로그래밍, 보안 등이 포함됨.

4. **데이터베이스 시스템 (Database Systems)**  
   - 데이터의 구조적 저장과 질의(Query) 처리, 트랜잭션 일관성 보장.  
   - ACID, 인덱스, 트랜잭션 로그, 동시성 제어 등의 개념 포함.

5. **분산 시스템 (Distributed Systems)**  
   - 여러 노드가 네트워크를 통해 협력하여 하나의 시스템처럼 동작.  
   - 주제: 클라우드 인프라, 컨테이너, 합의 알고리즘(Paxos, Raft), CAP 정리.  

---

<aside>시스템 설계 원칙</aside>

- **모듈화(Modularity):** 기능을 독립적인 구성요소로 분리.  
- **추상화(Abstraction):** 하드웨어 세부사항을 숨기고 단순한 인터페이스 제공.  
- **동시성(Concurrency):** 여러 프로세스/스레드가 자원을 효율적으로 공유.  
- **내결함성(Fault Tolerance):** 일부 오류 발생에도 시스템 전체 안정성 유지.  
- **확장성(Scalability):** 시스템 부하 증가에도 성능 저하 최소화.

---

<aside>연관 기술</aside>

- **가상화(Virtualization)** — 여러 운영체제를 한 하드웨어에서 실행 (VM, Docker)  
- **컨테이너(Containerization)** — 경량 환경에서 독립된 서비스 실행  
- **클라우드 컴퓨팅(Cloud Computing)** — 분산 인프라 기반 자원 확장  
- **시스템 보안(Security)** — 접근 제어, 암호화, 커널 보호 메커니즘

<aside>응용 및 실무 분야</aside>

- 서버 및 백엔드 시스템 설계  
- 클라우드 인프라 및 DevOps 환경 구축  
- 네트워크 장비 및 IoT 시스템 개발  
- 대규모 분산 데이터베이스 설계 및 운영  
- 임베디드 및 실시간 운영체제 설계

<aside>핵심 목표</aside>

시스템 분야의 목표는 **자원을 효율적으로 관리하고, 신뢰할 수 있는 계산 환경을 구현하는 것**이다.  
즉, 하드웨어를 이해하고 소프트웨어로 제어하며, 안정성과 성능을 동시에 보장하는 것이 본질이다.
