# Summary

리눅스는 유닉스(UNIX)를 기반으로 한 오픈소스 운영체제로,  
커널·GNU 유틸리티·패키지 시스템·파일 시스템으로 구성된다.  
서버·클라우드·임베디드·개발 환경에서 널리 사용되며 안정성·확장성·멀티태스킹 구조를 제공한다.

# Notes

<aside>리눅스 개요</aside>  

리눅스는 1991년 리누스 토르발스가 만든 커널을 기반으로 발전한 오픈소스 OS다.  
GNU 도구 세트와 결합하여 다양한 배포판(Distro)을 통해 제공된다.  
특징:  
- 멀티유저, 멀티태스킹  
- POSIX 기반 시스템  
- 강력한 CLI 중심 개발 환경  
- 서버/임베디드/클라우드 특성에 최적화  

<aside>구조와 구성 요소</aside>  

리눅스 구성은 크게 다음 네 부분으로 나뉜다.  
- **Kernel**: 프로세스, 메모리, 파일 시스템, 네트워크 관리  
- **System Libraries (glibc 등)**: 시스템 호출을 애플리케이션과 연결  
- **System Utilities**: shell, coreutils 등 기본 도구  
- **User Applications**: 패키지 관리로 설치되는 각종 소프트웨어  

대표 커널 기능:  
- 스케줄링 (CFS)  
- 가상 메모리 관리  
- 파일 시스템(VFS)  
- 네트워크 스택  
- 장치 드라이버  

<aside>리눅스 파일 시스템 구조</aside>  

주요 디렉터리:  
- `/` 루트 
- `/bin`, `/sbin`: 필수 실행 파일  
- `/usr`: 사용자 공간 프로그램  
- `/etc`: 설정 파일  
- `/var`: 로그 등 가변 데이터  
- `/dev`: 장치 파일  
- `/proc`, `/sys`: 커널 정보 제공 가상 파일 시스템  
- `/home`: 사용자 디렉터리  

파일 접근 권한:  
- 소유자/그룹/기타  
- rwx(읽기/쓰기/실행) 권한 모델  

<aside>프로세스 및 메모리 관리</aside>  

- 리눅스는 **fork + exec** 모델 기반  
- 프로세스 상태: Running, Sleeping, Zombie, Stopped  
- 스케줄러: Completely Fair Scheduler(CFS)  
- 메모리: 페이징, 스와핑, 가상 주소 공간 기반  
- `/proc`을 통해 실시간 확인 가능  

<aside>패키지 시스템</aside>  

배포판별 패키지 관리 방식:  
- Debian/Ubuntu: APT  
- RHEL/CentOS/Fedora: YUM/DNF  
- Arch: pacman  

역할:  
- 설치/업데이트/의존성 관리  
- 보안 패치 자동화  

<aside>배포판(Distro) 종류</aside>  

- Debian 계열: 라즈비안, 우분투 등, 비상업
- Fedora 계열: 레드햇, RHEL, CentOS 등, 상업적인 경우가 많다
- 그 외 : OpenSUSE, 안드로이드 등.

<aside>배포판 별 특징</aside>

- Ubuntu: 개발·서버 통합  
- Debian: 안정성 중시  
- Fedora: 최신 기술 적용  
- CentOS/RHEL: 기업용 서버  
- Arch Linux: 사용자가 직접 구성  
- Android: 리눅스 커널 기반 모바일 OS  

<aside>사용자·권한·보안</aside>  

리눅스는 사용자 기반 접근 제어 모델을 사용한다.  
- root와 일반 사용자 계층  
- sudo 기반 권한 상승  
- SELinux/AppArmor로 추가 보안 정책 적용  
- 로그( journalctl ) 기반 시스템 점검  

<aside>네트워크와 서비스 관리</aside>  

- 네트워크 도구: ping, ip, ss, netstat, curl  
- SSH 기반 원격 접속  
- systemd를 통한 서비스/데몬 관리  
- 서버 환경에서 Apache, Nginx, Docker와 함께 사용  

<aside>핵심 정리</aside>  

- 리눅스는 오픈소스 기반의 유연하고 확장 가능한 운영체제  
- 커널 기반으로 프로세스·메모리·장치·네트워크를 관리  
- CLI 중심 구조와 강력한 패키지 시스템 제공  
- 서버·개발·임베디드·클라우드 등 전 분야에서 활용된다
