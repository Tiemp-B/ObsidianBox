# Summary

- 개념: 물리적 디스크를 논리적 디스크로 분할하는 것.
- 다중 파티션의 장점:
	- 파일 점검 시간을 줄여 부팅 시간을 단축 
	- 높은 안정성
	- 백업과 업그레이드 편리
	- 상태 정보 파일 : /proc/partitions

# Notes

<aside>개념</aside>

하나의 물리적 디스크를 여러 개의 논리적 디스크로 분할

---

<aside>장점</aside>

- 독립적인 파티션의 파일시스템 -> 파티션간 영향 적음 -> 높은 안정성
- 특정 파티션만 포맷이 가능하기에 백업과 업그레이드가 편리
- 파티션 상태 정보 파일 : /proc/partitions

---

<aside>종류</aside>

- 주 파티션
	- 부팅이 가능한 기본 파티션
	- 하나의 하드 디스크에 최대 4개의 주 파티션 분할 가능
	- 하드디스크를 4개 이상의 파티션으로 사용할 때 하나의 확장 파티션을 설정하여 확장 파티션 안에 여러 개의 논리 파티션을 분할하여 데이터 저장
