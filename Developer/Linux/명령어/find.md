# 명령어 역할
사용자가 지정한 조건에 부합하는 파일 시스템에 존재하는 파일과 디렉터리를 찾는다

# 옵션
- -name
- -user
- -group
- -uid
- -gid
- -perm : 허가권
- -type : 파일 유형
	- b : 블록 디바이스
	- c : 캐릭터 디바이스
	- d : 디렉터리
	- p : 파이프
	- f : 파일
	- l : 심볼릭 링크
	- s : 소켓
- -a
