# 명령어 역할
파일 및 디렉터리 복사

# 옵션
- -r, -R, --recursive : 하위 파일 및 디렉터리도 복사
- -i, --interactive : 덮어쓰기가 필요한 경우 사용자 동의 요구
- -f, --force : 강제 적용. 덮어쓰기의 경우 기존 파일 삭제 후 시도
- -b : 이미 존재하는 파일인 경우 기존 파일명에 ~를 붙여 백업
- -s, --symbolic-link : 파일 복사가 아닌 심볼릭 링크를 생성한다. 
	- 단, 모든 소스 파일은 절대 경로여야 하고 대상경로는 현 디렉터릭 ㅏ아니어야 한다
- -p : 해당 파일의 허가권, 소유권, 파일 접근 시간, 수정 시간까지 복사
	- 미설정시 현 사용자의 정보로 복사된다
- -v, --verbose : 항목의 정보를 상세히 출력
- -d : 심볼릭 링크가 참조하는 파일이 아닌 심볼릭 링크 자체를 복사
- -a, --archive : 복사 시 원본의 모든 정보 유지 `-dR -preserve=ALL`과 동일
- -l, --link : 하드링크 생성
- -u, --update : 원본 파일이 대상 파일보다 최신이거나 대상 파일이 없는 경우 복사
