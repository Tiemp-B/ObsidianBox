# 명령어 역할
수많은 파일을 하나의 아카이브 파일로 만드는 유틸리티
유닉스의 TAR는 순수하게 파일을 아카이브하는 역할만 수행
리눅스의 TAR는 COMPRESS, GZIP, BZIP2, XZ 등으로 압축하는 것도 지원

# 옵션
아카이브 생성/추출
- -c, --create : 새로운 tar 생성
- -x, --extract : tar 파일을 해체

처리 정보
- v, --verbose : 사용자에게 보여주는 정보량 증가

인자
- -f, --file : 생성되는 tar파일명 지정
- -r, --append : tar 파일에
