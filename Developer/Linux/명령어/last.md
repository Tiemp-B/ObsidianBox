# 명령어 역할
/var/log/wtmp 정보를 참조하여 로그인, 로그아웃, 리부팅 이력을 확인
root 권한 불필요

`last [옵션]`

# 옵션
- -N : 최근 N개 항목만 출력
- -R : 호스트명/IP 생략
- -a : 호스트명/IP를 마지막 컬럼으로
- -d : IP를 호스트명으로 변환하여 출력
- -i : 호스트명을 IP로 변환하여 출력
- -w : 사용자명/도메인을 전체 길이로 출력
- -F : 로그인/로그아웃 시각 전체 출력
- -x : 시스템 종료 및 런레벨 변경 기록 포함 출력
- -f \[파일] : 기본 wtmp 대신 다른 파일 참조
- -t YYYYMMDDHHMMSS : 특정 시각 이전 기록 출력
