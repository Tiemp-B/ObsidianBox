# 명령어 역할
새 그룹을 생성
`groupadd [options] groupname`

# 옵션
- -f, --force : 이미 생성된 그룹이어도 성공으로 간주
	- -g 옵션하여 이미 존재하는 GID를 기입하면 자동으로 유일 GID를 배정한다
- -r, --system
	- 시스템 그룹 생성
	- l
