# 명령어 역할
지정 경로에 존재하는 파일과 디렉터리의 정보 출력
`ls [option] file`
# 옵션
- -a, --all : 숨겨진 파일까지 표시
- -F, --classify : 파일명뒤에 파일의 유형을 뜻하는 문자를 붙임
	- @ : 심볼릭 링크
	- * : 실행 파일
	- = : 소켓
	- | : 파이프
	- \ : 디렉터리
- -l : 자세한 정보
- -d, --directory  : 
- -t : 최근 수정 기준 정렬
- -u : 마지막 수정 시간 대신 접근 시간 출력
- -i, --inode : 아이노드 출력
- -r, --reverse : 정렬 순서를 잔대로
- -R, --recursive : 목록 중 디렉터리가 있다면 그 하위 파일 및 디렉터리도 반복적으로 출력
