# 명령어 역할
network manager를 확인하는 명령어

```bash
nmcli [<옵션>] <개체> { <명령> | help}
```

# 옵션
- 개체
	- g[eneral] : Network Manager의 일반 상태 및 작업
	- c[onnection] : 네트워크 연결
	- d[evice] : 관리하는 장치
	- a[gent] : 비밀 에이전트 또는 polkit 에이전트 q
	- m[onitor] : 변경 사항을 모니터링
	- r[adio] : 라디오 스위치
	- n[etworking] : 네트워크 관리 전반
- 옵션
	- -a : 매개변수 누락되면 물어보기
