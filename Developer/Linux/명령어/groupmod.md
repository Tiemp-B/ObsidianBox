# 명령어 역할
그룹 관련 설정 파일에서 그룹 관련 속성을 변경한다
- /etc/group
- /etc/gshadow
- /etc/passwd

`groupmod [options] groupname`

# 옵션
- -g, --gid
	GID 변경. -o 옵션으로 중복 가능. 기본은 불가
- -n, --new-name
	그룹명 변경
