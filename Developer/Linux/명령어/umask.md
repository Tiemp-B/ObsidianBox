# 명령어 역할
파일, 디렉터리를 생성할 때 적용하는 기본 허가권을 지정
`umask [option] [mask]`

# 옵션
- 미설정 : 현재 기본 허가권 설정. 4자리 숫자가 나온다. 첫 자리는 특수 권한 비트이다
- 원하는 비트를 0으로 설정한다고 보면 된다. 022 를 넣으면 파일의 경우 666-022로 644가 되고, 디렉터리의 경우 777-022로 755가 된다. 즉,  
- -S : 심볼릭 표기

- u=, g=,o=
