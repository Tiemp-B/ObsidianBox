# 명령어 역할
블록 단위로 데이터를 복사.
파티션이나 디스크 단위로 백업하는 용도로도 사용된다.
CD 장치에서 ISO 이미지를 추출할 때도 사용된다.
# 옵션
- if : 표준 입력 대신 지정한 파일에서 읽기를 진행한다
- of : 표준 출력 대신 파일 혹은 장치로 쓰기를 진행한다
- bs : 블록의 크기를 지정. 바이트 단위

# 예제
```bash
# SWAP 파일 생성. 빈 데이터로 생성. 블록 사이즈=1024바이트, 블록 수=1048576
dd if=/dev/zero of=/swapfile bs=1024 count=1048576
```
