# 명령어 역할
네트워크 인터페이스에 대한 환경설정을 수행
옵션 없이 사용하면 현재 활성화된 네트워크 인터페이스에 대한 정보 출력

탑재되어 있지 않다면 'net-tools'패키지를 설치한다.

# 옵션
- a : 비활성화된 인터페이스까지 포함하여 모든 인터페이스를 보여준다


## 출력 정보
- Link encap : 네트워크 인터페이스 유형
- Hwaddr : 인더넷 카드의 MAC 주소
- inet : IP 주소
- inet6 : IPv6 주소
- RX/TX : 송수신 패킷
- mtu : Maximum Transmission Unit  설정값
- Collisions : 충돌 패킷 개수
- Metric fkdnxld wjdqhfhtj rjflrkqt
- Mask : 넷 마스크
- Bcast : 브로드캐스트 주소
- flags :
