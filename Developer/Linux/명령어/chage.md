# 명령어 역할
사용자의 패스워드 만료 정보를 설정
`chage [options] username`
# 옵션
- -d, --lastday
	패스워드를 변경해야 할 날짜 수를 지정
- -E, --expiredate
- -I, --inactive
- -l, --list
- -m, --mindays
- -M, --maxdays
- -W, --warndays
