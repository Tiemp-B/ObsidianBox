# 명령어 역할
디스크 상에서 파티션을 생성, 삭제, 수정
`fdisk [option] device`

# 옵션
- -l : 지정 디스크의 파티션 정보 출력. 디스크 미지정시 /proc/partitions의 장치의 파티션 정보 출력
- -b : 섹터당 크기 설정
- -s : 지정 파티션의 블록의 수

인수
- a
- b
- c
- d
- n : 파티션 추가
- m : 도움말
- p : 현재 디스크 내 파티션 정보 출력
- w : 저장
등
# 예제
```bash
# 지정 디스크에 대한 파티션 설정. 대화형
fdisk /dev/sdb
# 대화형
Command (m for help): 


```
