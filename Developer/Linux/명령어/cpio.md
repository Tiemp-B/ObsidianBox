# 명령어 역할
아카이브로 파일복사 및 파일 추출

# 옵션
- 모드
	- `cpio -o < name-list > archive` : cpio-out 모드. 아카이브 생성
	- `cpio -i < archive` : cpio-in 모드. 아카이브에서 파일 추출
	- `cpio -p destination-directory < name-list` : cpio-pass 모드. 지정 디렉터리로 복사

- -v, --verbose : 처리중인 파일들의 목록 출력
- -c : -H newc 명령어와
