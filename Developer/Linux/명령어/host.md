# 명령어 역할
네임 서버에 질의하여 호스트의 정보를 얻을 수 있는 가장 간단한 도구
`host [option] hostname`

# 옵션
- -t type : 지정한 type의 정보
	- A : 호스트 IP 주소
	- NS : 네임 서버 호스트명
	- MX : 메일 서버
	- ANY : 타입의 모든 정보
- -v
- -a : -v -t ANY와 동일
