# 명령어 역할
지정 파일 및 디렉터리를 이동 및 이름 변경
`mv [option] source ... destination`

# 옵션
- -I, --interactive : 파일의 허가권과 관계없이 존재하는 파일을 덮어쓰기 전에 사용자 확인 요구
- -f, --force : 강제 덮어쓰기
- -b : 덮어쓰기 전에 기존 파일을 백업한다
- -u, --update : 지정 파일이 수정 일자가 최신인 경우만
- -t, --target-directory : 모든 원본 파일을 지정 경로로 이동
