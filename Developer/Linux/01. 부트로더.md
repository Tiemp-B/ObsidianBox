# Notes

<aside>정의</aside>

보조기억장치에 위치한 OS를 주기억장치로 로드하기 위한 프로그램

---

<aside>동작 원리</aside>

1. BIOS는 부트 섹터인 0번 섹터에서 512바이트의 Master Boot Record(MBR)을 읽는다.
2. MBR은 크기가 제한되기에 부트로더의 일부인 Initial Program Loader(IPL)을 실행한다.
3. IPL은 파티션 테이블을 검사하여 부트로더의 나머지 코드의 위치를 찾아 실행한다.

---

<aside>종류</aside>

1. [[LILO]]
	- __LI__nux __LO__ader
	- 모든 리눅스 배포판의 표준.
	- 가장 오래된 부트로더로 리눅스 커뮤니티의 지속적인 지원을 받는다.
	- 설정파일: /etc/lilo.conf
	- 설정 변경 후 LILO stage 1 부트로더를 MBR로 다시 쓰기 위해 lilo 명령을 반드시 수행해야 함
2. [[GRUB]]
	- Grand Unified Boot Loader
	- GNU 프로젝트에서 만든 부트로더
	- LILO와 달리 대화형 명령어 인터페이스 제공, 네트워크 부팅 제공
	- 설정파일 : /boot/grub/grub.cfg
	- 설정 변경 후 자동 적용됨
	- GRUB2의 출시 후 GRUB Legacy라 불린다.
	- GRUB의 한계(x86 및 x86-64 아키텍처만 지원)
	- 파일시스템: ext2fs, FAT, JFS, ReiserFS, XFS등의 리눅스용 파일 시스템 지원
3. [[GRUB2]]
	- GRUB Legacy의 한계를 극복하기 위해 완전히 다시 작성함
	- PowerPC, SPARC 등의 다양한 아키텍처를 지원한다.
	- BIOS, EFI, OpenFirmware 등의 다양한 펌웨어 유형을 지원
	- 정식으로 GPT(GUID Partition Table)을 지원한다.
	- RAID 및 LVM을 지원한다.
	- 마소의 NTFS, 애플의 HFS+, 썬의 ZFS 등의 다른 벤더의 파일 시스템도 지원
	- macOS 및 Darwin 커널과 같은 XNU도 부팅 가능
	- 설정파일: /boot/grub/grub.con
		- 일부 legacy를 같이 사용하는 경우 /boot/grub2/grub.cfg
