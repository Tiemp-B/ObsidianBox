# Summary

네트워크는 여러 컴퓨터와 장치가 데이터를 교환하기 위해 연결된 구조를 의미한다.  
통신 규칙(프로토콜), 계층 구조, 주소 체계 등을 통해 신뢰성 있고 효율적인 데이터 전송을 가능하게 하며,  
인터넷·클라우드·서버·보안 등 모든 현대 IT 시스템의 기반이 된다.

# Notes

<aside>네트워크 개요</aside>

네트워크는 두 개 이상의 노드(Node)가 통신 매체를 통해 데이터를 주고받는 시스템이다.  
노드는 컴퓨터, 서버, 라우터, 스위치, IoT 장치 등을 포함한다.  

네트워크의 목적:  
- 데이터 공유  
- 자원 공유(프린터, 서버 등)  
- 통신 비용 절감  
- 분산 처리 및 확장성 확보  

<aside>네트워크 구성 요소</aside>

- **노드(Node)**: 통신에 참여하는 장치  
- **링크(Link)**: 노드 간 연결 매체(유선/무선)  
- **스위치(Switch)**: 동일 네트워크 내 패킷 전달  
- **라우터(Router)**: 서로 다른 네트워크 간 경로 설정  
- **게이트웨이(Gateway)**: 서로 다른 프로토콜 네트워크 연결  

<aside>네트워크 분류</aside>

규모 기준:  
- **LAN**: 근거리 네트워크 (사무실, 학교)  
- **MAN**: 도시 단위 네트워크  
- **WAN**: 광역 네트워크 (인터넷)  

구조 기준:  
- **Client–Server**  
- **Peer-to-Peer(P2P)**  

전송 방식:  
- 유선(Ethernet, Fiber)  
- 무선(Wi-Fi, LTE, 5G)

<aside>OSI 7계층 모델</aside>

OSI 모델은 네트워크 통신을 7단계로 나눈 개념적 모델이다.

1. 물리 계층 – 전기적 신호, 케이블  
2. 데이터 링크 계층 – MAC 주소, 프레임  
3. 네트워크 계층 – IP 주소, 라우팅  
4. 전송 계층 – TCP, UDP  
5. 세션 계층 – 세션 관리  
6. 표현 계층 – 인코딩, 암호화  
7. 응용 계층 – HTTP, FTP, SMTP  

실무에서는 TCP/IP 4계층 모델이 더 많이 사용된다.

<aside>주요 프로토콜</aside>

- **IP**: 논리적 주소 지정  
- **TCP**: 신뢰성 보장, 연결 지향  
- **UDP**: 빠른 전송, 비연결  
- **HTTP/HTTPS**: 웹 통신  
- **DNS**: 도메인 → IP 변환  
- **ARP**: IP → MAC 주소 변환  

<aside>주소 체계</aside>

- **IP 주소**  
  - IPv4: 32bit  
  - IPv6: 128bit  

- **MAC 주소**  
  - 네트워크 장치 고유 주소  

- **포트 번호**  
  - 서비스 식별 (HTTP 80, HTTPS 443 등)

<aside>네트워크 성능 지표</aside>

- **대역폭(Bandwidth)**: 전송 용량  
- **지연(Latency)**: 전송 시간  
- **처리량(Throughput)**: 실제 전송량  
- **패킷 손실(Packet Loss)**  

성능은 사용자 체감 품질(QoS)에 직접적인 영향을 준다.

<aside>네트워크 보안</aside>

- 방화벽(Firewall)  
- IDS/IPS  
- VPN  
- TLS/HTTPS  
- 인증 및 접근 제어  

네트워크는 외부 공격의 주요 표적이므로 보안 설계가 필수다.

<aside>현대 네트워크 트렌드</aside>

- 클라우드 네트워크(AWS, GCP, Azure)  
- SDN / NFV  
- 컨테이너 네트워킹(Kubernetes)  
- 제로 트러스트 네트워크  
- 5G·IoT 네트워크  

<aside>핵심 정리</aside>

- 네트워크는 모든 IT 시스템의 기반  
- 계층 구조와 프로토콜을 통해 안정적 통신 제공  
- 주소·라우팅·보안이 핵심 요소  
- 클라우드·모바일 시대에 따라 지속적으로 진화 중
