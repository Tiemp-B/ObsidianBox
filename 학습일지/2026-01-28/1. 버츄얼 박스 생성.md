## 목적
1. 오라클 버츄얼 박스를 생성
	1) 컴퓨터에선 headless로 실행
2. 태블릿으로 접근
	1) CLI 접근
	2) GUI 접근

## 방법

### 1. 버츄얼 박스 생성
 사용할 ISO는 두가지이다. 리눅스 마스터 1급의 경우 커널 4.x 이상의 리눅스를 사용한다.
이는 레드햇 계열에서 RHEL/Rocky Linux 8, 데비안 계열에서 ubuntu 18.04 이상을 의미한다.
실기에선 Rocky Linux 8.8를 사용하게 된다. 
 그 중에서도 안정된 버전이고 한창 많이 기업에서 사용된 버전인 Rocky Linux 8.10과 ubuntu 22.04를 쓸 생각이다.

### 2. 우분투 세팅
1) 설치 및 세팅
	설치는 ISO 파일과 오라클 버츄얼박스를 사용하였다.
	포트 세팅은 다음과 같다.
	- 호스트 포트 2222로 접근시 22 로 SSH 접속
	- 호스트 포트 3389로 접근시 3389로 xrdp 접속
2) 필요 패키지 설치
	원격 SSH, 원격 GUI 실행용 패키지를 설치하고 systemctl 등록을 한다
	```bash
	# ubuntu용
	sudo apt install openssh-server xrdp xfce4 xfce4-goodies
	
	sudo systemctl enable ssh
	sudo systemctl enable xrdp
	
	echo "xfce4-session" > ~/.xsession
	sudo systemctl restart xrdp 
	```

Rocky 리눅스의 경우 일반적으로 ssh가 설치되어 있다.
```bash
# Rocky 용
sudo dnf install epel-release -y

sudo dnf install xrdp -y
sudo dnf inst

```
