## 이 자격증 고유의 결정 사항

- **개요 규칙 적용 시점 (2026-08-01 확정)**: 로봇소프트웨어개발기사는 기존 작업분과의 소급 문제 때문에 "4. 로봇 응용 소프트웨어 개발부터"로 제한했지만, 로봇하드웨어개발기사는 착수 시점에 완료된 세세항목이 전혀 없었으므로 **예외 없이 첫 세부항목부터(과목1 "1. 로봇 액추에이터 드라이버 요구사항 분석"부터) 개요 규칙을 전체 적용**한다. 모든 세부항목 폴더의 1번 페이지는 개요 페이지여야 한다.
