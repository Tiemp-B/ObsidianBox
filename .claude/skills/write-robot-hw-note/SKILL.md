## 필기 출제기준 전체 구조 (2026-08-01 확인)

과목 4개, 주요항목 11개, 세부항목 22개, 세세항목 51개. 실기 출제기준(작업형, 회로설계/PCB제작/펌웨어작성/조립 등)도 함께 대조해 확보함 — 실기 전용 내용(회로도 상세 설계, PCB 레이아웃 실제 작업, 펌웨어 소스 코드 작성, 조립·배선 절차, 테스트 지그 제작 등)은 필기 페이지에서 제외 대상.

- **1.로봇드라이버설계** (필기 20문제)
  - 1. 로봇 액추에이터 드라이버 개념 설계: 1) 요구사항 분석(액추에이터 종류/규격, 액추에이터용 센서, 제어방식) 2) 사양 설계(구동 드라이버 사양, 센서 인터페이스, 통신방식)
  - 2. 로봇 액추에이터 드라이버 회로 설계: 1) 회로 설계(회로설계, 레이아웃설계) 2) 보드 제작(보드 제작, 구동 테스트)
- **2.로봇제어부설계** (필기 20문제)
  - 1. 로봇 모션 제어기 하드웨어 구조 설계: 1) 요구사항 분석(모션제어 특성, 위치/속도 알고리즘) 2) 구조 설계(모션제어 프로파일, 모션제어 구조)
  - 2. 로봇 모션 제어기 회로 설계: 1) 회로 설계(회로설계, 인터페이스설계) 2) 구동 코드 작성(펌웨어/인터페이스/인터럽트 프로그램 — 필기 범위 여부 주의, 실기 "구동 코드 작성하기"와 경계 확인 필요)
  - 3. 로봇 MCU 하드웨어 개념 설계: 1) 요구사항 분석(MCU 사양분석, 입출력 신호처리, 노이즈 분석) 2) 회로사양 설계(시스템 사양설계, 주변기기간 신호처리)
  - 4. 로봇 MCU 하드웨어 회로 설계: 1) 회로 설계(MCU/주변기기 회로설계, 노이즈 대책, 전원 공급 설계) 2) 구동 코드 작성(구동 프로그램, 디버깅, 주변기기 동기화)
- **3.로봇센서및신호처리** (필기 20문제)
  - 1. 로봇 센서 신호처리 개념 설계: 1) 요구사항 분석(센서 종류/특성, 신호 요구분석, 신호 보정) 2) 특성 분석(신호처리 특성, 신호 최적화)
  - 2. 로봇 센서 신호처리부 설계: 1) 데이터 신호처리부 설계(신호처리부 설계, 신호 신뢰성 확보) 2) 신호처리부 구동(센서 구동, 데이터 측정 분석)
- **4.로봇시스템통합및시험평가** (필기 20문제)
  - 1. 로봇 하드웨어 아키텍처 구조 설계: 1) 구조 설계(아키텍처 구조, 컴포넌트 구성) 2) 시뮬레이션(아키텍처 시뮬레이션, 시뮬레이션 신호분석)
  - 2. 로봇 시스템 사양 설계: 1) 시스템 요구사항 분석(시스템 사양, 아키텍처 개발 유효성 검토, 구성 검토)
  - 3. 로봇 시스템 통합: 1) 시스템 설계(통합 설계, 최적화) 2) 시스템 조립(조립, 조립 검사 및 수정 — 실기 경계 주의) 3) 시스템 시험평가(평가절차, 시험평가)
  - 4. 로봇 하드웨어 시험평가: 1) 시험 평가 절차 설계(평가절차, 구동 특성) 2) 하드웨어 시험(시험환경, 시험 장비) 3) 하드웨어 평가(시험평가, 적합성 판단 기준, 결과분석)

주의: 과목2의 "구동 코드 작성"류 세부항목(펌웨어/인터페이스/인터럽트 프로그램, MCU 구동 프로그램·디버깅)은 이름만 보면 실기(코드 작성)처럼 보이지만 필기 출제기준에 명시된 세부항목이므로 제외하지 않는다 — 다만 실제 소스코드 작성·문법 암기가 아니라 "개념/원리/설계 시 고려사항" 수준(인터럽트 우선순위 개념, 디버깅 기법의 종류, 동기화 방식의 원리 등)으로 필기 성격에 맞게 다뤄야 한다. NCS 학습모듈 확보 후 "필요 지식" 절로 재검증할 것.
