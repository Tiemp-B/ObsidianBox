# Summary

전송 선로의 끝단에 다는, 선로의 특성 임피던스와 같은 값의 저항. 선로 끝의 임피던스 불연속을 없애 [[신호 반사(Signal Reflection)|신호 반사]]를 흡수하고 링잉·오버슈트를 막는다. (차동 버스에서 보통 100~120Ω)

# Notes

<aside>역할</aside>

- 선로 끝단의 임피던스 불연속을 없애 **신호 반사를 흡수** → 파형 왜곡(링잉·오버슈트) 방지
- 차동 버스([[Developer/통신/직렬 통신/RS-422|RS-422]]·[[Developer/통신/직렬 통신/RS-485|RS-485]]·[[CAN(Controller Area Network)|CAN]])에서 보통 **100~120Ω** (선로 특성 임피던스에 정합)
- 관련: [[임피던스 매칭(Impedance Matching)]]

<aside>위치(종류)</aside>

- **수신 보드에 존재**: 수신기 보드에 내장
- **케이블에 탑재**: 케이블·커넥터 쪽에 장착

<aside>중간 수신기에 종단 저항 설정 시 (조합별 현상)</aside>

| 중간 | 마지막 | 현상 |
|---|---|---|
| 미설정 | 미설정 | 신호 반사 발생 |
| 설정 | 미설정 | 중간에서 반사현상 발생 + 마지막에 종단저항이 없어 반사 → **링잉·오버슈트** |
| 설정 | 설정 | 종단저항이 **병렬**이 되어 드라이버 전류 증가 → **발열 증가** |

- 원칙: 종단 저항은 **버스의 양 끝단에만** 설치(중간 노드에는 설치하지 않음)

---

<aside>핵심 정리</aside>

- 종단 저항 = 선로 끝 반사를 흡수하는 특성 임피던스 정합 저항(차동 버스 보통 120Ω)
- 양 끝단에만 설치 — 중간에 달면 반사, 양끝 외 추가 시 병렬로 발열 문제
