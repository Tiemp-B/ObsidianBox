# Summary

여러 신호선(또는 클럭)의 신호가 수신 측에 **서로 다른 시각에 도착해 생기는 시간 차**. 선마다 전파 지연이 미세하게 달라 생기며, 병렬·고속 통신에서 오류의 원인이 된다.

# Notes

<aside>원인</aside>

- 선마다 **길이·임피던스·부하·배선 경로**가 미세하게 달라 **전파 지연(propagation delay)**이 제각각
- 병렬 전송에서 같은 순간 보낸 비트들이 **서로 다른 시각에 도착**

<aside>영향</aside>

- 고속일수록 비트 간격(주기)이 짧아져, 작은 skew도 **샘플링 시점에 비트가 뒤섞여** 오류를 유발
- **병렬 통신이 고속·장거리에서 불리한 핵심 이유** (직렬은 선이 하나라 선 간 skew가 없음)

<aside>종류와 완화</aside>

- **데이터 스큐(data skew)**: 데이터선 간 도착 시간 차
- **클럭 스큐(clock skew)**: 클럭이 각 지점에 도달하는 시간 차
- 완화: **선 길이 맞추기(length matching)**, 전송 속도 제한, 소스 동기 클럭, 고속에선 병렬 대신 **직렬화(SerDes)** 채택
