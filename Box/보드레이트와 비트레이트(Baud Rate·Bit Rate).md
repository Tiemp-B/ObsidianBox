# Summary

**보드레이트**는 초당 신호(심볼) 변화 횟수, **비트레이트**는 초당 전달되는 비트 수. 한 심볼에 여러 비트를 실으면 비트레이트가 보드레이트보다 커진다.

# Notes

<aside>정의</aside>

- **보드레이트(baud rate)**: 초당 **심볼(신호 상태) 변화 횟수**. $baud = 1 / T_s$
  - **심볼(symbol)**: 일정 시간 동안 유지되는 하나의 신호 상태
  - **$T_s$**: 심볼 주기(한 심볼이 유지되는 시간)
- **비트레이트(bit rate)**: 초당 전달되는 **비트 수** `[bps]`

<aside>관계</aside>

$$\text{비트레이트} = \text{보드레이트} \times (\text{심볼당 비트 수})$$

- 한 심볼이 1비트만 실으면 **비트레이트 = 보드레이트** (예: 기본 UART)
- 한 심볼이 여러 비트를 실으면(다중 레벨·위상 변조) **비트레이트 > 보드레이트**
