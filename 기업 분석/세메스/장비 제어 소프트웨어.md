# 장비 제어 소프트웨어

## 개요
반도체 제조 장비의 동작을 제어하고 모니터링하는 소프트웨어 시스템으로, 공정의 정밀도와 안정성을 보장하는 핵심 기술

---

## 주요 구성 요소

### 1. Equipment Control System (ECS)
**장비 제어 시스템**
- 실시간 장비 제어 및 동작 시퀀스 관리
- 센서 데이터 수집 및 처리
- 액추에이터 제어
- 알람 및 인터록 관리

### 2. Recipe Management
**레시피 관리**
- 공정 레시피 생성 및 편집
- 레시피 버전 관리
- 파라미터 설정 및 검증
- 레시피 실행 및 모니터링

### 3. Process Control
**공정 제어**
- [[PID 제어]]
- 피드백 제어 루프
- APC (Advanced Process Control)
- 공정 데이터 로깅

### 4. Communication Interface
**통신 인터페이스**
- SECS/GEM (SEMI E4/E5/E30)
	- 반도체 및 디스플레이 제조 설비와 공장 호스트 시스템 간의 표준화된 통신 규약으로, 장비의 상태 정보 수집, 원격 제어, 데이터 교환을 위해 사용
- Host 통신
- 장비 간 통신
- IoT 연동

---

## 소프트웨어 아키텍처

### Real-Time Control Layer
- RTOS 기반 실시간 제어
- 하드웨어 추상화 계층 (HAL)
- Device Driver
- 타이밍 크리티컬 작업 처리

### Application Layer
- HMI (Human Machine Interface)
- 데이터 분석 및 시각화
- 리포팅 시스템
- 유지보수 도구

### Integration Layer
- MES(Manifacture Execute System) 연동
	- 생산 현장의 [MES(제조 실행 시스템)](https://www.google.com/search?q=MES%28%EC%A0%9C%EC%A1%B0+%EC%8B%A4%ED%96%89+%EC%8B%9C%EC%8A%A4%ED%85%9C%29&oq=MES+%EC%97%B0%EB%8F%99&gs_lcrp=EgZjaHJvbWUqBwgAEAAYgAQyBwgAEAAYgAQyBggBEAAYHjIGCAIQABgeMggIAxAAGAgYHjIKCAQQABiiBBiJBTIICAUQABgFGB4yCAgGEAAYBRgeMggIBxAAGAUYHtIBCDIzMDhqMGo3qAIAsAIA&sourceid=chrome&ie=UTF-8&ved=2ahUKEwi6nIug1MORAxXTzTQHHf_nHCMQgK4QegQIARAC)와 ERP, 설비(PLC) 등 다양한 시스템을 실시간으로 연결하여 데이터를 통합하고 자동화함으로써, 생산 계획부터 실행, 모니터링, 분석까지 전 과정을 최적화하고 스마트 공장을 구축하는 것을 의미
- FDC (Fault Detection and Classification)
	- 
- SPC (Statistical Process Control)
- 데이터베이스 연동

## 표준 및 규격

### SEMI 표준
- **SEMI E4**: SECS-I (Serial Equipment Communication Standard)
- **SEMI E5**: SECS-II (Message Content)
- **SEMI E30**: GEM (Generic Equipment Model)
- **SEMI E84**: Enhanced Carrier Handoff
- **SEMI E87**: Carrier Management
- **SEMI E90**: Substrate Tracking
- **SEMI E94**: Control Job Management

### 기타 표준
- OPC UA (통신 표준)
- MQTT (IoT 통신)
- IEEE 표준
