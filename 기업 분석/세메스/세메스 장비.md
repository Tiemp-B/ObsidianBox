Prober 동작: 
- 웨이퍼 로드
- 위치 정렬
- 프로브 카드 접촉
- 테스터와 연동
- 수백~수천개의 접점 동시 접촉
- 전압 전류, 주파수 특성 측정, 기능 테스트
- 결과 기록

테스트 핸들러 동작:
패키징 완료된 반도체를 자동으로 테스터에 공급하고, 테스트 결과에 따라 분류
- 칩 공급
- 테스터 소켓 장착
- 테스트 수행
- 판정 및 분류
