# Summary

PID 하나만으로 부족한 성능을 보완하는 4가지 보상 기법: 지연 없이 미리 대응하는 **피드포워드**, 마찰력 자체를 모델링해 상쇄하는 **마찰 보상**, 모델 불확실성·외란을 추정해 제거하는 **외란 관측기**, 로봇 자중에 의한 처짐을 상쇄하는 **중력 보상**.

# Notes

<aside>피드포워드(Feedforward) 제어</aside>

- 출력을 되먹임하지 않고, **입력(지령)을 기반으로 미리 보정 신호를 추가**하는 방식
- 피드백 제어(오차 발생 후 대응)와 달리 지연 없이 즉각 대응 가능 → 핵심 장점은 **응답성(응답 속도) 향상**
- 한계: 모델 정확도에 의존, 단독으로는 외란 대응 불가 → 보통 피드백 제어와 결합해서 사용

<aside>마찰 보상(Friction Compensation)</aside>

- 실제 사용되는 방법: **쿨롱 마찰 모델 적용**, **점성 마찰 보상**, **관측기 기반 마찰 추정**, **LuGre 모델**(쿨롱·점성·스틱-슬립·스트라이벡 효과까지 포함하는 동적 마찰 모델, 피드포워드 보상기로 활용)
- **"적분 제어기 게인 증가"는 마찰 보상 기법이 아니다** — 이는 일반적인 PID 튜닝 행위이지, 마찰 자체를 모델링해 상쇄하는 방법이 아니므로 "마찰 보상 방법으로 부적절한 것"을 묻는 문제의 정답이 된다

<aside>외란 관측기(Disturbance Observer, DOB)</aside>

- 1989년 게이오대 오니시 코헤이 교수 그룹이 처음 제안
- 목적: **모델 불확실성과 외부 외란이 시스템에 미치는 영향을 추정하여 보상(제거)**
- 모터 제어·로봇 매니퓰레이터 제어에 널리 쓰이는 대표적 강인제어 기법
- 상태 피드백 제어기의 상태 추정기(옵저버) 역할도 겸할 수 있음

<aside>중력 보상(Gravity Compensation)</aside>

- 로봇 동역학 방정식의 중력항 g(q)에 해당하는 토크를 액추에이터가 상시 부담해야 하는 문제를 사전에 상쇄
- 목적: 정지 상태에서도 링크 무게에 의한 처짐 없이 **정적 평형(static equilibrium)** 유지

---

<aside>핵심 정리</aside>

- 4가지 보상 기법은 각각 다른 문제를 겨냥: 피드포워드=응답 지연, 마찰보상=마찰력, 외란관측기=모델불확실성/외란, 중력보상=자중에 의한 정적 처짐
- 마찰 보상의 실제 기법(쿨롱·점성·관측기·LuGre)과 "적분 게인 증가"(일반 PID 튜닝)를 혼동하지 않는다
