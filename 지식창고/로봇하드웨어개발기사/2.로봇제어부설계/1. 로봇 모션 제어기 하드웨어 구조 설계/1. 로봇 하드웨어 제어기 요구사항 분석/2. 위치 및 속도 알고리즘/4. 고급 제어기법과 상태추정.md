# Summary

PID·보상 기법을 넘어서는 고급 제어기법(슬라이딩모드·강인/적응제어·백스테핑·MPC·임피던스·토크제어)과, 상태를 직접 측정할 수 없을 때 필요한 상태추정 이론(상태공간·가관측성·칼만필터), 그리고 서보 시스템의 진동/안정성 이슈를 다룬다.

# Notes

<aside>슬라이딩 모드 제어(SMC)</aside>

- 강인제어 기법의 하나. 상태가 **슬라이딩 표면(초평면)**에 수렴한 이후에는 모델 불확실성·외란의 영향을 거의 받지 않는 **강건성(robustness)·불변성(invariance)**이 핵심 특징

<aside>강인제어 vs 적응제어</aside>

| 구분 | 강인제어(Robust Control) | 적응제어(Adaptive Control) |
|---|---|---|
| 방식 | 미리 정한 파라미터 변동 범위 안에서 **고정된** 보상기 설계 | 실시간으로 플랜트 파라미터를 **추정하며 제어법칙을 갱신** |
| 목적 | 모델 불확실성에 대한 강인성 확보 | **시스템 파라미터 변화**에 대응 |

<aside>백스테핑(Backstepping) 제어</aside>

- 복잡한 **비선형 시스템**을 여러 하위 시스템으로 나누고, 각각에 리아푸노프 함수를 재귀적으로 설계·통합해 전체 제어입력을 구성하는 **체계적 설계법**
- Strict-feedback 형태로 변환 가능한 비선형 시스템에 적용

<aside>모델예측제어(MPC)</aside>

- 시스템의 동적 모델로 **미래 거동을 예측**하며, 제약조건을 만족하는 범위에서 비용함수를 최적화하는 제어 입력을 매 시점 재계산(수신 지평선 제어)
- PID와 달리 **제약조건을 직접 다룰 수 있음**이 특징

<aside>임피던스 제어</aside>

- 로봇과 환경 사이의 상호작용력을 로봇의 임피던스(가상 스프링-댐퍼)로 조절
- 목적: **환경/인간과의 안전한 상호작용(접촉력) 제어** — 위치 정확도 자체가 목적이 아님

<aside>토크(힘) 제어</aside>

- 액추에이터가 내는 힘/토크 자체를 지령대로 추종 → **힘/토크 제어에 적합**, 접촉 작업에서 임피던스 제어의 하위 계층으로도 쓰임

<aside>상태공간 표현과 가관측성</aside>

- **상태공간 표현의 장점**: 미분방정식을 행렬로 표현해 **다입력-다출력(MIMO) 시스템**을 통일된 틀로 해석·설계 가능
- **가관측성(Observability)**: 출력만 관측해서 내부 **상태를 추정(재구성)할 수 있는지**를 나타내는 성질. 모든 상태를 직접 측정할 수 없을 때 옵저버(칼만 필터 등)로 상태를 추정할 수 있는지의 근거

<aside>칼만 필터(Kalman Filter)</aside>

- 노이즈가 포함된 측정치로부터 선형 동적 시스템의 상태를 추정하는 **재귀 필터**
- 예측(현재 상태·정확도 예측) → 갱신(측정치 오차 반영)의 2단계 반복
- 용도: **노이즈가 있는 센서 데이터의 상태 추정**(로봇 위치추정 등)

<aside>서보 시스템의 관성 부정합과 진동 억제</aside>

- 부하-모터 관성비가 크면 기계 공진으로 속도루프 안정성 저하
- 표준 해법: **저역통과 필터 추가**(또는 노치 필터로 공진 주파수 억제) — 위치 게인을 올리거나 토크 대역폭을 낮추는 것은 안정성/응답성을 오히려 해침
- **관성 모멘트와 응답 속도**: 뉴턴 운동방정식(토크=관성×각가속도) 상 관성 모멘트가 **클수록 같은 토크로 낼 수 있는 각가속도가 작아져 응답이 느려진다**

---

<aside>핵심 정리</aside>

- 강인제어=고정 보상기(불확실성 범위 내), 적응제어=실시간 파라미터 추정+제어법칙 갱신 — 목적어가 다르다("불확실성 대응" vs "파라미터 변화 대응")
- 가관측성은 "출력→상태 추정 가능성", 칼만필터는 그 추정을 실제로 수행하는 대표 알고리즘
- 관성 부정합 문제는 게인을 올리는 게 아니라 필터로 루프 이득을 정형화해서 해결한다
