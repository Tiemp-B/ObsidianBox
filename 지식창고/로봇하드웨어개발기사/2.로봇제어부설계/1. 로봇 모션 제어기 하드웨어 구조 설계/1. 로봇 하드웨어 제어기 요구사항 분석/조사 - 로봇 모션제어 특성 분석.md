# 조사 — 로봇 모션제어 특성 분석

## A. NCS 대조 결과

NCS 학습모듈 `LM1903080117/118 로봇 모션 제어기 하드웨어 설계`의 **학습1 "로봇 모션 제어기 하드웨어 요구 사항 분석하기" 중 1-1 "모션 제어기 구조 정의"**(필요지식, 원문 footer p.3~17)가 이 세세항목에 직접 대응한다. (1-2 "모션 제어 칩 선정"은 반도체/IC 분류 내용으로 이 세세항목보다는 이후 MCU 하드웨어 세부항목과 더 관련이 깊어 별도 보류.)

NCS 필요지식 핵심 내용:

1. **모션 제어의 정의**: 서보 제어의 한 부분으로, 위치·속도를 제어하여 정해진 프로파일을 추종하도록 하는 제어.
2. **모션 제어 시스템의 구성 요소**(6가지): 응용 소프트웨어(Application Software) → 모션 제어기(Motion Controller) → 증폭기/드라이브(Amp/Drive) → 모터(Motor) → 기계적 요소(Mechanical Element) → 피드백 디바이스(Feedback Device)가 폐루프를 구성.
3. **모션 제어의 3가지 종류**:
   - **시퀀스 제어**: KS C 0103(시퀀스 제어 기호) 규격 기반, PLC와 래더 다이어그램으로 구현.
   - **속도 제어**: 타코제너레이터 또는 광학식 엔코더로 속도 피드백, PLL(위상동기루프) 제어 언급.
   - **위치 제어**: 속도 제어를 포함하는 상위 루프. 서보드라이버를 아날로그(속도형)와 펄스(위치형)로 구분.
4. **상위/하위 제어기 계층 구조**: 1977년 미국표준국(NBS)이 제안, 1981년 ALBUS가 채택한 5단계 계층(System → Workstation → Elemental Move → Primitive Function → Servo Control).
5. **로봇 제어시스템 하드웨어 구조**: 마이크로프로세서 기반, Program Memory + Executive Processor + Computations Processor + Joint1~6 각 관절별 서보 피드백 제어.
6. **집중형(centralized) vs 네트워크형(distributed/network) 모션제어기**: 집중형은 케이블 직결·고응답성·시간지연 거의 없음이나 다수 모터 동기가 어려움. 네트워크형은 공유 전선으로 시간지연이 발생하나 다수 모터에 유리해 최근 더 많이 쓰임.
7. **모션 제어기 확보의 3가지 방식**: ① 상용 모션 제어기 사용(안정적이나 고가) ② 상용 하드웨어 + 알고리즘 자체 구현(저렴하나 개발 필요) ③ 직접 설계·제작(최소 비용이나 매우 높은 기술 수준 요구).

## B. 웹 검색 결과

1. **NBS 계층적 제어의 원출처**: Anthony J. Barbera가 1977년 12월 NBS Special Publication 500-23 "An Architecture for a Robot Hierarchical Control System"을 발표했고, James S. Albus 등이 이를 발전시켜 NASA/NBS Standard Reference Model(NASREM)로 정리했다. 계층 구조는 트리 형태로, 각 모듈이 상위 하나·하위 여럿을 가지며 상위로 갈수록 계획 범위(planning horizon)가 길어진다. — [NIST: Hierarchical Control for Robots in an Automated Factory](https://www.nist.gov/publications/hierarchical-control-robots-automated-factory), [NIST 1977 원문](https://tsapps.nist.gov/publication/get_pdf.cfm?pub_id=820181)
2. **KS C 0103**: "시퀀스 제어 기호(Sequence control symbols)"를 규정한 한국산업표준으로, 1978년 제정되었다. NCS 교재의 "KS C 0103" 언급은 시퀀스 제어에 쓰이는 기호 표준을 가리킨다. — [한국표준정보망 KS C 0103](https://www.kssn.net/search/stddetail.do?itemNo=K001010004931)
