# 조사 — 위치 및 속도 알고리즘

## A. NCS 대조 결과

NCS 학습모듈 117/118의 학습1(1-1, 1-2)에는 PID·상태공간·강인제어 등 알고리즘 자체에 대한 필요지식이 없다. 이 세세항목은 **문제은행 32문항**(전체 2위 규모) 전량이 웹 조사·도메인 지식으로 작성해야 하는 항목이다. 문제은행 문항을 주제별로 묶으면: PID 기본·게인 효과(9문항), 피드포워드·마찰보상·외란관측기·중력보상(6문항), 슬라이딩모드·강인/적응제어·백스테핑·MPC·임피던스·토크제어(9문항), 상태공간·가관측성·칼만필터(3문항), 서보 안정성(관성부정합·필터·관성모멘트)(3문항), Ziegler-Nichols(1문항), 관성모멘트-응답 관계(1문항) 로 나뉜다.

## B. 웹 검색 결과

1. **PID 게인의 개별 효과**: P 게인 증가 → 응답 속도 향상, 오버슈트 증가(게인과 오버슈트가 비례). I 게인 증가 → 정상상태 오차 감소(궁극적으로 0에 수렴), 단 응답이 빨라지되 과도하면 오버슈트·와인드업 유발. D 게인 증가 → 오차 변화율에 반대로 작용해 오버슈트 억제, 상승시간·정착시간 단축. 요약: P=속도, I=오차 제거, D=오버슈트 억제. — [PID 제어 정리](https://pus0319.github.io/embedded_control/PIDCONTROL/), [PID 제어기](https://velog.io/@brillianthhj/PID-%EC%A0%9C%EC%96%B4%EA%B8%B0)
2. **Ziegler-Nichols 튜닝법**: 1942년 발표. 플랜트의 수학적 모델을 몰라도 개루프/폐루프 응답만으로 Kp·Ki·Kd 초기값을 경험적으로 결정하는 방법으로, 스텝 응답에서 최대 오버슈트 약 25%를 목표로 하는 실험적 초기 튜닝 규칙(최적해는 아님). → 목적은 "제어기 이득값의 자동/경험적 조정". — [Ziegler-Nichols PID tuning method, Cal Poly Pomona](https://www.cpp.edu/faculty/fkhoshnoud/lab-8-zieglernichols-pid-tuning-method.pdf)
3. **슬라이딩 모드 제어(SMC)**: 강인제어 기법의 하나로, 상태가 슬라이딩 표면(초평면)에 수렴한 이후에는 모델 불확실성·외란의 영향을 거의 받지 않고 안정적으로 목표점에 수렴하는 강건성(robustness)·불변성(invariance)이 핵심 특징. — [SMC 개념, 고려대](https://sejong.korea.ac.kr/mbshome/mbs/emse/subview.do?id=emse_040300000000)
4. **외란 관측기(DOB)**: 1989년 게이오대 오니시 코헤이(Kouhei Ohnishi) 교수 그룹이 처음 제안. 모델 불확실성과 외부 외란이 시스템에 미치는 영향을 추정하여 이를 보상(제거)하는 것이 목적으로, 모터 제어·로봇 매니퓰레이터 제어에 널리 쓰이는 강인제어 기법. — [외란관측기 기반 제어 연구 동향, 제어로봇시스템학회](https://www.dbpia.co.kr/journal/articleDetail?nodeId=NODE11745354)
5. **임피던스 제어**: 로봇과 환경 사이의 상호작용력을 로봇의 임피던스(가상 스프링-댐퍼 특성)를 조절해 제어하는 기법으로, 목적은 "환경/인간과의 안전하고 에너지 효율적인 상호작용(접촉력) 제어"이며 위치 정확도 자체보다 접촉 시 힘 반응 특성 제어에 초점. — [Impedance Control, Clemson OpenTextbook](https://opentextbooks.clemson.edu/wangrobotics/chapter/impedance-control/)
6. **백스테핑(Backstepping) 제어**: 복잡한 비선형 시스템을 여러 개의 하위 시스템으로 나누고 각 하위 시스템에 리아푸노프 함수를 재귀적으로 설계·통합해 전체 제어 입력을 구성하는 체계적 설계법. Strict-feedback 형태로 변환 가능한 비선형 시스템에 적용. — [백스테핑 제어기법, DBpia](https://www.dbpia.co.kr/Journal/articleDetail?nodeId=NODE02050468)
7. **모델예측제어(MPC)**: 시스템의 동적 모델로 미래 거동을 예측하며, 제약조건을 만족시키는 범위에서 비용함수를 최적화하는 제어 입력을 매 시점 다시 계산(수신 지평선 제어, receding horizon). "미래 예측 기반 최적 제어"가 핵심 특징이며 PID와 달리 제약조건을 직접 다룰 수 있음. — [모델 예측 제어, 위키백과](https://ko.wikipedia.org/wiki/%EB%AA%A8%EB%8D%B8_%EC%98%88%EC%B8%A1_%EC%A0%9C%EC%96%B4)
8. **LuGre 마찰 모델**: 쿨롱 마찰·점성 마찰뿐 아니라 스틱-슬립(stick-slip), 스트라이벡(Stribeck) 효과까지 포함하는 동적 마찰 모델로, 서보 시스템의 위치제어 정밀도를 높이기 위한 피드포워드 마찰 보상기 설계에 사용된다. — [LuGre 모델 기반 마찰력 보상, KoreaScience](https://koreascience.kr/article/JAKO201110949597463.pdf)
9. **중력 보상**: 로봇 동역학 방정식의 중력항 g(q)에 해당하는 토크를 액추에이터가 상시 부담하는 문제를 보상해, 정지 상태에서도 링크 무게에 의한 처짐 없이 정적 평형(static equilibrium)을 유지하도록 하는 기법. — [Gravity compensation in robotics](https://www.tandfonline.com/doi/full/10.1080/01691864.2015.1090334)
10. **피드포워드 제어**: 출력을 되먹임하지 않고 입력(지령)을 기반으로 미리 보정 신호를 추가하는 방식. 피드백 제어(오차 발생 후 대응) 대비 지연 없이 즉각 대응할 수 있어 **응답성(응답 속도) 향상**이 핵심 장점이며, 정확도는 모델 정밀도에 의존한다. — [Feedforward 제어 알고리즘: 장점과 한계](https://seo.goover.ai/report/202409/go-public-report-ko-f39d4778-1284-4031-b3aa-66dace3c3f19-0-0.html)
11. **적응제어 vs 강인제어**: 강인제어는 미리 정해진 파라미터 변동 범위 안에서 항상 동작하도록 고정된 보상기를 설계(제어법칙을 바꾸지 않음). 적응제어는 실시간으로 플랜트 파라미터를 추정하며 제어법칙 자체를 갱신한다 — 즉, "시스템 파라미터 변화(불확실성)에 대응해 제어기를 스스로 조정"하는 것이 적응제어의 정의적 특징. — [Fundamental limitations and differences of robust and adaptive control](https://www.researchgate.net/publication/3912152_Fundamental_limitations_and_differences_of_robust_and_adaptive_control)
12. **가관측성(Observability)**: 시스템 출력의 관측만으로 내부 상태 변수를 추정(재구성)할 수 있는지를 나타내는 성질. 상태 피드백 제어기를 구성하려면 상태 변수가 필요한데, 모든 상태를 직접 측정할 수 없을 때 관측기(옵저버, 예: 칼만 필터)로 상태를 추정하며, 이 추정이 가능한지를 판단하는 근거가 가관측성이다. — [Observability, Wikipedia](https://en.wikipedia.org/wiki/Observability)
13. **칼만 필터**: 노이즈가 포함된 측정치로부터 선형 동적 시스템의 상태를 추정하는 재귀 필터. 예측(현재 상태·정확도 예측) → 갱신(측정치와의 오차 반영)의 2단계 반복. 로봇의 위치추정(localization) 등에서 센서 노이즈를 걸러내고 상태를 추정하는 용도로 쓰인다. — [칼만 필터, 위키백과](https://ko.wikipedia.org/wiki/%EC%B9%BC%EB%A7%8C_%ED%95%84%ED%84%B0)
14. **서보 드라이버의 관성 부정합과 진동 억제**: 부하-모터 관성비가 크면 기계 공진에 의한 진동으로 속도루프 안정성이 저하된다. 상용 서보 드라이버는 기계 공진을 검출해 자동으로 노치/저역통과 필터 특성을 설정하는 적응 필터 기능으로 진동을 억제한다(고주파 공진은 노치 필터, 저주파 잔류진동은 별도 진동억제 알고리즘). 즉 관성 부정합에 의한 불안정 문제의 표준적 해법은 **필터(저역통과/노치)를 통한 루프 이득 정형화**이며, 위치루프 게인을 올리거나 토크 대역폭을 낮추는 것은 오히려 안정성을 해치거나 응답성을 희생시킨다. — [서보시스템, 제대로 이해하기](https://motioncontrol.co.kr/technical-info?tpf=board%2Fview&board_code=2&code=875)

## C. 결론(도메인 지식으로 보완, 검색 불필요한 기초 사실)

- **P/PI/PD 제어기 특징**: P는 정상상태 오차가 남는다(비례항만으로는 오차 0 불가). PI는 정상상태 오차를 제거하나 응답은 P 단독보다 느릴 수 있다. PD는 오버슈트를 줄이고 응답을 빠르게 하지만 정상상태 오차를 제거하지 못한다("빠른 응답과 안정성 제공"이 PD의 핵심 특징이며 "정상상태 오차 완전 제거"는 PD가 아니라 I항의 역할).
- **토크 제어 vs 위치/속도 제어**: 토크(힘) 제어는 액추에이터가 내는 힘/토크 자체를 지령대로 추종시키는 방식으로, 힘/토크 정밀도가 중요한 접촉 작업(임피던스 제어의 하위 계층으로도 쓰임)에 적합하다.
- **관성 모멘트와 응답 속도**: 뉴턴 운동방정식(토크=관성×각가속도) 상 관성 모멘트가 클수록 같은 토크로 낼 수 있는 각가속도가 작아지므로, 관성 모멘트가 클수록 응답이 느려진다.
- **상태공간 표현의 장점**: 시간영역 미분방정식을 행렬 형태로 표현하여 다입력-다출력(MIMO) 시스템을 하나의 통일된 틀로 해석·설계할 수 있다는 것이 전달함수 기반 표현 대비 가장 큰 장점이다.
- **마찰 보상 방법으로 부적절한 것 판별**: 쿨롱 마찰 모델·점성 마찰 보상·관측기 기반 마찰 추정은 모두 마찰 보상의 실제 기법이지만, "적분 제어기 게인 증가"는 마찰 보상 기법이 아니라 정상상태 오차를 줄이는 일반적인 PID 튜닝 행위이므로 마찰 보상 방법으로는 부적절하다.
