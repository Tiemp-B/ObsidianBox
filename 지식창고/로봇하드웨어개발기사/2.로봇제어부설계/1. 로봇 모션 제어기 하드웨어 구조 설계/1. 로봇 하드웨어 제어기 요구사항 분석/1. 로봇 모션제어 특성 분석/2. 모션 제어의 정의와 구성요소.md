# Summary

모션 제어는 응용SW·모션제어기·드라이브·모터·기계요소·피드백디바이스 6가지가 폐루프를 이루는 시스템이며, 제어 대상 변수에 따라 시퀀스·속도·위치제어의 3종류로 나뉜다.

# Notes

<aside>모션 제어의 정의</aside>

- **모션 제어(Motion Control)**: 서보 제어의 한 부분으로, 위치·속도를 제어하여 정해진 프로파일(경로)을 추종하도록 하는 제어

<aside>모션 제어 시스템의 6가지 구성요소(폐루프)</aside>

| 순서 | 구성요소 | 역할 |
|---|---|---|
| 1 | 응용 소프트웨어(Application Software) | 상위 명령·경로 생성 |
| 2 | 모션 제어기(Motion Controller) | 프로파일 생성, 제어 연산 |
| 3 | 증폭기/드라이브(Amp/Drive) | 제어 신호를 모터 구동 전력으로 증폭 |
| 4 | 모터(Motor) | 실제 구동 |
| 5 | 기계적 요소(Mechanical Element) | 감속기·전달기구 등 |
| 6 | 피드백 디바이스(Feedback Device) | 위치·속도 센서로 폐루프 구성 |

→ 이 6요소가 순환 경로(폐루프)를 이루어야 "모션 제어"가 성립한다.

<aside>모션 제어의 3가지 종류</aside>

| 종류 | 특징 |
|---|---|
| **시퀀스 제어** | KS C 0103(시퀀스 제어 기호) 규격 기반, PLC와 래더 다이어그램으로 구현 |
| **속도 제어** | 타코제너레이터 또는 광학식 엔코더로 속도 피드백, PLL(위상동기루프) 활용 |
| **위치 제어** | 속도 제어를 포함하는 상위 루프. 서보드라이버를 아날로그(속도형)/펄스(위치형)로 구분 |

- 위치 제어는 속도 제어를 내부 루프로 포함하는 상위 개념 — 즉 위치 제어기 안에 속도 제어 루프가 캐스케이드로 존재하는 구조

---

<aside>핵심 정리</aside>

- 모션 제어 = "응용SW→모션제어기→드라이브→모터→기계요소→피드백" 6요소 폐루프
- 3종류: 시퀀스(PLC/래더), 속도(타코/엔코더+PLL), 위치(속도제어를 포함하는 상위 루프)
