# Summary

로봇 제어는 NBS/ALBUS의 5단계 계층 구조로 표준화되었고, 실제 로봇 제어시스템 하드웨어는 이를 마이크로프로세서 기반으로 구현한다. 모션제어기는 배선 방식에 따라 집중형/네트워크형으로 나뉘며, 개발 시 상용 제품·자체 구현·직접 설계 중 하나를 선택해 확보한다.

# Notes

<aside>계층적 제어(hierarchical control)의 유래</aside>

- 1977년 미국표준국(NBS)의 Anthony J. Barbera가 계층적 로봇 제어 구조를 제안(NBS Special Publication 500-23)
- 1981년 James S. Albus 등이 이를 발전시켜 채택 — 이후 NASA/NBS 표준 참조 모델(NASREM)로 정리
- 구조는 **트리 형태**: 각 모듈은 상위 하나·하위 여럿을 가지며, 상위로 갈수록 계획 범위(planning horizon)가 길다

<aside>로봇 제어의 5단계 계층</aside>

| 계층 | 이름 | 역할 |
|---|---|---|
| 1(최상위) | System | 전체 작업 계획 |
| 2 | Workstation | 작업장 단위 조정 |
| 3 | Elemental Move | 기본 이동 단위 |
| 4 | Primitive Function | 원시 기능(관절별 동작) |
| 5(최하위) | Servo Control | 실제 서보 제어(모터 구동) |

- 상위 계층의 명령은 하위 계층으로 갈수록 더 단순한 명령으로 분해된다

<aside>로봇 제어시스템 하드웨어 구조</aside>

- 마이크로프로세서 기반: **Program Memory + Executive Processor + Computations Processor**가 상위 연산을 담당
- **Joint 1~6**: 각 관절마다 독립적인 서보 피드백 제어 루프를 가짐

<aside>집중형 vs 네트워크형 모션제어기</aside>

| 구분 | 집중형(centralized) | 네트워크형(distributed/network) |
|---|---|---|
| 배선 | 케이블 직결 | 공유 전선(버스) |
| 응답성 | 고응답성, 시간지연 거의 없음 | 시간지연 발생 |
| 다수 모터 동기 | 어려움 | 유리 |
| 최근 추세 | - | 더 많이 사용됨 |

<aside>모션제어기 확보의 3가지 방식</aside>

| 방식 | 장점 | 단점 |
|---|---|---|
| ① 상용 모션 제어기 사용 | 안정적 | 고가 |
| ② 상용 하드웨어 + 알고리즘 자체 구현 | 저렴 | 개발 필요 |
| ③ 직접 설계·제작 | 최소 비용 | 매우 높은 기술 수준 요구, 개발 기간 매우 김 |

---

<aside>핵심 정리</aside>

- 로봇 제어 계층: NBS(1977)/ALBUS(1981)의 5단계(System~Servo Control), 상위일수록 계획범위가 길고 트리 구조
- 모션제어기는 배선 방식에 따라 집중형(고응답·동기어려움)/네트워크형(지연발생·다수모터유리, 최근 대세)으로 나뉘고, 확보 방식은 상용/자체구현/직접설계 3가지 중 트레이드오프로 선택
