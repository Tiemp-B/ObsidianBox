# Summary

로봇 제어는 사람이 인지하는 작업공간(말단 좌표)과 로봇이 실제로 구동하는 관절공간(관절 각도) 사이를 정/역기구학으로 오가며 이뤄진다. 인접 링크 간 관계는 DH 파라미터 4개로 기술하고, 기구부의 백래시는 예압으로 줄인다.

# Notes

<aside>정기구학 vs 역기구학</aside>

| 구분 | 입력 → 출력 |
|---|---|
| **정기구학(Forward Kinematics)** | 관절 각도 → 말단(손끝) 위치 |
| **역기구학(Inverse Kinematics)** | 말단 위치 → 관절 각도 |

- **역기구학의 목적**: 목표 위치에서 필요한 관절 각도를 계산하는 것

<aside>관절공간(Joint Space) vs 작업공간(Task Space)</aside>

- **작업공간**: 실제 작업이 이뤄지는 x,y,z(+자세) 공간 — 사람이 인지하는 좌표
- **관절공간**: 로봇이 제어되는 각 관절 각도(q₁...qₙ)의 공간 — 로봇이 실제로 구동하는 좌표
- 로봇은 작업공간 상의 목표 궤적을 **역기구학으로 관절공간 궤적으로 변환**해 각 관절에 명령
- **두 공간의 차이**: 제어 대상 변수의 차이(작업공간=말단 좌표, 관절공간=관절 각도) — 센서 종류나 하드웨어 구성의 차이가 아님

<aside>DH 파라미터(Denavit-Hartenberg)</aside>

- 인접한 두 링크 간의 공간 관계를 **4개 파라미터**만으로 완벽히 기술
- 링크 길이(a), 링크 비틀림각(α), 링크 오프셋(d), 관절각(θ)
- **관성 모멘트(I)는 DH 파라미터에 포함되지 않는다** — DH는 기구학(위치·자세) 파라미터이지 동역학(질량·관성) 파라미터가 아님

<aside>백래시(Backlash)와 예압(Preload)</aside>

- 기어 치면 사이의 유격(백래시)을 줄이는 대표적 방법: **예압(Preload)** — 맞물리는 같은 축의 기어에 스프링 등으로 토크를 걸어 치면 사이 유격을 제거
- 단순히 모터 토크를 늘리거나 제어 주파수를 낮추는 것은 백래시 자체를 줄이는 방법이 아님

---

<aside>핵심 정리</aside>

- 정기구학=관절→말단, 역기구학=말단→관절, 두 공간의 차이는 "제어 대상 변수"
- DH 파라미터 4개(a, α, d, θ)에 관성 모멘트는 포함되지 않음
- 백래시는 예압으로 줄인다
