# Summary

주어진 거리를 최소 시간에 구동하려면 시스템의 최대 허용 속도·가속도·저크·다이나믹 에러라는 4대 파라미터를 알아야 하며, 실제 최소 구동시간은 속도 제한과 가속도 제한 중 더 긴 쪽으로 결정된다.

# Notes

<aside>모션 시간 결정의 4대 파라미터</aside>

| 파라미터 | 결정 요인 |
|---|---|
| 최대 허용 속도 | 엔코더의 최대 출력 주파수·카운터부의 최대 입력 주파수 |
| 최대 허용 가속도 | 모터가 낼 수 있는 최대 힘과 부하의 크기(모터상수·앰프 최대전류·부하 질량) |
| 최대 허용 저크 | 제어 주파수(인터럽트 주파수), 전류 제어 대역폭, 모터 시정수, 기계·가이드 강성 등 — 경험·실험으로 검증 필요 |
| 최대 허용 다이나믹 에러 | 서보 운동 시 발생하는 시간에 따른 위치 오차. 위 3개 파라미터를 초과해 구동하면 증가 |

- **궤적 계획에서 고려해야 할 제약조건**: 속도 및 가속도 한계(위 표의 파라미터들)

<aside>최소 구동시간 계산</aside>

- 최대 허용 속도에 의한 최소 시간: **Tᵥ = 1.5 × S / y'max** (S: 이동거리, y'max: 최대허용속도)
- 최대 허용 가속도에 의한 최소 시간: **Tₐ = √(6S / y''max)** (y''max: 최대허용가속도)
- 실제 최소 구동시간 = **Max(Tₐ, Tᵥ)** — 두 조건을 모두 만족해야 하므로 더 긴 쪽이 병목
- 짧은 거리 → 가속도 제한이 병목 / 긴 거리 → 속도 제한이 병목

<aside>블렌딩(Blending)</aside>

- Point-to-Point 이동에서 여러 구간을 이어서 움직일 때, 각 구간의 속도 프로파일을 매끄럽게 연결해 **이동 경로의 연속성을 확보**하는 기법

---

<aside>핵심 정리</aside>

- 최소 구동시간은 Max(Tₐ, Tᵥ) — 속도·가속도 제한 중 더 느린 쪽이 실제 병목
- 저크·다이나믹 에러는 시간 계산식에 직접 들어가진 않지만 시스템이 버틸 수 있는 한계를 정하는 파라미터
