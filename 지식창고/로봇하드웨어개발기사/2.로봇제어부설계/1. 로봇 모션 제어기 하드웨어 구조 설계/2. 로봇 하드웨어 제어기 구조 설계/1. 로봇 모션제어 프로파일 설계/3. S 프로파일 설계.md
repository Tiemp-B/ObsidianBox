# Summary

S 프로파일은 사다리꼴의 진동 문제를 해결하기 위해 부드러운 곡선을 쓰는 모션 프로파일이다. 3차식은 위치·속도 경계조건만 만족시켜 가속도가 경계에서 불연속이고, 5차식은 가속도 경계조건까지 추가해 저크가 연속적인 더 부드러운 곡선을 만든다.

# Notes

<aside>저크(Jerk)의 정의</aside>

- **저크 = 가속도의 시간에 대한 변화율**
- 저크가 클수록 기구물에 가해지는 충격(가진량)이 커져 진동을 유발

<aside>3차식 S 프로파일</aside>

- 식: y = a + bt + ct² + dt³ (미지수 4개)
- **경계조건 4개**: 위치 y(0)=0, y(1)=1 / 속도 ẏ(0)=0, ẏ(1)=0
- 표준화된 해: **y = 3t² − 2t³**
- 가속도(y'')는 시간에 대해 선형(구간 내 연속)이지만, **시작·끝점에서 가속도가 0이 아닌 값에서 급격히 시작/종료** → 경계에서 저크가 임펄스적으로 불연속

<aside>5차식 S 프로파일</aside>

- 식: y = a+bt+ct²+dt³+et⁴+ft⁵ (미지수 6개)
- **경계조건 6개**: 위치 2개 + 속도 2개 + **가속도 2개**(ÿ(0)=0, ÿ(1)=0) — 3차식보다 2개 더 추가
- 표준화된 해: **y = 10t³ − 15t⁴ + 6t⁵**
- 시작·끝점에서 **가속도가 0이 되도록 강제** → 저크까지 연속적인 부드러운 곡선
- **5차 다항식을 쓰는 주된 이유**: 가속도의 연속성 보장(3차식이 갖지 못한 경계 가속도=0 조건 충족)

<aside>차수에 따른 트레이드오프</aside>

| 차수 | 진동 | 구동 시간 |
|---|---|---|
| 3차식 | 큼(경계 가속도 불연속) | 짧음 |
| **5차식** | 중간(경계 가속도·저크 연속) | 중간 |
| 7차식 이상 | 작음(더 매끄러움) | 김(같은 거리에 시간이 더 걸림) |

- **5차 프로파일은 초고속 서보 시스템에서 "어느 정도 진동을 허용하면서 빠르게 구동"하는 절충안**으로 적합

---

<aside>핵심 정리</aside>

- 저크=가속도의 변화율
- 3차식: 경계조건 4개(위치+속도), 5차식: 경계조건 6개(위치+속도+가속도) — 5차식이 가속도 연속성을 보장하는 것이 핵심 차이
- 고차로 갈수록 진동은 줄지만 구동 시간은 늘어남 → 5차식이 속도-진동 절충안
