# 조사 — 로봇 입출력 신호처리

## A. NCS 대조 결과

NCS 필요지식(footer p.3~9) "통신 인터페이스의 활용" 절에서 PWM·GPIO 등을 개괄적으로 소개하나, ADC 샘플링·디바운싱 등 신호처리 세부 원리는 다루지 않는다. 문제은행 4문항을 웹조사·전자공학 도메인 지식으로 작성한다.

## B. 웹 검색 결과

1. **ADC 샘플링 시간(Sampling Time) 증가의 효과**: 샘플링 시간을 늘리면 ADC 내부 커패시터가 입력 전압에 충분히 충전될 시간이 확보되어 **변환 정확도가 향상**된다(단, 대신 변환 속도는 느려지는 트레이드오프). — [아날로그-디지털 변환회로, 위키백과](https://ko.wikipedia.org/wiki/%EC%95%84%EB%82%A0%EB%A1%9C%EA%B7%B8-%EB%94%94%EC%A7%80%ED%84%B8_%EB%B3%80%ED%99%98%ED%9A%8C%EB%A1%9C)

## C. 결론(도메인 지식으로 보완, 검색 불필요한 기초 사실)

- **PWM(Pulse Width Modulation)의 주요 용도**: 펄스 폭(듀티비)을 조절해 평균 전압을 아날로그처럼 흉내 내는 방식으로, 로봇에서는 **모터 속도 제어**가 대표 용도(디지털 통신·아날로그신호 변환 자체·메모리 액세스가 목적이 아님).
- **디바운싱(Debouncing)의 목적**: 기계식 스위치를 누르거나 뗄 때 접점이 순간적으로 여러 번 붙었다 떨어지는 **채터링(chattering)을 제거**하는 것 — 노이즈 제거·신호 증폭·신호 변환과는 구분되는 개념(디바운싱은 채터링이라는 특정 현상을 겨냥).
- **ADC 분해능과 표현 가능한 값의 개수**: n비트 ADC는 2ⁿ개의 디지털 값을 표현. **12비트 = 2¹² = 4096개**.
