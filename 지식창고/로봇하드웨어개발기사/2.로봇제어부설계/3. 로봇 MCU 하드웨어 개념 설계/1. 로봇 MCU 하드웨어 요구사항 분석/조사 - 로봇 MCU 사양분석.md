# 조사 — 로봇 MCU 사양분석

## A. NCS 대조 결과

NCS 학습모듈 119(22v3, "로봇 주제어장치(MCU) 하드웨어 개념설계") 학습1 필요지식(footer p.3~9)은 주제어장치 개념설계 절차·구성요소·기술적 요소(CPU/메모리/입출력·통신 인터페이스/전원/보안/확장성)를 개괄적으로 다루나, 문제은행 문항(EEPROM·캐시·스택오버플로우·플래시메모리 등 구체적 컴퓨터 구조 지식)에 직접 대응하는 내용은 없다. footer p.10 이후는 로봇 요구사항 명세서 사례 비교·AI 도입 사례 등 수행내용(실기 성격)이라 제외. 문제은행 7문항은 웹조사·컴퓨터구조 도메인 지식으로 작성한다.

## B. 웹 검색 결과

1. **EEPROM의 특징**: 바이트 단위의 읽기·쓰기가 가능한 비휘발성 메모리로, 전원이 꺼져도 데이터를 보존한다. 쓰기/지우기 과정에 시간이 걸려 RAM보다 쓰기 속도가 느리고, 쓰기 횟수에 한계(최소 100만 회 수준)가 있어 "무제한 쓰기 가능"은 틀린 설명이다. — [EEPROM, electricity-magnetism.org](https://www.electricity-magnetism.org/ko/eeprom-%EC%A0%84%EA%B8%B0%EC%A0%81%EC%9C%BC%EB%A1%9C-%EC%A7%80%EC%9A%B8-%EC%88%98-%EC%9E%88%EB%8A%94-%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%A8-%EA%B0%80%EB%8A%A5%ED%95%9C-%EC%9D%BD%EA%B8%B0-%EC%A0%84/)
2. **캐시 메모리의 목적**: CPU의 연산 속도와 메인 메모리 접근 속도 차이를 줄이기 위해, 자주 쓰는 데이터를 더 빠른 캐시에 두어 **메모리 접근 속도를 향상**시키는 것이 핵심 목적(전력·보안·용량 확장이 목적이 아님). — [캐시 메모리, jaehyeon48.github.io](https://jaehyeon48.github.io/computer-architecture/cache-memory/)
3. **스택 오버플로우 방지**: 표준적 방법은 스택 크기 증가, 재귀 함수 사용 최소화, 지역 변수 사용 최소화. **힙 메모리 사용 증가는 스택이 아닌 별도 메모리 영역(힙)의 이야기**로, 스택 오버플로우 자체를 직접 방지하는 표준 기법으로 분류되지 않는다(임베디드 MCU에서는 힙 크기도 제한적이라 별도의 힙 고갈·단편화 문제를 유발할 수 있음). — [스택 버퍼 오버플로우, 위키백과](https://ko.wikipedia.org/wiki/%EC%8A%A4%ED%83%9D_%EB%B2%84%ED%8D%BC_%EC%98%A4%EB%B2%84%ED%94%8C%EB%A1%9C)
4. **플래시 메모리의 쓰기가 RAM보다 느린 이유**: RAM(D램)은 트랜지스터+커패시터 구조로 즉시 쓰기가 가능하지만, 플래시 메모리는 쓰기 전 반드시 **소거(erase) 과정**을 거쳐야 하므로(유한한 프로그램-소거 주기 P/E cycle 제약도 있음) 쓰기 속도가 느리다. — [플래시 메모리, 나무위키](https://namu.wiki/w/%ED%94%8C%EB%9E%98%EC%8B%9C%20%EB%A9%94%EB%AA%A8%EB%A6%AC)

## C. 결론(도메인 지식으로 보완)

- **플래시 메모리의 특징**: 비휘발성 메모리이며(EEPROM과 마찬가지로 전원 차단 시에도 데이터 보존), 읽기는 빠르지만 쓰기는 소거 과정 때문에 느리고, 쓰기 횟수에 한계가 있다 — "휘발성 메모리"·"빠른 읽기/쓰기 속도"·"무제한 쓰기 가능"은 모두 틀린 설명.
- **실시간 모션 제어를 위한 MCU 선정의 최소 요구사항**: 메모리 용량·통신 포트 수·ADC 분해능도 고려 요소이지만, 실시간성이 핵심인 모션 제어에서 **가장 중요한 것은 인터럽트 지연시간**(짧을수록 위치·속도 갱신이 지연 없이 이뤄짐).
- **MCU 선정 시 고려사항으로 부적절한 것**: 클록 주파수·메모리 용량·통신 인터페이스는 MCU 자체의 성능·기능을 좌우하는 핵심 고려사항이지만, **디스플레이 해상도는 MCU 선정과 무관한(주변장치인 디스플레이 모듈의 사양) 요소**.
