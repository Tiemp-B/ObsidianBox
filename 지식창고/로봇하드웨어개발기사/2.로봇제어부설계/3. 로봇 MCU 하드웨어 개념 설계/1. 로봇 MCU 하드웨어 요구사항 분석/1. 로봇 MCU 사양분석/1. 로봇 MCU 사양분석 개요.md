# Summary

MCU를 선정하려면 EEPROM·플래시·RAM·캐시 같은 메모리 종류별 특성과, 실시간 모션 제어에 필요한 클록 주파수·인터럽트 지연시간·통신 인터페이스 같은 선정 기준을 알아야 한다. NCS 필요지식(학습모듈 119 학습1, footer p.3~9)은 개괄적 개념설계 절차만 다루고, 문제은행 7문항의 세부 내용은 웹조사·컴퓨터구조 도메인 지식으로 작성했다.
