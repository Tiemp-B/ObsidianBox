# Summary

실시간 모션 제어용 MCU를 선정할 때 가장 중요한 기준은 인터럽트 지연시간이며, 클록 주파수·메모리 용량·통신 인터페이스도 핵심 고려사항이다. 반면 디스플레이 해상도처럼 MCU 자체와 무관한 주변장치 사양은 선정 기준이 아니다.

# Notes

<aside>실시간 모션 제어 MCU의 최소 요구사항</aside>

| 후보 기준 | 실시간 모션 제어의 핵심 요구사항인가 |
|---|---|
| 메모리 용량 | 고려 요소이나 최우선은 아님 |
| **인터럽트 지연시간** | **가장 중요** — 짧을수록 위치·속도 갱신이 지연 없이 이뤄짐 |
| 통신 포트 수 | 고려 요소이나 최우선은 아님 |
| ADC 분해능 | 고려 요소이나 최우선은 아님 |

<aside>MCU 선정 시 일반 고려사항</aside>

| 고려사항 | MCU 선정과 관련 있는가 |
|---|---|
| 클록 주파수 | O — 연산 속도를 좌우 |
| 메모리 용량 | O — 프로그램·데이터 저장 여력 |
| 통신 인터페이스 | O — 센서·드라이버·상위제어기 연결 방식 |
| **디스플레이 해상도** | **X — MCU 자체가 아닌 별도 주변장치(디스플레이 모듈)의 사양** |

---

<aside>핵심 정리</aside>

- 실시간 모션 제어 MCU의 최우선 기준 = 인터럽트 지연시간
- MCU 선정 4대 고려사항: 클록주파수·메모리용량·통신인터페이스(+인터럽트지연시간) — 디스플레이 해상도는 해당 없음
