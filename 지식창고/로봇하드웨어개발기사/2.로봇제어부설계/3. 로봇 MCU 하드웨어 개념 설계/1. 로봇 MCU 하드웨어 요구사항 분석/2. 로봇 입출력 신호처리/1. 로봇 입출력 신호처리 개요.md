# Summary

MCU는 PWM으로 모터 속도를 제어하고, ADC로 아날로그 센서 신호를 디지털 값으로 변환하며, 디바운싱으로 기계식 스위치의 채터링을 제거한다. 문제은행 4문항이며 NCS는 개념만 소개해 웹조사·전자공학 도메인 지식으로 보완했다.

<aside>PWM(Pulse Width Modulation)</aside>

- 펄스 폭(듀티비)을 조절해 평균 전압을 아날로그처럼 흉내 내는 방식
- 로봇에서의 주요 용도: **모터 속도 제어**(디지털 통신·아날로그신호 변환 자체·메모리 액세스가 목적이 아님)

<aside>ADC(Analog-to-Digital Converter)</aside>

- **샘플링 시간(Sampling Time) 증가 효과**: ADC 내부 커패시터가 입력 전압에 충분히 충전될 시간이 확보되어 **변환 정확도가 향상**(대신 변환 속도는 느려지는 트레이드오프)
- **분해능과 표현 가능한 값의 개수**: n비트 ADC는 2ⁿ개의 디지털 값을 표현 → **12비트 = 2¹² = 4096개**

<aside>디바운싱(Debouncing)</aside>

- 기계식 스위치를 누르거나 뗄 때 접점이 순간적으로 여러 번 붙었다 떨어지는 **채터링(chattering)을 제거**하는 것이 목적
- 노이즈 제거·신호 증폭·신호 변환과는 구분되는, 채터링이라는 특정 현상을 겨냥한 기법
