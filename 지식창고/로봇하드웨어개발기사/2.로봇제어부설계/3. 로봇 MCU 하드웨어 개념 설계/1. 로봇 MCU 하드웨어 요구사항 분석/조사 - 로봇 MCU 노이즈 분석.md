# 조사 — 로봇 MCU 노이즈 분석

## A. NCS 대조 결과

NCS 필요지식에 MCU 노이즈 분석에 대응하는 내용이 없다. 문제은행도 0문항이라, 과목1(로봇드라이버설계)에서 이미 웹조사로 검증한 전자회로 노이즈 대책 지식(디커플링 커패시터·페라이트 비드·그라운드 플레인 연속성)을 MCU 보드 설계 맥락으로 재구성하고, MCU 특유의 노이즈 이슈(클록 신호 EMI, ESD)를 추가한다.

## B. 도메인 지식 정리(과목1에서 검증된 내용 재사용 + MCU 특유 이슈)

- **디커플링 커패시터**: MCU 전원 핀 바로 옆에 배치해 스위칭 시 발생하는 순간적인 전류 요구를 커패시터가 국소적으로 공급, 전원 레일의 전압 리플·노이즈를 억제(과목1 액추에이터 드라이버 회로에서 이미 검증).
- **그라운드 플레인**: 접지를 여러 조각으로 분할하지 않고 **연속된 하나의 면으로 유지**하는 것이 EMI 저감의 핵심(분할하면 오히려 접지 임피던스가 커져 노이즈에 취약해짐 — 과목1에서 확인된 오답 함정).
- **페라이트 비드**: 고주파 노이즈 성분만 감쇠시키는 소자로, 전원 라인이나 신호 라인에 직렬로 삽입해 고주파 EMI를 억제.
- **MCU 클록 신호의 EMI**: 클록 발진기·클록 배선은 고속으로 스위칭하며 고조파를 발생시켜 자체가 EMI 방사원이 될 수 있다 — 클록 라인은 최대한 짧게, 다른 민감한 아날로그 신호선과 분리해 배선한다.
- **ESD(정전기 방전, Electrostatic Discharge) 보호**: 외부 커넥터·버튼 등 사람 손이 닿는 입출력 핀에는 ESD 보호 소자(TVS 다이오드 등)를 배치해 정전기로 인한 MCU 손상을 방지.
- **크로스토크(Crosstalk)**: 인접한 신호선 사이의 전자기 결합으로 한 신호선의 스위칭이 옆 신호선에 잡음을 유기하는 현상 — 고속 신호선 간 간격을 충분히 띄우거나 사이에 그라운드 신호선을 배치해 완화.

## C. 페이지 구성 설계

1개 세세항목 통합 1페이지(개요 겸 본문): 디커플링·그라운드플레인·페라이트비드(과목1 재사용) + 클록EMI·ESD·크로스토크(MCU 특유 이슈)
