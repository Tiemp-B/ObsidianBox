# Summary

MCU는 UART·SPI·I2C 같은 직렬 통신으로 센서·주변기기와 데이터를 주고받으며, DMA로 CPU 부담 없이 데이터를 옮기고 CRC로 전송 오류를 검증한다. 문제은행 7문항이며 NCS는 각 프로토콜의 정의·사례만 소개해 웹조사·임베디드 도메인 지식(과목2 D16에서 검증한 SPI/I2C 지식 포함)으로 보완했다.
