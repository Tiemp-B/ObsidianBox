# Summary

UART는 클록 없이 통신속도만 맞추는 비동기식, SPI는 4선식 동기식 싱글마스터, I2C는 2선식이다. DMA는 CPU 개입 없이 메모리 간 데이터를 옮겨 CPU 부하를 줄이고, CRC는 전송된 데이터의 무결성을 검증한다.

# Notes

<aside>UART(Universal Asynchronous Receiver/Transmitter)</aside>

- 송신부·수신부가 클록 신호를 **공유하지 않는 비동기식** 통신 — 대신 통신 속도(Baud Rate)를 사전에 맞춰 시작/정지 비트로 동기를 잡음
- **수신 오류 감지 방법**: 데이터 프레임에 패리티 비트를 추가해 홀수/짝수 검사로 오류 유무 판단하는 **패리티 비트 검사**(클럭 주파수 확인·전송속도 변경·송신버퍼 초기화는 오류 감지 방법이 아님)

<aside>SPI vs I2C 특징 비교</aside>

| 구분 | SPI | I2C |
|---|---|---|
| 신호선 | **4선식**(MOSI/MISO/SCK/SS) | **2선식**(SDA/SCL) |
| 동기 방식 | **동기식** | 동기식 |
| 마스터 구조 | **싱글 마스터**(멀티마스터 지원 아님) | 멀티마스터 가능 |
| 통신 거리 | 근거리·고속 | 근거리 |

- "SPI 통신의 특징"을 묻는 문제에서 참인 선택지는 **동기식 통신**(2선식·멀티마스터·장거리적합은 모두 오답)
- "I2C 통신의 특징"을 묻는 문제에서 참인 선택지는 **2선식 통신**(4선식·단방향·고속전용은 모두 오답)

<aside>DMA(Direct Memory Access)</aside>

- CPU를 거치지 않고 주변장치-메모리 또는 메모리-메모리 간 데이터를 직접 전송하는 컨트롤러
- **사용 목적**: **CPU 부하 감소**(전송을 DMA 컨트롤러에 맡기고 CPU는 다른 작업 수행)
- **주요 기능**: **CPU 개입 없이 메모리 간 데이터 전송**을 수행

<aside>CRC(Cyclic Redundancy Check)</aside>

- 전송 데이터 블록에 여유 부호(체크섬)를 붙여 보내고, 수신측이 재계산·비교해 오류를 검출하는 기법
- **용도**: **데이터 무결성 검증**(데이터 압축·암호화·정렬이 목적이 아님)
- Modbus·CAN 등 여러 산업 프로토콜에서 활용(과목2에서 다룬 필드버스들과 연결됨)

---

<aside>핵심 정리</aside>

- UART=비동기+패리티비트오류검출, SPI=4선동기싱글마스터, I2C=2선, DMA=CPU부하감소(메모리간 직접전송), CRC=무결성검증
