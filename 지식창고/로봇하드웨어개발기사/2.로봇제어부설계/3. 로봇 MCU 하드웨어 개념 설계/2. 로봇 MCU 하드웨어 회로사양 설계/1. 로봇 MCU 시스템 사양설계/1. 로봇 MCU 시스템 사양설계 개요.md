# Summary

MCU를 중심으로 한 주제어 장치 시스템 사양은 CPU·메모리·입출력 인터페이스·통신 인터페이스·전원 공급·보안/안전·확장성·신호처리라는 8가지 요소로 구성된다. NCS 필요지식(학습모듈 119 학습1 §3, footer p.5~6)이 이 세세항목의 핵심 출처이며, 문제은행 대응 문항은 없다.

<aside>주제어 장치(MCU) 시스템 사양의 8가지 구성 요소</aside>

| 요소 | 내용 |
|---|---|
| ① CPU | 제어·연산 담당. 고성능 멀티코어로 병렬처리·실시간 응답. 근래는 엣지/포그 컴퓨팅으로 연산 일부를 외곽 분산 |
| ② 메모리 | 플래시(프로그램 코드·데이터)와 RAM(실시간 처리·임시 저장)을 용도별 구분 사용 |
| ③ 입출력 인터페이스 | 디지털·아날로그 입력(센서 수집)/출력(액추에이터 제어) 포트 |
| ④ 통신 인터페이스 | 이더넷·USB·시리얼 등, 외부 장치와 데이터 교환·원격 제어·모니터링 |
| ⑤ 전원 공급 및 관리 | 안정적 전원 공급, 전원 변환기·배터리 관리 시스템 포함 |
| ⑥ 보안 및 안전 기능 | 암호화 통신, 접근 제어, 오류 감지·복구 |
| ⑦ 확장성과 모듈성 | 확장 슬롯·인터페이스로 추가 기능/모듈 연결·교체 가능 |
| ⑧ 신호 처리 및 변환 | 센서 신호 처리, A/D 변환기·신호처리 유닛으로 액추에이터 출력 변환 |

- 이 8요소는 [[3. MCU 선정 기준|MCU 선정 기준]](클록주파수·메모리용량·통신인터페이스)보다 상위의 **시스템 전체** 관점 사양이라는 점에서 구분된다
