# Summary

워치독 타이머는 시스템이 멈추면 자동으로 재시작시키고, 부트로더는 전원이 켜질 때 가장 먼저 실행되어 애플리케이션을 로딩한다. GPIO는 방향 설정이 최우선이며, RTOS의 세마포어는 초기값 1일 때 뮤텍스처럼 동작한다.

# Notes

<aside>워치독 타이머(Watchdog Timer)</aside>

- 시스템이 정상 동작 중 주기적으로 리셋(kick)해줘야 하는 독립 타이머
- 소프트웨어가 멈추거나 오작동해 리셋을 놓치면 타이머가 만료되어 **자동으로 시스템을 재시작**
- **주요 기능/목적**: **시스템 오작동 감지 및 자동 복구**(CPU 클록 속도 향상·프로그램 실행 속도 향상·메모리 사용량 감소가 목적이 아님)

<aside>부트로더(Bootloader)</aside>

- MCU 동작 중 가장 먼저 실행, 메모리 시작 부분에 위치
- 준비 과정과 애플리케이션 이상 유무 확인 후 애플리케이션으로 점프
- **역할**: **메인 프로그램(애플리케이션)의 로딩 및 실행**(운영체제 실행·메모리 관리·통신 프로토콜 처리 자체가 목적이 아님, 펌웨어 업데이트 기능도 겸함)

<aside>GPIO 포트 초기화</aside>

- 통신속도·ADC변환시간·인터럽트우선순위는 상황에 따라 필요하지만, GPIO를 쓰려면 가장 먼저 **입출력 방향(입력/출력) 설정**이 필수 — 방향 설정 없이는 핀 자체가 동작하지 않음

<aside>RTOS 세마포어와 뮤텍스</aside>

- 세마포어: 공유자원에 접근 가능한 개수를 나타내는 카운팅 변수 방식의 상호배제 기법
- **초기값을 1로 설정하면 이진(binary) 세마포어**가 되어 **뮤텍스와 동일하게 동작**
- 엄밀히는 뮤텍스는 소유권 개념이 있어(락을 획득한 태스크만 해제 가능) 세마포어와 차이가 있음

<aside>핵심 정리</aside>

- 워치독=오작동 자동복구, 부트로더=메인프로그램 로딩·실행, GPIO 초기화 최우선 항목=방향, 세마포어 초기값1=뮤텍스와 동일 동작
