# Summary

PWM의 듀티비는 타이머의 비교 레지스터로 조작하며, 분해능은 CPU 클럭 주파수가 결정한다. 하드웨어 타이머로 PWM을 생성하면 소프트웨어 부하가 줄고, 타이머/카운터는 PWM·인터럽트·이벤트 카운팅은 담당하지만 아날로그 신호 변환은 ADC의 역할이다.

# Notes

<aside>PWM 신호와 최소 비트 수</aside>

- 4비트(16단계)는 듀티비 조절이 너무 거칠어 실용적이지 않음
- 임베디드 과정에서 실용적인 PWM 최소 해상도로 흔히 언급되는 것은 **8비트(256단계)**

<aside>PWM 관련 레지스터</aside>

| 레지스터 | 역할 |
|---|---|
| 프리스케일러 레지스터 | 타이머 클록 분주 |
| 주기 레지스터 | PWM 주기(주파수) 결정 |
| **비교 레지스터(Compare Register)** | **듀티비(duty cycle) 조작** |
| 상태 레지스터 | 타이머 상태 플래그 |

<aside>PWM 분해능을 결정하는 요소</aside>

- 타이머가 셀 수 있는 카운트 범위는 결국 **CPU 클럭 주파수**(및 타이머 클록 분주)에 의해 결정
- 메모리 버스 속도·인터럽트 우선순위·캐시 메모리 크기는 PWM 분해능과 무관

<aside>하드웨어 타이머 기반 PWM의 장점</aside>

- CPU가 직접 폴링/토글하지 않고 타이머 하드웨어가 자동으로 펄스 생성
- **장점**: **소프트웨어 부하 감소**(메모리 사용량 증가·전력 소모 증가·제어 복잡도 증가는 장점이 아님)

<aside>타이머/카운터의 기능 범위</aside>

- 표준 기능: **PWM 신호 생성**, **주기적 인터럽트 발생**, **이벤트 카운팅**
- **적절하지 않은 것**: **아날로그 신호 변환**은 ADC(별도 모듈)의 역할이지 타이머/카운터의 기능이 아님
