# 조사 — 로봇 MCU 주변기기 동기화

## A. NCS 대조 결과

NCS 필요지식에 이 세세항목에 대응하는 내용이 없다(학습2 필요지식은 포그컴퓨팅 개념뿐). 문제은행도 0문항이라, 과목2에서 이미 검증한 개념(D16 실시간 동기화, D28 관련 RTOS 세마포어/뮤텍스)을 MCU-주변기기 관계로 재구성했다.

## B. 도메인 지식 정리(과목2에서 검증된 내용 재사용 + MCU 관점 보완)

- **다축 동기화**(과목2 D16): 여러 관절이 하나의 궤적을 이루며 동시에 움직여야 하는 다축 협조 제어에서는 축 간 시간 동기가 필수 — MCU가 여러 모터 드라이버·엔코더를 동시에 제어할 때도 동일한 원리가 적용된다.
- **인터럽트 기반 동기화**: 여러 주변기기(센서·통신·타이머)가 각각 다른 시점에 이벤트를 발생시킬 때, MCU는 인터럽트 우선순위(과목2 D17)로 어느 주변기기를 먼저 처리할지 조율한다.
- **RTOS 동기화 객체**(D29에서 다룰 세마포어·뮤텍스): 여러 태스크가 동일한 주변기기(예: 하나의 SPI 버스)에 동시 접근하려 할 때 뮤텍스로 상호 배제해 데이터 충돌을 방지한다.
- **DMA와 주변기기 동기화**(과목2 D24): DMA 컨트롤러가 CPU 개입 없이 주변기기-메모리 간 데이터를 옮기는 동안, CPU는 다른 주변기기를 동기적으로 처리할 수 있어 여러 주변기기를 병렬적으로 다루는 데 유리하다.

## C. 페이지 구성 설계

1개 세세항목 통합 1페이지(개요 겸 본문): 다축 동기화, 인터럽트 기반 동기화, RTOS 동기화 객체, DMA와의 관계 — 모두 과목2에서 다룬 개념의 MCU 주변기기 관점 재조명
