# Summary

접지 강화·필터 회로·차폐 적용이 표준 노이즈 대책이며, 클럭 주파수 증가나 신호선 길이 확대는 오히려 노이즈를 키운다. 접지 루프는 절연으로 끊고, 차폐선은 주파수에 맞는 접지 방식을 선택하며, ADC는 차동입력·오버샘플링·클록동기화로 노이즈를 줄인다.

# Notes

<aside>표준 노이즈 대책 vs 역효과 함정</aside>

| 표준 대책 | 역효과 함정(노이즈 대책 아님) |
|---|---|
| 접지(Ground) 강화 | **클럭 주파수 증가** — 고조파 방사(EMI) 증가 |
| 필터 회로 설치, 차폐(Shielding) 적용 | 위와 동일(클럭↑는 항상 오답 축) |
| 바이패스 커패시터, 전원선-신호선 분리, 페라이트 코어 | **신호선 길이 최대화** — 노이즈 노출 면적·안테나 효과 증가 |
| 바이패스 커패시터, 그라운드 플레인 설계, PCB 트레이스 길이 최소화 | 클럭 주파수 증가(반복 출제 축) |

- 문제은행에서 "노이즈 대책으로 부적절한 것"을 물을 때 **클럭 주파수 증가**와 **신호선 최대화**가 반복적으로 오답 선택지로 등장

<aside>접지 루프(Ground Loop) 해결 방안</aside>

- 표준 해결책: **광학적 절연**(옵토커플러), **차동 신호 전송**, **절연 변압기**, 공통모드 초크
- **부적절한 방안**: 접지선 임피던스 증가 — 그라운드 루프는 임피던스가 낮을수록 순환전류 문제가 완화되는 방향이므로, 임피던스를 "증가"시키는 것은 해결책이 아님

<aside>차폐 케이블의 접지 방식</aside>

| 접지 방식 | 적합한 상황 |
|---|---|
| 단일점 접지 | **저주파(약 1MHz 미만)** — 감지 효과가 약해 표준적으로 권장 |
| 양단(다중점) 접지 | 고주파·심각한 간섭 현장 — 단, 차폐층-내부신호선 결합 커패시턴스로 신호 루프에 잡음 유입 위험 |
| 부동 접지 | 접지 루프 자체를 없애는 절연 목적 |

- 4가지(단일점/다중점/양단/부동) 중 **다중점 접지가 그라운드 루프·노이즈 유입 위험이 가장 커** "가장 부적절한 접지 방식"의 정답으로 판단

<aside>ADC 노이즈 대책</aside>

| 대책 | 유효한가 |
|---|---|
| 차동 입력 사용 | O — 스위칭 노이즈·짝수차 고조파 왜곡 상쇄 |
| 오버샘플링 기법 | O — 양자화 노이즈를 신호대역 밖으로 밀어냄 |
| 클록 동기화 샘플링 | O — 지터·위상노이즈 저감 |
| **입력 임피던스 증가** | **X** — 높은 소스 임피던스는 오히려 노이즈 픽업에 취약, 샘플링 커패시터 충전도 느려짐 |

---

<aside>핵심 정리</aside>

- 클럭주파수 증가·신호선 최대화·접지선 임피던스 증가·ADC 입력임피던스 증가는 모두 "노이즈 대책처럼 보이지만 실제로는 역효과"인 반복 함정
- 차폐 접지는 주파수 기준(1MHz)으로 단일점/다중점을 구분
