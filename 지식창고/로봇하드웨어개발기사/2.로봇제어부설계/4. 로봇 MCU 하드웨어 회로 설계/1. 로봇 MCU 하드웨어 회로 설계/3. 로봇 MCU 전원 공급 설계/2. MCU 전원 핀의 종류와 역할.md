# Summary

MCU의 전원 핀은 배터리 백업(VBAT), 주전원(VDD/VSS), 코어용 내부 LDO(VDDLDO/VCAP), 아날로그 전용(VDDA/VSSA/VREF)으로 용도가 나뉘며, 각각 매칭·연결 규칙을 지켜야 정상 동작한다.

# Notes

<aside>VBAT</aside>

- 배터리를 연결하는 포트
- 주전원(VDD)이 공급되지 않을 때 VBAT 전원으로 **RTC·RTC 레지스터·백업 SRAM**에 전원을 공급해 계속 동작시킴

<aside>VDD/VSS</aside>

- 포트에 전원을 공급하는 핀 쌍
- **VDD는 VSS와 매칭되어야 함**(칩 전체에 분산 배치된 VDD/VSS 쌍마다 규칙 적용)
- VDD에는 규격 전압(예: +1.8V~3.3V)을, VSS에는 GND를 연결

<aside>VDDLDO_n/VDD_n</aside>

- MCU **core에 전원 공급을 담당하는 내부 LDO(전압조정기)**에 전원을 공급
- CPU·FLASH(D1 도메인), RAM·주변장치(D2 도메인), 시스템 로직(D3 도메인)에 전원을 분배

<aside>VCAP</aside>

- 내부 LDO 출력과 연결
- MCU 외부 GND(데이터시트 지정 커패시터)에 연결

<aside>VDDA/VSSA/VREF</aside>

- MCU 기능 중 **아날로그 신호를 처리하는 AD Converter·DA Converter, OP-AMP, comparator, REF_BUF**에 전원을 공급하는 아날로그 전용 도메인
- 디지털 노이즈로부터 분리하기 위해 별도 핀으로 구성(노이즈 대책 세세항목의 "디지털/아날로그 접지 분리" 원칙과 연결됨)

---

<aside>핵심 정리</aside>

- VBAT=백업(RTC/SRAM), VDD/VSS=주전원(매칭필수), VDDLDO/VCAP=코어 내부LDO용, VDDA/VSSA/VREF=아날로그 전용(디지털과 분리)
