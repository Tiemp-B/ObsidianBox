# Summary

스위칭 레귤레이터는 고효율, 리니어·LDO 레귤레이터는 저노이즈가 강점이며, POL 레귤레이터는 부하 근처 배치로 전압강하를 줄인다. 디커플링 커패시터는 ESR이 낮을수록 고주파 노이즈 억제에 유리하고, 딥 슬립 모드가 가장 낮은 전력을 소모하며, 브라운아웃 감지는 전압 강하 시 시스템을 보호한다.

# Notes

<aside>레귤레이터 종류 비교</aside>

| 종류 | 특징 |
|---|---|
| **스위칭 레귤레이터** | **높은 효율성**(전력 손실 적음), 소형화 가능, 대신 노이즈는 리니어보다 큼 |
| **리니어 레귤레이터** | **낮은 노이즈**, 대신 효율 낮음·발열 큼 |
| **LDO(Low-Dropout Regulator)** | 입력-출력 전압차(드롭아웃)가 작아도 동작, **낮은 출력 리플 전압**(저노이즈) — 스위칭보다 변환 효율은 낮음 |
| **POL(Point of Load) 레귤레이터** | 부하(칩) 바로 근처에 배치해 배선상의 **전압 강하(IR 드롭) 최소화**가 목적 |

<aside>디커플링 커패시터(Decoupling Capacitor)</aside>

- MCU 전원 핀 근처에 배치해 스위칭 시 순간 전류 요구를 국소적으로 공급
- **목적**: 전원 레일의 **고주파 노이즈 제거**(전류 용량 증가나 클록 속도 향상이 목적이 아님)
- **선정 시 가장 중요한 고려사항**: **ESR(등가직렬저항)** — ESR이 낮을수록 고주파 리플 전류에 대한 억제 효과가 큼(단순 용량 값만으로는 부족)

<aside>전력 관리 모드</aside>

- 액티브 모드 < 슬립 모드 < 스탠바이 모드 < **딥 슬립 모드** 순으로 소모 전력 감소
- **가장 낮은 전력 소모 = 딥 슬립 모드**(대부분의 주변장치·클록을 정지)

<aside>브라운아웃 감지(Brown-out Detection)</aside>

- 전원 전압이 정상 동작 임계값 이하로 떨어지는 순간을 감지해 MCU를 리셋
- **목적**: **전압 강하 시 시스템(오동작·메모리 손상) 보호**(과전류 보호·온도 감지·메모리 오류 검출이 목적이 아님)

---

<aside>핵심 정리</aside>

- 효율 우선=스위칭, 노이즈 우선=리니어/LDO, 전압강하 최소화=POL 근접 배치
- 디커플링 커패시터의 핵심 스펙은 ESR, 최저전력=딥슬립모드, 브라운아웃=전압강하 보호
