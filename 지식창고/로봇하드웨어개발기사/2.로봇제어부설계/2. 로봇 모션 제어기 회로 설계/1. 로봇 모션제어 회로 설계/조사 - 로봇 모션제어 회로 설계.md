# 조사 — 로봇 모션제어 회로 설계

## A. NCS 대조 결과

NCS 학습모듈 117/118의 **학습3 "로봇 모션 제어기 하드웨어 회로 설계하기" 중 3-1 "모션 제어기 회로 설계"**(필요지식, 원문 footer p.56~58)가 이 세세항목에 직접 대응한다.

NCS 필요지식 핵심 내용:

1. **마이크로컨트롤러의 버스 구조**: CPU와 외부 메모리·입출력 장치 사이는 버스로 접속. 3가지 시스템 버스:
   - **어드레스 버스(address bus)**: 메모리·I/O 장치의 번지를 지정, **단방향**. 신호선 수가 최대 사용 가능 메모리 용량/I/O 수를 결정.
   - **데이터 버스(data bus)**: 데이터 전송용, **양방향**. 신호선 수가 마이크로컨트롤러의 워드 길이와 같고 성능을 결정하는 요소.
   - **제어 버스(control bus)**: 작업 종류·상태를 알리거나 동작을 요구하는 신호, **단방향**.
2. **마이크로컨트롤러 내부 구조**: 메모리(ROM+RAM) + CPU(ALU+레지스터+시프터) + 보조모듈(통신 SPI/USART/I2C, AD/DA, 타이머)이 버스로 연결.
3. **폰 노이만 구조 vs 하바드 구조**:
   - **폰 노이만 구조**: 데이터·프로그램 메모리가 구분되지 않고 하나의 버스를 공유. Fetch→Decode→Execute→Store 순차 처리.
   - **하바드 구조**: 프로그램(명령어) 메모리와 데이터 메모리가 각각 별도. **속도는 빠르지만(파이프라이닝 용이) 공간을 더 차지**하고 회로가 복잡함.

수행내용(footer 59~68, 실기)에서 참고할 만한 설계 원칙(모션 제어기 자체 회로 예시, 00사 SMC-2V04 모듈 블록도): 모션 제어를 위한 신호는 **포토커플러로 전기적 절연**하고, 펄스 출력은 드라이버 측 입력 방식과 무관하게 동작하도록 **라인 드라이버**를 사용해 외부 장비 구동 시 발생하는 전기적 노이즈에 강건하게 설계한다.
