# 조사 — 로봇 모션제어 인터페이스 설계

## A. NCS 대조 결과

NCS 학습모듈 117/118의 **3-2 "모션 제어 통신 회로 설계"**(수행내용, footer p.69~74)에 EtherCAT 슬레이브 컨트롤러(ESC) 상세 구조가 나온다. **Distributed Clocks(분산 클럭) 기능**이 표에 "64bit" 폭으로 명시되어 있고, EtherCAT은 이 기능으로 네트워크 전체 노드 간 정밀 동기화를 지원한다 — 문제은행 Q459(EtherCAT DC 특징)에 대응. 다만 이 절 자체는 수행내용(실기)이라 CAN/SPI/I2C 등 나머지 프로토콜 세부사항은 문제은행·웹조사로 보완한다.

## B. 웹 검색 결과

1. **CAN SYNC 메시지(CANopen)**: SYNC 생산자(보통 정밀 클록을 가진 컨트롤러)가 주기적으로 SYNC 메시지를 브로드캐스트하면, 여러 SYNC 소비 노드들이 이를 기준으로 입력 샘플링·출력 구동을 동시에 수행 — **분산된 여러 장치 간 동기 제어**가 목적. — [CANopen SYNC](https://www.embedded-communication.com/en/canopen/canopen-sync/)
2. **SPI 통신**: 마스터가 클록(SCK)과 칩선택(SS/CS)을 구동해 하나 이상의 슬레이브와 통신하는 **마스터-슬레이브 구조**. 데이터 선(MOSI/MISO)이 분리되어 있어 **전이중(full-duplex) 통신** 가능. 여러 슬레이브를 연결할 수 있지만 슬레이브 수만큼 SS 선이 늘어나며, **슬레이브는 마스터를 통해서만 통신하고 슬레이브끼리 직접 데이터를 공유하지 않는다**(마스터가 먼저 시작해야 슬레이브가 응답 가능). — [SPI 통신, velog](https://velog.io/@lutein/SPISerial-Peripheral-Interface%EB%9E%80)
3. **SPI CPOL/CPHA 모드**: 클록 극성(CPOL, 2가지)과 클록 위상(CPHA, 2가지)의 조합으로 **2×2=4가지 모드(Mode 0~3)**가 정의된다(SPI 표준 지식).
4. **I2C 클록 스트레칭(Clock Stretching)**: 슬레이브가 8번째 클록 이후(ACK/NAK 이전 등) SCL 라인을 로우로 유지해 마스터를 대기 상태로 만드는 메커니즘. 목적은 **슬레이브가 데이터 처리(수신 데이터 저장, 다음 바이트 준비 등)에 필요한 시간을 확보**하는 것. — [What Causes I2C Clock Stretching?](https://www.totalphase.com/blog/2020/01/what-causes-i2c-clock-stretching-when-is-it-needed/)
5. **실시간 통신의 지터(Jitter) 최소화**: 우선순위 기반 스케줄링, 인터럽트 처리 시간 최소화, 결정론적 통신 프로토콜(EtherCAT 등)은 지터를 줄이는 표준적 방법. 반면 **"버퍼 크기 최대화"는 지연시간(latency)을 늘려 오히려 실시간 제어의 결정성을 해치므로 지터 최소화 방법으로 부적절**(지터 버퍼는 스트리밍처럼 지연 허용이 큰 응용에는 유효하나, 로봇의 hard real-time 제어 루프에는 부적합). — [지터란 무엇인가](https://velog.io/@agnusdei1207/jitter)

## C. 결론(도메인 지식으로 보완)

- **엔코더 신호 처리 방식 중 부적절한 것**: 4체배 방식·A/B상 위상차 검출·Z상 기준점 검출은 모두 엔코더 신호 처리의 표준 기법이지만, **PWM 신호 변조는 모터 구동(출력) 방식이지 엔코더 신호(입력) 처리 방식이 아니다** — 부적절한 선택지.
- **CAN 통신의 특징**: **멀티마스터 구조**(과목1 학습에서 이미 확인 — 임의의 노드가 버스 점유를 시도할 수 있고 비트 단위 중재로 충돌 해결). 마스터-슬레이브 구조나 점대점 전용, 아날로그 신호 전송은 CAN의 특징이 아니다.
- **동기화(Synchronization)가 필요한 경우**: 단일 축 제어는 다른 축과 맞출 필요가 없어 동기화가 불필요하지만, **다축 협조 제어**(여러 관절이 하나의 궤적을 이루며 동시에 움직여야 하는 경우)는 축 간 시간 동기가 필수적이다.

## D. 페이지 구성 설계

1. 개요
2. 직렬 통신 인터페이스 (SPI 구조·CPOL/CPHA 4모드·전이중, I2C 클록 스트레칭)
3. 필드버스·실시간 동기화 (CAN SYNC·멀티마스터, EtherCAT DC, 지터 최소화, 엔코더 신호처리, 다축 동기화)
