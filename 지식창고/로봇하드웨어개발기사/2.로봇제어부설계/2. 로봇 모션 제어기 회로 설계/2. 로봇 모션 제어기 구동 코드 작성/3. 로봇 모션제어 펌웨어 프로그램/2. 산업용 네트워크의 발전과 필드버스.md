# Summary

산업용 네트워크는 아날로그 일대일 연결에서 시작해 분산제어시스템·업체 독자 네트워크의 종속성 문제를 거쳐 표준 필드버스로 발전했다. 필드버스는 디바이스·셀·플랜트 3계층으로 나뉘고, 매체접속제어(MAC) 방식은 라운드로빈·경쟁·예약 3가지로 구분된다.

# Notes

<aside>산업용 네트워크의 발전 과정</aside>

| 시기 | 방식 | 특징/문제점 |
|---|---|---|
| 1970년대 | 4-20mA 아날로그 **일대일(point-to-point)** | 필드 센서-중앙 제어컴퓨터 직결 |
| 1980년대 초 | **분산제어시스템(DCS)** | 제어 기능을 여러 컴퓨터로 분산, 업체별 **독자 네트워크 모델**로 종속·고가 프로토콜 변환장치 필요 |
| 1980년대 초 | MAP/MiniMAP(GM·IBM) | PNP 표준화 시도, 생산현장 실시간 전송에 부적합 |
| 1980년대 후반 | **필드버스(fieldbus)** 개발 | 필드 장비 간 실시간 통신, 점대점 대비 상호 호환성·확장성·유지보수성 향상 |
| 1999년 | **IEC 61158** 국제표준 제정 | Profibus·Fieldbus Foundation·WorldFIP 등 포함 |

<aside>필드버스의 계층 구조</aside>

| 계층 | 통신 대상 | 주요 프로토콜 |
|---|---|---|
| 디바이스 계층(device level) | 센서·액추에이터 간 | EtherCAT, Mechatronlink, SERCOS 등 필드버스 |
| 셀 계층(cell level) | PLC·로봇 간 | 스위치드 이더넷 |
| 플랜트 계층(plant level) | 산업용컴퓨터·DB 간 | 스위치드 이더넷 |

- 필드버스와 이더넷은 **게이트웨이**를 통해 데이터 교환

<aside>매체접속제어(MAC) 방식 3종</aside>

| 방식 | 원리 | 대표 프로토콜 |
|---|---|---|
| **라운드로빈(round robin)** | 각 스테이션에 순차적으로 전송 기회 부여 | 중앙집중형: WorldFIP(스케줄링) / 분산형: Profibus(토큰패싱) |
| **경쟁(contention)** | 스테이션들이 전송권을 경쟁 획득 | DeviceNet·LonWorks(CSMA 변형) |
| **예약(reservation)** | 전송매체를 슬롯으로 나눠 예약 후 사용 | Interbus |

---

<aside>핵심 정리</aside>

- 발전 순서: 아날로그 일대일 → DCS(독자모델 문제) → 필드버스 → IEC 61158 표준화
- 필드버스 계층: 디바이스(필드버스)/셀·플랜트(스위치드 이더넷), 게이트웨이로 연결
- MAC 3방식: 라운드로빈(순차)·경쟁(CSMA)·예약(슬롯)
