# Summary

상위 제어기가 모션 제어기에 명령을 내릴 때는 명령을 곧바로 실행하지 않고 큐(queue)에 버퍼링해, 이전 모션이 끝나는 즉시 다음 모션을 지연 없이 이어 실행한다. 문제은행 1문항이며 NCS 대응 내용이 없어 웹조사로 작성했다.

<aside>모션 명령 큐(Motion Command Queue)</aside>

- 상위 제어기가 내린 모션 명령을 즉시 실행하지 않고 큐에 버퍼링
- 목적: **모션 명령의 버퍼링과 연속 실행** — 이전 모션 프로그램이 완료된 직후 중단 없이 다음 모션을 이어서 실행
- 연속으로 많은 짧은 이동이 필요한 응용(CNC 가공 등)에서 특히 유용
- 모터 드라이버의 전류 제한, 최대 속도 증가, 위치 피드백 값 저장이 목적이 아님

---

<aside>핵심 정리</aside>

- 명령 큐 = "버퍼링 + 연속 실행"이 핵심 목적, 전류·속도·피드백 저장과는 무관
