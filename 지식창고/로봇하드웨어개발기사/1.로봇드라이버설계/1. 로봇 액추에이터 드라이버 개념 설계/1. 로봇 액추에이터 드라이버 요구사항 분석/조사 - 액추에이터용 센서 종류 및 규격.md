# 액추에이터용 센서 종류 및 규격 — 조사 원자료 (정보덩어리)

## A. NCS 학습모듈 대조 결과

학습1 "필요 지식"(footer p.3~16)은 서보모터/스테핑모터/모터규격/인버터 위주이고, **액추에이터용 센서(엔코더 이외의 레졸버·타코제너레이터·힘토크센서·홀센서 등)에 대한 상세 설명은 없음** — §1 원칙대로 NCS 모듈 대응 없음으로 기록하고 웹조사+문제은행(39문항)으로 구성.

## B. 웹 검색 결과 (2026-08-01 조사)

### B1. 엔코더 증분형/절대형
- 기존 Box 용어 [[엔코더(Encoder)]]에 이미 상세히 있음 — 중복 서술 안 하고 링크만

### B2. 레졸버(Resolver)
- 구조: 기준(reference)·SIN·COS 세 개의 코일 권선. 기준 권선(1차)이 회전식 변압기를 통해 AC 전압으로 여자됨
- 회전식 변압기 방식이라 **브러시·슬립링이 필요 없어** 신뢰성·견고함이 높음
- 절대위치 검지가 필요하고 기계적으로 견고해야 하는 장소(고온·진동·먼지 등 가혹 환경)에 쓰임 — 하이브리드차 구동모터 등 벡터제어용 절대위치 검출에도 사용
- 출력은 사인·코사인 아날로그 전압비 → 위치값을 얻으려면 **R/D 컨버터(Resolver-to-Digital Converter)**로 복조·디지털 변환 필요
- 출처: [리졸버를 사용하여 모터 각위치와 각속도를 정밀하게 결정하는 방법 (DigiKey)](https://www.digikey.kr/ko/articles/how-to-precisely-determine-motor-angular-position-and-velocity-with-a-resolver), [모터 정밀 제어를 위한 레졸버 센서 신호처리 구조 (DBpia)](https://www.dbpia.co.kr/journal/articleDetail?nodeId=NODE08761766)

### B3. 타코제너레이터(Tachogenerator)
- 발전기 원리(전자기 유도)를 이용해 회전 속도를 그에 비례하는 **아날로그 전압**으로 직접 출력하는 속도 전용 센서
- 대부분 브러시형 DC 타입(영구자석 고정자+권선형 회전 전기자), 전압-속도 관계가 지정 범위 내에서 매우 선형(V = K × RPM)
- 별도의 미분 연산(엔코더 펄스 미분) 없이 속도를 직접 얻을 수 있다는 것이 장점
- 출처: [What is a tachogenerator and when is it used?](https://www.motioncontroltips.com/what-is-a-tachogenerator-and-when-is-it-used/), [D.C Tachogenerator Principle](https://instrumentationtools.com/d-c-tachogenerator-principle/)

### B4. 리니어 포텐셔미터
- 슬라이드(와이퍼)가 저항체 위를 직선으로 움직이며 위치에 비례하는 **아날로그 전압(분압비)**을 출력하는 접촉식 직선 위치 센서
- Wire 방식 접촉식 리니어 센서에서 감지소자(sensing device)로 포텐셔미터 또는 엔코더가 쓰이며, 포텐셔미터는 아날로그 0~10V 출력이 대표적
- **접촉식**이므로(슬라이더-저항체 물리적 접촉) 마모가 발생해 수명이 제한된다는 점이 비접촉식 센서 대비 단점(이 부분은 일반적으로 널리 알려진 상식 수준이며, 이번 검색에서 "접촉식→마모→수명제한"을 직접 명시한 출처를 못 찾음 — 정성적 서술로만 쓰고 구체적 수명 수치는 안 씀)
- 출처: [포지션 센서의 특징과 동작원리](https://visionsystem.kr/technical-info?tpf=board%2Fview&board_code=1&code=453)

### B5. 스트레인 게이지 게이지 팩터
- 공식: $GF = \dfrac{\Delta R/R}{\varepsilon}$ (저항변화율/변형률) → $\Delta R = GF \times R \times \varepsilon$ (기존 서술과 일치)
- 금속 포일 게이지 GF ≈ 2.0(내가 예제에 쓴 값과 일치, 신뢰 가능), 반도체 게이지는 GF 50~150(감도 높지만 비선형성도 큼)
- 미세한 저항 변화이므로 **휘트스톤 브리지**로 정밀 측정
- 출처: [스트레인게이지 원리·종류·선정 가이드](https://www.cndtec.co.kr/resources/strain-gauge.html), [Gauge factor (Wikipedia)](https://en.wikipedia.org/wiki/Gauge_factor)

### B6. 6축 F/T 센서 크로스토크
- 크로스토크: 인접 신호(축)간 원치 않는 간섭으로 신호가 섞이는 현상(일반적 전자공학 정의)
- 6축 F/T 센서 설계에서는 **각 축 하중에 대한 출력 변형률이 비슷한 수준이 되도록 스트레인게이지 위치를 정하고, 상호간섭 변형률이 최소화되도록 브리지 회로를 구성**해 크로스토크를 줄인다 — 탄성체 구조·게이지 배치가 핵심 설계 변수라는 기존 서술과 부합
- 6축 조인트 캘리브레이션(교정 행렬)으로 컴포넌트 간 크로스토크를 추가로 줄임 — 기존에 "캘리브레이션(교정 행렬)으로 보정"이라 쓴 것과 일치
- 출처: [유연한 고정단을 가진 6축 F/T 센서의 설계](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART001446033)

### B7. 홀 센서와 BLDC 커뮤테이션
- 홀센서 3개가 **회전자 주위에 전기각 120도 간격**으로 배치(기존 서술과 일치)
- 구형파(6-step) 제어 방식에서는 홀센서가 전기각 60도씩 차이나는 불연속 출력을 냄 → 3개 신호 조합이 총 6가지로 나뉨(기존 서술 "6가지 조합, 60도 간격"과 일치)
- 홀센서는 홀 효과(자석 접근 시 자기장 세기 감지)로 회전자 위치를 검출해 스위칭 소자(통전 상)를 결정
- 출처: [위치 인코더로 BLDC 홀 센서 사용하기 1부 (DigiKey)](https://www.digikey.kr/ko/blog/using-bldc-hall-sensors-as-position-encoders-part-1)

### B8. 전류 센서 대역폭(토크 제어)
- 모터 토크는 권선 전류에 직접 비례 → 전류를 정확히 측정해야 토크를 정밀 제어 가능(기존 서술과 일치)
- **대역폭이 낮으면(응답이 느리면) 토크 측정·제어가 둔하고(sluggish) 노이즈가 섞이며, 대역폭이 높으면 정확하고 즉각적인(crisp, precise) 토크 제어가 가능** — 자동차용 예시 기준 전류센서 대역폭은 통상 40kHz 이상(모터 기본파 최대 2kHz까지 따라가기 위해)이 요구되는 경우도 있음(구체적 kHz 수치는 응용 분야마다 다르므로 본문에는 "정성적으로 대역폭이 낮으면 응답 지연·왜곡"까지만 쓰고 특정 kHz 값은 넣지 않는다)
- 출처: [Automotive Current Sensor for Motor Control (LEM)](https://www.lem.com/en/automotive-motor-control), [CURRENT SENSING IN MOTOR DRIVES (Allegro)](https://www.allegromicro.com/-/media/files/application-notes/an296276-current-sensing-in-motor-drives.pdf?sc_lang=en)

### B9. 그레이코드(절대형 엔코더)
- 인접한 값 사이에 **1비트만 변화**하도록 설계된 이진 코드(기존 서술과 정확히 일치)
- 이유: 여러 비트가 동시에 바뀌는 순간(경계값 통과 시) 읽기 타이밍이 미세하게 어긋나면 큰 오차(글리치)가 발생할 수 있는데, 그레이코드는 1비트만 바뀌므로 이 오독 가능성을 최소화
- 출처: [An Introduction to Gray Code for Encoders](https://control.com/technical-articles/an-introduction-to-gray-code-for-encoders/)

## C. 결론 — 기존 서술 대비 정정 사항

- 대부분 이전에 썼던 서술이 검색 결과와 일치함(엔코더 위상차, 그레이코드, 레졸버 R/D변환, 타코제너레이터, 크로스토크 원인, 홀센서 120도/6가지조합, 게이지팩터 공식)
- **리니어 포텐셔미터의 "접촉식→마모→수명제한" 인과관계와 전류센서 "대역폭 낮으면 응답지연" 구체적 kHz 수치**는 직접 뒷받침하는 명확한 출처를 못 찾아 정성적 서술로 완화하고 숫자는 넣지 않는다
