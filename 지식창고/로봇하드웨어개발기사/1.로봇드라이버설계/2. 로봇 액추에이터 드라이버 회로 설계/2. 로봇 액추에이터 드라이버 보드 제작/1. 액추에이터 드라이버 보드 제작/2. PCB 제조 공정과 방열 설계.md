# Summary

다층 PCB(MLB, multi layer board)는 **16개 공정**으로 제작되며 그중에서도 **이메징·적층·도금·코팅**이 핵심 공정이다. 완성된 보드는 소자의 발열을 고려한 **방열 설계**까지 반영해야 한다.

# Notes

<aside>PCB 제조 공정 흐름</aside>

제단 → **내층이메징**(박막 내층기판에 정밀 회로 형성) → **내층표면처리**(화학적 방법으로 결합력 향상) → **적층**(회로 형성된 내층재+절연재를 합프레스, 고청정도 요구) → 드릴 → 고정도 솔더레지스트 코팅 → **소구경도금**(화학·전기적 방법, 10~15미크론) → **외층이메징**(표면실장용 첨단부품 탑재 위해 50~80미크론 Fine Pattern 형성) → **파인패턴도금**(15미크론가량 동 도금) → 외층에칭박리 → 노광현상 → **외형가공**(NC Router로 사용자 요구 사양에 맞춰 가공) → 검사 → 출하검사 → 포장

이 16개 공정 중 회로 정밀도와 신뢰성을 좌우하는 핵심은 **이메징(정밀 회로 패턴 형성)·적층(다층 합프레스)·도금(전기적 접속 형성)·코팅(보호막 형성)**이다.

<aside>방열 설계 고려사항</aside>

액추에이터 드라이버 보드의 방열 설계에서는 **열저항 계산**([[6. 전류 센싱과 BLDC 3상 구동회로|이전 세부항목]]에서 다룬 $\Delta T=R_{th}\times P$), **방열판(히트싱크) 크기**, **공기 순환**(컨벡션)을 함께 고려한다. 소프트웨어 버그는 방열 설계와 무관한 요소다.

---

<aside>핵심 정리</aside>

- PCB 제조 16개 공정 중 핵심은 **이메징·적층·도금·코팅**
- 방열 설계 = 열저항 계산 + 방열판 크기 + 공기 순환(소프트웨어 요소는 해당 없음)
