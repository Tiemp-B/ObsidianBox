# Summary

서보 드라이버의 제어 구조는 **토크 제어 루프(가장 안쪽) → 속도 제어 루프 → 위치 제어 루프(가장 바깥쪽)**의 3단 폐루프로 구성되며, 각 루프는 [[1. 액추에이터 제어방식 개요|개루프·폐루프]]의 폐루프(피드백) 원리를 그대로 따른다.

# Notes

<aside>개루프와 폐루프의 실제 혼재</aside>

현장에서는 개루프 제어가 폐루프보다 더 많이 쓰인다(구성이 간단하고 적용이 쉬움). 다만 개루프·폐루프가 한 시스템 안에 **혼재**되는 경우가 흔하다 — 예를 들어 컨베이어를 유도전동기+인버터로 구동할 때, 인버터 **내부의 전류 제어는 폐루프**이지만 컨베이어 전체(부하 변화에 대한 속도 유지)는 사람이 직감으로 조정하는 **개루프**로 볼 수 있다. 스테핑 모터도 마찬가지로 **드라이버 내부 전류 제어는 폐루프**(전류제어형의 경우)이지만, **모터가 탈조해도 상위 제어기가 알 방법이 없는 시스템 전체는 개루프**다.

<aside>서보모터 3단 제어 루프</aside>

| 루프 | 제어 대상 | 특징 |
|---|---|---|
| 토크 제어 루프 | 서보모터에 흐르는 전류(=토크) | 가장 기본적인 루프. 전류 검출기로 되먹임받아 토크 지령과 비교 — **서보모터 전체를 감싸는 루프가 아니라 개루프처럼 일정 전류만 공급**하는 구조 |
| 속도 제어 루프 | 서보모터 회전 속도 | 내부에 토크 제어 루프를 포함(폐루프). 속도 검출기(타코제너레이터/광학식 엔코더)로 서보모터 외부에서 되먹임 |
| 위치 제어 루프 | 서보모터 회전 위치 | 내부에 속도+토크 루프를 모두 포함하는 최외곽 루프 |

오차출력 = 지령값 - 되먹임 신호값이며, 이 오차를 제어연산 증폭기에 넣어 다음 안쪽 루프의 지령으로 전달한다.

<aside>제어연산 증폭기: P + Feed-forward 연산</aside>

교과서적인 PID(비례·적분·미분) 중, **상용 서보 드라이버는 적분·미분 연산은 잘 적용하지 않고 비례(P) 연산과 feed-forward(F) 연산을 주로 사용**한다 — "서보 드라이버의 제어연산 증폭기는 항상 완전한 PID 연산을 수행한다"는 서술은 실제 상용 제품의 관행과 어긋난 오답(함정)이다. feed-forward 연산은 위치명령의 변화를 오차연산과 별도로 속도명령에 바로 전달해, 위치명령에 대한 빠른 응답을 얻기 위해 쓰인다.

---

<aside>핵심 정리</aside>

- 개루프·폐루프는 시스템 전체 관점과 내부 구성요소 관점이 다를 수 있다(예: 인버터 내부 전류제어=폐루프, 컨베이어 전체=개루프)
- 서보모터 제어는 **토크(안)→속도→위치(밖)** 3단 폐루프 구조
- 상용 서보 드라이버는 PID 중 **P+F(feed-forward) 연산** 위주로 사용, 적분·미분은 잘 안 씀
