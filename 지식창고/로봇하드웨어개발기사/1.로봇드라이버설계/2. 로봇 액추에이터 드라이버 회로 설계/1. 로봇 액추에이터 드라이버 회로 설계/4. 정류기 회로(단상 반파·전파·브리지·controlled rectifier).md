# Summary

드라이버 회로는 교류 입력을 직류로 바꾸는 **정류기**에서 시작한다. 다이오드만 쓰는 단순 정류기(반파·전파·브리지)와, 스위치 소자로 지연각을 조절해 평균 출력 전압을 가변하는 **controlled rectifier**로 나뉜다.

# Notes

<aside>다이오드 정류기: 반파·전파·브리지</aside>

| 종류 | 다이오드 수 | 특징 |
|---|---|---|
| 단상 반파 정류기 | 1개 | 입력 전압 양(+)의 반주기만 도통, 음(-)의 반주기엔 출력 0V |
| 단상 전파 정류기(센터탭) | 2개 | 변압기 센터탭 이용, 변압기에 DC 성분 없어 코어 포화 문제 없음. 다이오드 역전압 최대치가 **입력 전압 최대치의 2배** |
| 단상 전파 정류기(브리지) | 4개 | **bridge rectifier**라 불리며 산업기기·정류회로에서 가장 널리 사용. 다이오드 역전압 최대치는 입력 전압 최대치와 같음(센터탭 방식보다 소자 부담 작음) |

<aside>Controlled Rectifier(제어 정류기)</aside>

다이오드만 쓰는 정류기는 **정해진 평균 출력 전압만 얻을 수 있다**는 한계가 있다. 원하는 평균 출력 전압을 얻으려면 스위치 소자(사이리스터 등)를 써서 도통 시간을 조절하는데, 이때 제어 변수를 **지연각(firing angle, delay angle) $\alpha$**라 한다. 이런 controlled rectifier는 구조가 간단·저렴하고 기대 효율이 **약 95%**로 높다.
- semiconverter: 1상한(quadrant) 동작, 출력 전압·전류 극성이 양(+)뿐
- full converter: 1상한+4상한 동작 가능, 출력 전압 극성은 양·음 모두 가능하나 전류 극성은 양만 가능
- dual converter: 모든 상한에서 동작 가능

단상 반파 controlled rectifier 기준 평균 출력 전압은 $V_{dc}=\dfrac{V_m}{2\pi}(1+\cos\alpha)$로 표현되며, 지연각 $\alpha$를 0에서 $\pi$까지 바꾸면 평균 출력 전압을 $V_m/\pi$에서 0까지 얻을 수 있다(최대 평균 출력 전압은 $\alpha=0$일 때, $\alpha$가 커질수록 $\cos\alpha$가 감소해 평균 출력 전압도 낮아진다).

---

<aside>핵심 정리</aside>

- 반파(다이오드1개)<전파-센터탭(다이오드2개, 역전압 2배)<전파-브리지(다이오드4개, 역전압 1배, 산업표준)
- Controlled rectifier는 지연각 $\alpha$로 평균 출력 전압을 가변(0→π일수록 전압 감소), 효율 약 95%
- semiconverter(1상한)<full converter(1·4상한)<dual converter(전상한) 순으로 동작 가능 범위가 넓어짐
