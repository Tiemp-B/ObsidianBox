# Summary

센서 신호는 출력 형태(전압/전류, 디지털/아날로그/통신)와 값 확인 절차(스탠바이/요구응답/주기응답/연속스트림)로 분류되며, MCU는 이를 폴링 또는 인터럽트로 확인한다. 실시간 처리는 알고리즘 복잡도가 좌우하고, 병렬 처리에는 FPGA가 유리하며, 표준편차로 측정값의 분산 정도를 평가한다. NCS 필요지식(학습모듈 121/122 학습3 §2, footer p.81~83)이 핵심 출처다.
