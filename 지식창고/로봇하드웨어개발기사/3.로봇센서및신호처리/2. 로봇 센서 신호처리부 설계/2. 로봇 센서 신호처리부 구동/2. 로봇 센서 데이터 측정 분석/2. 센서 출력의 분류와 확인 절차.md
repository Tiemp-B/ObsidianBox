# Summary

센서 출력은 물리적 형태(전압/전류)와 MCU 입력 신호 형태(디지털/아날로그/통신)로 나뉘고, 값을 확인하는 절차는 스탠바이형·요구-응답형·주기 응답형·연속 스트림형으로 구분된다.

# Notes

<aside>물리적 출력 형태</aside>

| 형태 | 설명 |
|---|---|
| 전압 출력형 | 측정값을 전압으로 출력 |
| 전류 출력형 | 측정값을 전류로 출력, 저항을 연결해 전압으로 변경해 사용 |

<aside>MCU 입력 신호 형태</aside>

| 형태 | 설명 |
|---|---|
| 디지털 신호형 | 측정값을 디지털 신호로 출력 |
| 아날로그 신호형 | 측정값을 아날로그 신호로 출력, ADC로 디지털 변환 |
| **통신 신호형** | 정해진 방식의 디지털 통신으로 일련의 신호 전송. **Fieldbus**(DeviceNet, CAN, ProfiBus, Ethernet 등)는 **ISO 15735** 국제표준. 변환기를 통해 USART(RS-232)로 MCU에 전달되거나, 드라이브 회로를 따로 구성해 MCU에 연결 |

<aside>센서값 확인 절차에 따른 분류</aside>

| 분류 | 설명 |
|---|---|
| **스탠바이형** | 센서의 측정값이 항상 준비되어 있어 MCU가 읽어오기만 하면 됨 |
| **요구-응답형** | MCU가 요청할 때 센서가 측정값을 전송 |
| **주기 응답형** | MCU의 요청이 없어도 센서가 정해진 주기마다 측정값을 전송 |
| **연속 스트림형(continuous stream)** | 센서의 측정이 완료되는 대로 계속하여 측정값을 전송 |

---

<aside>핵심 정리</aside>

- 물리적 출력(전압/전류) × 신호 형태(디지털/아날로그/통신) × 확인 절차(스탠바이/요구응답/주기응답/연속스트림) — 세 축을 조합해 센서-MCU 인터페이스를 설계
