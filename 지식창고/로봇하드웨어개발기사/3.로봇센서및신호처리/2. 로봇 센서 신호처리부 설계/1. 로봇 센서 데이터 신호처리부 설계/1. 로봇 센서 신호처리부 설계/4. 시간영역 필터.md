# Summary

이동평균필터는 윈도우가 클수록 노이즈 제거는 강해지지만 위상 지연도 커지고 급격한 변화 검출에는 불리하다. 중앙값 필터는 임펄스성 노이즈를, 적응필터는 신호 특성에 맞춰 계수를 바꿔가며 대응한다. FIR은 항상 안정하고 선형위상이지만 연산량이 많고, IIR은 적은 연산량으로 구현되지만 피드백 구조로 불안정해질 수 있다.

# Notes

<aside>이동평균 필터(Moving Average Filter)</aside>

- FIR 필터의 일종. 윈도우 안의 값들을 평균 내어 노이즈를 매끄럽게 함(저역통과 특성)
- **윈도우 크기가 클수록**: 노이즈 제거 효과 **증가**(감소율은 윈도우 내 포인트 수의 제곱근에 비례), 동시에 **위상 지연(신호 지연)도 증가**(단순 이동평균의 지연은 대략 윈도우 크기의 절반)
- **급격한 신호 변화(에지) 검출에는 불리**(신호 자체를 뭉갬)
- 계산이 간단하고 구현이 쉬우며 실시간 처리가 가능. 랜덤 노이즈 제거에 효과적이나 위상 지연은 필연적으로 발생

<aside>중앙값(미디언) 필터(Median Filter)</aside>

- 비선형 필터. 창 안의 값을 정렬해 중앙값을 출력
- **임펄스성(스파이크성) 노이즈 제거에 효과적**이며, 선형 필터보다 경계(edge)·급격한 신호 변화를 잘 보존

<aside>적응 필터(Adaptive Filter)</aside>

- 가변 매개변수(필터 계수)를 최적화 알고리즘으로 조정하는 필터
- **핵심 특징**: **신호 특성에 따라 필터 계수가 변함**(고정 계수 필터와 대조) — 오류 신호 피드백으로 비용함수를 최소화하도록 계수를 갱신(LMS, RLS 등)

<aside>IIR 필터 vs FIR 필터</aside>

| 구분 | IIR(무한 임펄스 응답) | FIR(유한 임펄스 응답) |
|---|---|---|
| 구조 | **피드백 있음**(과거 출력 사용) | 피드백 없음(탭 지연선) |
| 임펄스 응답 | 무한히 지속 | 유한 |
| 안정성 | **불안정해질 수 있음** | **항상 안정** |
| 위상 | 비선형 | **선형**(왜곡에 강건) |
| 연산량 | 적음(같은 특성에 계수 더 적게 필요) | **많음**(같은 특성에 더 많은 계수 필요) |

- **IIR 필터의 핵심 특징**: 피드백 구조로 인한 불안정성이 있을 수 있음
- **IIR이 FIR보다 항상 성능이 우수한 것은 아님** — 선형 위상이 중요하면 FIR, 적은 계수(메모리·연산 절약)가 중요하면 IIR을 선택하는 트레이드오프 관계

<aside>디지털 필터의 장점</aside>

- R·L·C 같은 아날로그 소자와 달리, 계수(소프트웨어)로 구현되어 **온도 변화·경년 변화(부품 노후화)에 안정적**이며 복잡한 필터 특성도 프로그램만으로 구현 가능
- **연산에 소요되는 처리 지연시간은 반드시 존재**

---

<aside>핵심 정리</aside>

- 이동평균필터: 윈도우↑→노이즈제거↑·위상지연↑, 급격한변화 검출엔 불리
- 중앙값필터=임펄스노이즈, 적응필터=계수가 변함
- FIR=항상안정·선형위상·연산량많음, IIR=피드백·불안정가능·연산량적음, 둘 다 "항상 우수"는 없음
- 디지털필터는 온도/경년변화엔 강하지만 처리지연은 반드시 존재
