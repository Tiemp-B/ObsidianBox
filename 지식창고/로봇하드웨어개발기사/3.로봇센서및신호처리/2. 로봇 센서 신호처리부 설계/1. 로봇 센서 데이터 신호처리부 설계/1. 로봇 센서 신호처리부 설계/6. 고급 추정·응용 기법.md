# Summary

칼만 필터는 잡음 섞인 측정치로 시스템 상태를 추정하고 센서 퓨전에도 쓰이지만 주파수 응답 개선과는 무관하다. 초음파의 다중 반사는 시간 윈도우(타임 게이팅)로 걸러내고, 비전 센서의 이미지 전처리에는 노이즈 제거·명암대비 향상·기하학적 보정이 포함되지만 모터 제어는 포함되지 않는다.

# Notes

<aside>칼만 필터(Kalman Filter)</aside>

- 잡음이 포함된 측정치로부터 선형 역학계의 **상태를 추정**하는 재귀 필터(예측→갱신 2단계 반복)
- **사용 이유**: 시스템의 상태 추정, 센서 융합(센서 퓨전), 측정 노이즈 제거 — **주파수 응답 개선은 칼만 필터의 목적이 아님**(칼만 필터는 시간영역 상태추정 기법이지 주파수영역 필터 설계 기법이 아님)
- **설명으로 적절한 것**: 시스템 모델과 측정값을 결합하여 최적 추정을 수행(비선형 시스템에만 적용 가능·과거 모든 측정값 저장 필요·연산량 많아 실시간 불가능은 모두 틀린 서술 — 기본 칼만 필터는 선형 시스템용이며, 재귀적이라 과거값을 모두 저장할 필요 없고, 계산 비용이 작아 MCU에서도 실시간 처리 가능)
- 급격한 신호 변화를 가장 잘 보존하면서 노이즈를 제거하는 방법으로도 꼽힘(이동평균필터·저역통과필터보다 우수 — 모델 기반 예측 덕분)

<aside>초음파 센서의 다중 반사(Multipath) 처리</aside>

- 여러 표면에서 반사되어 돌아오는 다중 에코 문제
- **가장 효과적인 방법**: **시간 윈도우 필터링(타임 게이팅)** — 예상 반사 도달 시간 범위 밖의 신호는 무시하고, 그 범위 안의 신호만 유효한 것으로 인정
- 중앙값·평균값·미분 필터는 일반 노이즈 제거 기법이지, 특정 시간대의 반사만 선별하는 다중경로 억제 기법은 아님

<aside>비전 센서의 이미지 전처리(Image Preprocessing)</aside>

- 포함되는 과정: **노이즈 제거**, **명암 대비 향상**, **기하학적 보정**(렌즈 왜곡 보정 등)
- **포함되지 않는 것**: **모터 제어** — 모터 제어는 이미지 처리 결과를 바탕으로 한 후속 동작 단계이지 이미지 전처리 과정 자체가 아님

<aside>핵심 정리</aside>

- 칼만필터=상태추정·센서퓨전·노이즈제거(주파수응답개선은 아님), 초음파 다중반사=시간윈도우(타임게이팅)
- 비전센서 전처리=노이즈제거·명암대비향상·기하학적보정(모터제어는 전처리 아님)
