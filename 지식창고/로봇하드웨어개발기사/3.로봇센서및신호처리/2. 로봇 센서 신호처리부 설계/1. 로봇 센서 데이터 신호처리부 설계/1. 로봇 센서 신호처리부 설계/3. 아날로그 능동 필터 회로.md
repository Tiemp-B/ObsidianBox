# Summary

OP앰프는 입력 임피던스가 매우 크고 출력 임피던스가 매우 작으며, 부궤환 구성 시 가상 단락이 일어난다. 이를 이용해 전압팔로워·비반전·반전 증폭기를 만들고, 수동 필터 뒤에 붙이면 컷오프 주파수와 이득을 독립적으로 설계할 수 있는 능동 HPF/LPF가 된다. 힘 센서는 휘트스톤 브리지로 신호를 조정한다.

# Notes

<aside>OP앰프(Op-Amp)의 기본 특징</aside>

- **입력 임피던스가 매우 큼**(이론상 무한대)
- **출력 임피던스가 매우 작음**(이론상 0)
- 개방 루프 이득이 매우 큼, 동상 제거비(CMRR)가 높음
- '-'단자로 부궤환을 만들면 **가상 단락**(V₊=V₋)이 일어나고, 두 단자 사이에는 전류가 흐르지 않음

<aside>OP앰프 기본 회로 3종</aside>

| 회로 | 이득(Av) | 특징 |
|---|---|---|
| **전압 팔로워** | 1 | 전후 회로를 전기적으로 분리, 신호는 그대로 전달(버퍼) |
| **비반전 증폭기** | 1+RF/RG | 입력과 같은 부호, 증폭만 가능(1 미만으로는 축소 불가) |
| **반전 증폭기** | -RF/RG | 입력과 반대 부호, 증폭·축소 모두 가능(RF=RG면 반전기) |

<aside>능동 HPF/LPF</aside>

- RC 수동 필터 뒤에 비반전/반전 증폭기를 연결한 구조
- OP앰프의 높은 입력 임피던스 덕분에 전후 회로가 서로 격리 → **수동 필터의 컷오프 주파수(fc)와 OP앰프의 이득(Av)을 독립적으로 계산**할 수 있음(수동 필터만 쓸 때보다 설계가 단순해짐)
- 2차 필터(R·C 2개씩)로 컷오프 주파수 특성을 더 급격하게 만들 수 있음

<aside>휘트스톤 브리지(Wheatstone Bridge)</aside>

- 스트레인 게이지의 극도로 작은 저항 변화를 측정하는 표준 회로
- **로봇 포스(힘) 센서·로드셀의 신호 조정 회로**로 표준적으로 사용
- 안정화된 여기전압을 걸고 하중에 비례하는 차동 전압을 출력
- 풀스케일 출력이 매우 작아 ADC 입력 범위에 맞추려면 흔히 100~500배의 증폭이 필요

<aside>차동 증폭기(Differential Amplifier)</aside>

- 두 입력의 **차이**만 증폭하고 두 입력에 공통으로 실린 신호는 상쇄
- **목적**: **공통 모드 노이즈 제거**(대역폭 확대·위상지연 보상·임피던스 정합이 목적이 아님)

---

<aside>핵심 정리</aside>

- OP앰프: 입력임피던스 매우큼, 출력임피던스 매우작음, 가상단락
- 전압팔로워(Av=1, 분리)·비반전(1+RF/RG, 증폭만)·반전(-RF/RG, 증폭·축소)
- 능동필터는 수동필터+OP앰프로 컷오프·이득 독립설계, 휘트스톤브리지=힘센서 신호조정, 차동증폭기=공통모드노이즈 제거
