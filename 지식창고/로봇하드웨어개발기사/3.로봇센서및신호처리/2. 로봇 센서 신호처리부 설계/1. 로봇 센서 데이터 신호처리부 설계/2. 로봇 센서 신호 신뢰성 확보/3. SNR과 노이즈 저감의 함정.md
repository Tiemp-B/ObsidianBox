# Summary

측정 범위를 넓히거나 샘플링 주파수만 높이는 것은 SNR 개선처럼 보이지만 실제로는 역효과이거나 무관하다. 로봇 관절 속도 피드백에서 샘플링 주기를 늘리는 것도 나이퀴스트 조건을 해쳐 부적절하며, 무선 전송에서는 데이터 무결성이 최우선이다.

# Notes

<aside>SNR(신호대잡음비) 개선 방법과 함정</aside>

| 방법 | SNR 개선에 유효한가 |
|---|---|
| 차폐(Shielding) 강화 | O |
| 접지(Grounding) 개선 | O |
| 신호 증폭단의 최적화 | O(단순 증폭이 아니라 "최적화") |
| 평균화(Averaging) 처리 | O |
| **측정 범위를 최대한 확장** | **X** — ADC 비트 수 고정 시 1LSB가 커져 양자화 잡음이 상대적으로 커짐(D36 양자화 오차 원리와 동일) |
| **샘플링 주파수 증가(단독)** | **X** — 후속 저역통과필터링·평균화와 결합되지 않으면 그 자체로는 SNR을 개선하지 않음 |

<aside>로봇 관절 속도 피드백의 노이즈 저감</aside>

- 저역통과필터·이동평균필터·차동증폭기는 모두 실제 노이즈 저감에 기여하는 표준 기법
- **"샘플링 주기 증가"는 부적절** — 주기를 늘리는 것은 샘플링 **주파수를 낮추는** 것과 같은 의미(용어 함정 주의) → 나이퀴스트 조건(fs≥2fm)을 해칠 위험, 피드백 제어 루프의 응답성도 저하

<aside>무선 전송 시 가장 중요한 고려 요소</aside>

- 전송 속도·전력 소모·전송 거리도 중요하지만, 로봇 제어용 센서 데이터는 손상되면 오동작·안전사고로 이어질 수 있어 **데이터 무결성**이 최우선

<aside>급격한 신호 변화를 보존하며 노이즈를 제거하는 필터</aside>

- 미디언(중앙값) 필터: 급격한 신호 변화 제거(스파이크 제거)에 가장 적합 — 평균 필터·고역통과필터·대역통과필터보다 이 목적에 부합
- FIR 필터를 신뢰성 향상 목적으로 선택하는 이유: **위상 응답이 선형적**이라 신호 왜곡이 적음

---

<aside>핵심 정리</aside>

- 측정범위확장은 양자화잡음↑로 역효과, 샘플링주파수증가 단독으로는 SNR 무관 — 둘 다 SNR 개선 함정
- "샘플링 주기 증가"=주파수 감소(용어 함정), 무선전송 최우선=데이터무결성, 급격한변화 보존=미디언필터
