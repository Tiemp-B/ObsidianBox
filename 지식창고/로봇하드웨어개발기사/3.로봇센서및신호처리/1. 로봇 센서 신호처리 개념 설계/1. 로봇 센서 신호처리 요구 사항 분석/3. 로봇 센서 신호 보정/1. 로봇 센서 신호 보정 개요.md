# Summary

센서 신호 보정(캘리브레이션)은 재현성·히스테리시스·동작온도를 확인하고, 영점·스팬·선형성을 조정하는 절차다. NCS에는 캘리브레이션 절차 자체가 없어 문제은행 15문항(과목3에서 두 번째로 큰 규모)을 웹조사·계측공학 도메인 지식으로 작성했다.
