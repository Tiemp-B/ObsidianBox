# Summary

USART는 1:1(RS-232)/1:N(RS-422)/N:N(RS-485)로 확장되는 비동기 통신, SPI는 4가닥 근거리 동기 통신, I2C는 2가닥 표준 100Kbps 통신, CAN은 차량용 멀티마스터 N:N 통신이다. 각각 통신 거리·속도·전선 수의 트레이드오프가 다르다.

# Notes

<aside>USART(비동기 통신)</aside>

- 최소 GND·TX·RX 3가닥, Baud rate·데이터비트·스톱비트·흐름제어를 사전 설정하는 **비동기** 통신
- 1:1 = **RS-232**, 1:N = **RS-422**, N:N = **RS-485**(ANSI/TIA/EIA 표준)
- 로봇 MCU 신호(0~5V/3.3V)를 ±15V로 변환하는 **MAX232(5V용)/MAX3232(3.3V용)** 칩 사용

<aside>SPI(동기 통신)</aside>

- RS-232보다 짧은 거리의 **1:N 마스터-슬레이브 동기식** 통신
- SCLK·SS·MOSI·MISO **4가닥**
- 통신 속도는 빠르나 신호 전압 변환이 없어 **노이즈·스파크에 더 취약**, 주로 칩-칩 간 통신에 사용

<aside>I2C(TWI)</aside>

- 필립스 개발, **1:N 내부 통신**, SCL·SDA **2가닥**
- 마스터-슬레이브 방식, 표준 모드 **100Kbps**

<aside>CAN</aside>

- 원래 **차량용**으로 설계된 **멀티마스터 N:N** 통신
- 이론상 버스당 최대 **2032개** 유닛 연결 가능
- 최대 **1Mbps**(거리가 늘어날수록 속도 저하, **1Km에서는 40Kbps**)
- CAN_H/CAN_L 2선 + 전력공급용 GND/VCC를 함께 사용하는 경우가 일반적

<aside>고속 통신(참고)</aside>

- USB·EtherCAT·Bluetooth·ZigBee·Ethernet·WiFi 등은 MCU 레벨에서 직접 처리하기 어려워 **시리얼 변환기**를 거치는 경우가 많음 — 이 경우 통신 속도가 **시리얼 통신의 최대 속도로 제한**됨에 유의

---

<aside>핵심 정리</aside>

- USART 1:1/1:N/N:N = RS-232/422/485, SPI=4선 동기(칩간), I2C=2선(필립스, 100Kbps), CAN=차량용 멀티마스터(최대1Mbps, 거리↑속도↓)
