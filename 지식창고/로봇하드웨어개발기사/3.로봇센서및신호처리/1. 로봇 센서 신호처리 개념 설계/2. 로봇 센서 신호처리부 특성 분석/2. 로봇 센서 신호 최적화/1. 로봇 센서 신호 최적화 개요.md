# Summary

신호 최적화는 문제 유형에 맞는 필터를 고르는 일이다. 오프셋·드리프트에는 HPF, 고주파 잡음에는 LPF, 특정 대역에는 BPF/BSF/노치필터를 쓰며, 능동 필터를 쓰면 여러 필터 단을 서로 독립적으로 설계할 수 있다. 문제은행 0문항이라 NCS 필요지식 나머지 부분으로 작성했다.

<aside>노이즈 문제별 필터 선택 전략</aside>

| 문제 | 해결 필터 |
|---|---|
| 오프셋 전압·드리프트 전압(저주파 고정/서서히 변하는 성분) | **HPF** |
| 고주파 잡음 성분 | **LPF** |
| 특정 대역만 통과시키고 싶을 때 | **BPF** |
| 특정 대역만 제거하고 싶을 때 | **BSF(BRF)** |
| 아주 좁은 특정 주파수 성분만 제거(예: 상용전원 험) | **노치 필터** |

<aside>수동 필터 vs 능동 필터의 최적화 트레이드오프</aside>

- **수동 필터**: R·L·C만 사용, 회로가 단순하지만 여러 단을 직렬 연결하면 각 단이 서로 영향을 미쳐 설계가 복잡해짐(HPF+LPF로 BPF 구현 시 수식적으로 정확하지 않음)
- **능동 필터**: OP앰프의 무한대 입력 임피던스를 이용한 voltage follower로 필터 단들을 **전기적으로 독립**시킴 → 각 단(HPF의 R1·C1, LPF의 R2·C2)을 서로 무관하게 설계 가능, 신호 증폭도 함께 가능

<aside>주파수 분석 표현 관례</aside>

- 가로축(주파수)은 **로그 스케일**, 세로축(배율·이득)은 **dB**로 표시하는 것이 일반적
- 컷-오프 주파수는 **3dB**(=20log(1/√2)=20log0.707) 떨어지는 지점

<aside>핵심 정리</aside>

- 필터 선택은 "노이즈가 저주파냐 고주파냐 특정대역이냐"에 따라 결정, 여러 필터를 조합할 땐 능동 필터(OP앰프)로 단을 분리하는 것이 설계 최적화의 핵심
