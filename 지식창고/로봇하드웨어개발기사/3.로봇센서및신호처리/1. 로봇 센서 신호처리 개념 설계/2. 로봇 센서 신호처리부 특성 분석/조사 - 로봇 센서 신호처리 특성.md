# 조사 — 로봇 센서 신호처리 특성

## A. NCS 대조 결과

NCS 학습모듈 121 학습2 필요지식(footer p.26~41)이 이 세세항목의 핵심 출처다.

**§1 아날로그 출력 센서의 수동 필터**: R·L·C만으로 구현되면 수동 필터(출력이 입력보다 항상 작음), OP앰프가 포함되면 능동 필터(출력이 입력보다 클 수 있음).
- **전압 분배기**: Vi = R2/(R1+R2) × Vs
- **HPF(고역통과)**: 오프셋 전압·드리프트 전압(저주파) 제거. 컷-오프 주파수 f=1/(2πRC)에서 출력이 0.707배(-3dB)로 떨어짐
- **LPF(저역통과)**: 고주파 잡음 제거. 대역폭 BW=1/(2πRC)
- **BPF(대역통과)**: L·C·R 사용(방법1) 또는 HPF+LPF 직렬연결(방법2, OP앰프로 isolator 추가 시 정확). 중심주파수 f₀=1/(2π√LC)
- **BSF/BRF(대역차단)**: 두 컷오프 주파수 사이 신호 제거
- **노치 필터(Notch Filter)**: 대역차단필터의 한 종류로, 컷오프 주파수 사이 간격이 매우 좁아 **특정 주파수만 급격히 제거**하는 것이 특징

**§2 통신 데이터의 오류 확인**: 디지털 데이터도 통신선·PCB 패턴을 통해 노이즈가 추가될 수 있어 오류 확인이 필요.
- **패리티 체크**: 데이터의 1의 개수를 짝수(even-parity) 또는 홀수(odd-parity)로 맞추는 패리티 비트를 추가하는 가장 간단한 오류 확인 방법(1비트 단위)
- **체크섬(Checksum)**: 패킷(여러 바이트) 단위 오류 확인, 데이터를 모두 더한 결과의 하위 바이트를 추가 — 오버헤드가 작고 계산이 간단해 널리 사용
- (CRC는 §1-1에서 이미 다룸: 오류 확인뿐 아니라 가장 오류 확률이 적은 값으로 데이터 정정까지 가능)

## B. 웹 검색 결과

문제은행의 나이퀴스트·SNR·분해능·동적범위 등은 신호처리·계측공학의 표준 정의로, 이미 확립된 공식·정의를 다루므로 별도 웹 검색 없이 도메인 지식으로 작성했다(공학수학·신호처리 교재 수준의 확립된 사실).

## C. 결론(도메인 지식으로 정리)

- **나이퀴스트(Nyquist) 정리**: 신호를 원래대로 복원하려면 샘플링 주파수가 신호의 최대 주파수의 **2배 이상**이어야 함. 역으로 **샘플링 주파수 100Hz**로 정확히 복원 가능한 신호의 최대 주파수(나이퀴스트 주파수)는 **fs/2 = 50Hz**.
- **샘플링 주파수 결정 시 가장 중요한 요소**: **측정하고자 하는 신호의 최대 주파수**(나이퀴스트 정리의 근거) — 센서의 물리적 크기·제조사·동작전압은 샘플링 주파수 결정과 무관.
- **양자화 SNR**: n비트 ADC의 이론적 SNR(dB) ≈ **6.02n + 1.76**. n=12 → 6.02×12+1.76 = 72.24+1.76 ≈ **74dB**.
- **분해능(Resolution)**: 센서가 **구별할 수 있는 최소 입력 변화량**(측정 범위나 최대값 자체가 아님).
- **동적 범위(Dynamic Range)**: 센서가 측정할 수 있는 **최대값과 최소값의 차이**.
- **동적 응답 특성 지표**: 상승시간(Rise Time)·정착시간(Settling Time)·오버슈트(Overshoot)는 시간에 따른 응답(동특성) 지표 — **히스테리시스는 입력 증감 시 출력 경로가 다른 정특성(static characteristic) 지표**이므로 동적 응답 특성 지표가 아님.
- **파워 스펙트럼 밀도(PSD)**: 신호(노이즈)의 에너지가 주파수별로 어떻게 분포하는지를 나타내는 함수 — 측정 목적은 **주파수별 노이즈 분포 분석**(전력 소비량·동작전압·온도특성과는 무관).
