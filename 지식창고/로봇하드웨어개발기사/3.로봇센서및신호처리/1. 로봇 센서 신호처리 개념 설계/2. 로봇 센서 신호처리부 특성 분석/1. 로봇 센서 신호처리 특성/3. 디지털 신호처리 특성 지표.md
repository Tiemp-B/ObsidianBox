# Summary

나이퀴스트 정리에 따르면 샘플링 주파수는 신호 최대 주파수의 2배 이상이어야 하고, 12비트 ADC의 이론적 SNR은 약 74dB다. 분해능은 구별 가능한 최소 변화량, 동적범위는 최대-최소값 차이이며, 상승시간·정착시간·오버슈트는 동특성, 히스테리시스는 정특성 지표다.

# Notes

<aside>나이퀴스트(Nyquist) 정리</aside>

- 신호를 원래대로 복원하려면 샘플링 주파수가 신호 최대 주파수의 **2배 이상**이어야 함
- **샘플링 주파수 100Hz** → 정확히 복원 가능한 최대 신호 주파수(나이퀴스트 주파수) = fs/2 = **50Hz**
- **샘플링 주파수 결정 시 가장 중요한 요소**: **측정하고자 하는 신호의 최대 주파수**(센서의 물리적 크기·제조사·동작전압은 무관)
- 샘플링 주파수 결정 시 고려사항: 나이퀴스트 주파수, 센서의 응답속도, 데이터 저장 용량 — **센서의 물리적 크기는 고려사항이 아님**

<aside>양자화 SNR</aside>

- n비트 ADC의 이론적 SNR(dB) ≈ **6.02n + 1.76**
- n=12 → 6.02×12+1.76 = 72.24+1.76 ≈ **74dB**

<aside>분해능(Resolution) vs 동적 범위(Dynamic Range)</aside>

| 지표 | 정의 |
|---|---|
| **분해능** | 센서가 **구별할 수 있는 최소 입력 변화량** |
| **동적 범위** | 센서가 측정할 수 있는 **최대값과 최소값의 차이** |

<aside>동적 응답 특성 지표</aside>

- **동특성(시간 응답) 지표**: 상승시간(Rise Time), 정착시간(Settling Time), 오버슈트(Overshoot)
- **히스테리시스는 정특성(입력 증감 시 출력 경로 차이) 지표** — 동적 응답 특성 지표가 아님

<aside>파워 스펙트럼 밀도(PSD, Power Spectral Density)</aside>

- 신호(노이즈)의 에너지가 **주파수별로 어떻게 분포**하는지를 나타내는 함수
- 측정 목적: **주파수별 노이즈 분포 분석**(전력 소비량·동작전압·온도특성과는 무관)

<aside>통신 데이터 오류 확인(NCS §2)</aside>

| 방법 | 단위 | 특징 |
|---|---|---|
| **패리티 체크** | 1비트 | 데이터의 1의 개수를 짝수(even)/홀수(odd)로 맞추는 가장 간단한 방법 |
| **체크섬(Checksum)** | 패킷(여러 바이트) | 데이터를 모두 더한 값의 하위 바이트를 추가, 오버헤드 작고 계산 간단 |
| CRC | 패킷 | 오류 확인뿐 아니라 오류 확률이 가장 적은 값으로 데이터 정정도 가능 |

---

<aside>핵심 정리</aside>

- 나이퀴스트: 샘플링주파수≥신호최대주파수×2, 12비트 SNR≈74dB
- 분해능=최소구별변화량, 동적범위=최대-최소값 차, 동특성지표(상승/정착/오버슈트)≠히스테리시스(정특성)
- PSD=주파수별 노이즈분포, 통신오류확인=패리티(1비트)/체크섬(패킷)/CRC(정정까지)
