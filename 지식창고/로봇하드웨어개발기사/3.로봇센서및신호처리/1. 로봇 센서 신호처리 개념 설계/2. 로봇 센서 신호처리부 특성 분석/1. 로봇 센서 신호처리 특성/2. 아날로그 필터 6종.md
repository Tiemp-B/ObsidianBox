# Summary

수동 필터는 R·L·C만으로 구현되어 항상 출력이 입력보다 작아지고, HPF·LPF·BPF·BSF·노치필터가 각각 저주파차단·고주파차단·특정대역통과·특정대역차단·특정주파수만차단을 담당한다. 컷오프 주파수는 출력이 0.707배(-3dB)로 떨어지는 지점이다.

# Notes

<aside>수동 필터 vs 능동 필터</aside>

- **수동 필터(passive filter)**: R·L·C 소자만으로 구현, 출력 전압이 **항상 입력 전압보다 작음**
- **능동 필터(active filter)**: OP앰프 포함, 출력이 입력보다 **클 수 있음**(증폭 가능)

<aside>전압 분배기(Voltage Divider)</aside>

- Vi = R2/(R1+R2) × Vs — 큰 센서 전압을 ADC 입력 범위로 축소시키는 회로

<aside>필터 6종 비교</aside>

| 필터 | 통과 대역 | 용도 | 소자 |
|---|---|---|---|
| **HPF**(고역통과) | 고주파만 통과 | 오프셋·드리프트 전압(저주파) 제거 | R, C |
| **LPF**(저역통과) | 저주파만 통과 | 고주파 잡음 제거 | R, C |
| **BPF**(대역통과) | 특정 대역만 통과 | 특정 대역 신호만 수신 | L,C,R(방법1) 또는 HPF+LPF 직렬(방법2) |
| **BSF/BRF**(대역차단) | 특정 대역만 차단 | 특정 대역 잡음 제거 | R, L, C |
| **노치 필터** | 아주 좁은 특정 주파수만 차단 | 단일 주파수 잡음(예: 상용전원 험) 제거 | R, L, C(BSF보다 컷오프 간격 매우 좁음) |

<aside>컷오프 주파수(Cut-off Frequency)</aside>

- 출력 크기가 입력의 **0.707배(=1/√2)**가 되는 주파수
- dB로 표현하면 **-3dB** 지점(20log(1/√2) = -3dB)
- HPF/LPF: f_cutoff = 1/(2πRC)
- BPF/BSF/노치필터: 중심주파수 f₀ = 1/(2π√LC), 대역폭 BW = (1/2π)(R/L)

<aside>능동 필터의 장점</aside>

- OP앰프의 입력 임피던스가 이론상 무한대이므로, 필터 여러 단을 직렬 연결해도 **각 단이 서로 전기적으로 독립**(voltage follower로 분리) → 각 단의 R·C 값을 서로 무관하게 설계 가능
- 센서 신호 크기 자체를 증폭시키는 것도 가능

---

<aside>핵심 정리</aside>

- 수동필터=RLC만(감쇄만), 능동필터=OP앰프 포함(증폭+단분리 가능)
- HPF=저주파제거, LPF=고주파제거, BPF=특정대역만통과, BSF=특정대역만차단, 노치=매우좁은대역만차단
- 컷오프주파수=0.707배(-3dB) 지점
