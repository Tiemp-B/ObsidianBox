# 조사 — 로봇 센서 신호 최적화

## A. NCS 대조 결과

NCS 필요지식(footer p.26~41)에서 D34가 다루지 않은 나머지 내용 — **필터 선택 전략**과 **수동/능동 필터의 트레이드오프**, **주파수 분석 표현 관례**가 이 세세항목에 대응한다. footer p.42 이후는 R/L/C 값을 대입한 계산 예제·엑셀 그래프 작성법(수행내용, 실기)이라 제외.

1. **필터 선택 전략**(어떤 노이즈 문제에 어떤 필터를 쓰는가):

| 문제 | 해결 필터 |
|---|---|
| 오프셋 전압·드리프트 전압(저주파 고정/서서히 변하는 성분) | HPF |
| 고주파 잡음 성분 | LPF |
| 특정 대역만 통과시키고 싶을 때 | BPF |
| 특정 대역만 제거하고 싶을 때 | BSF(BRF) |
| 아주 좁은 특정 주파수 성분만 제거(BSF보다 컷오프 간격 좁음) | 노치 필터 |

2. **수동 필터 vs 능동 필터**:
   - **수동 필터**: R·L·C만 사용, 출력이 입력보다 항상 작아짐(감쇄만 가능)
   - **능동 필터**: OP앰프 포함, 출력을 입력보다 크게 만들 수 있음(증폭 가능), **필터 전후 회로를 전기적으로 독립**시켜줌(고임피던스 입력의 voltage follower로 필터 단들을 분리하면 각 단의 R·C 선택이 서로 무관해져 설계·계산이 단순해짐)
3. **주파수 분석 표현 관례**: 가로축(주파수)은 로그 스케일로, 세로축(배율·이득)은 dB로 표시하는 것이 일반적. 컷-오프 주파수는 3dB(=20log(1/√2)=20log0.707) 떨어지는 지점.

## B. 웹 검색 결과

문제은행 0문항이며 NCS 필요지식으로 충분히 커버되어 별도 웹 검색을 수행하지 않았다.

## C. 페이지 구성 설계

1개 세세항목 통합 1페이지(개요 겸 본문): 노이즈 문제별 필터 선택 전략, 수동/능동 필터 트레이드오프, 주파수 분석 표현 관례(로그축·dB·3dB 컷오프)
