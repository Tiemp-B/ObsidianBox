# Summary

통합 설계는 서로 다른 서브시스템(기계·전기·소프트웨어)을 하나의 로봇 시스템으로 엮는 원칙을 다룬다. 핵심은 서브시스템 간 인터페이스이며, 인터페이스 불일치·통신 오류가 통합 시 가장 흔한 문제다. 프로토콜 표준화, 결합도를 낮추는 인터페이스 추상화, 케이블 굽힘 수명, 작업공간 분석이 세부 주제다.

<aside>로봇 시스템 통합 설계의 범위</aside>

- **통합의 핵심**: 서브시스템 간 인터페이스(신호·전원·통신 규격의 정합) — 과목4 주요항목2 D46 "컴포넌트 간 호환성"과 같은 문제의식의 연장
- **설계 요소**: 프로토콜 표준화, 실시간 태스크 우선순위(주기성), 모듈 결합도(인터페이스 추상화로 낮춤)
- **물리적 요소**: 케이블 설계(굽힘 수명), 작업공간(관절각도·링크길이) 분석
