# Summary

세부항목 "로봇 시스템 설계"는 이미 통합된 시스템의 **성능을 끌어올리는 최적화**(이 세세항목)와, 여러 서브시스템을 **하나로 엮는 설계 원칙**(통합 설계) 두 축으로 나뉜다. 최적화는 캘리브레이션·열변형보상·진동억제·동역학 해석을 통해 정밀도와 안정성을 높이는 작업이다.

# Notes

<aside>세부항목 안에서의 위치</aside>

| 세세항목 | 초점 |
|---|---|
| 1. 로봇 시스템 최적화(이 세세항목) | 이미 구성된 시스템의 정밀도·안정성·성능 향상 |
| 2. 로봇 시스템 통합 설계 | 서브시스템을 하나로 엮는 인터페이스·구조 설계 원칙 |

<aside>로봇 시스템 최적화의 범위</aside>

- **캘리브레이션(정밀도 향상)**: 기구학적 파라미터 보정
- **오차 보상**: 열 변형 보상(온도센서 기반 실시간 보정)
- **진동 억제**: 공진 방지(구조 강성·댐핑), 노치필터
- **동역학 최적화**: Lagrange 승수법(구속조건 고려), 경로 최적화(시간·에너지), 동역학 해석(토크·가속도)

---

<aside>핵심 정리</aside>

- 최적화=이미 만든 시스템의 성능을 끌어올림, 통합설계=서브시스템을 엮는 원칙 — 서로 다른 층위
- NCS 전용 학습모듈 없음 → 웹조사+도메인지식으로 보완(모듈109/110 학습1은 PCB 실기 내용이라 무관)
