# Summary

볼스크류는 너트 예압으로 백래시를 없애고 강성을 높이며, 하모닉드라이브는 웨이브제너레이터·플렉스플라인·서큘러스플라인 3요소로 감속한다. 조립은 기계 프레임→전기 연결→소프트웨어 순으로 진행하고, 토크렌치는 균일한 체결력을 확보하기 위해 사용한다.

<aside>볼스크류 백래시 조정 — 너트 예압(Preload)</aside>

- 예압의 목적: **백래시 감소 + 축방향 변위 저감 → 강성 향상**(대가로 회전 구동 토크는 증가)
- 방식: 이중 너트 조정(압축 스프링으로 두 볼너트에 반대방향 축하중), 스킵 리드 예압 등
- **볼스크류 백래시 조정 방법으로 가장 적절한 것**: **너트 예압(Preload) 적용**(회전속도 조절·윤활유 점도·피치 변경과 무관)

<aside>하모닉드라이브 구조와 조립 주의사항</aside>

| 구성요소 | 역할 |
|---|---|
| 웨이브제너레이터 | 타원형, 볼베어링으로 플렉스플라인을 타원으로 변형시킴(입력) |
| 플렉스플라인 | 컵 형상의 탄성 기어, 타원 변형되며 서큘러스플라인과 부분적으로 맞물림(출력) |
| 서큘러스플라인 | 내주면에 치가 있는 링 형상(고정) |

- 플렉스플라인 치형수가 서큘러스플라인보다 2개 적어, 웨이브제너레이터 1회전당 치형수차 2개분만큼 상대회전 → 감속비
- **하모닉드라이브 조립 시 주의사항으로 부적절한 것**: **플렉스플라인의 기어비 조정**(기어비는 부품 제작 시 이미 결정되는 값이지 조립 시 조정 대상이 아님 — 웨이브제너레이터 편심량 확인·서큘러스플라인 회전방향 설정·윤활유 도포는 실제 필요한 주의사항)

<aside>조립 순서와 토크렌치</aside>

- **로봇 시스템 조립 시 우선 고려 순서**: **기계적 프레임 → 전기적 연결 → 소프트웨어 설치**(물리적 토대 확보 후 전기, 전기 통전 후 소프트웨어)
- **토크 렌치를 사용하는 주된 목적**: **균일한 체결력 확보**(체결시간 단축·나사산보호·피로도감소는 부수효과)

<aside>케이블 배선 작업 시 고려사항</aside>

- 적절: 굽힘 반경 유지, 전원선과 신호선의 분리 배치(노이즈 간섭 방지), 케이블 타이 조임 강도(과압박 방지)
- **케이블 배선 작업 시 고려사항으로 가장 부적절한 것**: **케이블의 도체 단면적 확대**(단면적은 설계 단계에서 허용전류로 이미 결정되는 규격값 — 작업 중 임의 확대 대상 아님)
