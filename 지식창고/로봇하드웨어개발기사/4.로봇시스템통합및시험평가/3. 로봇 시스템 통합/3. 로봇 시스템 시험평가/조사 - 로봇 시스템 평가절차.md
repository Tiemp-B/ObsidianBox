# 조사 — 로봇 시스템 평가절차

## A. NCS 대조 결과

전용 NCS 학습모듈 없음. 문제은행 1문항뿐인 경량 세세항목 — 도메인 지식으로 결론.

## B. 결론(도메인 지식으로 보완)

- 일반적인 평가(시험평가) 절차는 **평가 기준 설정 → 시험 수행 → 결과 분석 → (필요시) 개선 방안 도출 → 보고서 작성** 순서를 따른다. 무엇을·어떤 기준으로 평가할지 먼저 정해야 이후 시험·분석이 의미를 갖기 때문.
- **로봇 시스템 평가절차에서 첫 번째 단계**: **평가 기준 설정**(결과 분석·보고서 작성·개선 방안 도출은 모두 기준이 정해진 이후에 가능한 후속 단계).

## C. 페이지 구성 설계

1개 세세항목 통합 1페이지(개요 겸 본문, 경량): 평가절차의 일반적 순서와 "평가기준 설정"이 첫 단계인 이유
