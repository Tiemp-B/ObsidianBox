# Summary

동적 응답 특성의 3대 지표는 상승시간·오버슈트·정착시간이며, 기하학적 정확도는 정적/공간적 개념이므로 동적 특성 지표가 아니다.

# Notes

<aside>동적 응답 특성 3대 지표</aside>

| 지표 | 정의 |
|---|---|
| 상승시간(Rise Time) | 목표값의 10%→90%에 도달하는 시간 |
| 오버슈트(Overshoot) | 최고값과 최종값 차이의 백분율(시스템의 진동적 특성에서 발생) |
| 정착시간(Settling Time) | 시스템이 안정화(허용오차 범위 진입)되는 데 걸리는 시간 |

- **로봇 시스템의 동적 응답 특성 평가에 사용되는 지표**: **상승시간, 오버슈트, 정착시간**(제조원가·브랜드인지도·시장점유율과 무관)

<aside>동적 특성이 아닌 지표</aside>

- **성능 평가 항목 중 동적 특성을 평가하는 지표가 아닌 것**: **기하학적 정확도**(오버슈트·정착시간·상승시간은 시간에 따른 응답 변화를 나타내는 동적 지표인 반면, 기하학적 정확도는 특정 시점의 위치·형상이 기준과 얼마나 일치하는지를 보는 정적/공간적 개념)

---

<aside>핵심 정리</aside>

- 동적특성 3대지표=상승시간+오버슈트+정착시간, 기하학적 정확도는 동적특성 아님(정적개념)
