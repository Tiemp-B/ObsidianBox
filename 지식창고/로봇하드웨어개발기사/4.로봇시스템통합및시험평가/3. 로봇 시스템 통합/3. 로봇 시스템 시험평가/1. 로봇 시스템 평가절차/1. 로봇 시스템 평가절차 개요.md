# Summary

로봇 시스템 평가는 평가 기준 설정 → 시험 수행 → 결과 분석 → 개선 방안 도출 → 보고서 작성 순서로 진행된다. 무엇을 어떤 기준으로 평가할지를 먼저 정해야 이후 시험·분석이 의미를 갖기 때문에 평가 기준 설정이 첫 단계다.
