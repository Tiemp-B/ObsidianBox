# Summary

로봇 시스템은 매니퓰레이터·말단장치·동력공급장치·제어기 4대 요소로 구성되며, 하드웨어 구성 검토의 핵심은 이들 간의 호환성이다. 부하 토크는 관성 모멘트와 중력으로, 엔드이펙터 위치 정확도는 백래시·엔코더 분해능·링크 처짐으로 결정된다. NCS 필요지식(학습모듈 112 학습1 §1)이 핵심 출처다.

<aside>로봇 시스템의 4대 구성요소(NCS)</aside>

| 구성요소 | 역할 |
|---|---|
| **매니퓰레이터(Manipulator)** | 인간의 팔과 유사한 동작 제공. 팔/몸체 운동+손목 관절 운동(피치·요·롤=방위좌표축) |
| **말단 장치(End Effector)** | 로봇 팔에 부착되는 고정물(그리퍼=열고닫는 장치, 공정 공구=그 외 부착물) |
| **동력 공급 장치(Power Supply)** | 전기(가장 널리 사용)·공압·유압 3종으로 운동 에너지 공급 |
| **제어기(Controller)** | 로봇의 운동·시퀀스를 총괄하는 통신·정보처리 장치 |

- **하드웨어 구성 검토 시 중점 확인 사항**: 제조사 브랜드·포장재·운송방법이 아니라 **컴포넌트 간 호환성**(신호·전원·통신 규격이 서로 맞는지)

<aside>부하 토크 계산</aside>

- 로봇 동역학 방정식은 관성·코리올리·중력·원심력 성분을 포함
- **부하 토크 계산 시 고려 요소**: **관성 모멘트 및 중력 영향**(로봇 색상·브랜드명·제조일자는 무관)

<aside>엔드이펙터 위치 정확도의 영향 요소</aside>

| 요소 | 위치 정확도에 직접 영향 |
|---|---|
| 기구부의 백래시 | O(기어 유격) |
| 엔코더 분해능 | O(위치 피드백 정밀도) |
| 링크의 처짐 | O(탄성 변형) |
| **모터의 최대 토크** | **X — 속도·가속·부하대응 능력과 관련, 위치정확도를 직접 결정하는 요소는 아님** |

---

<aside>핵심 정리</aside>

- 로봇 = 매니퓰레이터+말단장치+동력공급+제어기, 구성검토 핵심=컴포넌트 호환성
- 부하토크=관성모멘트+중력, 위치정확도 영향요소=백래시·엔코더분해능·링크처짐(모터최대토크는 아님)
