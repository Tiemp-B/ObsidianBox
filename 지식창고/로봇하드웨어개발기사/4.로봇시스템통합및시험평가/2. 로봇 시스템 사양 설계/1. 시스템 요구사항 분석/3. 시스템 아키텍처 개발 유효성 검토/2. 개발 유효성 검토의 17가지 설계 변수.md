# Summary

제품 설계 과정에서는 기능·비용·납기·수량 같은 기본 변수부터 안전·품질·신뢰성·유지보수성·인간 요소까지 17가지 변수를 체계적으로 점검해야 하며, 안전 위험은 완전 제거→보호·격리→경고 순으로 대응한다.

# Notes

<aside>17가지 일반 설계 변수(NCS 원문)</aside>

| 변수 | 핵심 내용 |
|---|---|
| 기능과 성능 | 기계적·전기적·음향적 등 성질을 규정, 비현실적 성능은 비용 증가 초래 |
| 제품의 비용 | 경쟁사 벤치마킹, 비용절감은 구현 전 단계에서 채택 |
| 납기일 | 짧을수록 설계 해석 시간 부족, 짧은 리드타임 공정 필요 |
| 수량 | 배치 크기가 공정계획·투자비용 좌우 |
| 환경 문제 | 규제 대상이자 시장 성공 요소 |
| **안전 문제** | 위험 제거 3방법: **①완전 제거(개념설계 단계 대안 선정) → ②보호장치·격리(제거 안 되는 위험) → ③경고문·안전지침 제공** |
| 품질 | 고객 요구조건 충족 능력, 근본원인 제거가 가장 저렴한 해결법 |
| 에너지 소비 | 소모원인 제거·손실 격리·효율 향상 3원칙 |
| **신뢰성 변수** | 정해진 운전 조건에서 의도된 기능을 수행할 확률, 품질과 밀접 |
| 유지보수성 | 설계 단계 초기부터 고려, 접근 용이성·부품교체 쉬움 등 |
| 크기 변수 | 운송 가능한 크기, 공장 출입구 크기 고려 |
| 중량 변수 | 제조·취급·수송·운전비용·성능에 영향 |
| 심미성 변수 | 시각적 매력·표면조직·색채 등 정성적 변수 |
| 주변 환경 조건 | 온도·습도·화학물질·청정도 등 |
| 포장과 운송 변수 | 제조 후 창고 이동, 대형 로봇은 분해 운송 고려 |
| 인간 요소 | 사용자 인터페이스(경고음·점멸등·터치펜던트 등) |
| 사용 수명 변수 | 부품마다 다른 수명, 먼저 교체될 수 있는 부품 존재 |

<aside>기업 차원 고려사항</aside>

- **비용**: 가격-비용=이익, 가격-비용의 만족도 차이=가치. 성숙 제품은 비용 절감, 신제품은 만족도 향상 전략
- **제품과 생산 주기**: 제품 수명주기(도입-성장-성숙-쇠퇴), 기술 개발·대체 주기(S자 곡선, 기존 기술 성숙 시 신기술로 전환)

<aside>핵심 정리</aside>

- 17가지 변수는 "기능/비용/일정/물량"(기본) + "환경/안전/품질/에너지/신뢰성/유지보수"(운영) + "크기/중량/심미성/환경조건/포장/인간요소/수명"(물리적)으로 그룹핑 가능
- 안전 위험 대응 순서: 완전제거 > 보호·격리 > 경고문
