# Summary

로봇 시스템은 기구부(구동모듈+링크+베이스+그리퍼)와 전장부(제어보드+전원공급장치+티칭펜던트+케이블)로 구성된다. 구동모듈의 핵심은 감속기(하모닉드라이브)·모터·엔코더·브레이크이며, 액추에이터는 그 중 물리적 동작을 담당한다. NCS 필요지식(학습모듈 113/114 학습1)이 핵심 출처다.

<aside>로봇 시스템의 구성 요소</aside>

| 대분류 | 중분류 | 소분류 |
|---|---|---|
| **기구부** | 구동모듈 | 감속기·모터·브레이크·엔코더·드라이버·안전감지센서·커버 |
| | 링크 | 링크1·링크2 |
| | 베이스, 그리퍼 | |
| **전장부** | | 제어보드, 전원공급장치, 티칭펜던트, IO링크, 케이블(외부/내부=전원·통신) |

<aside>핵심 구동모듈 부품</aside>

- **감속기**: 산업용 로봇은 백래시 1arcmin 이내인 정밀급(유성치차·사이크로이드·RV·**하모닉 드라이브**). 하모닉 드라이브는 출력토크 대비 무게가 가장 가볍고 중공 내경을 가장 많이 확보(3대 부품: 웨이브 제너레이터·플렉스 스플라인·서큘러 스플라인)
- **모터**: **정밀서보급 모터**가 핵심 구성요소(중실형 대표적, 중공형은 경박단소·고출력토크)
- **엔코더**: 산업용 로봇 기본은 **멀티턴 앱솔루트 엔코더**(멀티턴=감속기 회전 절대치 인식, 싱글턴=모터 1회전 절대치 인식)
- **브레이크**: 비상정지·보호정지 기능. **전원 오프 시 브레이크 온**(fail-safe), 전원 공급 시 브레이크 오프가 일반적

<aside>액추에이터와 DMA</aside>

- **액추에이터의 주요 역할**: 제어 신호를 받아 **물리적 동작을 수행**(센서데이터처리·제어신호생성·통신프로토콜관리는 각각 센서·제어보드·통신모듈의 역할)
- **DMA(Direct Memory Access)의 주요 목적**: CPU 개입 없이 **입출력 장치의 직접적인 메모리 접근**(CPU처리속도향상 자체·메모리용량확장·캐시관리가 목적이 아님)

<aside>핵심 정리</aside>

- 로봇 = 기구부(구동모듈+링크+베이스+그리퍼) + 전장부(제어보드+전원+티칭펜던트+케이블)
- 구동모듈 4대 요소: 감속기(하모닉드라이브)·모터(정밀서보)·엔코더(멀티턴앱솔루트)·브레이크(전원오프시 온)
