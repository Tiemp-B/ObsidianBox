# 조사 — 로봇 컴포넌트 구성

## A. NCS 대조 결과

NCS 학습모듈 113/114 학습1 필요지식(footer p.3~22)이 이 세세항목의 핵심 출처다.

**로봇 시스템 구성 요소 표(대분류-중분류-소분류)**:
- **기구부**: 구동모듈(**감속기·모터·브레이크·엔코더·드라이버·안전감지센서·커버**), 링크(링크1·링크2), 베이스, 그리퍼
- **전장부**: 제어보드, 전원공급장치, 티칭펜던트, IO링크, 케이블(로봇 외부 케이블 / 로봇 내부 케이블 = 전원케이블·통신케이블)

**핵심 구동모듈 부품 특성**:
1. **감속기**: 백래시 1arcmin 이내인 정밀급 감속기(유성치차·사이크로이드·RV·**하모닉 드라이브**). **하모닉 드라이브**는 출력토크 대비 무게가 가장 가볍고 중공 내경을 가장 많이 확보할 수 있음. 3대 컴포넌트: 웨이브 제너레이터(타원형상, 볼베어링)·플렉스 스플라인(박육 금속탄성체 부품)·서큘러 스플라인(강체 링, 내주에 플렉스스플라인보다 이가 2개 더 많음). 1959년 미국 발명가 MUSSER가 고안.
2. **모터**: 산업용 로봇의 가장 핵심적인 구성요소 중 하나로 **정밀서보급 모터** 사용(중실형이 대표적, 중공형은 경박단소·고출력토크에 유리).
3. **엔코더**: 산업용 로봇에는 기본적으로 **멀티턴 앱솔루트 엔코더**가 적용됨(멀티턴=감속기에 의한 회전을 절대치로 인식, 싱글턴=모터의 1회전을 절대치로 인식). 협업 로봇에는 경박 중공형 엔코더 사용.
4. **브레이크**: 비상시 정지와 보호 시 정지의 2가지 기능. 스프링과 전자석 원리로 구성되며 **전원이 오프되었을 때 브레이크 온(fail-safe), 전원 공급 시 브레이크 오프**되는 타입이 일반적.

## B. Phase 1 — 초기 웹 조사

문제은행 2문항 중 "DMA"는 이 프로젝트 과목2(D16)·과목3(D36)에서 이미 검증된 지식을 재사용(별도 검색 불필요).

## C. Phase 2 — 자체 검토

- "액추에이터의 주요 역할"은 로봇공학 기초 상식(제어 신호를 받아 실제 물리적 힘/운동을 만들어내는 장치)이라 별도 검색 없이 도메인 지식으로 확정

## D. 결론(도메인 지식 + 재사용)

- **액추에이터의 주요 역할**: 센서 데이터 처리·제어 신호 생성·통신 프로토콜 관리는 각각 센서·제어보드·통신모듈의 역할이며, 액추에이터는 그 제어 신호를 받아 **물리적 동작을 수행**하는 것이 본질적 역할.
- **DMA(Direct Memory Access)의 주요 목적**: CPU를 거치지 않고 주변장치가 메모리에 직접 접근 — **입출력 장치의 직접적인 메모리 접근**(CPU 처리속도 향상 자체·메모리 용량 확장·캐시 관리가 목적이 아님, 과목2 D16에서 이미 확인).

## E. 페이지 구성 설계

1개 세세항목 통합 페이지: 로봇 시스템 구성요소(기구부/전장부) + 감속기/모터/엔코더/브레이크 특성 + 액추에이터 역할 + DMA
