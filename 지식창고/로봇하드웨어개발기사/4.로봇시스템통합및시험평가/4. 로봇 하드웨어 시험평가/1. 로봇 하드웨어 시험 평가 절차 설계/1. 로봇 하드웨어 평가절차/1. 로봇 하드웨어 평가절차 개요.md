# Summary

NCS 학습2(모듈109/110)는 계측 기본용어(오차·정확도·정밀도·감도·보정)와 시험 관련 용어(적합시험·내구성시험·가속시험 등), 시험절차서 필수 항목(목적·적용범위·시험조건·시험방법 등)을 정의한다. 평가절차 설계의 핵심은 평가 환경의 표준화다.

<aside>계측 기본 용어(NCS §1-2)</aside>

| 용어 | 정의 |
|---|---|
| 오차(error) | 측정값 - 참값 |
| 불확실성(uncertainty) | 오차의 상한치 추정값(참값은 알 수 없으므로) |
| 정확도(accuracy) | 측정값과 참값의 차이 |
| 정밀도(precision) | 반복 측정 결과들 간의 차이 |
| 감도(sensitivity) | 입력 변화에 대한 출력 변화의 비율(입출력곡선의 기울기) |
| 이력현상(hysteresis) | 측정 접근 방향(증가/감소)에 따라 값이 달라지는 현상 |
| 보정(calibration) | 표준 계측기와 비교해 오차를 줄이는 작업 |
| 영점오차/스팬오차 | 입출력곡선의 원점이 어긋남/기울기가 어긋남 |

<aside>시험 관련 용어(NCS §2-1)</aside>

- **적합시험**: 요구사항 적합 여부 판정 / **결정시험**: 사양서의 수치를 결정
- **시험실시험** vs **현장시험**: 제어된 조건 vs 실제 운용현장
- **내구성시험**: 스트레스의 기간·반복 적용에 의한 영향 조사
- **가속시험**: 기준조건을 초과하는 스트레스로 반응 관측 기간을 단축(단, 고장 메커니즘 자체는 변화시키면 안 됨)
- 시간가속계수·고장률가속계수·고장강도가속계수: 서로 다른 스트레스 조건 간 고장/열화 비율

<aside>시험평가 절차서 작성 필수 항목(NCS §3)</aside>

- 목적 → 적용 범위 → 관련 표준 → 용어의 정의 → 설비 및 기구 → 시험 조건 → 시료 → 시험 방법 → 해석 및 조치 사항

<aside>평가절차 설계 시 고려 요소</aside>

- **로봇 하드웨어 평가절차 설계 시 고려해야 할 요소**: **평가 환경의 표준화**(NCS "시험 조건" 항목이 온도·습도 등 환경 표준화를 명시 — 평가자 개인 취향·회사 내부 정치·경쟁사 동향은 무관)

<aside>핵심 정리</aside>

- 계측용어: 오차=측정-참값, 정확도=참값과의 차이, 정밀도=반복측정간 차이(서로 다른 개념)
- 시험용어: 적합시험≠결정시험, 가속시험은 고장메커니즘 불변 전제, 평가절차 핵심=환경표준화
