# 조사 — 시험 평가 결과분석

## A. NCS 대조 결과

모듈109/110 학습4는 "시험 결과"를 평가항목·판정기준·평가방법·불량수·판정결과로 기록한다고 명시(§2-7, footer p.87)하나, 통계적 데이터 분석 기법 자체는 다루지 않음 — 도메인 지식으로 보완.

## B. 결론(도메인 지식으로 보완)

- **시험 평가 결과분석에서 수행해야 할 작업**: **데이터 통계 분석 및 경향 파악**(결과데이터삭제·임의수정·분석과정생략은 결과분석의 기본 원칙 위반).
- **로봇의 위치 정확도 시험 데이터 분석 방법으로 가장 적절하지 않은 것**: **첨도 분석**(첨도(kurtosis)는 분포의 뾰족한 정도·꼬리 두께를 나타내는 통계량으로, 오차 분포의 형태를 정밀 분석할 때는 쓰이지만, 위치 정확도 시험처럼 "목표값과의 편차 크기"를 직접 평가하는 목적에는 표준편차·평균값·최대오차가 표준 지표이며 첨도는 그에 비해 부차적).
- **로봇 하드웨어 시험평가 결과의 신뢰성을 높이는 방법**: **반복 시험 및 통계적 분석**(시험횟수최소화·주관적판단강화·단일조건시험은 신뢰성을 오히려 낮춤 — 세부항목3 "로봇 시스템 시험평가"의 반복정밀도 30회 이상 측정 원칙과 같은 맥락).

## C. 페이지 구성 설계

1개 세세항목 통합 1페이지(개요 겸 본문): 결과분석 작업(통계분석+경향파악), 위치정확도 데이터 분석방법(첨도분석은 부적절), 신뢰성 향상 방법(반복시험+통계분석)
