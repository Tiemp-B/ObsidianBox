# Summary

시험 판정 기준은 단위시험·통합시험·성능시험·환경시험·수명시험으로 체계화되며, 판정기준을 초과·미달하면 부적합이다. 호환성 테스트는 전기적 신호 레벨과 통신 프로토콜을 확인한다.

# Notes

<aside>세부항목 안에서의 위치</aside>

| 세세항목 | 초점 |
|---|---|
| 1. 로봇 하드웨어 시험평가(이 세세항목) | 시험을 어떤 기준으로 판정하는가 |
| 2. 하드웨어 적합성 판단 기준 | 구체적 수치 기준은 무엇인가 |
| 3. 시험 평가 결과분석 | 시험 데이터를 어떻게 분석·활용하는가 |

<aside>시험 판정 기준 체계(NCS §1)</aside>

| 시험 종류 | 대상 | 판정 방식 |
|---|---|---|
| 단위 시험 | 전압·전류·발진회로·모터구동회로 등 최소기능단위 | 절차서 판정기준 초과/미달 시 부적합 |
| 통합 시험 | 두 단위 이상의 기능 동시 시험 | 절차서 판정기준 초과/미달 시 부적합 |
| 성능 시험 | 외관·입력전류·출력전류 등 | 판정기준=시험절차서에 명시 |
| 환경 시험·수명 시험 | 규정 조건 하 동작 후 성능 재확인 | 성능시험 판정기준 만족 여부 |

<aside>시험 결과보고서 구성(NCS §2)</aside>

- 제품명, 시료 수(신뢰수준 결정 요소), 시험 목적, 시험 제품 사진, 총 페이지, 담당자, 시험 결과(평가항목·판정기준·평가방법·시료수·허용불량수·고장수·결과)

<aside>호환성 테스트</aside>

- **로봇 하드웨어 호환성 테스트에서 확인해야 할 사항**: **전기적 신호 레벨 및 통신 프로토콜**(제품 브랜드 일치성·포장 크기 적합성·가격 경쟁력과 무관 — 서로 다른 컴포넌트가 호환되려면 신호 전압 레벨과 통신 규약(USART/I2C/SPI 등)이 일치해야 함)

---

<aside>핵심 정리</aside>

- 판정기준=단위+통합+성능+환경+수명 시험 체계, 기준 초과/미달=부적합
- 호환성테스트 확인사항=전기적신호레벨+통신프로토콜
