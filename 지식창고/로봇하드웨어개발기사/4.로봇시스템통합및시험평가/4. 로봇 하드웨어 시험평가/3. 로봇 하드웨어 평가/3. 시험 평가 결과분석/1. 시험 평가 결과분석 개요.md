# Summary

결과분석은 데이터 통계 분석과 경향 파악이 핵심이며, 위치 정확도 분석에는 표준편차·평균값·최대오차가 쓰이고 첨도 분석은 부적절하다. 신뢰성은 반복 시험과 통계적 분석으로 높인다.

<aside>결과분석의 기본 작업</aside>

- **시험 평가 결과분석에서 수행해야 할 작업**: **데이터 통계 분석 및 경향 파악**(결과데이터 삭제·임의수정·분석과정 생략은 결과분석의 기본 원칙을 위반)

<aside>위치 정확도 데이터 분석 방법</aside>

| 방법 | 적절성 |
|---|---|
| 표준편차 계산 | 적절(산포도 파악) |
| 평균값 산출 | 적절(대표값 파악) |
| 최대 오차 확인 | 적절(최악 조건 파악) |
| **첨도 분석** | **부적절**(분포의 뾰족함·꼬리두께를 나타내는 지표로, 목표값 대비 편차 크기를 직접 평가하는 위치정확도 시험 목적과는 거리가 먼 부차적 통계량) |

- **로봇의 위치 정확도 시험에서 측정된 데이터의 분석 방법으로 가장 적절하지 않은 것**: **첨도 분석**

<aside>결과 신뢰성 향상</aside>

- **로봇 하드웨어 시험평가 결과의 신뢰성을 높이는 방법**: **반복 시험 및 통계적 분석**(시험횟수 최소화·주관적 판단 강화·단일 조건 시험은 신뢰성을 오히려 낮춤 — "로봇 시스템 시험평가"의 반복정밀도 30회 이상 측정 원칙과 같은 맥락)

---

<aside>핵심 정리</aside>

- 결과분석=통계분석+경향파악, 위치정확도 분석=표준편차+평균값+최대오차(첨도분석은 부적절)
- 신뢰성 향상=반복시험+통계적분석(단일조건·시험횟수최소화는 오히려 신뢰성 저하)
