# 1. 파일 및 디렉터리 관리
## (1) 소유권과 허가권
### 소유권
다수의 사용자가 공동으로 사용할 수 있는 멀티 유저 시스템.
각 파일 혹은 디렉터리를 소유할 사용자나 그룹을 지정하여 리소스를 보호한다
### 허가권
- 소유자 허가권
	소유한 사용자의 허가권
- 그룹 허가권
	파일이나 디렉터리를 소유한 그룹에 속한 사용자의 허가권.
- 다른 사용자 허가권
	소유자, 소유 그룹에 속하지 않은 사용자의 허가권
### 허가권 변경
허가권은 `ls -l`이나 `ls -n`옵션으로 확인할 수 있다.
형식은 `----------`에 맨 앞자리는 파일 유형, 다음 3자리는 소유자 허가권, 그다음 3자리는 그룹 허가권, 그 다음 3자리는 다른 사용자 허가권이다
- 파일 유형
	- - : 일반 파일
	- d : 디렉터리
	- l : 심볼릭 링크
	- b : 블록 디바이스
	- c : 캐릭터 디바이스
	- p : FIFO, pipe. 서로 다른 프로세스간 데이터를 주고 받을 수 있도록 하는 특수 파일
	- s : 소켓
- 허가권
	`---` 3자리가 한 세트이며 각 자리는 `rwx` 로 표기된다
	허가권의 변경은 [[chmod]]명령어로 가능하다.
	`chmod [option] mode file(s)`

| 권한  | 파일         | 디렉터리                                                      |
| :-- | ---------- | --------------------------------------------------------- |
| r   | 내용 확인 및 복사 | 디렉터리 내에 포함된 파일 및 디렉터리 확인 가능                               |
| w   | 내용 수정      | 디렉터리가 포함하고 있는 파일 등을 수정할 수 있다<br>해당 파일에 대한 허가권이 없어도 삭제는 가능 |
| x   | 실행 가능      | 디렉터리 안으로 접근할 수 있는 권한. cd 명령어의 가능여부                        |
	
### 소유권 변경
[[chown]]명령어로 수정이 가능하다. 소유권의 변경은 루트 사용자만 가능하다

### 허가권 기본 설정
[[umask]] 명령어로 해당 사용자 및 세션의 기본 허가권을 설정한다

## 특수 권한
좀 더 효율적인 운영을 위하여 특수권한이 존재
- Set-UID
	- 파일의 소유자 권한으로 실행된다
	- 예로 /usr/bin/passwd 파일이 있다. 비밀번호를 바꾸는 해당 명령어는 /etc/shadow를 수정하게 되는데 해당 파일은 루트 계정만 수정이 가능하다. 따라서 passwd는 실행 시 루트 계정으로 실행되도록 한다. `ls -l` 명령어로 허가권을 보면 소유자 권한(루트)에 rws 로 설정되어 있음을 볼 수 있다
	- x가 설정되어 있고 Set-UID를 설정하면 s
	- x가 설정되어 있지 않고(실행권한 없음) Set-UID를 설정하면 S
	- 폴더에선 무시된다.
- Set-GID
	- 파일 및 디렉터리를 소유 그룹 권한으로 실행한다
