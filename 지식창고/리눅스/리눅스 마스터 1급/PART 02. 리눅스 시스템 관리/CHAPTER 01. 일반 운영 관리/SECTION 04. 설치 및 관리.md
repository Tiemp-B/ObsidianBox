# 2. 레드햇 패키지 도구
### 저수준 패키지 관리 도구 RPM (Red Hat Package Manager)
- 개발사 : 레드햇
- 사용 배포판 : Novell NetWare, IBM's AIX, CentOS, Fedora, Oracle Linux 등
- 패키지 파일 : .rpm
- 명령어 [[rpm]]

### 고수준 패키지 관리 도구 
- [[yum]](Yellowdog Updator, Modified)
	옛 RHEL 계열 기본 패키지 관리
	패키지와 패키지가 가지고 있는 의존성을 체크하여 패키지를 설치할 수 있게 한다
- [[dnf]]
	RHEL 8 / CentOS 8 이후의 기본 패키지 관리

# 4. 소스 코드 컴파일을 통한 SW 설치
## 개요
### 설명
소스코드는 보통 tar로 아카이브한 후 파일 크기를 줄이기 위해 gzip이나 bzip2로 압축한다

일반적으로 패키지는 소스코드인 .c, .h 파일 등의 코드 파일과 설치 보조를 하는 Makefile과 configure 파일을 가지고 있다. 빌드도구로 설치를 진행한다
### 절차
1. configure를 실행하여 config.h.in을 automake로 하여금 Makefile.in을 생성하게 하고, 환경변수와 관련 패키지 설치 유무 등을 고려하여 시스템을 위한 Makefile과 config.h 파일을 생성한다.
2. [[make]] 명령어로 Makefile의 정의되어 있는 설치를 실행한다.

## 빌드 도구
### CMake
크로스플랫폼에서 빌드가 가능하도록 해당 시스템에 적합한 Makefile의 생성만을 수행하는 make의 발전된 빌드 도구. 즉, 직접 빌드가 아닌 Makefile만 생성한다

## 컴파일러
### gcc(GNU Compiler Collection)
GNU에서 제작한 대부분의 프로그래밍 언어를 지원하는 컴파일러.
소스코드를 컴파일하는 컴파일러와 다른 시스템 환경에서도 컴파일 가능하도록 하는 툴체인 등 크게 2가지로 구성
[[gcc]] 명령어로 가능하다


## 아카이브
### tar (tape archive)
수많은 파일을 하나의 아카이브 파일로 만드는 유틸리티
파일 구조는 POSIX.1-1988으로 표준화되었고 이후 POSIX.1-2001로 개정
유닉스의 TAR는 순수하게 파일을 아카이브하는 역할만 수행
리눅스의 TAR는 COMPRESS, GZIP, BZIP2, XZ 등으로 압축하는 것도 지원

## 압축하기
### compress, uncompress
ncompress 패키지를 설치하면 둘 다 설치된다
- 압축 알고리즘 : 렘펠지브(Lempel-Ziv)
- 확장자 : .Z
	- 파일명 중 .Z를 이미 포함한다면 생략
	- 파일 사이즈가 더 이상 줄어들 수 없다면 대상에서 제외
### gzip, gunzip
- 압축 알고리즘 : 렘펠지브
- 확장자 : .gz
- 표준 입력을 받거나 표준 출력으로 실행 결과의 전달이 가능하여 다른 명령어와 파이프 조합을 통해 편리하게 사용 가능
- 심볼릭 링크 파일 제외

### bzip2, bunzip2
- 압축 알고리즘 : 버로우-휠러 알고리즘, 허프만 알고리즘
