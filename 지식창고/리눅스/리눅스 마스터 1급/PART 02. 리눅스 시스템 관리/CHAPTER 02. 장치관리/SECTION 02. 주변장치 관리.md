# 1. 디스크 확장
## 개요
### 목적
 용량 부족을 해결하기 위해 새로운 하드디스크를 추가
### 과정
1. 하드디스크 장착
	fdisk -l 옵션으로 장착 확인
2. 확장 파티션 생성
	fdisk 디스크
3. 논리 파티션 생성
4. 파티션 포맷
	파일 시스템을 지정하여 논리적 파티션을 포맷한다.
5. 마운트
	파일 시스템을 명시하며 마운트한다.
6. 확인
	df 명령어로 마운트를 확인
7. /etc/fstab 등록

# 2. 프린터
## 리눅스 프린팅 시스템
### 역사
1. 초기 프린터
	고정 크기, 단일 폰트를 갖는 텍스 혀식으로 한 줄씩 출력하는 라인 프린터 사용
	- BSD 프린팅 시스템
		- 서버에서 동작하는 라인 프린터 데몬
		- 프린트 요청을 위한 lpr 명령어를 포함하는 클라이언트
		- ㅅ
2. 스풀링(Spooling : Simultaneous Peripheral OPeration On Line)
	기존 라인프린터의 느린 속도를 개선함.
