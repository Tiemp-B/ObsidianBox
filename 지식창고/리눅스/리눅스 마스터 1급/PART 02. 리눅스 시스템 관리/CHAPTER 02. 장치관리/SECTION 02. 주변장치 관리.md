# 1. 디스크 확장
## 개요
### 목적
 용량 부족을 해결하기 위해 새로운 하드디스크를 추가
### 과정
1. 하드디스크 장착
	fdisk -l 옵션으로 장착 확인
2. 확장 파티션 생성
	fdisk 디스크
3. 논리 파티션 생성
4. 파티션 포맷
	파일 시스템을 지정하여 논리적 파티션을 포맷한다.
5. 마운트
	파일 시스템을 명시하며 마운트한다.
6. 확인
	df 명령어로 마운트를 확인
7. /etc/fstab 등록

# 2. 프린터
## 리눅스 프린팅 시스템
### 역사
1. 초기 프린터
	고정 크기, 단일 폰트를 갖는 텍스트 형식으로 한 줄씩 출력하는 라인 프린터 사용
	- BSD 프린팅 시스템
		- 서버에서 동작하는 라인 프린터 데몬
		- 프린트 요청을 위한 lpr 명령어를 포함하는 클라이언트
		- 프로토콜 : Line Printer Daemon Protocol
2. 스풀링(Spooling : Simultaneous Peripheral OPeration On Line)
	기존 라인프린터의 느린 속도를 개선함.

## CUPS (Common Unix Printing System)
### 개요 
- 다양한 프린터를 지원하기 위한 모듈러 프린팅 시스템
### 특징
- 프린터마다 독자적으로 사용한 장치 드라이버의 작성을 용이하게 함
- 라인 프린터, 포스트스크립트 프린터 등의 여러 프린터 형식을 유닉스 OS에서도 사용 가능하록 지원
- HTTP 기반 [[IPP 프로토콜]]을 사용하고 [[SMB 프로토콜]]도 지원

# 3. 사운드 카드
## 개요
### 리눅스 사운드 오픈소스
1. OSS (Open Sound System)
	유닉스 및 유닉스 호환 시스템 지원
2. ALSA(Advanced Linux Sound Architecture)
	리눅스에서만 지원
	리눅스 커널 2.4까지는 OSS API를 포함했으나 그후에 OSS쪽은 제거하고 ALSA가 추가됨

## OSS
### 정의
유닉스와 유닉스 호환 OS를 위한 사운드 생성 및 캡처 인터페이스이자 인터페이스를 구현하기 위한 디바이스 드라이버와 사운드 컨트롤러 자체

### 특징
- POSIX의 표준 시스템 호출을 기반으로 API 구성
- 기본 장치는 /dev/dsp.
- 라이선스
	- 초기에는 자유 소프트웨어
	- 이후 4Front Tech와 계약 후 신기능과 개선 내용이 4Front Tech 사의 소유가 되었다
	- 2007년 오픈 솔라리스를 위한 CDDL 라이선스와 리눅스를 위한 GPL 라이선스를 갖는 코드 공개
	- 2008년 FreeBSD를 위해 BSD 라이선스로 코드 공개

## ALSA
### 정의
사운드 카드 디바이스 드라이버를 위한 API를 제공하는 리눅스에 포함된 소프트웨어 프레임워크

목표 : 사운드 카드 하드웨어에 대한 자동 설정과 시스템 상 복수 개의 장치 지원

### 특징
- 하드웨어 기반 MIDI 합성 기능
- 다중 채널 하드웨어 믹싱 기능 지원
- 전이중 입출력 제공
- 멀티 프로세서 및 쓰레드 안전 디바이스 드라이버 제공
- 라이선스
	- GPL, LGPL을 바탕으로 개발
