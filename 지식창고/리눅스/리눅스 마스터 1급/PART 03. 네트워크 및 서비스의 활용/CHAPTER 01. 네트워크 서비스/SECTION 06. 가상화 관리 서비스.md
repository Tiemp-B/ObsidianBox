# 1. 가상화 서비스의 개요
## 가상화의 특징
### 가상화의 개념
- A개의 물리적 자원을 B개의 논리적 자원으로 치환하여 제공하는 기술
### 특징
논리적인 자원 풀ㅇ에 기반한 효율적 자원 활용, 물리적 공간 절약, 가용성, 중앙 집중 관리에 따른 보안성 향상 등의 장점 제공
- 공유
- 프로비저닝
- 단일화
- 에뮬레이션
- 분리
## 가상화 서비스 방식과 기술
VMM(Virtual Machine Monitor)로 물리적인 하드웨어를 가상머신의 하드웨어와 매핑하고 Guest OS의 자원 사용 관리
### 하드웨어 레벨 가상화
1. 전가상화
	- 게스트 OS가 수정 없이 그대로 실행되도록 하드웨어 전체를 가상화
	- 하이퍼바이저가 CPU 명령어와 하드웨어 자원을 완전 에뮬레이션
	- 장점: 게스트 OS 수정 불필요
	- 단점: 하드웨어 명령을 소프트웨어가 에뮬레이션하므로 성능 손실 발생
	- 사용 프로그램: VMware, VirtualBox, QEMU(기본 모드), KVM(초기 단계)
2. 반가상화
	- 게스트 OS를 수정하여 하이퍼바이저로만 API 호출하는 방식
	- 게스트 OS가 가상화 환경을 인식하고, 하이퍼바이저와 협력적 작동
	- 장점: 하드웨어 명령을 직접 에뮬레이션하지 않음 -> 성능 우수
	- 단점: 게스트 OS 커널 수정 필요 -> 사용에 어려움
	- 사용 프로그램: Xen(PV 모드), KVM(일부 모드), L4Linux 등
### 호스트 기반 가상화 방식
- 호스트 기반 가상화는 호스트 운영체제에 VMM을 설치하고 가상머신을 생성
- 예) VirtualBox, VMware Player 등
