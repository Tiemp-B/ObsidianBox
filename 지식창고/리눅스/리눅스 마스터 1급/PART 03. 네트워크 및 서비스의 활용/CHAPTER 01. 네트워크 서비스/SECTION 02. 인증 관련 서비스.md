# 1. 개요
## 리눅스 인증의 개요
### 인증과 인가
- 인증 : 시스템을 사용하는 클라이언트가 등록된 사용자인지 확인
- 인가 : 인가된 크라이언트에게 권한을 부여. 권한에 따라 사용 가능한 서비스, 자원이 달라진다
### 네트워크 기반 인증 서비스의 필요성
- 다수의 시스템을 운영할 경우 사용자 등록, 패스워드 관리 등의 어려움 발생
	-> 네트워크 기반 인증서비스가 필요
- 네트워크 기반 인증 서비스 : 인증에 필요한 정보를 인증 서버에 등록한 후, 필요한 시스템에 인증 관련 정보 제공
- 예 : NIS()
