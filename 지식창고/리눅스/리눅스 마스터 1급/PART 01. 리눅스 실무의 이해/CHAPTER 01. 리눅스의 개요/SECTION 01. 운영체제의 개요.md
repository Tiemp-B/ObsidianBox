
## OS의 정의 및 목적, 역할
### 정의
1. 사용자와 하드웨어 간의 상호작용을 위한 UI 제공 시스템 소프트웨어
2. CPU, 메모리 등의 하드웨어의 효율적 관리
3. 프로그래밍 인터페이스 제공 : 응용 프로그램이 동작할 수 있는 환경
### 목적
1. 처리능력의 향상을 목적
	- 처리 능력: 일정 시간 동안 처리하는 일의 양
2. 반환 시간의 최소화를 목적
	- 작업 의뢰 후 시스템에서 결과가 얻어질 때까지의 시간
3. 신뢰도의 향상을 목적
	- 정확하게 처리하는 정도
4. 사용 가능도의 향상을 목적
	- 이용 가능한 시스템 자원
### 역할
1. 하드웨어 제어, 입출력 등의 관리 수행 -> 하드웨어 접근 용이
2. 한정된 하드웨어 자원을 공유하는 기능
3. 자원 스케쥴링으로 한정 자원을 효율적으로 사용
4. 시스템 호출 -> 응용 프로그램의 작성과 실행 편리
5. 오류 복구 기능 -> 오류에 대한 시스템 안정성
6. 파일 관리 및 데이터베이스 기능 -> 데이터 조직화 및 저장
7. 네트워크 기능 -> 원격의 컴퓨터와 연결
8. UI ->사용자 편의성

## OS의 구조와 기능
### 구조
1. 단일형 구조(Monolithic)
	모든 운영체제 기능이 하나의 커널 공간에 통합된 구조
	각 모듈 간의 경계가 명확하지 않아 모든 커널 함수가 서로를 직접 호출 가능
2. 계층형 구조(Layered)
	기능을 여러 계층으로 분리하여 각 계층이 명확한 역할과 인터페이스를 가지는 구
	Layer 0 : 물리적 자원 -> CPU, 메모리, 디스크 등
	Layer 1 : CPU 스케줄링과 프로세스 관리 
	Layer 2 : 메모리 관리 -> 가상 메모리, 페이징
	Layer 3 : Inter-Process Communication
	Layer 4 : 입출력 관리와 장치 드라이버를 포함
	Layer 5 : 파일 시스템을 제공
	최상위 계층 : 사용자 프로그램과 인터페이스


3. 사용자 <-> 응용 프로그램
	사용자는 시스템의 기능을 사용하기 위해 응용 프로그램, shell, GUI, batch를 통하여 OS의 기능을 사용한다
4. 응용 프로그램 <-> 커널
	응용 프로그램은 [[시스템 콜]]을 통해 [[커널]]의 서비스를 이용한다
5. 커널 <-> 하드웨어 추상 계층(Hardware Abstraction Layer)
	커널은 시스템 자원을 직접 제어하는 소프트웨어 계층이다. 메모리, CPU, 파일 등을 
6. HAL <-> 하드웨어

### 기능
1. 리소스 관리
2. 자원 스케줄링
3. 하드웨어 관리, 네트워크 제어
4. 데이터 관리, 자원 공유 
5. 무분별한 접근 방지를 통한 자원 보호
6. 오류 검사 및 복구
7. 자원의 유휴 시간을 최소화를 위한 가상화 

## OS의 운용 기법

### OS 운용 기법의 종류
1. 일괄 처리 시스템(Batch Processing System)
	- 초기 OS 형태
	- 여러 작업을 묶어서 한 번에 처리
	- OS가 처리를 시작하면 대기해야 함
	- 처리 중 시스템 이용 불가 -> 효율성 낮음
2. 다중 프로그래밍 시스템(Multi Programming System)
	- 일괄 처리 시스템의 유휴 자원을 사용하는 것이 목적
	- 하나의 입출력 중 다른 작업을 할당하여 CPU 사용률과 처리량을 향상
	- 작업 단위로 CPU 스케줄링 수행
3. 시분할 시스템(Time Sharing System)
	- '타임 슬라이스' 또는 '타임 퀀텀' 단위로 작업을 전환하여 실행
4. 다중 처리 시스템(Multi-Processing System)
	- 병령 처리 시스템
	- 복수 개의 CPU를 통해 복수 개의 작업을 처리하는 운용 기법
	- 종류
		- 비대칭적 다중 처리
			- 프로세스 간 주종 관계 존재
			- 주 프로세스의 대기 큐의 프로세스를 종 프로세스에 할당 처리
			- 시스템 콜이나 인터럽트 처리 같은 OS 기능은 주 프로세서가 처리
		- 대칭적 다중 처리
			- Symmetric Multi-Processing
				- 모든 프로세서가 동등한 권한을 가지고 OS를 공유
				- 모든 프로세서가 단일 공유 메모리에 접근, 동일 입출력 장치와 버스 사용 => 긴밀 결합
				- 대부분의 현대 서버와 워크스테이션, 윈도우즈 서버, 리눅스, 유닉스 등이 지원
			- Massively Parallel Processing
				- 각 프로세서가 독립적인 메모리와 OS를 가진다.
				- 수많은 프로세서 노드로 확장 가능
				- **느슨한 결합 시스템** => 노드는 사실상 독립된 컴퓨터
				- **메시지 전달** 방식 프로세서 간 통신 -> 고속 네트워 인터커넥트(InfiniBand, Ethernet 등)
				- 작업은 명시적으로 여러 노드에 분할, 각 노드가 독립적 처리
				- 슈퍼컴퓨터, 대규모 데이터베이스 시스템(Teradata, Greenplum), 과학 계산, 빅데이터 분석 등
5. 실시간 처리 시스템(Real Time Processing System)
	- 작업 요청의 수행 결과가 요구 시간 내에 반환되야 한다
	- 엄격한 정도에 따라서 재분류
		- 경성 실시간 처리 시스템
			- 반드시 처리 완료되야 한다.
			- 무기 제어, 산업 로봇 등
		- 연성 실시간 처리 시스템
			- 큰 영향이 없다
			- 영상 재생 등
6. 다중 모드 시스템(Multi-Mode System)
	- 위 5가지를 모두 혼용하여 사용 가능한 운용 시스템
