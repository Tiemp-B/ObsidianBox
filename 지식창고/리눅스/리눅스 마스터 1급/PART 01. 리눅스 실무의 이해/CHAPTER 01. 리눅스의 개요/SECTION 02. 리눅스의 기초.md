
## 계열
### Debian
APT와 dpkg를 패키지 관리자로 사용하며 안정성을 최우선으로 하는 배포판
- Ubuntu
	- Kubuntu, Xubuntu, Ubuntu Server 등 다양한 변형 있음
- Mint
### Red Hat
RHEL은 상업용 배포판으로 기업 환경에 최적화 됨
RPM과 YUM/DNF를 패키지 관리자로 사용
- RHEL
- Fedora
	- RHEL의 커뮤니티 버전으로 최신 기술을 빠르게 도입
- CentOS
	- RHEL의 무료 클론이었지만 CentOS Stream으로 전환되어 RHEL의 upstream 버전이 됨

### Arch 계열
단순성과 최신성을 중점으로 한 롤링 릴리스 배포판
Pacman을 패키지 관리자로 사용
- Arch Linux
- Manjaro

### SUSE 계열
독일 기반의 배포판
YaST를 관리도구로 제공
- openSUSE
- SUSE Linux Enterprise

### Gentoo 계열
소스 기반 배포판으로 모든 패키지를 컴파일하여 설치
최대 성능 최적화가 가능하나 설치 및 유지보수가 어려움

### Slackware 계열
가장 오래된 배포판 중 하나로 UNIX 철학을 따름
단순하고 안정적이나 자동화 도구가 적음

### 특수 목적
- Kali Linux
	보안 테스팅과 침투 테스트 도구 제공
- Ubuntu Studio
	멀티미디어 제작에 최적화
- Raspbian
	라즈베리파이용
