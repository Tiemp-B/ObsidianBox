# 조사 - 뉴턴랩슨반복공식·다중해선택기준 (2026-08-08)

개요 페이지에 "NCS 자료 대조" aside가 있어 이번 재작업에서 직접 재편집하며 삭제(2026-08-08 규칙, 직접 재작업 시 소급 삭제 허용). 문제은행(세부항목 슬롯 10문항 중 이 세세항목 소관 "역기구학 닫힌 형태 해 특징" 1문항) 기존 페이지 커버 확인. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "numerical inverse kinematics Newton-Raphson Jacobian inverse iterative method robot" 검색 → 기존 페이지는 "자코비안 역행렬을 이용한 반복 계산"이라고만 쓰고 실제 반복 공식이 없음. 뉴턴-랩슨 방식의 반복 갱신 공식($\Delta\theta = J^{-1}(x_d - f(\theta_i))$)을 확인 — 신규 공백
- "inverse kinematics multiple solutions elbow up elbow down robot arm example" 검색 → 기존 페이지는 elbow-up/down을 "해가 여러 개 존재하는 예"로만 언급하고, 실무에서 여러 해 중 무엇을 고르는지는 다루지 않음 — 신규 공백

### 2라운드 — 파생 심화 검색
- "로봇 역기구학 수치해법 뉴턴랩슨 반복 자코비안 역행렬" 검색 → 한국어 자료에서도 동일하게 자코비안(또는 의사역행렬)을 이용해 현재 위치→목표 위치 오차를 관절각 변화량으로 환산해 반복 갱신하는 방식 확인
- "역기구학 다중 해 선택 기준 현재 자세와 가까운 해 장애물 회피" 검색 → 다중 해 선택 기준 확인: 관절 한계를 넘는 해 배제, 직전 자세에서 가장 가까운 해 선택, 여유자유도(redundant DOF)가 있으면 장애물 회피 등에 활용

### 3라운드 — 반영 후보 구체화 검색
- "뉴턴랩슨 반복공식 delta theta J역행렬 목표위치 현재위치 오차" 검색 → 반복 공식 $\Delta\theta = J^{-1}(x_d - f(\theta_i))$, $\theta_{i+1} = \theta_i + \Delta\theta$ 확정. 목표위치와 현재위치의 오차를 자코비안 역행렬로 관절각 변화량으로 바꿔 매 반복 갱신한다는 구조 확정 — "3. 로봇 기구학 해석"에서 이미 다룬 자코비안 정의와 직접 연결됨

## Phase 2 — 자체 검토

- 뉴턴-랩슨 반복 공식은 기존 "수치 해법" aside의 "자코비안 역행렬을 이용한 반복 계산"이라는 한 문장을 구체화하는 자연스러운 확장이며, "3. 로봇 기구학 해석"에서 다룬 자코비안 정의를 재사용해 교차 링크. 수렴성 증명이나 감쇠최소제곱(DLS) 같은 특이점 근방 보정 기법까지는 실기 범위라 넣지 않음(§2 원칙, 개요 페이지의 기존 스코프 판단과 일관)
- 다중 해 선택 기준은 기존 "역기구학 해의 존재와 다중성" aside의 elbow-up/down 언급을 실무적으로 확장하며, SVD 기반 다중 로봇 협동제어처럼 개요 페이지가 이미 실기 범위로 명시한 심화 내용과는 구분되는 개념 수준의 선택 기준(관절 한계, 최근접 해, 여유자유도)만 반영
- NCS 자료 대조 aside는 2026-08-08 규칙에 따라 이번 직접 재작업 과정에서 삭제, 대신 스코프 설명(왜 심화 수식을 제외하는지)은 "이 세세항목의 구성" 문맥에 자연스럽게 남김
