# 조사 - 자코비안·특이점종류 (2026-08-08)

개요(허브) 링크 정상. 문제은행(세부항목 슬롯 10문항 중 이 세세항목 소관 "DH파라미터 구성요소×2"·"다관절로봇 특징"·"특이점 문제"·"순기구학 목적" 5문항) 전부 기존 페이지 커버 확인, 역기구학/동차변환행렬/좌표계/동역학 문항은 형제 세세항목 소관으로 확인. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "robot Jacobian matrix joint velocity end effector velocity definition kinematics" 검색 → 기존 페이지는 특이점 설명에서 "자코비안 행렬이 특이(랭크 손실)"라고만 쓰고 자코비안 자체를 정의하지 않음. 자코비안은 관절속도-엔드이펙터속도를 연결하는 행렬($\dot x = J\dot q$)이라는 정의 확인 — vault 전체에 자코비안을 다룬 곳이 없음(신규 공백)
- "Jacobian matrix rank loss singularity robot manipulator relationship" 검색 → 특이점은 경계 특이점(boundary)과 내부 특이점(interior)으로 나뉘며, 손목 특이점(두 회전축 정렬)이 대표적 내부 특이점 사례임을 확인 — 기존 페이지는 특이점의 "정의"만 있고 "종류/구체적 예시"가 없음

### 2라운드 — 파생 심화 검색
- "로봇 자코비안 행렬 정의 관절속도 엔드이펙터속도 특이점" 검색 → 한국어 자료에서도 동일하게 자코비안을 관절속도→말단속도 선형 변환으로 정의, 특이점을 자코비안 랭크 저하로 판별한다는 점 확인
- "robot arm singularity example elbow fully extended wrist axes aligned" 검색 → 팔꿈치 특이점(elbow, 팔을 완전히 편/접은 경계 자세)과 손목 특이점(wrist, 손목의 두 회전축이 겹치는 자세)이라는 구체적 두 종류와 각각의 발생 조건 확인

### 3라운드 — 반영 후보 구체화 검색(한국어 검증)
- "로봇 팔 특이점 종류 팔꿈치 특이점 손목 특이점 경계 특이점" 검색 → 한국어 자료로 "팔꿈치 특이점"(경계, 팔 길이 한계)·"손목 특이점"(손목 두 축 겹침, 티칭 중 손목이 갑자기 한 바퀴 도는 사고) 용어 확정. 손목 특이점이 "1. 좌표계" 배치에서 이미 다룬 짐벌락·손목 반전(wrist flip)과 사실상 동일한 현상임을 확인 — 교차 링크 대상

## Phase 2 — 자체 검토

- 자코비안은 특이점 설명을 자기완결적으로 만드는 데 필요한 선행 개념이라 신규 aside로 반영. 자코비안의 편미분 유도나 특이값분해(SVD)까지는 실기 범위라 넣지 않고, 정의(속도 관계)와 특이점과의 연결만 반영(§2 원칙)
- 특이점 종류(팔꿈치/손목)는 기존 특이점 aside를 구체화하는 자연스러운 확장이며, 손목 특이점은 "1. 좌표계"에서 다룬 짐벌락·손목 반전과 같은 현상이므로 새로 설명하지 않고 교차 링크로 처리(중복 방지)
- 자코비안은 로봇공학에서 범용 개념이라 신규 Box 용어로 생성. 특이점 종류는 기존 "특이점(Singularity)" aside의 확장이라 별도 Box 용어 없이 vault 페이지에만 반영
