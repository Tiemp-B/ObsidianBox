# 조사 - 짐벌락·쿼터니언 (2026-08-08)

개요(허브)·2번 페이지 링크 정상. 문제은행(세부항목 슬롯 10문항 중 이 세세항목 소관은 "Z-Y-X 오일러 각 회전 순서" 1문항)만 이 세세항목 소관이며 기존 페이지가 커버 확인. 나머지 9문항은 DH파라미터/동차변환행렬/특이점/역기구학/동역학 등 형제 세세항목("2. 변환행렬", "3. 로봇 기구학 해석", "4. 로봇 역기구학 해석") 소관. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "gimbal lock Euler angles robot orientation explanation" 검색 → 짐벌락은 두 회전축이 겹쳐 자유도 3→2로 줄어드는 특이 현상. 기존 Box 용어 `오일러 각(Euler Angle)`에 한 줄로만 언급되어 있고, 정작 이 세세항목의 실제 vault 페이지에는 전혀 반영되어 있지 않음을 확인
- "quaternion vs Euler angle robot orientation representation advantages" 검색 → 쿼터니언은 짐벌락이 없고, 삼각함수 없이 대수 연산만으로 계산 가능하며, SLERP로 매끄러운 보간이 가능하다는 점에서 오일러 각의 대안으로 로봇 제어기에 흔히 쓰임. vault 전체에 쿼터니언을 다루는 페이지·용어가 전혀 없음(신규 공백)

### 2라운드 — 파생 심화 검색
- "gimbal lock robot arm pitch 90 degree example roll yaw same axis" 검색 → 피치 90도에서 롤·요 축이 겹치는 원리 확인. 산업용 로봇 팔에서는 이를 "손목 반전(wrist flip)"이라 부르며, 손목 3축이 한 점에서 만나는 트리플롤 손목 구조에서 2번째 손목 축이 자세 유지를 위해 순간적으로 180° 회전하려는 문제로 구체화됨 — 로봇 도메인에 맞는 구체적 예시
- "quaternion four parameters w x y z unit quaternion rotation representation basics" 검색 → 쿼터니언은 (w, x, y, z) 4개 실수로 구성되며, 단위 쿼터니언(길이 1)만 회전 표현에 쓰인다는 기본 구조 확인

### 3라운드 — 반영 후보 구체화 검색(한국어 검증)
- "로봇 짐벌락 손목 특이점 오일러각 문제점" 검색 → 한국어 자료에서도 동일하게 손목 짐벌락을 오일러각의 대표적 한계로 설명하며, "저장·보간은 쿼터니언, 계산은 회전행렬, 사람에게 보여주는 것만 오일러각"이라는 실무 역할 분담 원칙 확인
- "쿼터니언 로봇 자세 표현 짐벌락 회피 SLERP" 검색 → 쿼터니언 4개 수(w,x,y,z)에 제약이 하나(길이 1)뿐이라 회전의 자유도 3에 정확히 대응하고 표현이 연속적이라는 점, SLERP(구면 선형 보간) 용어 한국어 표기 확인

## Phase 2 — 자체 검토

- 짐벌락은 이 세세항목(오일러 각의 한계)의 핵심 내용이므로 vault 페이지에 정식 aside로 반영 — 기존 Box 용어의 한 줄 언급을 보강하고 서로 교차 링크
- 쿼터니언은 이름·4개 파라미터 구조·짐벌락 회피 이유·"저장/보간용, 오일러각은 표시용"이라는 역할 구분까지만 반영하고, 쿼터니언 곱셈 공식이나 SLERP의 수식 유도까지는 실기 범위라 넣지 않음(§2 원칙)
- 손목 반전(wrist flip) 예시는 로봇 팔 도메인에 특화된 구체적 사례라 짐벌락 aside에 예시로 포함
- 문제은행 소관 외 9문항(DH파라미터/특이점/역기구학/동역학 등)은 형제 세세항목 소관이라 이번 배치에서는 다루지 않음 — 각 세세항목 배치에서 재확인 예정

## Phase 3 — 결론

1개 페이지(2. 오일러 각과 회전 순서)에 신규 개념 2건(짐벌락, 쿼터니언) 반영. 기존 Box 용어 `오일러 각(Euler Angle)`의 짐벌락 서술 보강, 신규 Box 용어 `쿼터니언(Quaternion)` 생성.
