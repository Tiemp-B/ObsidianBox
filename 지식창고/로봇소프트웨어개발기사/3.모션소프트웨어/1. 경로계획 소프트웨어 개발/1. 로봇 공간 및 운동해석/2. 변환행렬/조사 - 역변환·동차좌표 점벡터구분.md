# 조사 - 역변환·동차좌표 점벡터구분 (2026-08-08)

개요(허브) 링크 정상. 문제은행(세부항목 슬롯 10문항 중 이 세세항목 소관 "동차변환행렬 회전행렬 특성"·"6DOF 변환행렬 크기" 2문항) 전부 기존 페이지 커버 확인, DH파라미터·순기구학 관련 문항은 형제 세세항목("3. 로봇 기구학 해석") 소관으로 확인. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "homogeneous transformation matrix inverse robotics R transpose formula" 검색 → 동차 변환행렬의 역변환은 일반적인 4×4 역행렬 계산이 아니라, 회전행렬이 직교행렬이라는 성질을 이용해 $T^{-1} = [R^T, -R^T p; 0, 1]$로 간단히 구할 수 있음을 확인 — 기존 페이지엔 역변환이 전혀 없었음(신규 공백)
- "homogeneous coordinates point vector fourth component 1 vs 0 meaning" 검색 → 동차좌표의 4번째 성분이 점은 1, 방향벡터는 0이라는 구분이 있고, 이 덕분에 이동변환이 점에는 적용되고 벡터에는 적용되지 않는다는 실용적 차이가 있음을 확인 — 기존 페이지는 "동차좌표 표기를 위한 상수 행"이라고만 하고 이 구분을 설명하지 않음(신규 공백)

### 2라운드 — 파생 심화 검색
- "로봇 동차변환행렬 역변환 R전치행렬 -R전치*p 공식" 검색 → 한국어 자료에서도 동일하게 회전 부분은 R의 전치, 이동 부분은 $-R^T p$로 계산하는 구조 확인, "회전변환→이동변환 순으로 정변환했으므로 역변환은 이동역변환→회전역변환 순으로 곱한다"는 유도 논리 확인
- "robot end effector to base frame transform inverse example DH kinematics" 검색 → 순기구학 T(베이스→말단)를 알 때, 반대 방향(말단→베이스) 변환이 필요하면 T를 다시 유도하지 않고 $T^{-1}$을 계산해 쓴다는 실제 활용 맥락 확인

### 3라운드 — 반영 후보 구체화 검색
- "homogeneous transformation matrix inverse example convert point from tool frame to base frame robot arm" 검색 → 점을 다른 좌표계로 옮길 때는 $[x,y,z,1]$을 곱하고, 방향벡터를 옮길 때는 $[x,y,z,0]$을 곱한다는 구체적 활용 예시 확인(점은 이동의 영향을 받고, 방향벡터는 이동의 영향을 받지 않음) — 로봇 팔의 카메라·툴 좌표계 변환처럼 실제 로봇 도메인에서 쓰이는 패턴임을 재확인

## Phase 2 — 자체 검토

- 역변환 공식은 이 세세항목(변환행렬)의 핵심 계산 내용이자, 회전행렬의 직교성(1번 페이지에 이미 있는 특성)과 바로 연결되므로 신규 aside로 반영. 유도 과정의 수식 전개까지는 넣지 않고 공식과 그 근거(직교성)만 반영(§2 원칙)
- 점 vs 방향벡터 구분은 동차좌표의 4번째 성분이 왜 존재하는지를 설명하는 핵심 개념이며, 기존 페이지의 "동차좌표 표기를 위한 상수 행"이라는 서술을 구체화하는 자연스러운 확장이라 반영
- 두 개념 모두 로봇 팔의 좌표계 변환(툴↔베이스)이라는 동일한 실무 맥락으로 예시를 통일해 서로 연결
