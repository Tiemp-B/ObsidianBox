# 조사 - A*와다익스트라의관계 (2026-08-08)

개요(허브) 링크 정상, NCS 자료 대조 aside 없음(이미 클린). 문제은행(세부항목 슬롯 14문항 중 이 세세항목 소관 "C-space 장애물 용어"·"RRT 특징"·"PRM 특징"·"A* 휴리스틱 함수 조건"·"A* 알고리즘 특징 아닌 것"·"Voronoi 다이어그램 장점" 6문항) 확인: 5문항은 기존 페이지가 커버, "A* 알고리즘의 특징이 아닌 것" 1문항은 기존 페이지가 f(n)=g(n)+h(n)과 admissible 조건만 다루고 A*의 더 넓은 성질(다익스트라와의 관계 등)이 없어 신규 반영 필요. Potential Field 관련 1문항("지역 경로 계획에서...")과 DWA·Pure Pursuit·VFH 관련 4문항은 "3. 이동로봇 지역 경로계획"(다음 세세항목) 소관으로 확인. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "A* algorithm relation to Dijkstra greedy best-first search generalization" 검색 → A*는 다익스트라(비용 기반 탐색)와 그리디 최선탐색(휴리스틱 기반 탐색)을 결합한 알고리즘이며, 휴리스틱 함수 h(n)=0으로 두면 A*가 다익스트라와 동일해진다는 사실 확인 — 기존 페이지엔 이 관계가 전혀 없음(신규 공백)
- "A* algorithm properties completeness optimality characteristics not features" 검색 → A*는 완비성(해가 있으면 반드시 찾음)과 최적성(admissible+consistent 휴리스틱 조건 하에 최단경로 보장)을 갖는다는 일반 성질 확인

### 2라운드 — 파생 심화 검색
- "A* 알고리즘 다익스트라 관계 h(n)=0 그리디탐색 차이 한국어" 검색 → 한국어 자료에서도 "다익스트라는 모든 노드 t에 대해 h(t)=0인 A*의 특수 케이스"라는 동일한 설명 확인, A*는 목적지가 정해져 있어 다익스트라(도착지 없이 모든 노드까지 최단경로)보다 실행이 더 빠르다는 차이 확인
- "로봇 경로계획 A* 다익스트라 비교 완비성 최적성" 검색 → 다익스트라는 완비성·최적성을 항상 보장하지만 연산량이 많고, A*는 휴리스틱으로 탐색 범위를 줄여 효율적이지만 적절한 휴리스틱이 아니면 최적성을 보장하지 못한다는 트레이드오프 재확인

### 3라운드 — 반영 후보 구체화 검색
- "다익스트라 알고리즘 A* 특수한 경우 h(n)=0 시험 문제" 검색 → "다익스트라는 h(n)=0인 A*의 특수 사례"라는 관계와, A*가 목적지 지정 탐색이라 다익스트라(전체 노드 대상 탐색)보다 빠르다는 차이를 최종 확정 — 기존 A* aside(f(n)=g(n)+h(n), admissible 조건)를 자연스럽게 확장하는 내용임을 확인

## Phase 2 — 자체 검토

- A*-다익스트라 관계는 기존 "그래프 탐색 알고리즘" aside가 두 알고리즘을 나열만 하고 관계를 설명하지 않았던 부분을 채우는 자연스러운 확장이라 반영
- 그리디 최선탐색과의 3자 비교나 A* 변형(D*, Anytime A* 등) 심화까지는 실기/심화 범위라 넣지 않고, 다익스트라와의 관계(h(n)=0 특수 사례)와 실행 속도 차이 이유까지만 반영(§2 원칙)
- Potential Field·DWA·Pure Pursuit·VFH 관련 문제은행 문항은 "3. 이동로봇 지역 경로계획" 소관으로 이번 배치에서는 다루지 않음
