# 조사 - 저크·S자형속도프로파일 (2026-08-08)

개요 페이지에 "NCS 자료 대조" aside가 있어 이번 재작업에서 직접 재편집하며 삭제(2026-08-08 규칙). 문제은행(세부항목 슬롯 14문항 중 이 세세항목 소관 "C-space 장애물 용어"·"사다리꼴 속도 프로파일 특징"·"PRM 특징"·"Joint Space 가속도 연속성 궤적" 4문항)을 확인한 결과, C-space/PRM 2문항은 형제 세부항목 "2. 이동로봇 전역 경로계획/3. RRT와 PRM.md"에 매니퓰레이터 예시까지 포함해 이미 커버되어 있어 중복 작성 대신 교차 링크로 처리, 나머지 2문항(사다리꼴/5차다항식)은 이 세세항목 페이지가 이미 커버. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "S-curve velocity profile vs trapezoidal jerk limited motion robot" 검색 → 사다리꼴 프로파일은 가속-등속-감속 전환 지점에서 가속도가 계단식으로 바뀌어 저크(jerk, 가속도의 변화율)가 순간적으로 무한대가 되고, 이것이 로봇 구조의 잔류 진동을 유발한다는 점 확인. S자형(S-curve) 프로파일은 저크를 유한한 값으로 제한해 이 문제를 줄인다 — 기존 페이지는 사다리꼴의 3구간만 다루고 저크·S자형은 전혀 없음(신규 공백)
- "jerk robot motion profile definition why smooth acceleration matters" 검색 → 저크는 기구부 스트레스·공진·진동과 직결되는 개념이며, 5차 다항식이 가속도 연속성을 보장하는 이유(=저크를 유한하게 만듦)와도 직접 연결됨을 확인

### 2라운드 — 파생 심화 검색
- "저크 S자형 속도 프로파일 사다리꼴 프로파일 진동 로봇" 검색 → 한국어 자료에서도 "사다리꼴 프로파일은 가속도가 0→2.0→0으로 계단처럼 뛰어 저크가 그 순간 무한대이며, 링크가 길고 가늘수록 이 충격이 구조를 때려 잔진동이 남는다"는 구체적 설명 확인
- "S-curve motion profile acceleration phases seven segments jerk time example" 검색 → S자형 프로파일은 저크(가속)-등가속-저크(감속) 등으로 나뉘어 사다리꼴의 3단계보다 세분화된 7단계 구조를 가진다는 점 확인

### 3라운드 — 반영 후보 구체화 검색(한국어 검증)
- "로봇 저크 정의 가속도의 시간에 대한 미분 진동 원인" 검색 → 한국어 자료로 저크(가가속도)가 "가속도의 변화율"이라는 정의, 저크가 클수록 진동이 강해지고 로봇 고속 모션 제어 시 공진에 의한 잔류 진동을 유발한다는 점, 사다리꼴 대신 S자형 프로파일을 써서 저크를 제한하는 것이 대책이라는 점을 최종 확정

## Phase 2 — 자체 검토

- 저크·S자형 속도 프로파일은 기존 "사다리꼴 속도 프로파일"·"5차 다항식" aside들이 암묵적으로 전제하고 있던 "왜 부드러운 전환이 필요한가"를 명시적으로 설명하는 자연스러운 확장이라 신규 반영
- S자형 프로파일의 7단계 세부 수식이나 비대칭 S-커브 같은 심화 변형까지는 넣지 않고, 저크의 정의·사다리꼴과의 차이(유한 저크 vs 무한 저크)·진동과의 인과관계만 반영(§2 원칙)
- C-space·PRM은 문제은행에 이 세세항목 소관 문항이 있지만 이미 형제 세부항목 페이지에 매니퓰레이터 예시까지 포함해 충분히 커버되어 있어, 내용을 새로 쓰지 않고 개요 페이지에 교차 링크만 추가(중복 방지)
- NCS 자료 대조 aside는 2026-08-08 규칙에 따라 이번 직접 재작업 과정에서 삭제
