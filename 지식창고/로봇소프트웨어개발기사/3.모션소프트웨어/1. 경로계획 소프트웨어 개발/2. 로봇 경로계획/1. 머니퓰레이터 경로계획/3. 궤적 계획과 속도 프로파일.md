# Summary

경로(path)가 공간상의 점들의 나열이라면, **궤적(trajectory)**은 여기에 시간에 따른 위치·속도·가속도를 더한 것이며, 실무에서는 **사다리꼴 속도 프로파일**과 **다항식 궤적**이 널리 쓰인다.

# Notes

<aside>경로와 궤적의 차이</aside>

경로 계획은 시작점에서 목표점까지의 **공간적인 점들의 연속**을 정하는 것이고, 궤적 계획은 그 경로를 **언제, 얼마의 속도로** 지나갈지까지 정하는 것이다. 즉 궤적 = 경로 + 시간(속도·가속도) 정보다.

<aside>이동계획(궤적 생성)의 관점</aside>

이동계획 프로그램은 초기 상태(Initial State)에서 최종 상태(Final State)를 달성시키는 최적 경로에서, 시간에 대한 위치·속도·가속도 함수를 구체적으로 정의하여 로봇이 그 궤적을 따라가도록 제어한다. 대표적인 생성 방식은 **사다리꼴**, **S커브**, **다항식(3·5차)** 세 가지다.

<aside>사다리꼴 속도 프로파일(Trapezoidal Velocity Profile)</aside>

사다리꼴 속도 프로파일은 이동 시작 시 0에서 속도를 **일정하게 증가(가속 구간)**시키고, 목표 최고 속도에 도달하면 **일정 속도를 유지(등속 구간)**하다가, 목표 지점에 가까워지면 **속도를 줄여(감속 구간)** 0으로 도착하는, 속도-시간 그래프가 사다리꼴 모양을 이루는 프로파일이다.

- 가속 구간과 감속 구간에서는 가속도가 일정(직선)하고, 등속 구간에서는 가속도가 0
- 가속도가 전환 지점에서 $0 \rightarrow a$ 로 **계단처럼 급격히 증가**하여 진동 및 충격이 발생함(가장 단순하지만 충격이 큰 형태)
- 이동 거리가 짧으면 최고 속도에 도달하기 전에 감속을 시작해야 해 사다리꼴이 아닌 삼각형 모양이 될 수 있음

> 각도(위치)는 S자로 증가, 각속도는 사다리꼴, 각가속도는 $+a / 0 / -a$ 의 직사각형 펄스 형태로 나타난다.

<aside>저크(Jerk)와 S자형 속도 프로파일</aside>

[[저크(Jerk)와 S자형 속도 프로파일|저크]]는 가속도의 변화율이다. 사다리꼴 프로파일은 가속-등속-감속 전환 지점에서 가속도가 계단처럼 바뀌어 저크가 순간적으로 무한대가 되고, 이 충격이 로봇 링크의 잔류 진동으로 나타난다. **S자형(S-curve) 속도 프로파일**은 저크를 유한한 값으로 제한해 가속도 자체를 완만하게 변화시켜 진동을 줄이지만, 그만큼 가감속에 시간이 더 걸려 사다리꼴보다 이동 시간이 길어질 수 있다. S커브는 각가속도 그래프 자체가 사다리꼴 형태가 되며, **저진동이 요구되는 환경(정밀 장비 운송 등)**에 적합하다.

<aside>Joint Space에서의 다항식 궤적</aside>

관절각을 시간의 함수 $\theta(t)$로 표현할 때, 시작·끝의 위치·속도(그리고 필요시 가속도)를 제약 조건으로 삼아 다항식 계수를 구한다.

| 다항식 차수 | 만족할 수 있는 제약 조건 | 특징 |
|---|---|---|
| 3차 다항식 | 시작/끝의 위치, 속도(4개) | 위치·속도는 연속이지만 가속도가 불연속적으로 튈 수 있음 |
| 5차 다항식 | 시작/끝의 위치, 속도, 가속도(6개) | **가속도까지 연속성을 보장** — 더 유연하고 부드러운 움직임 |

<aside>다항식 궤적의 수식 (3차·5차)</aside>

**3차 다항식(Cubic)** — 미정계수 4개($a, b, c, d$)

$$\theta(t) = a + bt + ct^2 + dt^3$$
$$\dot{\theta}(t) = b + 2ct + 3dt^2$$
$$\ddot{\theta}(t) = 2c + 6dt$$

- 계수 4개를 시단·종단의 **위치와 속도** 4개 조건($\theta(0), \dot{\theta}(0), \theta(t_f), \dot{\theta}(t_f)$)으로 결정한다.
- 가속도 $\ddot{\theta}(t) = 2c + 6dt$ 는 1차식이라 **시단·종단의 가속도를 0으로 독립 지정할 수 없어**, 구간을 이을 때 경계에서 가속도가 불연속적으로 튈 수 있다.

**5차 다항식(Quintic)** — 미정계수 6개($a_0 \sim a_5$)

$$\theta(t) = a_0 + a_1 t + a_2 t^2 + a_3 t^3 + a_4 t^4 + a_5 t^5$$
$$\dot{\theta}(t) = a_1 + 2a_2 t + 3a_3 t^2 + 4a_4 t^3 + 5a_5 t^4$$
$$\ddot{\theta}(t) = 2a_2 + 6a_3 t + 12a_4 t^2 + 20a_5 t^3$$

- 계수 6개를 시단·종단의 **위치, 속도, 가속도** 6개 조건으로 결정한다.
- 3차식에서 반영하지 못한 끝단 가속도(보통 0)까지 맞출 수 있어 **가속도가 연속**이 되고, 더 부드러운 움직임을 만든다.

<aside>예시 — 픽앤플레이스 작업의 궤적 설계</aside>

**예시**: 짧은 거리를 빠르게 반복 이동하는 픽앤플레이스 작업에는 계산이 단순한 사다리꼴 속도 프로파일을, 정밀한 곡면 가공처럼 가속도 변화가 부드러워야 하는 작업에는 가속도 연속성을 보장하는 5차 다항식 궤적을 사용한다.

<aside>핵심 정리</aside>

- 궤적은 경로에 시간(속도·가속도) 정보를 더한 것이며, 사다리꼴 속도 프로파일은 가속-등속-감속 세 구간으로 구성된다
- 저크(가속도의 변화율)는 사다리꼴 프로파일의 전환 지점에서 무한대가 되어 진동을 유발하며, S자형 프로파일은 저크를 제한해 진동을 줄이는 대신 이동 시간이 길어질 수 있다
- 3차 다항식(계수 4개)은 위치·속도까지, 5차 다항식(계수 6개)은 가속도까지 연속성을 보장한다
