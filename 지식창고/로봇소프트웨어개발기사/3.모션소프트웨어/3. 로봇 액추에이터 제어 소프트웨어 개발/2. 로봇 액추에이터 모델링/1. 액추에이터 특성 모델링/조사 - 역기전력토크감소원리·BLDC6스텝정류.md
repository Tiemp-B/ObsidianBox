# 조사 - 역기전력토크감소원리·BLDC6스텝정류 (2026-08-09)

개요(허브) 링크 정상, NCS 자료 대조 aside 없음(이미 클린). 문제은행(세부항목 슬롯 6문항 중 이 세세항목 소관 "Kt-Ke 관계×2"·"전기/기계 시정수 관계"·"BLDC 센서리스 역기전력 검출"·"DC모터 특징 아닌것"·"BLDC 특징 아닌것" 6문항) 전부 기존 페이지 커버 확인. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "why DC motor torque decreases with speed back-EMF explanation Kt Ke relationship" 검색 → 속도가 높아지면 역기전력(E=Ke·ω)이 커져 전류(I=(V-E)/R)가 줄고, 토크(τ=Kt·I)도 줄어든다는 인과 관계 확인 — 기존 페이지는 Kt=Ke라는 "관계"만 있고, 이 관계가 "왜 토크-속도 곡선이 선형으로 감소하는지"(직전 세세항목에서 다룬 내용)를 설명하는 데 쓰이지 않음(신규 공백, 세세항목 간 연결 기회)
- "BLDC motor 6-step commutation trapezoidal control hall sensor explanation" 검색 → BLDC의 "전자 회로로 정류"가 구체적으로는 홀센서 3개를 120도 간격으로 배치해 60도 전기각마다 스위칭하는 6-스텝(사다리꼴) 정류 방식임을 확인 — 기존 페이지는 "전자 회로로 정류한다"고만 하고 구체적 방식이 없음(신규 공백)

### 2라운드 — 파생 심화 검색
- "DC모터 속도 증가 역기전력 증가 전류 감소 토크 감소 원리" 검색 → 한국어 자료로 전압방정식 $V=IR+E$($E=K_e\omega$)에서 속도 증가→역기전력 증가→전류 감소→토크 감소의 연쇄 확인
- "BLDC 6스텝 정류 홀센서 120도 사다리꼴 통전 방식" 검색 → 한국어 자료로 홀센서 3개(U/V/W) 120도 배치, 6단계 정류마다 MOSFET 스위칭, 사다리꼴 파형이라는 이름의 유래까지 확인

### 3라운드 — 반영 후보 구체화 검증
- "DC모터 무부하속도 역기전력 공급전압 같아짐 전류 거의 0" 검색 → 무부하 상태(직전 세세항목 "액추에이터 동역학적 구동 프로파일"의 토크-속도 곡선에서 다룬 무부하속도)에서는 역기전력이 공급전압과 거의 같아져 전류·토크가 0에 가까워진다는 점을 확인 — 두 세세항목의 내용이 하나의 인과 관계로 자연스럽게 연결됨을 최종 확정

## Phase 2 — 자체 검토

- 역기전력에 의한 토크 감소 원리는 Kt=Ke 관계를 "왜 중요한지"로 완성하는 동시에, 직전 세세항목의 토크-속도 곡선(무부하속도·정지토크)의 물리적 근거가 되므로 교차 링크와 함께 신규 반영
- BLDC 6-스텝 정류는 기존 "전자 회로로 정류"라는 한 문장을 구체화하는 자연스러운 확장이며, FOC(벡터 제어) 같은 심화 제어 방식이나 상세 스위칭 표까지는 §2 원칙에 따라 넣지 않고 홀센서 120도 배치·60도마다 스위칭·사다리꼴 파형까지만 반영
- 전압방정식($V=IR+E$)의 완전한 유도까지는 넣지 않고, "속도↑→역기전력↑→전류↓→토크↓"라는 인과 흐름만 정성적으로 반영

## Phase 3 — 결론
