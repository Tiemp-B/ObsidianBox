# 조사 - 표준운동방정식(관성·코리올리·중력항) (2026-08-09)

개요(허브) 링크 정상, NCS 자료 대조 aside 없음(이미 클린). 문제은행: 이 세세항목 소관 슬롯 자체엔 문항이 없으나, "1. 로봇 공간 및 운동해석" 슬롯의 "로봇 동역학 모델링에서 라그랑지안 방법의 장점은?" 문항(과거 배치에서 형제 세세항목 소관으로 분류·보류)이 이 세세항목의 기존 "두 방식의 비교" aside로 정확히 커버됨을 재확인. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "robot manipulator equation of motion standard form mass matrix Coriolis centrifugal gravity term" 검색 → 뉴턴-오일러·라그랑지안 두 방식 모두 결국 표준형 운동방정식 $M(q)\ddot q + C(q,\dot q)\dot q + g(q) = \tau$로 귀결된다는 점 확인 — 기존 페이지는 두 "유도 방법"만 비교하고, 그 결과물인 표준 운동방정식 자체와 각 항의 의미가 전혀 없음(신규 공백)
- "inertia matrix M(q) Coriolis C(q,qdot) gravity G(q) robot dynamics physical meaning" 검색 → $M(q)$(관성행렬, 자세에 따라 변함)·$C(q,\dot q)$(코리올리·원심력, 속도에 관련)·$g(q)$(중력항, 자세에만 의존하고 속도와 무관)라는 세 항의 물리적 의미 확인

### 2라운드 — 파생 심화 검색
- "로봇 매니퓰레이터 운동방정식 관성행렬 코리올리항 중력항 표준형" 검색 → 한국어 자료에서도 동일한 표준형과, 관성이 자세의 함수라 팔을 접었을 때 맞춘 게인이 폈을 때는 안 맞을 수 있다는 실무적 함의, 속도의 제곱에 비례하는 코리올리/원심력 항의 성질 확인
- "중력보상 코리올리력 원심력 로봇팔 제어 실무 의미" 검색 → 실무에서 중력보상은 필수적으로 다루지만, 저속으로 동작하는 일반적인 산업용 로봇 팔에서는 코리올리력·원심력을 무시해도 제어 정밀도에 큰 영향이 없어 계산 부하를 줄이는 경우가 많다는 실무적 절충 확인

### 3라운드 — 반영 후보 구체화 검증
- "로봇 동역학 방정식 관성행렬 자세에 따라 변함 중력항 속도무관 오답" 검색 → 관성행렬은 자세(q)에 따라 변하는 대칭행렬, 중력항은 속도와 무관하게 자세에만 의존한다는 성질을 최종 확정 — "중력항이 속도에 비례한다"거나 "관성행렬이 상수"라는 서술을 오답 포인트로 구성 가능함을 확인

## Phase 2 — 자체 검토

- 표준 운동방정식은 뉴턴-오일러·라그랑지안 두 방법이 공통으로 도달하는 결과물이라는 점에서 기존 페이지를 완성하는 핵심 내용이며, 신규 aside로 반영
- $M(q)$의 대칭·양정치성 증명이나 $C(q,\dot q)$의 구체적 유도(크리스토펠 기호 등)까지는 심화 범위라 넣지 않고, 세 항이 각각 무엇에 의존하는지(자세/속도)와 실무적 의미(중력보상 필수, 저속에서 코리올리·원심력 생략 가능)까지만 반영(§2 원칙)
- 새로운 범용 개념이라 Box 용어로 생성해 향후 관련 세세항목(제어기 게인 설정 등)에서도 참조 가능하게 함
