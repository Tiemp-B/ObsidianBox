# 조사 - 감속기토크증폭·스테핑모터개루프탈조 (2026-08-09)

개요 페이지에 "NCS 자료 대조" aside가 있어 이번 재작업에서 직접 재편집하며 삭제(2026-08-09 규칙). 페이지 하단 "관련 노트"의 "1. 로봇 제어기"(트레일링 스페이스 오타) 링크를 실제 내용 페이지 "1. 로봇 제어기 특성"으로 정정. 문제은행(세부항목 슬롯 4문항: 서보모터 토크 하중 계산/스테핑모터 특징 아닌 것/서보모터 위치피드백 센서/스테핑모터 분해능 높이는 법) 전부 기존 페이지가 정확히 커버 확인. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "gear ratio reducer torque multiplication motor robot joint output torque formula" 검색 → 로봇 관절은 대부분 감속기(gear reducer)를 통해 모터의 고속·저토크를 저속·고토크로 변환하며, 출력 토크 = 모터 토크 × 감속비 × 효율(η)이라는 공식 확인 — 기존 페이지의 토크 계산 예시($\tau=F\cdot r$)는 모터 축 자체의 토크만 다루고, 실제 로봇 관절에 흔히 쓰이는 감속기의 토크 증폭 개념이 vault 전체에 전혀 없음(신규 공백)
- "gearbox efficiency output torque input torque gear ratio speed reduction robot actuator" 검색 → 감속비가 클수록 이론상 토크가 그만큼 커지지만, 실제로는 감속기 효율 손실(예: 유성기어 90~95%, 웜기어 50~85%)로 이론값보다 작다는 점 확인

### 2라운드 — 파생 심화 검색
- "감속기 기어비 출력토크 모터토크 곱 효율 로봇 관절" 검색 → 한국어 자료에서도 동일하게 "감속기 출력 토크 = 모터 정격 토크 × 감속비 × 효율"이라는 공식과, 감속기가 속도를 줄이고 토크를 높이는 역할을 한다는 점 확인
- "감속기 로봇 관절 속도 감소 토크 증가 예시 계산" 검색 → 모터 3,000rpm에 감속비 30:1인 감속기를 쓰면 출력축은 100rpm으로 줄고 토크는 이론상 30배 증가한다는 구체적 예시 확인 — 기존 페이지의 서보모터 토크 계산 예시와 형식이 자연스럽게 이어짐

### 3라운드 — 반영 후보 구체화 검증
- "감속기 효율 손실 이론적 토크 증폭 실제 출력토크 차이 오답" 검색 → "감속비만큼 토크가 정확히 증가한다"는 이론값과, 효율 손실 때문에 "실제 출력 토크는 이보다 작다"는 것이 명확한 오답 포인트로 확정. 스테핑모터 관련해서는 vault 내 기존 Box 용어 `스텝모터(Stepper Motor)`, `스테핑 모터`에 개루프 구동·탈조(step skip) 특성이 이미 충분히 다뤄져 있음을 확인 — 새로 작성하지 않고 교차 링크로 처리

## Phase 2 — 자체 검토

- 감속기 토크 증폭은 기존 페이지의 서보모터 토크 계산 예시를 로봇 관절 실무로 확장하는 자연스러운 내용이라 신규 반영. 유성기어·웜기어 등 감속기 종류별 상세 효율 수치나 하모닉드라이브 같은 특정 구조까지는 실기·심화 범위라 넣지 않고, 공식과 효율 손실 오답 포인트까지만 반영(§2 원칙)
- 스테핑모터의 개루프 구동·탈조 특성은 vault의 기존 Box 용어 2건에 이미 충분히 상세하게(홀딩토크·풀인/풀아웃토크·미드레인지 불안정성까지) 다뤄져 있어, 재작성 대신 현재 페이지의 "스테핑모터 특징" aside에 짧게 언급하고 교차 링크로 연결(중복 방지)
- 개요 페이지의 NCS 자료 대조 aside 삭제, 트레일링 스페이스 오타 링크 정정은 이번 직접 재작업 과정에서 함께 처리

## Phase 3 — 결론

1개 페이지(2. 액추에이터 기본 용어와 서보모터 사양)에 신규 개념 2건(감속기의 토크 증폭 공식, 스테핑모터 개루프·탈조 특성 교차 링크) 반영. 개요 페이지의 NCS 자료 대조 aside 삭제, 오타 링크 정정. 신규 Box 용어 `감속기(Gear Reducer)` 생성.
