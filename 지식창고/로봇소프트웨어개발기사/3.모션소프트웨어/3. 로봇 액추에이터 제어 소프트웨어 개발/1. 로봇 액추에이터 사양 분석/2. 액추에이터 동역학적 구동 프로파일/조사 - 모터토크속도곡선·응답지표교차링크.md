# 조사 - 모터토크속도곡선·응답지표교차링크 (2026-08-09)

개요(허브) 링크 정상, NCS 자료 대조 aside 없음(이미 클린). 문제은행 세부항목 슬롯("1. 로봇 액추에이터 사양 분석" 4문항)은 전부 형제 세세항목("1. 액추에이터 사양 분석", 완료)의 서보모터/스테핑모터 관련 문항으로 이미 배정 확인, 이 세세항목 소관 문항 없음. 기존 페이지의 "제어 목표"(안정성·명령추종·외란제거·잡음축소)가 1과목 "로봇 제어기 특성/4. 제어 응답 특성 지표 전반"의 상승시간·정착시간·오버슈트·정상상태오차·PID·피드백/피드포워드 내용과 상당 부분 겹침을 발견 — 재설명 대신 교차 링크로 처리. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "DC motor torque speed curve characteristic robot actuator dynamic profile" 검색 → 이 세세항목의 제목("액추에이터 동역학적 구동 프로파일")과 달리 기존 페이지 내용은 일반적인 제어 시스템 구조·목표만 다루고 모터 자체의 동역학적 특성(토크-속도 관계)이 전혀 없음을 확인 — DC 모터는 속도가 높아질수록 토크가 선형적으로 반비례해 낮아진다는 점 확인(신규 공백)
- "motor torque speed curve rated torque stall torque no-load speed relationship linear" 검색 → 이상적인 DC 모터의 토크-속도 곡선은 **무부하속도(no-load speed, 토크 0일 때 최대 속도)**와 **정지토크(stall torque, 속도 0일 때 최대 토크)** 두 점만으로 완전히 특징지어지는 직선이라는 점 확인

### 2라운드 — 파생 심화 검색
- "모터 토크 속도 곡선 무부하속도 기동토크 정지토크 반비례 선형" 검색 → 한국어 자료에서도 동일하게 속도가 높아질수록 토크가 반비례해 낮아지며, 기동 토크(전동기가 정지 상태에서 움직이기 시작할 때 필요한 토크)는 부하 토크보다 커야 한다는 실무 조건 확인
- "로봇 액추에이터 동작점 부하 토크속도곡선 교차점 최대출력" 검색 → 로봇 액추에이터 선정 시 필요한 토크(최대 부하)와 필요한 속도(민첩성)를 함께 고려해야 한다는 원칙 확인 — 부하가 커질수록 실제 동작점이 토크-속도 곡선 상에서 저속·고토크 쪽으로 이동한다는 원리와 일치

### 3라운드 — 반영 후보 구체화 검증
- 1·2라운드 결과 재검토 → 토크-속도 곡선(무부하속도·정지토크 두 점, 선형 반비례, 부하에 따른 동작점 이동)을 신규 반영 확정. 기존 "제어 목표" aside의 "명령 추종"·"외란 제거" 같은 정성적 서술은 1과목에서 이미 정량적 지표(상승시간·정착시간·오버슈트·정상상태오차)와 PID로 구체화되어 있으므로 재설명하지 않고 교차 링크로 연결

## Phase 2 — 자체 검토

- 토크-속도 곡선은 이 세세항목의 제목("동역학적 구동 프로파일")이 실제로 의도하는 내용에 가장 가까운 핵심 개념이라 판단해 신규 반영. 전압별 곡선군(family of curves)이나 최대 출력점(곡선 중점, 효율 50%) 같은 심화 내용까지는 §2 원칙에 따라 넣지 않고, 두 기준점과 선형 반비례 관계, 부하에 따른 동작점 이동까지만 반영
- 1과목의 응답 특성 지표·PID 내용은 이미 매우 상세하므로 재작성하지 않고, "제어 목표" aside에 짧은 교차 링크 문장만 추가
- 신규 개념(토크-속도 곡선)은 액추에이터 전반에 적용되는 범용 개념이라 Box 용어로 생성

## Phase 3 — 결론

1개 페이지(2. 제어 시스템의 구성과 제어 목표)에 신규 개념 1건(모터 토크-속도 곡선) 반영, 기존 "제어 목표" 내용을 1과목 응답특성 페이지와 교차 링크. 신규 Box 용어 `토크-속도 곡선(Torque-Speed Curve)` 생성.
