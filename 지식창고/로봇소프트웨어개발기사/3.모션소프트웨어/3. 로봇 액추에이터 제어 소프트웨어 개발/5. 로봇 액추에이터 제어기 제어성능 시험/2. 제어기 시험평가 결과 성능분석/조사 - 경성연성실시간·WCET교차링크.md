# 조사 - 경성연성실시간·WCET교차링크 (2026-08-09)

개요(허브) 링크 정상, NCS 자료 대조 aside 없음(이미 클린). 문제은행(세부항목 슬롯 6문항 중 이 세세항목 소관 "실시간제어시스템 성능평가지표 적절하지않은것" 1문항) 기존 페이지 커버 확인, "부하테스트"·"단위테스트"는 개요가 이미 과목2로 교차 링크 처리, "이득여유 배율환산"·"오버슈트-정착시간 허용오차"는 형제 세세항목("1. 제어기 소프트웨어 성능시험") 소관, "정상상태오차 안정화판단시점"은 1과목 정착시간 정의로 커버됨을 재확인. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "hard real-time vs soft real-time system deadline miss consequence difference robot control" 검색 → 경성(hard) 실시간 시스템은 데드라인을 놓치면 시스템 실패(치명적)로 간주되고, 연성(soft) 실시간 시스템은 가끔 놓쳐도 치명적이지 않고 성능만 저하된다는 구분 확인 — 기존 페이지는 "왜 데드라인 준수가 중요한지"는 예시로만 있고, 이를 분류하는 표준 용어(경성/연성)가 없음(신규 공백)
- "firm real-time system definition between hard and soft classification examples" 검색 → 경성/연성 사이에 펌(firm) 실시간이라는 중간 분류도 있으나(데드라인을 넘기면 결과는 버려지지만 시스템은 실패하지 않음), 필기 시험 수준에서는 경성/연성 2분류가 핵심이라 판단

### 2라운드 — 파생 심화 검색
- "경성 실시간 시스템 연성 실시간 시스템 차이 데드라인 놓치면 치명적" 검색 → 한국어 자료로 경성 실시간의 예(무기제어·발전소제어·철도자동제어·미사일자동조준), 연성 실시간의 예(영상 프레임 재생) 확인, 경성이 연성보다 지터가 적다는 부가 특징 확인
- "로봇 제어 경성 실시간 시스템 예시 데드라인 준수 필수" 검색 → 로봇 관절 제어처럼 데드라인을 놓치면 위험한 상황(진동·발진)으로 이어지는 응용은 경성 실시간 시스템에 해당한다는 점 확인 — 기존 페이지의 "예시" aside(로봇 관절 제어 응용)와 정확히 연결됨

### 3라운드 — 반영 후보 구체화 검증
- 1·2라운드 결과 재검토 → 경성/연성 실시간 분류를 확정하고, 기존 페이지의 예시(A/B 제어기 비교)가 사실상 "경성 실시간 응용에서는 데드라인 준수율이 절대적으로 중요하다"는 것을 보여주는 사례임을 명확히 연결. 또한 1과목에 이미 상세히 다뤄진 WCET(최악 실행 시간, 스케줄링 가능성 분석의 기초)가 "데드라인 준수를 어떻게 사전에 보장하는가"의 답이라는 점에서, 새로 설명하지 않고 교차 링크로 연결하기로 확정

## Phase 2 — 자체 검토

- 경성/연성 실시간 분류는 기존 "데드라인 준수율이 중요한 이유"를 시스템 유형별로 구체화하는 자연스러운 확장이며, 펌(firm) 실시간 같은 중간 분류나 실시간 스케줄링 이론(RMS/EDF)까지는 넣지 않고 경성/연성 2분류와 로봇 제어 응용 예시까지만 반영(§2 원칙)
- WCET은 1과목 "실시간 운영체제와 스케줄링"에 이미 RMS/EDF와 함께 상세히 다뤄져 있어 재설명하지 않고, 이 페이지의 "데드라인 준수율" 표에 교차 링크만 추가(중복 방지)

## Phase 3 — 결론

1개 페이지(2. 실시간 제어 시스템의 성능평가 지표)에 신규 개념 1건(경성/연성 실시간 시스템 분류) 반영, WCET은 1과목 페이지와 교차 링크. 신규 Box 용어 없음.
