# 조사 - 위상여유(PhaseMargin) (2026-08-09)

개요(허브) 링크 정상, NCS 자료 대조 aside 없음(이미 클린). 문제은행(세부항목 슬롯 6문항 중 이 세세항목 소관 "이득 여유 10dB 배율 환산"·"오버슈트 20%일 때 정착시간 허용오차범위"(1과목 응답특성 정의로 커버) 2문항) 기존 페이지 커버 확인, "부하테스트/단위테스트/실시간제어시스템 성능평가지표/정상상태오차 안정화판단시점" 4문항은 형제 세세항목("2. 제어기 시험평가 결과 성능분석") 소관으로 확인. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "phase margin definition gain crossover frequency control system stability" 검색 → 위상 여유는 이득 교차 주파수(개루프 이득이 0dB가 되는 주파수)에서 위상이 -180°까지 얼마나 여유가 있는지를 나타내는 지표이며, 통상 45° 이상을 목표로 설계한다는 점 확인 — 기존 페이지는 이득 여유만 있고, 항상 짝으로 다뤄지는 위상 여유가 전혀 없음(신규 공백)
- "gain margin vs phase margin relationship both needed for stability robustness" 검색 → 이득 여유는 위상 교차 주파수에서의 이득 변동 여유, 위상 여유는 이득 교차 주파수에서의 위상 변동 여유로 서로 다른 주파수·다른 물리량을 측정하며, 둘 다 확인해야 진짜 강건성을 판단할 수 있다는 점(한쪽만 커도 다른 쪽이 나쁘면 불안정할 수 있음) 확인

### 2라운드 — 파생 심화 검색
- "위상 여유 이득 여유 차이 정의 이득교차주파수 위상교차주파수" 검색 → 한국어 자료로 이득교차주파수(개루프 이득 0dB인 주파수), 위상교차주파수(위상이 -180°인 주파수)의 정의와, 위상 여유는 상대적 안정성(진동 경향), 이득 여유는 절대 안정성과 연결된다는 구분 확인
- "위상여유 45도 기준 안정성 로봇 제어 서보" 검색 → 서보 제어 시스템에서 위상 여유의 통상적 설계 목표가 45~60도라는 점, 제어 주기가 낮아지면(느려지면) 위상 여유가 줄어들어 안정성에 영향을 줄 수 있다는 실무적 함의 확인

### 3라운드 — 반영 후보 구체화 검증
- 1·2라운드 결과 재검토 → "20dB 이득 여유 + 10° 위상 여유"인 시스템이 "6dB 이득 여유 + 60° 위상 여유"인 시스템보다 오히려 더 발진하기 쉽다는 구체적 대비 사례를 확인 — 한쪽 지표만으로는 안정성을 온전히 판단할 수 없고 두 지표를 함께 봐야 한다는 핵심 메시지를 뒷받침하는 좋은 오답 포인트 소재로 확정

## Phase 2 — 자체 검토

- 위상 여유는 이득 여유와 항상 짝을 이루는 표준 안정성 지표이며, 이 세세항목("제어기 소프트웨어 성능시험")의 핵심 내용을 완성하는 데 필수적이라 신규 반영
- 보드 선도(Bode plot)의 전체 작도법이나 나이퀴스트 안정성 판별법까지는 심화 범위라 넣지 않고, 위상 여유의 정의(이득교차주파수에서의 위상 여유)·통상 설계 목표(45~60°)·이득 여유와의 관계까지만 반영(§2 원칙)
- 이득 여유와 짝을 이루는 범용 개념이라 Box 용어로 생성
