# 조사 - 마이크로스테핑해상도vs정확도 (2026-08-09)

개요(허브) 링크 정상, NCS 자료 대조 aside 없음(이미 클린), BLDC 관련 내용은 개요 페이지가 이미 "로봇 액추에이터 모델링"으로 교차 링크 처리해둠. 문제은행(세부항목 슬롯 11문항 중 이 세세항목 소관 "BLDC 구동특성"(교차링크)·"마이크로스테핑 설명 틀린것"·"마이크로스테핑 장점 아닌것" 3문항) 기존 페이지 커버 확인, PID/PI/Ziegler-Nichols/서보모터제어방식/마찰력보상 관련 8문항은 형제 세세항목("2. 액추에이터 제어구조 설계", "3. 제어기 게인 설정") 소관으로 확인. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "microstepping resolution vs accuracy stepper motor nonlinearity limitation" 검색 → 마이크로스테핑은 해상도(resolution, 명령 가능한 최소 각도 단위)를 높이지만 정확도(accuracy, 로터가 실제로 그 위치에 도달하는 정밀도)는 높이지 못하며, 오히려 떨어질 수도 있다는 점 확인 — 기존 페이지의 "한계" aside는 유지 토크 감소만 다루고, 해상도-정확도가 별개 개념이라는 더 근본적인 한계가 없음(신규 공백)
- "stepper motor microstepping sine wave current waveform driver implementation" 검색 → 마이크로스테핑은 두 코일에 사인파·코사인파 형태로 전류를 흘려 위치를 정의하는 구동 방식이라는 구체적 원리 확인(기존 페이지의 "부드러운 곡선(사인파에 가깝게)" 서술을 뒷받침)

### 2라운드 — 파생 심화 검색
- "마이크로스테핑 해상도 정확도 다름 비선형 자기토크 오차" 검색 → 한국어 자료로 "마이크로스텝은 고해상도를 제공하지만 정확도를 높이지는 않는다"는 동일한 결론과, 모터의 비선형 자기토크 특성·마그네틱 백래시가 오차의 원인이라는 점 확인
- "마이크로스테핑 사인파 전류 구동 방식 원리" 검색 → 한국어 자료로 마이크로스테핑 드라이브가 풀스텝(1.8°)을 최대 256개의 마이크로스텝으로 나눌 수 있다는 구체적 수치 확인

### 3라운드 — 반영 후보 구체화 검증
- "1.8도 풀스텝 256 마이크로스텝 예시 오차 부하 위치 벗어남" 검색 → 마이크로스텝 수를 늘릴수록 미세 스텝당 증분 토크가 급격히 줄어 정지 마찰이나 부하 토크가 그보다 크면 로터가 실제로 움직이지 않는 문제, 부하로 인한 마그네틱 백래시가 위치를 벗어나게 하는 문제를 최종 확정 — 기존 "유지 토크 감소" 한계와 같은 뿌리(미세 스텝당 토크 감소)를 공유하므로 자연스럽게 이어붙일 수 있음을 확인

## Phase 2 — 자체 검토

- 해상도 vs 정확도 구분은 마이크로스테핑을 "스텝을 잘게 나누면 나눌수록 무조건 좋다"고 오해하기 쉬운 지점을 정확히 짚어주는 핵심 한계이며, 기존 "한계"(유지 토크 감소) aside를 근본 원인까지 확장하는 자연스러운 내용이라 반영
- 마그네틱 백래시의 물리적 유도나 고차 고조파 왜곡의 수식적 분석까지는 심화 범위라 넣지 않고, "해상도↑ ≠ 정확도↑"라는 핵심 명제와 그 이유(미세 스텝당 토크 감소로 부하에 밀림)까지만 반영(§2 원칙)
- 사인파 전류 구동 방식은 기존 "부드러운 곡선(사인파에 가깝게)" 서술을 구체화하는 수준으로만 짧게 반영
