# 조사 - 전류루프PI극점영점상쇄 (2026-08-09)

개요(허브) 링크 정상, NCS 자료 대조 aside 없음(이미 클린). 문제은행(세부항목 슬롯 11문항 중 이 세세항목 소관 "Ziegler-Nichols Ti 공식" 1문항) 기존 페이지가 정확히 커버 확인. "DC 모터 전류 제어기 PI 적분시간 상수 설정시 고려사항" 1문항은 기존 ZN 동조법(모델 없이 실험적으로 구함)만으로는 완전히 답할 수 없는, 모델 기반 설계 기법이 필요한 문항으로 판단 — 신규 반영 대상으로 확정. PID 게인 개별 역할·효과 관련 4문항은 1과목 "제어 응답 특성 지표 전반"에서 이미 커버(개요 페이지가 이미 교차 링크 처리). 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "PI current loop tuning integral time constant electrical time constant pole zero cancellation motor control" 검색 → 전류 루프의 PI 게인 설계에서는 지글러-니콜스처럼 실험적으로 구하는 대신, PI 제어기의 적분시간을 모터의 **전기적 시정수**($\tau_e = L/R$)와 일치시켜 전달함수의 극점을 상쇄하는 **극점-영점 상쇄(pole-zero cancellation)** 기법이 널리 쓰임을 확인 — 기존 페이지는 ZN 동조법(모델 불필요, 실험적)만 다루고, 모터 모델을 아는 경우의 설계 기법이 전혀 없음(신규 공백). "1. 액추에이터 특성 모델링"에서 이미 다룬 전기적 시정수 개념과 직접 연결됨
- "current controller PI gain design motor L/R time constant bandwidth consideration" 검색 → 전류 루프는 모터의 전기적 시정수와 전류 센싱 잡음에 의해 대역폭이 제한되며, 저항(R)이 온도에 따라 변하면 적분 이득도 함께 추적 조정해야 한다는 실무적 고려사항 확인

### 2라운드 — 파생 심화 검색
- "전류제어기 PI 적분시간 전기적 시정수 극점상쇄 설계 모터" 검색 → 한국어 자료에서 DC 모터 전류제어기가 PI 제어기와 역기전력 전향(피드포워드) 보상을 함께 쓰는 경우가 많다는 점과, PI 제어기의 적분시간(Tn) 개념 확인
- "극점 영점 상쇄 PI 제어기 적분시간 상수 시정수와 같게 설정" 검색 → 극점-영점 상쇄는 PI 제어기의 영점을 플랜트의 극점과 일치시켜, 적분시간을 시스템 시정수와 같게 설정하는 고전 제어 기법(IMC 기반 PID 동조와도 연결)이라는 점 확인

### 3라운드 — 반영 후보 구체화 검증
- 1·2라운드 결과 재검토 → 전류 루프 PI 설계 시 적분시간을 전기적 시정수 $\tau_e$와 같게 설정해 극점을 상쇄하면, 폐루프 전달함수가 1차 저역통과 필터 형태로 단순화된다는 점을 최종 확정. 이는 "모델 없이 실험적으로" 게인을 구하는 지글러-니콜스와 대비되는 "모델을 아는 경우"의 설계 기법이라는 위치를 명확히 함

## Phase 2 — 자체 검토

- 극점-영점 상쇄는 기존 ZN 동조법(모델-프리)과 대비되는 모델-기반 동조법이라는 점에서 "제어기 게인 설정"이라는 세세항목의 범위를 완성하는 자연스러운 확장이며, 이미 다룬 전기적 시정수 개념과 직접 연결되어 신규 반영
- 극점-영점 상쇄의 완전한 전달함수 유도나 저항 온도 보상(적응 게인) 같은 심화 내용까지는 §2 원칙에 따라 넣지 않고, "적분시간 = 전기적 시정수로 설정 → 극점 상쇄 → 1차 필터로 단순화"라는 핵심 아이디어까지만 반영
- 신규 Box 용어보다는 기존 ZN 페이지에 두 번째 동조법으로 나란히 배치하고, "1. 액추에이터 특성 모델링"의 전기적 시정수 내용과 교차 링크

## Phase 3 — 결론

1개 페이지(2. 지글러-니콜스 동조법)에 신규 개념 1건(전류 루프 PI 게인의 극점-영점 상쇄 설계) 반영, 전기적 시정수 페이지와 교차 링크. 신규 Box 용어 없음.
