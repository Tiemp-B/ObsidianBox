# 조사 - 쿨롱·점성마찰모델·대역폭분리규칙 (2026-08-09)

개요(허브) 링크 정상, NCS 자료 대조 aside 없음(이미 클린). 문제은행(세부항목 슬롯 11문항 중 이 세세항목 소관 "서보모터 위치 제어 마찰력 보상 방법 아닌것"·"서보모터 제어방식 설명 올바른것" 2문항) 기존 페이지 커버 확인, PID/PI/Ziegler-Nichols 관련 6문항·마이크로스테핑 2문항·BLDC 1문항은 형제 세세항목("1. 액추에이터 구동원리", "3. 제어기 게인 설정") 소관으로 확인. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "Coulomb friction vs viscous friction model robot servo control difference" 검색 → 쿨롱 마찰(속도와 무관하게 일정한 크기)과 점성 마찰(속도에 비례)이라는 두 기본 마찰 모델 구분 확인 — 기존 페이지는 "마찰 모델 기반 보상"이라고만 하고 정작 그 마찰이 어떤 모델인지가 없음(신규 공백)
- "cascade control loop bandwidth separation rule inner loop faster than outer loop factor" 검색 → 다중 루프(cascade) 제어에서 안쪽 루프는 바깥쪽 루프보다 최소 5~10배 빠른 대역폭을 가져야 한다는 정량적 설계 규칙 확인 — 기존 페이지는 "안쪽 루프일수록 응답이 빠르고 대역폭 넓어야"라고 정성적으로만 서술(신규 공백)

### 2라운드 — 파생 심화 검색
- "쿨롱마찰 점성마찰 모델 서보모터 마찰보상 차이" 검색 → 한국어 자료에서 직접적인 서보모터 맥락 정보는 제한적이었으나 일반 마찰력 종류(건조/유체/윤활 등) 확인, 추가 검색 필요 판단
- "다중 루프 제어 대역폭 분리 규칙 내부루프 외부루프 5배 10배" 검색 → 외부 루프 대역폭이 내부 루프 대역폭의 5배 이하면 두 루프가 서로 간섭해 불안정해질 수 있다는 한국어 기술문서 확인 — 영어 자료의 "5~10배" 규칙과 일치

### 3라운드 — 반영 후보 구체화 검증
- "쿨롱 마찰 점성 마찰 정의 속도 비례 일정한 크기" 검색 → 한국어 자료로 쿨롱 마찰(운동마찰력, 미끄럼 속도의 크기와 무관하게 일정)과 점성 마찰(선형적, 속도에 비례)의 정의를 최종 확정. 서보모터의 "마찰 모델 기반 보상"이 구체적으로 이 두 모델(또는 둘의 합)을 사전에 구해 제어 입력에 더하는 것임을 명확히 할 수 있음을 확인

## Phase 2 — 자체 검토

- 쿨롱·점성 마찰 모델은 기존 "마찰 모델 기반 보상" 서술을 구체화하는 자연스러운 확장이며, 스트라이벡 효과(Stribeck effect) 같은 더 정교한 모델까지는 §2 원칙에 따라 넣지 않고 두 기본 모델의 정의(속도 무관 vs 속도 비례)까지만 반영
- 대역폭 분리 규칙(5~10배)은 기존 "안쪽 루프일수록 빠르고 대역폭 넓어야"라는 정성적 서술에 구체적 수치 기준을 더하는 자연스러운 확장이며, 전달함수 유도나 위상여유 계산까지는 넣지 않고 규칙과 그 이유(간섭·불안정 방지)까지만 반영
- 두 개념 모두 기존 aside를 구체화하는 확장이라 별도 Box 용어보다는 기존 페이지 내 보강으로 처리

## Phase 3 — 결론

1개 페이지(2. 서보 제어의 다중 루프 구조와 마찰력 보상)에 신규 개념 2건(쿨롱·점성 마찰 모델, 다중 루프 대역폭 분리 규칙) 반영. 신규 Box 용어 없음.
