# 조사 - PWM주파수분해능트레이드오프 (2026-08-09)

개요(허브) 링크 정상, NCS 자료 대조 aside 없음(이미 클린). 문제은행(세부항목 슬롯 10문항 중 이 세세항목 소관 "PWM 주파수 선정"·"멀티스레딩 주의사항 아닌것" 2문항) 기존 페이지 커버 확인, 뮤텍스/세마포어·상태머신·동기화 4문항은 1과목·과목2로 이미 교차 링크 처리됨을 재확인. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "PWM frequency vs resolution tradeoff timer clock counter period microcontroller" 검색 → 타이머 클럭이 고정되어 있으면, PWM 주파수를 높일수록 한 주기 안에 들어가는 타이머 틱(카운트) 수가 줄어 듀티비를 표현할 수 있는 단계(해상도)가 줄어든다는 관계 확인 — 기존 페이지는 PWM 주파수를 "소음 vs 스위칭 손실" 트레이드오프로만 다루고, 세 번째 축인 "해상도"가 전혀 없음(신규 공백)
- "PWM duty cycle resolution bits higher frequency lower resolution formula" 검색 → 16MHz 타이머 기준 244Hz에서 16비트, 62.5kHz에서 8비트 해상도가 나온다는 구체적 수치 예시 확인

### 2라운드 — 파생 심화 검색
- "PWM 주파수 분해능 트레이드오프 타이머 카운터 듀티비 미세조정" 검색 → 한국어 자료로 PWM 분해능이 타이머 클럭·카운터 구성에 좌우된다는 점, 최적 분해능을 위해 타이머 주기를 계산한다는 원리 확인
- "PWM 해상도 낮아짐 주파수 높이면 듀티비 단계 감소 모터 제어" 검색 → 모터 제어에서 PWM 주파수 2~20kHz 범위가 스위칭 손실과 토크 매끄러움의 균형점이며, 낮은 주파수는 듀티비 해상도가 높고 높은 주파수는 소음·리플이 준다는 트레이드오프 재확인 — 기존 페이지의 소음/스위칭손실 트레이드오프와 자연스럽게 연결됨

### 3라운드 — 반영 후보 구체화 검증
- "타이머 클럭 고정 PWM 주파수 높이면 카운터 최대값 작아짐 분해능 비트수 감소 예시" 검색 → 공식 "PWM 주파수 = 타이머 클럭 ÷ (카운터 최대값 + 1)"을 확정. 타이머 클럭이 고정일 때 주파수를 높이려면 카운터 최대값을 줄여야 하고, 이는 곧 표현 가능한 듀티비 단계(분해능)의 감소로 직결된다는 인과관계 최종 확정

## Phase 2 — 자체 검토

- PWM 주파수-분해능 트레이드오프는 기존 페이지가 이미 다룬 "소음 vs 스위칭 손실" 트레이드오프에 세 번째 축(제어 정밀도)을 더하는 자연스러운 확장이라 반영
- 특정 마이크로컨트롤러(AVR, STM32 등)의 레지스터 설정법이나 다중 위상 DLL 같은 고분해능 구현 기법까지는 실기·심화 범위라 넣지 않고, "PWM 주파수 = 타이머 클럭 ÷ (카운터 최대값+1)" 공식과 "주파수↑ → 해상도↓"라는 핵심 관계까지만 반영(§2 원칙)
- 신규 Box 용어보다는 기존 PWM aside를 확장하는 수준으로 처리
