# 조사 - 칼만이득·EKF선형화 (2026-08-09)

개요(허브) 링크 정상, NCS 자료 대조 aside 없음(이미 클린). 문제은행(세부항목 슬롯 10문항 중 이 세세항목 소관 "칼만 필터 설명"·"MCL 입자필터 특징"·"Dead Reckoning 문제점" 3문항) 전부 기존 페이지 커버 확인, 나머지 7문항(루프클로징/pose graph/파티클필터SLAM/EKF SLAM한계/토폴로지컬맵/SLAM의미)은 "1. 이동로봇 지도작성"(완료) 또는 "3. 이동로봇 SLAM"(다음 항목) 소관으로 확인. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "Kalman gain formula meaning trust measurement vs prediction" 검색 → 칼만 이득이 크면 측정값을 더 신뢰하고, 작으면 예측값을 더 신뢰한다는 직관적 의미 확인 — 기존 페이지는 "칼만 이득으로 반영해 보정"이라고만 하고 이 값이 무엇을 뜻하는지가 없음(신규 공백)
- "Extended Kalman Filter EKF linearization Jacobian nonlinear system principle" 검색 → EKF는 매 시점 현재 추정치 주변에서 테일러 급수로 비선형 모델을 선형 근사(자코비안 행렬 사용)한다는 원리 확인 — 기존 페이지는 "비선형 시스템에는 EKF·UKF를 사용"이라고만 하고 EKF가 "어떻게" 비선형을 다루는지가 없음(신규 공백)

### 2라운드 — 파생 심화 검색
- "칼만 이득 K 값 크면 측정값 신뢰 작으면 예측값 신뢰" 검색 → 한국어 자료에서도 동일하게 "예측이 불확실할수록 관측을 더 믿고, 관측이 noisy할수록 예측을 더 믿는다"는 자동 가중치 조절 설명 확인
- "확장 칼만 필터 EKF 비선형 시스템 테일러 전개 선형화 자코비안" 검색 → 한국어 자료로 EKF가 현재 추정치 주변에서 다변량 테일러 급수 전개로 선형 근사하고, 공분산 예측에 이 선형화된 자코비안 행렬을 사용한다는 점 확인

### 3라운드 — 반영 후보 구체화 검증
- "EKF SLAM 상태벡터 랜드마크 계산복잡도 한계 vs 일반 EKF 선형화 오차" 검색 → EKF-SLAM의 한계(상태벡터가 랜드마크 수만큼 커져 계산량이 O(N²)로 증가)는 "일반 EKF의 테일러 선형화 원리"와는 별개의, SLAM 특유의 문제임을 확인 — 이번에 반영할 "EKF의 선형화 원리"는 "3. 이동로봇 SLAM"에서 다룰 "EKF SLAM의 한계"와 내용이 겹치지 않음을 재확인

## Phase 2 — 자체 검토

- 칼만 이득의 직관적 의미는 기존 "측정 업데이트" 서술을 완성하는 자연스러운 확장이며, 계산식 유도 없이 "크면 측정 신뢰/작으면 예측 신뢰"라는 개념만 반영(§2 원칙)
- EKF의 선형화 원리는 기존 페이지가 이미 "EKF·UKF" 이름만 언급한 것을 완성하는 자연스러운 확장이며, 자코비안 행렬의 구체적 계산식이나 UKF의 unscented transform까지는 넣지 않고 "왜 필요한가(비선형 모델을 작업점 주변에서 선형 근사)"까지만 반영
- EKF-SLAM의 계산복잡도 문제는 이 세세항목이 아니라 다음 세세항목("3. 이동로봇 SLAM")에서 다룰 내용이라 이번 배치에서는 언급하지 않음(스코프 분리 확인 완료)
