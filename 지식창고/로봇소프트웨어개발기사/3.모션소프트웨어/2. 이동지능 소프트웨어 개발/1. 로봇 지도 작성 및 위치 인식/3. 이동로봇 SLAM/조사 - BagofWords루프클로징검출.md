# 조사 - BagofWords루프클로징검출 (2026-08-09)

개요(허브) 링크 정상, NCS 자료 대조 aside 없음(이미 클린). 문제은행(세부항목 슬롯 10문항 중 이 세세항목 소관 "루프클로징 목적"·"pose graph optimization 목적"·"파티클필터 기반 SLAM 특징"·"EKF SLAM 한계"·"SLAM 의미" 5문항) 전부 기존 페이지 커버 확인. "2. SLAM의 구성 요소와 루프 종료" 페이지의 "지역적 로봇 위치 계산 오차의 종류" aside가 "2. 이동로봇 위치인식/2. 추측항법과 상대·절대 위치인식"의 "오차의 두 종류" aside와 거의 동일하게 중복됨을 발견 — 직접 재작업 중이므로 교차 링크로 정리. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "loop closure detection method SLAM bag of words image similarity how robot recognizes revisited place" 검색 → 루프 클로징은 카메라 영상 특징을 시각 단어(visual word)의 히스토그램으로 표현하고, 두 이미지의 히스토그램 유사도를 비교해 로봇이 이전에 지나간 장소인지 판단하는 Bag of Words(BoW) 방식이 대표적임을 확인 — 기존 페이지는 루프 클로징의 "목적"만 있고 "어떻게 이전 장소를 인식하는지"가 없음(신규 공백)
- "SLAM front-end back-end difference scan matching odometry loop closure role" 검색 → SLAM 파이프라인에서 프론트엔드(센서 데이터로 상대 이동 추정, 그래프 초기값 제공)와 백엔드(그래프 최적화)의 역할 분담 확인 — 기존 페이지는 GraphSLAM 부분에서 front-end/back-end를 이미 다루고 있어 중복 방지를 위해 이 배치에서는 반영하지 않음

### 2라운드 — 파생 심화 검색
- "루프 클로징 검출 방법 Bag of Words 시각 단어 이미지 유사도 SLAM" 검색 → 한국어 자료로 BoW 방식이 학습 이미지에서 추출한 특징을 클러스터링해 시각 단어 어휘집을 만들고, 각 이미지를 시각 단어의 히스토그램(Bag of Word vector)으로 표현해 이미지 간 유사도(거리)를 비교한다는 구조 확인
- "SLAM 프론트엔드 백엔드 차이 스캔매칭 그래프최적화" 검색 → front-end/back-end 역할 분담을 재확인했으나 기존 페이지 내용과 중복되어 반영 대상에서 제외 확정

### 3라운드 — 반영 후보 구체화 검증
- "DBoW ORB-SLAM 루프클로징 검출 시각단어 히스토그램 유사도 임계값" 검색 → 대표적인 비전 기반 SLAM인 ORB-SLAM이 DBoW2 라이브러리로 각 키프레임을 BoW 벡터로 변환하고, 현재 키프레임과 유사도가 높은(임계값 이상인) 과거 키프레임을 루프 클로징 후보로 찾는다는 구체적 사례 확인 — 이미 페이지에 있는 "비전 기반 SLAM"의 PTAM 예시와 자연스럽게 이어지는 구체적 사례

## Phase 2 — 자체 검토

- Bag of Words 기반 루프 클로징 검출은 기존 "루프 클로징의 목적" aside(왜 필요한지)를 완성하는 "어떻게 검출하는지"의 자연스러운 확장이라 반영
- DBoW2의 구체적 구현(계층적 시각 단어 트리, TF-IDF 가중치 등)이나 front-end/back-end 역할 재설명까지는 §2 원칙(과다 반영 방지)에 따라 넣지 않고, "시각 단어 히스토그램 유사도 비교"라는 핵심 원리와 ORB-SLAM 사례까지만 반영
- 중복 발견된 "지역적 로봇 위치 계산 오차의 종류" aside는 새 내용 반영이 아니라 기존 중복을 정리하는 것으로, 신규 반영 항목과는 별개로 처리(이미 다룬 내용과의 관계를 명시하는 교차 링크로 축소)
