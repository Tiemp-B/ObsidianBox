# 조사 - 쿼드트리기반점유격자지도 (2026-08-08)

개요 페이지에 "NCS 자료 대조" aside가 있어 이번 재작업에서 직접 재편집하며 삭제(2026-08-08 규칙). 문제은행(세부항목 슬롯 10문항 중 이 세세항목 소관 "로그 오즈 방식 장점 아닌 것"·"토폴로지컬 맵 특징 아닌 것" 2문항) 기존 페이지 커버 확인, 나머지 8문항(SLAM/칼만필터/MCL/파티클필터/DeadReckoning/EKF SLAM)은 형제 세세항목("2. 이동로봇 위치인식", "3. 이동로봇 SLAM") 소관으로 확인. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "quadtree occupancy grid map memory efficiency adaptive resolution robotics" 검색 → 쿼드트리 기반 점유격자지도는 균일한 영역(완전히 빈 공간이나 완전히 점유된 영역)은 큰 셀로 남겨두고, 경계처럼 정보가 섞인 영역만 재귀적으로 세분화해 저장량을 크게 줄일 수 있음을 확인 — 기존 페이지는 점유격자지도의 단점(공간이 넓어질수록 저장량 증가)만 서술하고 그 해결책이 없음(신규 공백)
- "occupancy grid map resolution tradeoff storage accuracy robot mapping" 검색 → 해상도가 높을수록 정확하지만 저장량·계산량이 커지고, 낮을수록 그 반대라는 트레이드오프 확인, 이를 절충하는 다중 해상도(multi-resolution) 접근법의 대표 사례가 쿼드트리임을 재확인

### 2라운드 — 파생 심화 검색
- "쿼드트리 점유격자지도 저장량 해상도 적응적 세분화" 검색 → 한국어 자료로 쿼드트리가 픽셀(셀) 단위로 전부 저장하는 대신, 영역이 완전히 0 또는 1이 아닐 때만(즉 경계일 때만) 세분화하는 적응적 방식임을 확인 — 과목3 "이동로봇 전역 경로계획"에서 이미 다룬 쿼드트리(셀 분해 방식)와 동일 개념임을 확인, 중복 없이 교차 링크 가능
- "점유격자지도 해상도 트레이드오프 정확도 저장공간 로봇" 검색 → 한국어 자료에서 직접적인 세부 확인은 제한적이었으나, 지도 해상도 정보가 로봇 지도 표준에 포함된다는 점에서 해상도가 실무적으로 중요한 파라미터임을 재확인

### 3라운드 — 반영 후보 구체화 검증
- 1·2라운드 결과 재검토 → 쿼드트리 기반 점유격자지도가 균일 영역은 큰 셀로 병합하고 경계만 세분화해 저장량 문제를 완화한다는 내용을 최종 확정. 과목3 "전역 경로계획의 세 가지 방식"에서 이미 다룬 쿼드트리(셀 분해)를 재설명하지 않고 교차 링크로 연결

## Phase 2 — 자체 검토

- 쿼드트리 기반 점유격자지도는 기존 페이지가 명시한 점유격자지도의 단점(저장량 증가)을 정확히 해결하는 후속 내용이라 자연스러운 확장으로 반영
- 옥트리(Octree, 3차원 확장)나 확률적 쿼드트리의 통계적 분할 기준 수식까지는 심화 범위라 넣지 않고, "왜 저장량이 줄어드는가"(균일 영역은 병합, 경계만 세분화)까지만 반영(§2 원칙)
- 과목3 "이동로봇 전역 경로계획"에서 이미 다룬 쿼드트리(셀 분해 방식)와 동일 개념이므로 재설명 대신 교차 링크로 처리(중복 방지)
- 개요 페이지의 NCS 자료 대조 aside는 이번 직접 재작업 과정에서 삭제

## Phase 3 — 결론

1개 페이지(2. 점유격자지도와 특징지도)에 신규 개념 1건(쿼드트리 기반 점유격자지도) 반영. 개요 페이지의 NCS 자료 대조 aside 삭제. 신규 Box 용어 없음, 기존 "전역 경로계획의 세 가지 방식" 페이지와 교차 링크.
