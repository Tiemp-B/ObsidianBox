# Summary

로봇 제어기가 [[4. 제어 응답 특성 지표 전반|피드백 제어]]를 하려면 실제 위치를 측정하는 센서가 반드시 필요하다. 서보 제어에서 위치 피드백의 표준 센서는 **[[엔코더(Encoder)|엔코더]]**이며, 센서에서 들어오는 신호에는 노이즈가 섞여 있으므로 이를 걸러내기 위한 신호처리(필터링)가 함께 사용된다. 대표적인 방법이 **[[이동평균 필터(Moving Average Filter)|이동평균 필터]]**다.

# Notes

<aside>서보 위치 피드백 센서 — 엔코더</aside>

서보 제어 시스템에서 관절(모터축)의 위치·속도 피드백을 위해 가장 널리 쓰이는 센서는 **엔코더(Encoder)**다. 모터의 회전 각도와 속도를 정밀하게 측정할 수 있어, 로봇 관절의 정확한 위치 제어를 위한 피드백 신호를 제공한다.

- **증분형(Incremental) 엔코더**: 회전량(펄스 수)만 측정하며, 전원이 꺼지면 절대 위치 정보를 잃는다. 전원을 켤 때 원점 복귀(호밍) 동작이 필요하다.
- **절대형(Absolute) 엔코더**: 축의 절대 각도 값을 직접 출력하므로, 전원이 꺼졌다 켜져도 원점 복귀 없이 현재 위치를 바로 알 수 있다.

가속도 센서나 자이로스코프도 로봇에 사용되지만, **서보 모터의 위치 피드백** 용도로 가장 대표적이고 직접적인 센서는 엔코더라는 점이 핵심이다.

<aside>센서 노이즈와 이동평균 필터</aside>

엔코더 등에서 들어오는 원신호(raw signal)에는 전기적 노이즈, 진동 등에 의한 잡음이 섞여 있어 그대로 사용하면 제어 성능이 떨어진다. 이를 완화하는 가장 단순한 방법이 **이동평균 필터(Moving Average Filter)**다.

- 동작 원리: 과거 N개의 데이터를 평균 내어 현재 값을 계산한다.
- 장점: 구현이 매우 간단하고, 무작위 노이즈를 효과적으로 완화한다.
- **단점 — 지연시간(Lag) 발생**: 과거 값들을 평균하는 방식이므로, 실제 신호가 급격히 변해도 필터를 통과한 값은 뒤늦게 반응한다. 즉 노이즈 제거와 응답 지연은 트레이드오프 관계이며, 평균에 사용하는 데이터 개수(윈도우 크기)가 클수록 노이즈 제거 효과는 커지지만 지연시간도 함께 커진다.

이 지연 특성 때문에, 실시간 서보 제어 루프처럼 빠른 응답이 중요한 구간에는 이동평균 필터 대신 [[저역통과 필터(Low-pass Filter)|저역통과 필터]]나 [[칼만 필터(Kalman Filter)|칼만 필터]]처럼 지연을 더 정교하게 관리할 수 있는 방법이 함께 고려되기도 한다. (칼만 필터의 본격적인 원리와 활용은 위치추정·SLAM을 다루는 다른 과목 페이지에서 별도로 정리한다.)

---

<aside>핵심 정리</aside>

- 서보 위치 피드백의 대표 센서 = **엔코더** (증분형 vs 절대형)
- 이동평균 필터 = 과거 N개 데이터 평균 → 노이즈 완화는 되지만 **지연시간(Lag)이 발생**
- 윈도우 크기 ↑ → 노이즈 제거 효과 ↑, 그러나 지연시간도 함께 ↑ (트레이드오프)
