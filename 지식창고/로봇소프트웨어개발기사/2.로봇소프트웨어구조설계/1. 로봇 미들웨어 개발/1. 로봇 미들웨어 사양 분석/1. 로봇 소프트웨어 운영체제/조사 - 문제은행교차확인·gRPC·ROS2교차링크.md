## Phase 1 — 이 세세항목 고유 주제에 대한 신규 조사

### gRPC — RPC 미들웨어의 현대적 구현체 (신규)
- 기존 페이지2의 "원격 프로시저 호출(RPC)" 항목은 개념만 설명하고 실제 구현체를 언급하지 않았음
- **gRPC**: Google이 개발한 오픈소스 RPC 프레임워크로, HTTP/2 위에서 동작하고 **Protocol Buffers(protobuf)** 로 메시지를 이진 직렬화해 REST/JSON보다 빠르고 가벼움. 여러 언어로 클라이언트·서버 코드를 자동 생성할 수 있어 마이크로서비스·분산 로봇 시스템에서 널리 쓰임
- 로봇 분야에서는 여러 대의 로봇·백엔드 서비스·모바일 앱을 연결하는 원격 호출에 활용되는 사례가 있음
- 출처: [What is gRPC? - Kong](https://konghq.com/blog/learning-center/what-is-grpc), [gRPC official](https://grpc.io/)

### ROS2 — 페이지3(로봇 운영체제의 종류)에 대한 최신화 교차 링크 (신규, 경량)
- 기존 페이지3은 ROS(1)만 다루고 ROS2를 언급하지 않음. ROS2는 이미 형제 세세항목(`2. 로봇 구성요소간 통신프로토콜 / 3. ROS2와 DDS QoS`)에서 마스터 없는 DDS 기반 구조·QoS 정책까지 상세히 다루고 있으므로, 중복 작성 대신 짧은 교차 언급 + 링크만 추가

## Phase 2 — 자체 검토

- gRPC는 NCS 원문에 없는 최신 개념이지만, 기존 6종 미들웨어(RPC 항목)의 "실제 구현 사례"로 자연스럽게 연결되므로 반영. 세부 프로토콜 스펙은 넣지 않고 개념·특징만 반영
- 문제은행 교차 확인 결과는 페이지 본문이 아니라 개요 페이지의 "관련 노트" 성격 aside로만 반영(§ 컨벤션에 따름 — 실제 콘텐츠는 원 세세항목에 있으므로 여기서 재작성하지 않음)

## Phase 3 — 결론

문제은행 11문항 중 10건이 이미 다른 세세항목에서 커버됨을 확인 → 개요 페이지에 교차 링크 aside 추가. 페이지2에 gRPC 신규 반영. 페이지3에 ROS2 교차 링크 추가(경량).
