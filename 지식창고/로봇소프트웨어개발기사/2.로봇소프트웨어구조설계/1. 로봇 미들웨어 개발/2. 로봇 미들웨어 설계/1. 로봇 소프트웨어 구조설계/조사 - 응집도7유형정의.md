# 조사 - 응집도7유형정의 (2026-08-07)

NCS 대응 모듈 있음(LM1903080304 학습2 "로봇 미들웨어 설계하기"). 이 세세항목 전용 문제은행 슬롯은 확인되지 않음(§1-2, 정보처리 일반 소프트웨어공학 지식). 개요(허브) 링크 정상.

## Phase 1 — 조사 및 내부 비대칭 발견

기존 페이지4("모듈 응집도와 프로그램 구조")는 결합도 페이지(5개 유형 전부 정의됨)와 비대칭적으로, 응집도 7유형을 **이름만 나열**하고 정의는 하나도 적지 않았음("기능적·순차적·교환적·절차적·시간적·논리적·우연적 응집도가 있으며..."). 표준 소프트웨어공학 정의를 조사해 결합도 페이지와 동일한 수준(정의 표)으로 보강한다.

### 응집도 7유형 정의 (강함→약함 순)
| 유형 | 정의 |
|---|---|
| 기능적(Functional) | 모듈 안의 모든 요소가 **단 하나의 명확한 기능** 수행에 집중 — 가장 강한(바람직한) 응집도 |
| 순차적(Sequential) | 한 요소의 **출력이 다음 요소의 입력**이 되어 파이프라인처럼 연결됨 |
| 교환적/통신적(Communicational) | 서로 다른 기능을 하지만 **같은 입력·출력 데이터**를 함께 다룸 |
| 절차적(Procedural) | 특정 **순서대로 실행되어야** 하는 처리 절차들을 모아 놓음(기능적 연관은 약함) |
| 시간적(Temporal) | **같은 시점**(예: 초기화, 종료)에 실행되어야 한다는 이유만으로 묶임 |
| 논리적(Logical) | 유사한 범주로 **분류**만 되고, 실제로는 제어 플래그로 어떤 기능을 실행할지 분기함 |
| 우연적(Coincidental) | 요소들 사이에 **의미 있는 관련이 전혀 없이** 우연히 한 모듈에 모임 — 가장 약한(나쁜) 응집도 |

## Phase 2 — 자체 검토

- 순서(강함→약함)는 기존 페이지의 나열 순서와 정확히 일치함을 확인(기능적·순차적·교환적·절차적·시간적·논리적·우연적) — 새로 조사한 정의가 기존 서술과 모순되지 않음
- 결합도 페이지와 형식을 통일해(정의 표) 두 페이지 간 비대칭을 해소
