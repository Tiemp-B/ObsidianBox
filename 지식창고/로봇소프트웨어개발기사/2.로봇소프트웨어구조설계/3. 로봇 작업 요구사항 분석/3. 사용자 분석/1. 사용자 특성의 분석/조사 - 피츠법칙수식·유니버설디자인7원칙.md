# 조사 - 피츠법칙수식·유니버설디자인7원칙 (2026-08-07)

개요(허브) 링크 정상. 문제은행 4문항(피츠법칙/밀러법칙/힉법칙/사용자특성고려요소) 전부 기존 페이지 커버 확인.

## Phase 1 — 조사

### 피츠의 법칙 수식 — ID·MT 공식 (신규)
- 기존 페이지3은 피츠의 법칙을 "거리 비례, 크기 반비례"라는 정성적 서술로만 다루고, 실제 정량 공식은 다루지 않았음
- **이동 시간(MT) = a + b·ID**, **난이도 지수(ID) = log₂(2A/W)** — A는 목표까지의 거리(이동량), W는 목표의 폭(크기), a·b는 실험적으로 정해지는 상수
- 거리(A)가 클수록, 폭(W)이 작을수록 ID(난이도)가 커지고 그만큼 이동 시간(MT)도 길어진다는 것을 수식으로 확인 가능 — 기존 페이지의 정성적 설명을 정량적으로 뒷받침
- 출처: [Fitts's Law and Its Applications in UX - NN/G](https://www.nngroup.com/articles/fitts-law/), [Movement Time Prediction - York](https://www.yorku.ca/mack/GI92.html)

### 유니버설 디자인(Universal Design) 7원칙 — 다양한 사용자를 위한 설계 프레임워크 (신규)
- 기존 페이지2는 사용자 그룹별(목적/연령/전문성) UI 차별화 원칙을 개별 사례로만 나열하는데, 이를 아우르는 공식화된 설계 프레임워크인 **유니버설 디자인 7원칙**(Ron Mace, 1997)이 빠져 있었음
- 7원칙: ① 공평한 사용(Equitable Use), ② 사용의 유연성(Flexibility in Use), ③ 간단하고 직관적인 사용(Simple and Intuitive Use), ④ 인지 가능한 정보(Perceptible Information), ⑤ 오류에 대한 관용(Tolerance for Error), ⑥ 적은 신체적 노력(Low Physical Effort), ⑦ 접근과 사용을 위한 크기와 공간(Size and Space for Approach and Use)
- 특정 사용자 그룹(고령자·비전문가 등)만을 위한 별도 설계가 아니라, 가능한 한 **모든 사용자가 공통으로 쓸 수 있게** 설계한다는 점에서, 기존 페이지의 "그룹별 UI 차별화" 접근과는 상호 보완적인 다른 설계 철학
- 출처: [7 Principles of Universal Design - CEUD](https://universaldesign.ie/about-universal-design/the-7-principles), [Universal Design Principles - RL Mace Universal Design Institute](https://www.udinstitute.org/principles)

## Phase 2 — 자체 검토

- 피츠 법칙 수식의 로그 밑(log₂)과 단위(bit)는 계산 문제로 이어질 수 있어 조사md에는 남기되, 페이지 본문에는 공식과 "거리↑·폭↓ → ID↑·MT↑"라는 관계만 명확히 반영
- 유니버설 디자인 7원칙은 이름과 핵심 개념만 반영하고, 각 원칙의 세부 하위 지침까지는 넣지 않음(과다 반영 방지)

## Phase 3 — 결론

2개 페이지(2. 사용자 그룹 분류와 고려 요소 — 유니버설 디자인 1건, 3. UI 설계 법칙 — 피츠 법칙 수식 1건)에 신규 개념 반영. Box 용어는 `유니버설 디자인(Universal Design)` 신규 생성, `피츠의 법칙(Fitts' Law)`은 수식 보강.
