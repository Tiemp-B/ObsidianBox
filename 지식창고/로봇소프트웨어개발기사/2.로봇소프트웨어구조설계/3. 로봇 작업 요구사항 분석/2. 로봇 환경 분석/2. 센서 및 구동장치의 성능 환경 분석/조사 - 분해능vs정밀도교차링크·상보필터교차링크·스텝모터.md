# 조사 - 분해능vs정밀도교차링크·상보필터교차링크·스텝모터 (2026-08-07)

개요(허브) 링크 정상. 문제은행 3문항(IMU드리프트보정/서보모터특징/센서분해능) 전부 기존 페이지 커버 확인.

## Phase 1 — 조사 및 내부 교차 확인

### 분해능(Resolution) vs 위치 정밀도(Accuracy)·반복 정밀도(Repeatability) — 이미 다른 곳에서 다룬 인접 개념 (교차 링크)
- 기존 페이지2는 분해능만 다루는데, 로봇 성능 지표에서 자주 헷갈리는 인접 개념인 **위치 정밀도(Accuracy)**·**반복 정밀도(Repeatability)**가 이 vault의 다른 세세항목("2. ISO 9283 로봇 성능 지표(정밀도·반복성)")에 이미 상세히 다뤄져 있음을 확인
- 세 개념의 차이: 분해능(구분 가능한 최소 변화량) / 정확도(측정값이 참값에 얼마나 가까운가) / 정밀도·반복성(반복 측정값들이 서로 얼마나 일관되는가) — 서로 독립적인 지표
- 중복 작성하지 않고 교차 링크로 안내

### 상보 필터(Complementary Filter) — IMU 드리프트 보정의 경량 대안 (교차 링크)
- 기존 페이지2는 IMU 드리프트 보정 방법으로 GPS/비전/칼만 필터를 언급하는데, 이 vault의 다른 세세항목(IoT디바이스 연동)에서 이미 다룬 **상보 필터**가 칼만 필터보다 계산량이 적은 대안으로 자연스럽게 연결됨
- 중복 작성하지 않고 교차 링크만 추가

## Phase 2 — 신규 조사

### 스텝모터 vs 서보모터 — 개루프 vs 폐루프 구동 방식의 대비 (신규)
- 기존 페이지3은 서보모터의 폐루프 피드백 특징만 다루는데, 이와 대비되는 **스텝모터(개루프)** 가 빠져 있었음
- **스텝모터**: 펄스 신호 하나당 정해진 각도(예: 1.8˚)만큼 회전 — 피드백(엔코더) 없이 "펄스를 보냈으니 그만큼 돌았을 것"이라고 가정하는 **개루프(open-loop)** 제어. 부하가 보유 토크를 넘으면 **탈조(step skip)** 가 발생해도 이를 감지하지 못하고 그대로 진행
- **서보모터**: 엔코더로 실제 위치를 계속 확인·보정하는 **폐루프(closed-loop)** 제어 — 스텝모터보다 더 큰 토크·속도를 낼 수 있지만 구조가 복잡하고 비쌈
- 로봇 관절처럼 정밀도·부하 보정이 중요한 곳은 서보모터가, 비용이 중요하고 부하가 예측 가능한 곳(3D프린터 등)은 스텝모터가 적합
- 출처: [The Choice Between Servo Motors and Stepper Motors](https://blog.orientalmotor.com/the-choice-between-servo-motors-and-stepper-motors), [Servo Motors vs. Stepper Motors](https://www.omc-stepperonline.com/support/servo-motors-vs-stepper-motors)
