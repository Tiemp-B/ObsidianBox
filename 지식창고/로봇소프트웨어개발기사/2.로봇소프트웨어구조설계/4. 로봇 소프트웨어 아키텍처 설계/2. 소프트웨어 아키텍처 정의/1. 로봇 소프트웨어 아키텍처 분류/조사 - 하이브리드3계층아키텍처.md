# 조사 - 하이브리드3계층아키텍처 (2026-08-07)

개요(허브) 링크 정상. 문제은행 7문항(계층형×4/Subsumption/마이크로서비스/Deliberative) 전부 기존 페이지 커버 확인.

## Phase 1 — 조사

### 하이브리드(3계층) 아키텍처 — Deliberative와 Subsumption 사이의 절충안 (신규)
- 기존 페이지2는 Deliberative(숙고형, 느리지만 정교한 계획)와 Subsumption(반응형, 빠르지만 중앙 계획 없음)을 순수하게 대비되는 두 극단으로만 제시하는데, 로봇공학에서 널리 쓰이는 **하이브리드(3계층) 아키텍처**가 둘 사이의 절충안으로 자리 잡고 있음
- **하이브리드(3계층) 아키텍처**: 세 계층으로 구성됨
  - **반응 계층(Reactive Layer)**: 센서 입력에 즉각 반응하는 저수준 실시간 제어(Subsumption과 유사)
  - **실행 계층(Executive/Sequencing Layer)**: 반응 계층과 숙고 계층을 조정하며 작업 순서를 관리
  - **숙고 계층(Deliberative Layer)**: 환경 모델을 바탕으로 한 고수준 계획·추론
- 순수 Subsumption(계획 능력 부족)과 순수 Deliberative(실시간 반응 부족)의 단점을 서로 보완 — 반응 계층이 즉각적 위험에 대응하는 동안, 숙고 계층은 장기 계획을 수립
- 출처: [Three-layer architecture - Wikipedia](https://en.wikipedia.org/wiki/Three-layer_architecture), [Hybrid control - Fiveable](https://fiveable.me/introduction-autonomous-robots/unit-4/hybrid-control/study-guide/9iJrqU5Hk2cQcaMY)

## Phase 2 — 자체 검토

- ATLANTIS 같은 구체적 하이브리드 아키텍처 구현 사례명은 참고 수준으로만 조사md에 남기고, 페이지 본문에는 "3계층 구조와 각 계층의 역할"이라는 핵심 개념만 반영
- 기존 페이지의 "Subsumption vs Deliberative는 반대되는 철학" 서술과 모순되지 않도록, 하이브리드는 "그 둘을 조합한 절충안"이라는 위치로 명확히 서술

## Phase 3 — 결론

1개 페이지(2. 로봇 소프트웨어 아키텍처 스타일 비교)에 신규 개념 1건(하이브리드 3계층 아키텍처) 반영. Box 용어는 `하이브리드(3계층) 아키텍처(Hybrid·Three-Layer Architecture)` 신규 생성.
