# 조사 - 툴체인저 (2026-08-10)

개요(허브) 링크 정상, NCS 자료 대조 aside 없음(이미 클린). 이 세세항목 소관 문제은행 슬롯("2. 작업 수행 지능 설계" 18문항) 중 하드웨어 인터페이스 관련 문항은 없으나, 슬롯 내 나머지 문항(모듈화·API·성능측정지표·설정관리·문서화 등)이 이미 과목1·2에서 커버되었음을 재확인(모듈화→과목2 미들웨어프로세스관리, API→과목2 Box 용어, 통신프로토콜→1과목 통신프로토콜심화·과목4 후속 세세항목, 티칭 관련→1과목 로봇교시프로그래밍). 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "robot tool changer automatic quick change coupler end effector interface" 검색 → 툴체인저는 로봇 팔과 엔드이펙터(그리퍼·용접건 등) 사이에 장착해 도구를 빠르게 자동 교체할 수 있게 하는 기계적 인터페이스라는 정의 확인 — 기존 페이지는 "모션 티칭/생성", "센서", "상태 출력"만 다루고, 로봇의 대표적 주변장치 인터페이스인 엔드이펙터 교체 장치가 전혀 없음(신규 공백)
- "robot tool changer master plate tool plate pneumatic electrical signal pass-through" 검색 → 툴체인저는 로봇쪽 마스터 플레이트(master plate)와 공구쪽 툴 플레이트(tool plate)로 구성되며, 공압·전기신호가 이 두 플레이트를 그대로 통과(pass-through)해 도구를 교체해도 배선을 다시 연결할 필요가 없다는 구조 확인

### 2라운드 — 파생 심화 검색
- "로봇 툴체인저 자동 공구교환장치 마스터플레이트 툴플레이트 공압 전기신호" 검색 → 한국어 자료로 동일 구조(마스터/툴 플레이트) 확인, 공압으로 마스터 피스톤을 작동시켜 결속 상태를 유지하는 방식, 협동로봇(코봇)용 툴체인저도 활용된다는 점 확인
- "로봇 엔드이펙터 자동교환 그리퍼 여러 작업 하나의 로봇 활용" 검색 → 하나의 로봇이 여러 공정(멀티 공정)을 수행하려면 다양한 엔드이펙터가 필요하며, 자동 교환 시스템이 이를 지원해 로봇 활용도를 높인다는 실무적 의의 확인

### 3라운드 — 반영 후보 구체화 검증
- "로봇 자동툴체인저 장점 셋업시간 단축 다기능 하나의 로봇" 검색 → 툴체인저의 핵심 장점이 도구 교체 시간(셋업 시간) 단축과 하나의 로봇으로 다양한 작업을 수행할 수 있게 하는 다기능성임을 재확인. 마스터 플레이트는 로봇쪽, 툴 플레이트는 공구쪽에 장착되는 구성이라는 점을 명확히 구분해 확인

## Phase 2 — 자체 검토

- 툴체인저는 기존 페이지가 이미 다룬 센서(입력)·모션 티칭(제어 입력)·상태 출력에 이어, 로봇의 대표적인 네 번째 주변장치 인터페이스 유형이라 자연스럽게 반영
- 구체적 잠금 메커니즘(자석식·공압식 등 세부 구조)이나 제조사별 규격까지는 심화 범위라 넣지 않고, 마스터/툴 플레이트 구조·공압전기 pass-through·활용 목적(셋업시간 단축, 다기능화)까지만 반영(§2 원칙)
- 범용 개념이라 Box 용어로 생성

## Phase 3 — 결론

1개 페이지(2. 로봇과 주변장치 인터페이스의 구성)에 신규 개념 1건(툴체인저) 반영. 신규 Box 용어 `툴체인저(Tool Changer)` 생성.
