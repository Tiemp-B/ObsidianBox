# 조사 - 퍼지추론·의미망·STRIPS (2026-08-10)

개요(허브) 링크 정상, NCS 자료 대조 aside 없음(이미 클린). 문제은행(세부항목 슬롯 18문항) 확인 결과, 이 세세항목("작업지능 소프트웨어 설계") 소관으로 판단되는 문항 중 "퍼지 추론 시스템의 구성요소가 아닌 것"·"의미망(Semantic Network) 설명 틀린것"·"STRIPS 알고리즘의 구성 요소가 아닌 것" 3문항이, 지식 표현·계획이라는 고전 AI 기법임에도 vault 전체에 전혀 반영되어 있지 않음을 발견 — **문제은행 공백**으로 판단해 최우선 보강. "A* 평가함수/휴리스틱"은 과목3에서 이미 상세히 다룬 개념으로 교차 링크, "Q-learning"은 개요가 이미 1과목으로 교차 링크 처리, 나머지 다수(애자일/CI/단위테스트/로깅/모듈화/프로파일링 등)는 과목1·2에서 이미 커버되었거나 형제 세세항목("2. 주변장치 인터페이스 분석") 또는 다른 배치에서 순차 확인 예정. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "fuzzy inference system components fuzzification rule base inference engine defuzzification" 검색 → 퍼지 추론 시스템은 퍼지화(fuzzification)·규칙베이스(rule base)·추론엔진(inference engine)·비퍼지화(defuzzification) 4단계로 구성된다는 표준 구조 확인
- "semantic network knowledge representation nodes edges AI definition example" 검색 → 의미망은 개념·객체를 노드(node)로, 관계를 링크(edge)로 표현하는 지식 표현 기법이며, "개→동물" 같은 계층·상속 관계 표현에 흔히 쓰인다는 점 확인
- "STRIPS planning algorithm components preconditions effects goal state robot" 검색 → STRIPS는 각 행동을 전제조건(precondition)·추가목록(add list)·삭제목록(delete list)으로 정의해 초기상태에서 목표상태로의 행동열을 자동 생성하는 고전 AI 계획 기법 확인

### 2라운드 — 파생 심화 검색
- "퍼지 추론 시스템 구성요소 퍼지화 규칙베이스 추론엔진 비퍼지화" 검색 → 한국어 자료로 동일한 4단계 구조(퍼지화기/규칙베이스/추론엔진/비퍼지화기) 확인, 비퍼지화 방법으로 무게중심법 등이 쓰인다는 점 확인
- "의미망 지식표현 노드 링크 인공지능 예시" 검색 → 한국어 자료로 노드-링크 구조, 계층관계에 따른 속성 상속, 지식베이스가 커지면 복잡해진다는 단점까지 확인
- "STRIPS 알고리즘 로봇 작업계획 전제조건 효과 구성요소" 검색 → 한국어 자료로 전제조건·추가목록·삭제목록 3요소 재확인, STRIPS가 1971년 SRI의 로봇 Shakey를 위해 개발된 최초의 실용 AI 계획 시스템이라는 역사적 배경 확인

### 3라운드 — 반영 후보 구체화 검증
- "Shakey the robot STRIPS 최초 적용 사례 로봇 계획" 검색 → Shakey는 방·복도·문·스위치로 이루어진 제한된 세계에서 "이동/문 열기·닫기/스위치 조작/물체 밀기" 같은 행동을 STRIPS로 계획해 "발판 위 블록을 밀어라" 같은 목표를 달성한 최초의 추론 기반 로봇이라는 구체적 사례 확인 — 로봇 작업지능 설계 맥락에 직접 부합하는 예시로 확정
- "퍼지 추론 로봇 응용 예시 장애물회피 온도제어" 검색 → 이동로봇과 장애물 사이의 거리 정보를 퍼지 규칙으로 추론해 회피 동작을 결정하는 응용 사례 확정 — 로봇 작업지능의 구체적 활용 예시로 반영

## Phase 2 — 자체 검토

- 세 기법 모두 "작업지능 소프트웨어 설계"가 다루는 지식 표현·추론·계획이라는 핵심 주제에 정확히 부합하며, 문제은행에 명시적으로 출제되는 내용이라 최우선 반영
- 퍼지 논리의 소속함수(membership function) 수학적 정의, 의미망의 상속 추론 알고리즘, STRIPS의 탐색 알고리즘(전방/후방 탐색) 구체 구현까지는 심화 범위라 넣지 않고, 각 기법의 구성요소·정의·로봇 응용 예시까지만 반영(§2 원칙)
- 세 기법 모두 독립적인 범용 AI 개념이라 각각 Box 용어로 생성
