# 조사 - 위치정밀도저하요인·경로속도특성 (2026-08-10)

개요(허브) 링크 정상, NCS 자료 대조 aside 없음(이미 클린). 문제은행(세부항목 슬롯 11문항 중 이 세세항목 소관 "반복정밀도 측정방법"·"동적성능 평가지표 아닌것"·"반복정밀도 설명 올바른것"·"위치정밀도 저하요인 아닌것" 4문항) 확인 결과 "반복정밀도 측정방법"·"반복정밀도 설명"은 기존 페이지가 정확히 커버, "위치정밀도 저하요인"은 vault 전체에 전혀 없는 신규 공백, "동적성능 평가지표"는 기존 표(오버슈트·안정화시간·경로정밀도)가 일부 커버하나 ISO 9283이 실제로 규정하는 항목(경로속도특성·위빙편차)이 빠져 있음을 확인 — 둘 다 최우선 보강. 3라운드 웹검색 반복 적용.

## Phase 1 — 3라운드 반복 검색

### 1라운드 — 후보 개념 탐색
- "robot positioning accuracy degradation factors calibration backlash thermal drift kinematic error" 검색 → 위치 정밀도를 저하시키는 요인은 크게 기구학적 오차(제조·조립 공차, 전체 오차의 약 90% 차지)와 비기구학적 오차(온도 변화로 인한 열팽창, 기어 백래시, 관절·링크의 컴플라이언스)로 나뉜다는 점 확인 — 기존 페이지는 위치정밀도의 "정의"만 있고 "무엇이 이를 저하시키는지"가 전혀 없음(신규 공백)
- "ISO 9283 dynamic performance indicators velocity accuracy path velocity robot" 검색 → ISO 9283이 실제로 규정하는 성능 항목에는 기존 페이지의 5개 항목 외에도 **경로속도특성(path velocity characteristics, 정격 경로속도의 100%·50%·10%에서 시험)**과 **위빙편차(weaving deviation)**가 포함된다는 점 확인 — 기존 표에 이 항목들이 빠져 있음(신규 공백)

### 2라운드 — 파생 심화 검색
- "로봇 위치정밀도 저하 요인 기구학적 오차 열팽창 백래시 기어" 검색 → 한국어 자료로 기어 백래시(간극)가 위치 오차 누적→피드백 보정 증가→운동 안정성 저하로 이어지는 과정, 가공 오차·열팽창이 백래시 설계와 얽혀 있다는 점 확인
- "ISO 9283 경로속도특성 위빙편차 동적성능 로봇" 검색 → 한국어 자료에서 세부 수치까지는 확인하지 못했으나, ISO 9283이 "성능 항목 및 시험방법"을 규정하는 국제표준이라는 점과 KS로도 채택되어 있음을 재확인

### 3라운드 — 반영 후보 구체화 검증
- "robot accuracy degradation NOT caused by repeatability high does not guarantee accuracy exam distractor" 검색 → 위치 정밀도 저하의 대표 원인으로 **링크 길이 오차·관절 영점 오차**(제조 공차의 대표 사례)와 **구조 강성 부족(관절 탄성)**을 추가 확인, "반복 정밀도가 높으면 위치 정밀도도 자동으로 보장된다"는 것이 명확한 오답 포인트임을 재확인(기존 페이지가 이미 이 독립성을 다루고 있어 자연스럽게 연결됨)

## Phase 2 — 자체 검토

- 위치정밀도 저하요인은 기존 위치정밀도 정의를 완성하는 자연스러운 확장이며, 캘리브레이션 알고리즘(Gauss-Newton 등)의 구체적 보정 수식까지는 심화 범위라 넣지 않고 기구학적/비기구학적 오차의 대표 사례까지만 반영(§2 원칙)
- 경로속도특성·위빙편차는 기존 ISO 9283 시험항목 표를 완성하는 자연스러운 확장이며, 정격 경로속도의 100/50/10%라는 구체적 시험 조건까지만 반영
- 위치정밀도 저하요인은 기존 Box 용어 `위치 정밀도(Accuracy)`에 보강

## Phase 3 — 결론

1개 페이지(2. ISO 9283 로봇 성능 지표)에 신규 개념 2건(위치정밀도 저하요인, 경로속도특성·위빙편차) 반영. 기존 Box 용어 `위치 정밀도(Accuracy)`에 저하요인 보강. 신규 Box 용어 없음.
