## Phase 1 — 3라운드 반복 검색

### 1라운드 (영문, 개념별 확인)
검색어: "PCA principal component analysis feature extraction purpose machine vision object recognition", "ReLU activation function purpose batch normalization deep learning effect", "OpenCV computer vision library main functions robot vision applications", "stereo vision robot depth perception principle disparity triangulation"

- PCA: 분산이 가장 큰 축을 첫 주성분으로 삼는 직교 선형변환. 고차원 특징벡터(예: 100×100 영상=10,000차원)를 저차원으로 축소해 연산량을 줄이고 과적합을 완화. 물체 인식에서는 모델 영상의 대표 특징을 정하고 대상 영상과의 거리를 측정하는 데 사용(Eigenface 얼굴인식이 대표 사례).
- ReLU: 순전파 DNN에서 널리 쓰이며 기울기 소실 문제 완화에 기여.
- 배치 정규화: 보통 선형층과 활성화 함수(ReLU) 사이에 배치되어 은닉층의 특징 분포를 정규화, 학습 안정화. ReLU 같은 비유계(unbounded) 활성화 함수의 수치 불안정성을 특히 완화.
- OpenCV: 2,500개 이상의 알고리즘(영상처리·특징검출·객체검출·모션분석·3차원 재구성), C++/Python/Java/MATLAB 지원. 로봇 분야에서 내비게이션·장애물검출·경로계획에 활용.
- 스테레오 비전: 삼각측량(triangulation) 원리 — 두 카메라 영상 간 대응점의 x좌표 차이(시차, disparity)로 깊이를 계산. 베이스라인(두 카메라 간 거리)이 클수록 원거리 정확도 향상, 작을수록 근거리(로봇 파지 등)에 적합.

### 2라운드 (한국어, 재확인)
검색어: "주성분분석 PCA 차원축소 특징추출 영상인식 목적", "ReLU 활성화함수 배치 정규화 딥러닝 효과 기울기 소실", "스테레오 비전 로봇 깊이 인식 원리 시차 삼각측량"

- PCA는 기존 변수를 조합해 서로 연관성 없는 새 변수(주성분)를 만들어 차원을 축소하는 기법이며, 컴퓨터 비전에서 고차원 특징벡터의 학습 속도 개선에 쓰인다는 점을 한국어 자료로 재확인.
- ReLU는 양수 구간에서 미분값이 항상 1이므로 기울기 소실이 발생하지 않아 더 깊은 신경망 학습이 가능해지고 손실 감소 속도가 빠르다는 점 재확인. 단, 음수 구간은 기울기가 0이라 완전한 해결책은 아님(dying ReLU 한계).
- 배치 정규화는 과적합 문제 해결을 위해 개발된 정규화 기법 중 하나로, 활성화 함수와는 별개의 기법이라는 점을 한국어 자료로도 재확인.
- 스테레오 비전은 인간의 양안시차와 동일한 원리(좌우 카메라 간 시차→삼각측량→거리 추정)이며, 자율주행·로봇 내비게이션·물류자동화에 광범위하게 활용된다는 점 재확인.

### 3라운드 (심화 — OpenCV 로봇 활용 구체화 + 과적합 방지 기법 범위 확정)
검색어: "OpenCV 로봇 비전 활용 주요 기능 영상처리 라이브러리", "과적합 방지 방법이 아닌 것 시험 문제 드롭아웃 정규화 배치정규화 활성화함수"

- OpenCV의 로봇 활용 구체 사례 확인: 컨베이어 벨트 위 제품의 실시간 추적(로봇 팔 픽업 타이밍 계산), 자율주행 로봇의 환경 매핑·위치 추정·경로계획. 최근에는 DNN(딥러닝) 모델 실행 기능도 포함.
- **과적합 방지 기법 범위 확정**: 드롭아웃·L1/L2 정규화·배치 정규화는 모두 과적합 방지 기법이지만, **활성화 함수(ReLU 등) 자체는 비선형성 추가·기울기 소실 완화가 목적**이며 과적합 방지 기법으로 분류되지 않는다는 점을 확정 — 문제은행 6·8번 문항과 직결.

## Phase 2 — 자체 검토

- 3라운드 모두 상호 보강되며 신뢰도 높음. 특히 "활성화 함수는 과적합 방지 기법이 아니다"라는 구분은 문제은행 문항과 정확히 일치해 aside로 반영.
- 분량이 많아(5개 개념) 하나의 페이지에 몰아넣기보다 주제 응집도에 따라 2개 페이지로 분리: (4) PCA·ReLU·배치정규화 — "딥러닝 기반 인식 모델 설계 기법", (5) OpenCV·스테레오비전 — "실무 비전 도구와 3차원 인식".
- 음성인식·형태소분석(NLP) 관련 3문항은 이 세세항목 개요가 명시한 범위(머신비전·물체인식·추적·상황인식) 밖이므로 이번 배치에서 다루지 않고, HRI 세세항목 재작업 시 기존 HRI 페이지의 커버리지를 재확인하기로 결정.
