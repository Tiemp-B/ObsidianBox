# 조사 - 센서인터페이스설계고려사항·모듈간통신교차링크

**대상 세세항목**: 과목4 지능소프트웨어 / 3. 로봇 센서 인터페이스 개발 / 2. 로봇 센서 프로토콜 설계 / 1. 로봇센서 인터페이스

**문제은행 확인**: 이 세세항목은 전용 슬롯 없이 부모 세부항목 슬롯(13문항)만 존재. 전수 분류 결과:

| 문항 | 처리 |
|---|---|
| I2C 통신 방식·START조건, RS-485 특징, USB 3.0 특징×2, SPI 신호선, UART 특징 | 기존 페이지 "I2C·SPI·UART·RS-485·USB 인터페이스"에 이미 상세 존재 |
| TCP/IP 실시간 제어, QoS 보장 요소, CAN 특징×2 | 형제 세세항목("2. 통신 프로토콜 설계")의 전용 슬롯(4문항)과 동일 주제 — 이월 |
| 모듈 간 통신 방식이 아닌 것 | 과목2 "로봇 구성요소간 통신프로토콜"의 ROS Topic/Service/Action(통신 모델) 페이지에 이미 존재 → 교차링크만 |
| **로봇센서 인터페이스 설계 시 고려해야 할 주요 요소가 아닌 것** | **공백** — 이 세세항목의 정체성에 정확히 부합하는 종합형 문항이나 vault에 없었음 |

## Phase 1 — 3라운드 반복 검색

### 1라운드 (영문)
검색어: "sensor interface design considerations power consumption sampling rate noise cable length"

- 센서 인터페이스 회로는 넓은 입력범위·양호한 선형성·저잡음·고분해능이 필요하며, **저전력**이 특히 중요(샘플링레이트가 높아질수록 전송률과 소비전력이 함께 증가하는 트레이드오프).
- 센서 신호는 대개 대역폭이 크지 않지만(수십 kHz 이하), 나이퀴스트 기준의 5배 정도 샘플링레이트를 확보하면 충분한 정확도 확보 가능.
- 220V 전원선 근처의 60Hz 잡음처럼 외부 노이즈에 취약하므로 저잡음 설계가 필요.
- 케이블 길이는 신호 무결성·전력 전달·비용에 영향을 주며, 통신 표준(RS-485는 수백 m, Single Pair Ethernet은 1km)에 따라 최대 길이가 달라짐.

### 2라운드 (한국어, 재확인)
검색어: "센서 인터페이스 설계 시 고려사항 전력소비 샘플링레이트 노이즈 케이블길이"

- 전력소비·노이즈(그라운딩·GND plane·디커플링)·샘플링레이트(나이퀴스트 주파수 기준)·케이블/신호전송이 핵심 고려사항으로 한국어 자료에서도 일관되게 확인됨.

### 3라운드 (심화 — 신호무결성·커넥터까지 확인)
검색어: "센서 인터페이스 설계 고려요소 아닌 것 신호무결성 대역폭 커넥터", "센서 인터페이스 설계 고려요소 아닌 것 신호무결성 대역폭 커넥터"

- 신호무결성(Signal Integrity)·대역폭·커넥터 설계도 고속 신호 전달 시 함께 고려해야 할 요소로 확인됨 — 앞선 2라운드의 항목들과 종합하면 **데이터 형식·통신 프로토콜(이미 과목4/1에서 다룸) + 전력소비 + 샘플링레이트 + 노이즈·신호무결성 + 케이블/커넥터**로 정리 가능.
- "센서 인터페이스 설계 고려요소가 아닌 것"이라는 문제 유형은 vault의 기존 사례(주변장치 인터페이스 분석 페이지의 "외관 디자인·색상은 고려사항이 아니다")와 일관되게, 물리적 성능·신호 특성과 무관한 요소(외관·가격 등)는 설계 고려사항에 해당하지 않는다는 점이 일반적임을 재확인.

## Phase 2 — 자체 검토

- 3라운드 모두 동일한 핵심 카테고리(전력소비·샘플링레이트·노이즈/신호무결성·케이블·커넥터)에 수렴해 신뢰도 높음.
- 데이터 형식·통신 프로토콜은 이미 과목4 "1. 작업지능 소프트웨어 개발/2. 작업 수행 지능 설계/2. 주변장치 인터페이스 분석"에서 "가장 중요한 고려사항"으로 다뤘으므로 중복 서술하지 않고 교차링크로 연결.
- 모듈 간 통신 방식은 과목2 ROS 통신모델 페이지로 충분히 커버되므로 이번 배치에서 새로 쓰지 않고 교차링크만 추가.

## Phase 3 — 결론

- 신규 페이지 "4. 센서 인터페이스 설계 시 고려사항(전력·샘플링레이트·노이즈·케이블)" 작성.
- 신규 Box 용어는 만들지 않는다(개별 하위 개념(전력소비·샘플링레이트 등)이 이미 일반적인 전기·통신 상식 수준이라 별도 Box 용어보다 페이지 내용으로 충분).
