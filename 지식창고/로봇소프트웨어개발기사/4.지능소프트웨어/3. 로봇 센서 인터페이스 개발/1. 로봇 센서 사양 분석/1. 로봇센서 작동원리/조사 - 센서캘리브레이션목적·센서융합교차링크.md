# 조사 - 센서캘리브레이션목적·센서융합교차링크

**대상 세세항목**: 과목4 지능소프트웨어 / 3. 로봇 센서 인터페이스 개발 / 1. 로봇 센서 사양 분석 / 1. 로봇센서 작동원리

**문제은행 확인**: 이 세세항목 전용 슬롯(2문항: "센서 융합의 목적이 아닌 것", "센서 캘리브레이션의 목적이 아닌 것") 확인. 부모 세부항목 슬롯(16문항)은 초음파·근접·힘토크·ToF·MEMS자이로·IMU·엔코더·정전용량형터치 등 대부분 형제 세세항목("2. 센서 종류")의 구체 센서 종류 소관이며, 이번 배치에서는 다루지 않고 이월. 부모 슬롯의 "센서 융합 목적"·"작동원리 분류 아닌 것"은 전용 슬롯과 중복이거나 기존 오답 aside로 이미 커버.

## Phase 1 — 3라운드 반복 검색

### 1라운드 (영문)
검색어: "sensor calibration purpose accuracy drift offset correction robot"

- 센서 캘리브레이션은 센서 출력을 알려진 기준값과 비교해 조정·보상하는 과정이며, 센서 오차·불확실성을 줄이고 로봇 시스템의 정확도·신뢰성을 높이는 것이 목적.
- 오차는 제조 결함·환경 조건·노화·잡음·간섭·바이어스 등 다양한 원인으로 발생하며, 특히 온도 등 환경 요인으로 오프셋이 시간에 따라 서서히 변하는 **드리프트**가 발생.
- 체계적 오차(systematic error)는 일관되고 예측 가능하므로 알려진 오프셋·보정계수를 적용해 교정 가능.

### 2라운드 (한국어, 재확인)
검색어: "로봇 센서 캘리브레이션 목적 오차보정 드리프트 정확도"

- 센서는 저마다 다른 오프셋 값·이득 값을 가지며, 장시간 사용 시 환경요인으로 발생하는 측정값 오차를 보정하는 것이 캘리브레이션의 목적이라는 점이 한국어 특허·연구자료로 재확인됨.
- 출하 시 1차 보정(오프셋 오차·온도 계수) 외에도, 장기 사용에 따른 감도 변화를 주기적으로 재보정할 필요가 있음.
- 자이로 센서의 바이어스 드리프트(정지 중에도 바이어스가 시간에 따라 변하는 현상)가 대표적인 캘리브레이션 필요 사례로 확인됨.

### 3라운드 (심화 — 오답 함정 확정)
검색어: "센서 캘리브레이션 목적이 아닌 것 오프셋 이득 선형화 표준화"

- 센서 캘리브레이션의 구체적 대상은 **오프셋(offset)·이득(gain)·선형화(linearity)·온도 계수**로 확정.
- "표준화(Standardization)"는 캘리브레이션의 직접적 목적이 아니라 제조 과정의 품질 관리 단계에 가깝다는 점을 확인 — 오답 후보로 "센서의 제조 규격을 표준화하는 것" 등을 활용 가능.

## Phase 2 — 자체 검토

- 3라운드 모두 "출력값을 알려진 기준과 비교해 오프셋·이득·선형성을 보정 → 정확도·신뢰성 확보"라는 동일 결론에 수렴해 신뢰도 높음.
- 기존 "카메라 보정(Calibration)" 내용(3D-2D 좌표계 관계, 내부/외부 변수)은 시각 센서에 특화된 별개 개념이므로, 이번에 추가하는 범용 센서 캘리브레이션(오프셋·이득·선형화·드리프트 보정)과 혼동되지 않도록 페이지에서 명확히 구분한다.
- 센서 융합은 과목1에 이미 충실히 존재하므로 이번 배치에서는 내용을 새로 쓰지 않고 교차링크만 추가한다.

## Phase 3 — 결론

- 신규 페이지 "3. 센서 캘리브레이션의 목적과 센서 융합" 작성 — 캘리브레이션(오프셋·이득·선형화·드리프트 보정)을 신규 서술하고, 센서 융합은 과목1 페이지로 교차링크한다.
