## Phase 1 — 3라운드 반복 검색

### 1라운드 (영문)
검색어: "capacitive touch sensor working principle characteristics vs proximity sensor"

- 정전용량형 터치센서는 사람 몸(전도성)이 센서 근처(fringing field)에 닿을 때 발생하는 정전용량 변화를 감지. 자가 정전용량(self-capacitance) 방식은 근접센서·단일터치에, 상호 정전용량(mutual-capacitance) 방식은 터치스크린의 다중터치 감지에 주로 쓰임.
- 정전용량형 근접센서와 터치(버튼)센서의 차이: 근접센서는 사용자가 표면에 닿기 **전**에 반응하도록, 터치(버튼)센서는 실제로 표면에 **닿았을 때** 반응하도록 민감도가 조정됨.
- 고체 상태(무접점)로 기계적 마모가 없어 내구성이 높고, 빠른 스위칭이 가능.

### 2라운드 (한국어, 재확인)
검색어: "정전용량형 터치센서 원리 특징 습기 오작동 다중터치"

- 손가락이 센서 근처에 위치할 때 발생하는 정전용량 변화를 감지하는 원리, 기계식 대비 높은 신뢰성·긴 수명이 한국어 자료로도 재확인됨.
- **습기에 의한 오작동**이 대표적 한계로 확인됨 — 물방울이 묻으면 정전식 터치스크린이 오작동할 수 있음.
- 다중터치는 상호 정전용량(X·Y축 전도성 그리드) 방식으로 구현됨.

### 3라운드 (심화 — 오답 함정 확정)
검색어: "정전용량형 터치센서 특징 아닌 것 기계적 압력 불필요 장갑 낀 손 미검출"

- **"기계적 압력이 필요 없다"는 특징**(맞는 서술) — 손가락이 정전용량 변화를 일으키기만 하면 되고, 물리적으로 눌러야 하는 것이 아님. 이 점은 저항막(Resistive) 방식과의 핵심 차이.
- **"장갑 낀 손도 잘 검출한다"는 서술은 오답**으로 활용 가능 — 오히려 장갑(비전도성)을 낀 손가락 검출은 정전용량형의 현재 기술적 한계로 확인됨.

## Phase 2 — 자체 검토

- 정전용량형 터치센서는 앞서 다룬 정전용량형 근접센서와 **동일한 물리 원리**(유전율/정전용량 변화 감지)를 공유하되, 민감도 조정(터치 시점 vs 근접 시점)만 다르다는 점이 확인됨 — 따라서 완전히 새로운 페이지보다는 기존 "거리·근접 센서" 페이지의 정전용량형 근접센서 aside에 짧게 연결·확장하는 것이 자연스럽다.
- 힘/토크 센서 용도는 과목4의 힘 제어 페이지로 충분히 커버되므로 별도 서술 없이 교차링크만 추가한다.

## Phase 3 — 결론

- 기존 페이지 "2. 거리·근접 센서(초음파·ToF·정전용량형)"의 "근접 센서" aside 뒤에 "정전용량형 터치 센서" 소단락을 추가한다.
- 기존 페이지 "3. 관성·힘 센서"의 힘/토크 센서 aside에 과목4 힘 제어 페이지로의 교차링크를 추가한다.
- 신규 Box 용어는 만들지 않는다(정전용량형 근접센서 Box 개념과 원리가 사실상 동일해 중복 방지).
