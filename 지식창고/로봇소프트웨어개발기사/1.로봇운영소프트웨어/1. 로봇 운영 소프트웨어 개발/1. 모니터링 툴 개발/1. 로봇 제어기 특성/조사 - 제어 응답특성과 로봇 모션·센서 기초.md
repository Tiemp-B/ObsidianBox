# 조사 자료 — 제어 응답특성과 로봇 모션·센서 기초

세세항목 "1. 로봇 제어기 특성"의 자료조사 Phase 1 초안(2/3). 제어 응답 특성 지표, 좌표계·보간법, 센서 피드백·신호처리를 다룬다.

---

## 1. 제어 응답 특성 지표 (계단응답 기준)

- **상승시간(Rise Time, $t_r$)**: 정상상태값의 10%→90%(또는 저감쇠계에서는 최초로 정상상태값에 도달하는 시점)까지 걸리는 시간.
- **정착시간(Settling Time, $t_s$)**: 응답이 정상상태값의 지정 오차범위(관례적으로 ±2% 또는 ±5%) 이내로 들어와 계속 머무는 데 걸리는 시간.
- **오버슈트(Overshoot)**: 응답이 정상상태값을 초과하는 최대량. 정상상태값 대비 백분율(%Overshoot)로 표현.
- **정상상태오차(Steady-State Error, $e_{ss}$)**: 시간이 무한히 지났을 때 목표값(입력)과 실제 출력의 차이.

이 네 지표는 로봇 제어기의 응답 성능을 정량화하는 표준 지표로, 제어이론 교재(2차 시스템 계단응답 분석)에 공통적으로 정의되어 있어 추가 검증이 필요 없는 확립된 정의로 판단.

## 2. 좌표계

로봇 시스템은 여러 개의 좌표 기준 프레임을 함께 사용한다.
- **월드 좌표계(World Coordinate Frame)**: 원점과 축 방향이 고정된 전역 기준 좌표계. 여러 로봇·센서의 데이터를 하나의 공통 기준으로 통합하는 데 사용.
- **베이스 좌표계(Robot Base Frame)**: 로봇 베이스(고정부)에 원점을 둔 좌표계 — 로봇의 기계적 구조 설계 기준.
- **툴 좌표계(Tool Frame / TCP)**: 로봇 말단 작업 도구(Tool Center Point)를 중심으로 한 좌표계 — 로봇이 실제로 피벗·이동하는 기준점.
- 관절 좌표계(Joint Frame)는 각 관절의 로컬 기준 프레임으로, 정/역기구학 계산의 기본 단위가 된다(과목3 "1. 좌표계" 세세항목에서 상세히 다룰 영역이므로 이 페이지에서는 개념만 소개하고 중복 서술하지 않음).

어떤 좌표계를 기준으로 명령을 내리는지 명확히 인지하지 않으면 위험한 동작으로 이어질 수 있다는 점이 실무적으로 강조된다.

## 3. 보간법 (Interpolation)

로봇의 이동 명령은 대표적으로 3가지 보간 방식으로 나뉜다.
- **관절 보간(Joint Interpolation)**: 각 관절이 독립적으로 목표 각도까지 움직이며, TCP의 경로는 직선이 아닌 임의의 곡선을 그림 — 계산이 단순하고 빠르지만 경로 예측이 어려움.
- **직선 보간(Linear Interpolation)**: TCP가 시작점-끝점을 직선으로 이동하도록 각 관절을 동기 제어 — 경로가 예측 가능해 협소 공간·정밀 작업에 적합.
- **원호 보간(Circular Interpolation)**: TCP가 지정된 원호를 따라 이동 — 용접 등 곡선 경로 작업에 사용.

세 방식 모두 목표는 시작점 A에서 끝점 B로 이동하는 것이지만, 실제로 TCP가 그리는 경로 형태가 근본적으로 다르다는 점이 핵심 구분 포인트.

> [출처] [Robot Motion Command Types (control.com)](https://control.com/technical-articles/robot-motion-command-typesexplained/), [compas_fab — Coordinate frames](https://gramaziokohler.github.io/compas_fab/latest/examples/01_fundamentals/02_coordinate_frames.html)

**중복 방지 확인**: 좌표계·보간법의 수학적 상세(변환행렬, DH 파라미터, 순기구학/역기구학 유도)는 과목3 "1. 로봇 공간 및 운동해석"(좌표계/변환행렬/기구학해석/역기구학해석 4개 세세항목)에서 본격적으로 다루므로, 이 페이지에서는 로봇 제어기가 다루는 개념 차원의 소개로 범위를 한정하고 위키링크로 연결한다.

## 4. 센서 피드백과 신호처리

- **엔코더(Encoder) 기반 폐루프 제어**: 엔코더는 기계적 움직임을 전기 신호로 변환해 위치·속도·방향 정보를 실시간으로 제어기에 피드백. 제어기는 이 피드백과 목표값의 오차를 기반으로 제어 신호를 갱신하는 폐루프(closed-loop) 구조를 형성.
- **노이즈 문제**: 산업 현장의 전자기 간섭(EMI)이 엔코더 신호를 왜곡시켜 위치·속도 데이터 오차를 유발할 수 있음. 엔코더 피드백을 직접 미분(속도 추정)하면 측정 노이즈가 증폭되어 제어 신호에 채터링(chattering)이 발생할 수 있음.
- **대응책**: 차폐 케이블·접지, 노이즈에 상대적으로 강인한 광학식 엔코더 채택, 저역통과 필터 등 전자적 필터링. (저역통과 필터·이동평균필터·칼만필터는 기존 Box 용어/과목1 "6. 센서 피드백과 신호처리" 원 페이지에서 이미 다룸 — 재사용)
