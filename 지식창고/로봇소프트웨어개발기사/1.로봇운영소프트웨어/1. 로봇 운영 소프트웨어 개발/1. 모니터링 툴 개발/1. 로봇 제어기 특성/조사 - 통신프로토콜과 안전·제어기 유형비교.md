# 조사 자료 — 통신 프로토콜과 안전회로·제어기 유형비교

세세항목 "1. 로봇 제어기 특성"의 자료조사 Phase 1 초안(3/3). 로봇 제어기 통신 프로토콜, 안전회로·기능안전, 제어기 유형별(산업용·협동·이동로봇) 비교를 다룬다.

---

## 1. 로봇 제어기 통신 프로토콜

개별 프로토콜(EtherCAT/CAN/Modbus/PROFIBUS 등)의 상세 스펙은 이미 `지식창고/Box/`에 용어 페이지로 폭넓게 구축되어 있으므로, 이 페이지에서는 **로봇 제어기 맥락에서의 선정 기준·실시간성 비교**에 집중한다.

- **EtherCAT**: 산업용 실시간 이더넷 중 가장 결정론적(deterministic) 응답을 제공한다고 평가됨. 목표 사이클타임 **100µs 이하, 지터 1µs 이하** 수준(EtherCAT Technology Group 발표 자료 기준 — 1,000 I/O 처리 32.5µs, 100축 제어 125µs). 나노초 단위 정밀도의 Distributed Clock(분산 클록) 동기화가 모션제어·로보틱스에 특히 유리.
- **CAN**: EtherCAT 대비 대역폭·결정론은 낮지만 배선 단순성·강인성 때문에 이동로봇·서브시스템(액추에이터 모듈 등)에서 여전히 널리 사용.
- **Modbus(TCP)**: 비결정론적(네트워크 부하에 따라 응답시간 변동) — 엄격한 타이밍이 필요 없는 기본적 데이터 수집·모니터링 용도에 적합, 모션제어 실시간 루프에는 부적합.
- 로봇 제어기 아키텍처에서 흔한 조합: **EtherCAT를 구동부(드라이브·분산 I/O) 실시간 백본으로, CAN을 서브시스템(액추에이터 모듈 등) 내부 통신으로** 함께 쓰는 계층적 구성.

> [출처] [5 Real-Time Ethernet-Based Fieldbuses Compared (Automate.org/IntervalZero)](https://www.automate.org/tech-papers/5-real-time-ethernet-based-fieldbuses-compared), [Why EtherCAT is Superior (백서, PDF)](https://data.embeddedcomputing.com/uploads/articles/whitepapers/14029.pdf), [EtherCAT vs Modbus](http://www.masterofplc.com/2025/11/ethercat-vs-modbus-why-next-generation.html)

**⚠ Phase 2 확인 필요**: EtherCAT 사이클타임/지터 수치는 EtherCAT Technology Group(주관 단체) 발표 자료가 원출처로 널리 재인용되는 값이라 신뢰도는 높으나, 이번 조사에서는 1차 표준 문서가 아닌 2차 백서·블로그 인용이므로 본문에는 "약 100µs 이하" 등 범위 표현으로 반영하고 단일 확정값처럼 단정하지 않는다.

**중복 방지**: 기존 원 페이지("7. 로봇 제어기 통신 프로토콜 심화")가 이미 프로토콜별 상세를 다루고 있었다면, 재작성 시에도 프로토콜 자체의 상세 스펙은 각 Box 용어 페이지로 위키링크하고, 이 페이지는 "제어기가 어떤 기준으로 프로토콜을 선택하는가"에 집중해 중복을 피한다.

## 2. 안전회로와 기능안전

- **ISO 13849-1**: 기계·유압·공압을 포함한 모든 기술 영역의 기능안전을 다루는 표준. 안전기능별로 요구되는 **성능 레벨(Performance Level, PL)**을 PL a(낮음)~PL e(높음) 5단계로 규정. 위험성평가(부상 심각도·노출 빈도·회피 가능성)를 통해 필요 PL을 도출.
- **IEC 62061**: 전기/전자/프로그래머블 전자(E/E/PE) 시스템의 전체 라이프사이클을 다루며, **안전 무결성 레벨(Safety Integrity Level, SIL)** 4단계로 안전기능 성능을 규정. ISO 13849-1과 적용 범위가 겹치되(전기 시스템), 유압·기계 요소까지 포괄하는 ISO 13849-1과 커버리지가 다름.
- **안전 회로 카테고리(ISO 13849-1의 Category B/1/2/3/4)**: 하드웨어 구조 요구사항.
  - **Category 3**: 산업 안전 응용에서 가장 흔한 구조. 두 개의 독립 채널을 병렬로 사용해 한 채널만으로도 안전 정지 가능, 한 채널의 단일 고장이 안전 기능 상실로 이어지지 않음(cross-monitoring으로 고장 검출).
  - **Category 4**: 센서부터 최종 제어기까지 이중화(redundancy)를 요구하는 최고 수준. 이중화된(force-guided) 접촉기를 각각 안전 릴레이가 모니터링해, 둘 다 정상적으로 차단되어야 부하가 꺼짐.
- **비상정지(E-stop) 회로**: 이중 채널(dual-channel)로 배선된 두 개의 상시닫힘(NC) 접점이 각각 안전 릴레이의 입력 채널에 연결되며, cross-shortage 모니터링으로 단선·접점 융착·단락을 검출해 Category 3/4 및 PL d/e를 달성. ISO 10218-1은 로봇 셀 안전장치 작동 후 **수동 재시작**을 요구.

**협동로봇 안전기준 사례**: 국내 협동로봇 업체가 일반 산업표준(PL d, Cat 3)을 넘는 **PL e, Cat 4** 수준의 기능안전을 달성했다고 공개한 사례가 있어, 협동로봇이 산업용 로봇보다 높은 안전등급을 지향하는 경향을 보여준다(다만 이는 개별 제품 사례이므로 "협동로봇은 항상 PL e"라는 식으로 일반화하지 않는다).

## 3. 제어기 유형별 비교 (산업용 · 협동 · 이동로봇)

**협동로봇 4대 협업 모드(ISO/TS 15066)**: ISO 10218-1/2를 보완하는 협동로봇 전용 기술사양으로, ①안전정격 감시정지(Safety-rated Monitored Stop) ②핸드가이딩(Hand Guiding) ③속도·이격거리 모니터링(Speed and Separation Monitoring) ④동력·힘 제한(Power and Force Limiting, PFL) 4가지 협업 모드를 정의(Phase 3 재확인 완료 — ISO 공식 표준 페이지·학술문헌 교차 확인). 이 중 PFL이 사람과의 직접 물리적 접촉을 허용하는 모드로, 접촉 시 로봇이 이를 감지해 안전하게 반응하도록 요구한다.

| 구분 | 산업용 로봇 제어기 | 협동로봇(Cobot) 제어기 | 이동로봇 제어기 |
|---|---|---|---|
| 동작 환경 | 안전펜스 내부, 사람 접근 차단 | 사람과 같은 공간에서 근접 협업 | 개방된 동적 환경 이동 |
| 속도·힘 | 고속·고출력 우선 | 충돌 감지 시 즉시 정지(제한된 속도·힘) | 이동 안전성(장애물회피) 우선 |
| 프로그래밍 | 엔지니어의 코드 작성(정밀 티칭) | 핸드가이딩(demo teaching) 등 직관적 교시 | 목표점·경로 지정 + 자율 주행 알고리즘 |
| 핵심 제어기술 | 고정밀 서보 위치제어 | 컴플라이언스 제어(순응 제어), 충돌감지 | 위치추정(오도메트리·SLAM) + 경로계획 |
| 대표 안전기준 | ISO 10218-1(로봇 자체), Cat 3~4 | ISO 10218-1/2 + ISO/TS 15066(협동로봇 전용) | 이동체 특화 리스크 평가(장애물·낙상 등) |

**컴플라이언스 제어(Compliance Control)**: 협동로봇·이동로봇에서 사람과의 안전한 상호작용을 위한 핵심 제어 기법 — 위치제어만으로 강성 있게 움직이는 대신, 예상치 못한 외력(접촉·충돌)에 대해 순응적으로 반응하도록 제어 루프를 구성. 산업 사례에서는 "척수반사 계층(안전 지능·컴플라이언스 제어)"과 "정밀 작업 계층(궤적 보정)"처럼 계층을 나눠 안전성과 정밀도를 동시에 확보하는 구조가 언급된다.

**이동로봇 제어기의 계층 구조**: 상위(고수준) 플래너가 목표 획득·중장거리 경로계획을 담당하고, 하위(저수준) 제어기가 로봇의 운동학/동역학 모델을 바탕으로 개별 액추에이터 입력으로 변환한다. 저수준 제어기는 액추에이터별 오차를 계산해 PID 제어기로 전달하고, 오도메트리(엔코더+IMU 등에서 산출한 위치추정)를 실제 속도 피드백으로 사용해 상위 명령과 비교한다.
