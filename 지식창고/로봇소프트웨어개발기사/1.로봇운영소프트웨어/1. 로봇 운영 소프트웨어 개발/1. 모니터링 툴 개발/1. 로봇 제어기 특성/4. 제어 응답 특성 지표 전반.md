# Summary

로봇 제어기의 성능은 "얼마나 목표값에 빠르고 정확하게 도달하는가"로 평가되며, 이를 정량화한 것이 **응답 특성 지표**(시정수·상승시간·정착시간·오버슈트·정상상태오차)다. 대부분의 로봇 제어기는 **[[PID 제어|PID]] 제어기**를 사용해 이 응답 특성을 조정하며, P/I/D 각 게인이 서로 다른 지표에 영향을 준다. 제어 방식은 크게 출력을 측정해 오차를 보정하는 **[[피드백 제어(Feedback Control)|피드백 제어]]**와, 시스템 모델을 이용해 오차가 생기기 전에 미리 보정하는 **[[피드포워드 제어(Feedforward Control)|피드포워드 제어]]**로 나뉜다.

# Notes

<aside>제어 응답 특성 지표 개관</aside>

계단 입력(목표값이 순간적으로 바뀌는 입력)에 대해 시스템의 출력이 어떻게 변화하는지를 나타내는 대표 지표들이다.

| 지표 | 기호 | 정의 |
|---|---|---|
| [[시정수(Time Constant)\|시정수(Time Constant)]] | $\tau$ (타우) | 1차 시스템 응답이 최종값의 **63.2%(=1-1/e)**에 도달하는 데 걸리는 시간. 값이 작을수록 응답이 빠름 |
| [[상승시간(Rise Time)\|상승시간(Rise Time)]] | $t_r$ | 출력이 최종값의 일정 비율(예: 10%→90%)까지 상승하는 데 걸리는 시간 |
| [[정착시간(Settling Time)\|정착시간(Settling Time)]] | $t_s$ | 출력이 최종값의 허용 오차 범위(예: ±2%) 안에 들어가 안정되는 데 걸리는 시간 |
| [[오버슈트(Overshoot)\|오버슈트(Overshoot)]] | $M_p$ (또는 OS%) | 출력이 최종값을 초과해서 올라가는 최대 정도 |
| [[정상상태오차(Steady-State Error)\|정상상태오차(Steady-State Error)]] | $e_{ss}$ | 충분히 시간이 지난 후에도 남아있는, 목표값과 출력값의 차이 |

이 지표들은 서로 트레이드오프 관계에 있다 — 예를 들어 응답을 빠르게 하려고 게인을 높이면 오버슈트가 커지는 식이다. PID 제어기의 P/I/D 게인은 바로 이 지표들을 조정하는 손잡이 역할을 한다. 각 지표의 상세한 계산식은 개별 용어 페이지([[시정수(Time Constant)]] 등)에서 다룬다.

<aside>PID 제어기의 구성</aside>

PID 제어기는 **비례(P, Proportional) + 적분(I, Integral) + 미분(D, Derivative)** 세 가지 제어 동작의 조합으로 구성된다. "지수(Exponential) 제어"와 같은 동작은 PID의 구성 요소가 아니다.

- **비례(P) 제어**: 현재 오차의 크기에 비례해 제어 출력을 만든다. P 게인을 높이면 응답 속도가 빨라지지만, 지나치면 오버슈트가 커지고 시스템이 불안정해질 수 있다.
- **적분(I) 제어**: 과거 오차를 누적해서 반영한다. 시간이 지나도 남아있는 **정상상태 오차를 제거**하는 역할을 한다. 다만 I 게인을 과도하게 높이면 오차가 과하게 누적되어 오버슈트가 커지고 **오히려 안정성이 저하**될 수 있다 — "I 게인을 높이면 안정성이 항상 향상된다"는 서술은 틀린 설명이다.
- **미분(D) 제어**: 오차의 변화율(기울기)에 반응한다. 오버슈트를 억제하고 응답을 빠르게 감쇠시키는 데 도움을 주지만, 노이즈에 민감해지는 단점이 있다.

세 동작을 합친 PID 출력은 다음과 같이 표현된다.

$$u(t) = K_p\,e(t) + K_i\int e(t)\,dt + K_d\,\frac{de(t)}{dt}$$

<aside>피드백 제어 vs 피드포워드 제어</aside>

| 구분 | 피드백 제어 | 피드포워드 제어 |
|---|---|---|
| 동작 방식 | 출력을 **센서로 측정**해 목표값과 비교, 오차를 보정 | 시스템의 **수학적 모델**을 이용해 오차가 생기기 전에 미리 제어 입력을 계산 |
| 센서 필요 여부 | **반드시 필요** (오차를 계산하려면 실제 출력을 측정해야 함) | 이론적으로 센서 없이도 동작 가능(모델 기반 예측) |
| 외란(External Disturbance) 대응 | 외란이 출력에 반영된 후에 사후 보정 → 외란에 강함 | 예측하지 못한 외란에는 대응하지 못함 |
| 요구 사항 | 정확한 오차 측정 | **정확한 시스템 모델**이 반드시 필요 |
| 구현 난이도 | 상대적으로 간단(모델 없이도 동작) | 모델링이 필요해 상대적으로 복잡 |

- 실무에서는 두 방식을 함께 쓰는 경우가 많다 — 피드포워드로 큰 흐름(예: 목표 궤적에 따른 예상 토크)을 미리 보정하고, 피드백으로 남은 오차와 외란을 보정하는 **피드포워드+피드백 혼합 구조**가 대표적이다.

<aside>핵심 정리</aside>

- 응답 특성 지표: $\tau$(시정수, 63.2%)·$t_r$(상승시간)·$t_s$(정착시간)·$M_p$(오버슈트)·$e_{ss}$(정상상태오차)는 서로 트레이드오프 관계
- PID 구성: **P(비례)·I(적분)·D(미분)** — 지수 제어는 해당하지 않음
- 피드백 제어: **센서 필수**, 외란에 강함 / 피드포워드 제어: **정확한 시스템 모델 필수**, 외란 예측 못 함
