# Summary

로봇 제어기는 센서 상태를 입력받아 정해진 시간 안에 제어 연산을 수행하고, 액추에이터·드라이브에 명령을 보내는 핵심 장치이다. 제어기의 핵심 특성은 실시간성·결정성, 정밀도, 신뢰성·진단성, 통신·확장성, 안전성이며, 모니터링 툴은 이 특성을 나타내는 상태·성능·알람 데이터를 상위 계층에서 관측하고 기록한다.

# Notes

<aside>1. 역할과 시스템 경계</aside>

- 센서·엔코더 등의 입력을 수집하고, 제어 알고리즘으로 목표값과 현재 상태의 오차를 계산한다.
- 계산 결과를 모터 드라이버·액추에이터에 전달하여 위치·속도·토크 등을 제어한다.
- 상위 PC·HMI·서버에는 상태값, 진단 정보, 알람을 제공한다.
- 제어기는 제어 루프를 수행하는 하위 계층이고, 모니터링 툴은 이를 관측·기록하는 상위 계층이다. 모니터링 툴이 서보 제어 주기와 동일하게 동작할 필요는 없다.

<aside>2. 기본 구성</aside>

| 구성 요소 | 역할 |
|---|---|
| 연산부 | 제어 알고리즘과 실시간 태스크 실행 |
| 센서·I/O 인터페이스 | 엔코더, 전류·온도 센서, 디지털·아날로그 신호 수집 |
| 구동 인터페이스 | 제어 명령을 드라이버·액추에이터에 전달 |
| 통신 인터페이스 | 상위 시스템 및 분산 장치와 상태·명령 교환 |
| 전원·안전부 | 전원 보호, 비상정지 및 안전 상태 처리 |

<aside>3. 핵심 특성</aside>

| 특성 | 의미 | 모니터링 관점 |
|---|---|---|
| 실시간성·결정성 | 정해진 제어 주기와 데드라인을 예측 가능하게 준수하는 능력 | 제어주기, 지터, 데드라인 초과 횟수 |
| 정밀도 | 목표값을 정확히 추종하는 능력 | 위치·속도·토크 오차, 정착시간, 오버슈트 |
| 신뢰성·진단성 | 장시간 안정적으로 동작하고 이상을 감지·복구하는 능력 | 오류 코드, 통신 오류, 온도, 전류, 재시작 이력 |
| 통신·확장성 | 상위 시스템 및 센서·드라이브 모듈과 연동·확장하는 능력 | 연결 상태, 통신 지연, 손실률, 연결 장치 수 |
| 안전성 | 위험 상태에서 안전 기능을 수행하는 능력 | 비상정지·인터록 상태, 안전 알람, 안전 기능 동작 이력 |

<aside>4. 성능 평가 지표</aside>

- **시간 특성**: 제어주기, 지터, 응답시간, 통신 지연
- **제어 품질**: 위치·속도·토크 오차, 정착시간, 오버슈트
- **자원 상태**: CPU·메모리 사용률, 전원 상태, 온도
- **신뢰성 상태**: 오류 코드, 통신 손실, 장애 횟수, 복구 이력
- **안전 상태**: 비상정지, 인터록, 안전 한계 초과 여부

<aside>5. 모니터링 툴 적용</aside>

모니터링 툴은 제어기 내부의 제어 알고리즘을 직접 대체하지 않는다. 대신 운영 목적에 맞는 주기로 상태값을 수집하고, 정상 범위·경고·고장 조건을 구분해 표시·기록한다. 따라서 화면 설계 시에는 각 항목의 **측정 단위, 갱신 주기, 정상 범위, 경고 임계값, 기록 필요 여부**를 함께 정의해야 한다.

<aside>핵심 정리</aside>

- 로봇 제어기는 센서 입력, 제어 연산, 구동 명령, 상태 제공을 담당한다.
- 제어기 특성은 실시간성·정밀도·신뢰성·통신/확장성·안전성으로 정리할 수 있다.
- 모니터링 툴은 이 특성을 수치와 상태 정보로 관측·경고·기록하는 상위 계층이다.
