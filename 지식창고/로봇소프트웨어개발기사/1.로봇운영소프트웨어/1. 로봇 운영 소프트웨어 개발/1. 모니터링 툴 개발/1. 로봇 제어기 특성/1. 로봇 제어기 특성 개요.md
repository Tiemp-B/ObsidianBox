# Summary

로봇제어기는 센서의 입력을 기반으로 제어 알고리즘을 수행하고 액추에이터를 제어하는 핵심 장치이다.
실시간성, 신뢰성, 정밀성, 확장성, 안전성 등의 특성을 가지며 다양한 산업용 통신 인터페이스를 지원한다.

# Notes

<aside>1. 로봇제어기 개요</aside>

- 로봇의 두뇌 역할 수행
- 센서와 액추에이터를 연결하는 중앙 제어장치
- 제어 알고리즘을 실행하여 로봇의 동작을 결정
- MCU, PLC, 산업용 PC 등이 사용됨

---

<aside>2. 로봇제어기의 구성</aside>

### CPU
- 제어 알고리즘 수행
- 실시간 연산 처리

### Memory
- 프로그램 및 데이터 저장
- Flash, RAM 사용

### I/O Interface
- Digital I/O
- Analog I/O
- PWM
- Encoder 입력

### Communication
- CAN
- EtherCAT
- Ethernet
- RS-485
- Modbus

### Power Management
- 전원 공급 및 보호
- 전압 변환

### RTOS
- 작업 스케줄링
- 인터럽트 처리
- 실시간성 보장

---

<aside>3. 로봇제어기의 주요 특성</aside>

### 실시간성(Real-Time)
- 일정한 제어주기 유지
- Deadline 만족
- Jitter 최소화

### 신뢰성(Reliability)
- 장시간 안정적인 동작
- Fault Detection
- Error Recovery

### 정밀성(Precision)
- 위치제어
- 속도제어
- 토크제어

### 확장성(Scalability)
- 센서 추가 가능
- 모듈 확장 가능

### 안전성(Safety)
- Emergency Stop
- Safety Interlock
- 이상 상태 감지

<aside>8. 핵심 정리</aside>

✔ 로봇제어기는 센서와 액추에이터를 연결하는 핵심 장치이다.

✔ 가장 중요한 특성은 실시간성이다.

✔ 안정적인 제어를 위해 RTOS와 인터럽트 기반 제어를 사용한다.

✔ 산업용 통신(CAN, EtherCAT 등)을 통해 주변 장치와 연결된다.

✔ 응답속도, 신뢰성, 정밀성, 안전성이 제어기 성능을 결정하는 핵심 요소이다.
