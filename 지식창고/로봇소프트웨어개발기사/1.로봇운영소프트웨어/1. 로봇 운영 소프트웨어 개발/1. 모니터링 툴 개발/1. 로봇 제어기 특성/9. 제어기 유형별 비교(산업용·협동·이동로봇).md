# Summary

"로봇 제어기"라고 해도 산업용 매니퓰레이터, 협동로봇, 이동로봇은 제어 대상과 제어 목표가 서로 다르다. 산업용은 **정확한 위치**를, 협동로봇은 **사람과 접촉해도 안전한 힘/토크**를, 이동로봇은 **속도와 방향(조향)**을 주로 제어한다. 이 페이지는 [[1. 로봇 제어기 ]] 개요에서 다룬 "구조에 따른 분류(중앙집중형/분산형/계층형)"를 로봇 유형 관점에서 더 구체적으로 비교한다.

# Notes

<aside>산업용 매니퓰레이터 제어기</aside>

- **제어 대상**: 각 관절의 **위치(Position Control)** 가 핵심. 정해진 좌표로 정확하고 빠르게 이동하는 것이 목표.
- **환경 가정**: 사람과 격리된 안전펜스 안에서 동작(고정된 작업 환경)하는 것을 전제로 하는 경우가 많다.
- **대표 제어 방식**: 위치 PID + 궤적 생성(보간법)을 통한 정밀 위치 제어.
- **하드웨어 특징**: 고강성(rigid) 구조, 고출력 서보 모터, 높은 위치 반복 정밀도.

<aside>협동로봇(Cobot) 제어기</aside>

**[[협동로봇(Cobot)|협동로봇]]**은 안전펜스 없이 사람과 같은 공간에서 함께 작업하도록 설계된다.

- **제어 대상**: 위치뿐 아니라 **힘/토크(Force/Torque Control)**를 함께 제어한다. 사람과 부딪혔을 때 즉시 감지하고 힘을 제한해야 하기 때문이다.
- **[[컴플라이언스 제어(Compliance Control)|컴플라이언스 제어]]**: 로봇 관절이 마치 스프링처럼 유연하게 반응하도록 제어하여, 외부 접촉(사람과의 충돌 등)이 발생했을 때 딱딱하게 버티지 않고 부드럽게 밀려나도록 하는 제어 기법. 순수 위치 제어만으로는 구현할 수 없고, 관절의 토크 센서 정보를 함께 사용하는 힘 기반 제어가 필요하다.
- **안전 요구사항**: 충돌 감지 후 정지까지의 반응 속도, 접촉력 제한 등이 [[8. 안전 회로와 기능안전]]에서 다룬 기능안전 요구사항과 직접 연결된다.

<aside>이동로봇(Mobile Robot) 제어기</aside>

- **제어 대상**: 관절 위치가 아니라 로봇 전체의 **속도와 조향(Velocity/Steering Control)**. 목표 지점까지의 경로를 따라가도록 바퀴(또는 다리)의 속도를 제어한다.
- **대표 구동 방식**: 차동 구동(Differential Drive, 좌우 바퀴 속도 차이로 방향 전환), 옴니휠(Omni-wheel, 전방향 이동) 등.
- **필요한 추가 기능**: 위치 제어 루프 외에도 자기 위치를 스스로 추정하는 **위치 인식(Localization)**과 주변 지도를 만드는 **지도 작성(Mapping)** 기능이 결합되어야 목적지까지 이동할 수 있다(예: SLAM).
- **환경 가정**: 산업용/협동로봇과 달리 작업 공간이 고정되어 있지 않고, 이동하며 계속 변화하는 환경(장애물 등)에 실시간으로 대응해야 한다.

<aside>세 유형 비교</aside>

| 구분 | 산업용 매니퓰레이터 | 협동로봇(Cobot) | 이동로봇 |
|---|---|---|---|
| 주 제어 대상 | 관절 위치 | 위치 + 힘/토크 | 속도/조향 |
| 대표 제어 기법 | 위치 PID + 궤적 생성 | 컴플라이언스 제어(힘 기반) | 속도 제어 + 위치 인식/지도 작성 |
| 사람과의 공존 | 안전펜스로 격리 | 같은 공간에서 직접 협업 | 개방된 공간에서 이동하며 공존 |
| 핵심 안전 요구 | 접근 금지(펜스, 인터록) | 접촉력 제한, 충돌 감지 | 장애물 회피, 충돌 방지 |

---

<aside>핵심 정리</aside>

- 산업용 = **위치 제어** 중심, 협동로봇 = **위치+힘/토크(컴플라이언스) 제어**, 이동로봇 = **속도/조향 + 위치인식·지도작성**
- 협동로봇의 컴플라이언스 제어는 순수 위치 제어로는 구현 불가 — 힘/토크 센서 기반 제어 필요
- 이동로봇은 관절 제어 루프 외에 SLAM 등 위치 인식·지도 작성 기능이 추가로 필요
