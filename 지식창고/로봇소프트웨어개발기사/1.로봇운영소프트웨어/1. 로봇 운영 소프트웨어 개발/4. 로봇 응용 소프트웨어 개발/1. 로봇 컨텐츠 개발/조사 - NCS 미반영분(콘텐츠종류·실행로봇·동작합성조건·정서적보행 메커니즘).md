# 조사 - NCS 미반영분 발굴 (2026-08-07)

이 세세항목은 이미 `NCS_학습모듈_참고자료.md`(LM1903080309_14v1 전체 정리, 7/30 작성)가 있고 7페이지 모두 그 내용을 잘 반영하고 있다. 목표(추가정보 발굴)에 맞춰, 이미 정리된 NCS 원문 안에서 **아직 페이지에 반영되지 않은 항목**을 찾는 데 집중했다(추가 웹조사보다 기존 1차 자료 재발굴이 더 근거가 확실하고 효율적이라 판단 — NCS 원문 자체가 근거이므로 별도 검증 불요).

## 발굴한 미반영 항목

1. **로봇 콘텐츠 종류 10개 전체 나열**(학습1): 정보/홈케어/맞춤형/기본/교육/오락/가사/감성/로봇기능/기관정보 서비스 — 현재 페이지2는 "정보·교육·오락·가사·감성" 5개만 언급, NCS 원문은 10개 분류를 제시함 → 페이지2에 전체 목록 보강
2. **로봇 콘텐츠 실행 로봇(휴머노이드) 플랫폼 분류**(학습2): 성인급(ASIMO/HRP/HUBO/똘망/ATLAS/iCub/TORO), 어린이급(NAO/ROBOTIS-OP), 바퀴형 상체(PEPPER/실벗) — 현재 어느 페이지에도 전혀 없음 → 페이지4에 신규 aside로 추가(구체적 실행 하드웨어 사례를 몰라 헷갈리는 문제은행 유형 대비)
3. **동작 합성(연결·합성)의 구체적 정합 조건**(학습3): 연결 시 시작-종료시간 일치+각도차 보정+각속도 일치 조건, 합성 시 짧은 궤적을 긴 궤적 종료시간에 맞춰 시간비율로 늘여 합산 — 현재 페이지5는 "연결/합성"이라는 용어만 정의하고 그 정합 조건은 없음 → 보강
4. **정서적 보행의 구체적 메커니즘**(학습3): PSO(입자군집최적화)로 ZMP 안정 궤적을 추종하는 하체 관절궤적을 최적화, **시간축 조정계수(α, 클수록 속도 증가)**와 **각도 배율계수(β, 클수록 보폭 증가)**로 감정별 파라미터 차별화 — 현재 페이지5는 정서적 보행을 "파라미터를 다르게 설정"이라고만 정성적으로 서술, 구체적 메커니즘(PSO 최적화, α/β 두 계수의 역할)이 없음 → 보강
5. **Gazebo에서 로봇 콘텐츠 시뮬레이션을 구성하는 요소**(학습4): 로봇 모델링(URDF/SDF), 센서 추가, 맵(환경) 구성, 모션 플러그인, 메타모델 해석기 연동(soarwrapper), 멀티미디어 재생(sound_play) — 현재 페이지7은 Gazebo를 개념적으로만 소개, 콘텐츠 시뮬레이션에 필요한 6가지 구성요소가 없음 → 개념 수준으로만 보강(구체적 패키지 설치 명령어·소스코드는 실기 영역이므로 제외)
