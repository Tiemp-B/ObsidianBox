# Summary

**로봇 컨텐츠 개발**은 로봇을 매개로 사용자에게 전달되는 체험(교육, 엔터테인먼트, 시뮬레이션 등)을 기획하고 구현하는 작업을 다룬다. 로봇 자체의 제어 로직이 아니라 **사용자가 로봇과 상호작용하며 겪는 경험의 품질**에 초점을 맞춘다는 점에서, 같은 세부항목의 "로봇과 ICT 융합"(통신·데이터 연계)이나 "로봇과 IoT디바이스 연동"(외부 디바이스 연동)과 대비된다.

# Notes

<aside>로봇 컨텐츠 개발이란</aside>

로봇을 매개로 사용자에게 전달되는 콘텐츠(교육용 프로그램, 엔터테인먼트, 시뮬레이션 등)를 기획·구현하는 작업이다. 핵심은 로봇의 제어 알고리즘이 아니라, 사용자가 실제로 체감하는 **경험(UX)**을 설계하는 데 있다.

<aside>세부항목 안에서의 위치</aside>

| 세세항목 | 초점 |
|---|---|
| 1. 로봇 컨텐츠 개발(이 세세항목) | 사용자가 체감하는 콘텐츠·경험의 품질 |
| 2. 로봇과 ICT 융합 | 로봇과 통신·데이터 기술의 연계 |
| 3. 로봇과 IoT디바이스 연동 | 로봇과 외부 IoT 디바이스 간 연동 |

<aside>이 세세항목에서 다루는 주제</aside>

이후 페이지는 콘텐츠 개발의 세 축을 다룬다: [[2. UX 설계와 접근성|UX 설계와 접근성]](누구나 잘 쓸 수 있도록 설계하는 방법), [[3. 게임화와 사용성 테스트|게임화와 사용성 테스트]](몰입도를 높이고 그 효과를 검증하는 방법), [[4. Unity3D 엔진과 업데이트 루프|게임 엔진 활용]](이를 실제로 구현하는 기술적 도구).

<aside>왜 게임 엔진을 사용하는가</aside>

로봇 콘텐츠, 특히 교육·엔터테인먼트용 콘텐츠는 3D 그래픽 렌더링, 물리 시뮬레이션, 사용자 입력 처리가 필요한 경우가 많다. 이런 요구를 직접 구현하기보다 Unity3D 같은 기존 게임 엔진을 활용하는 경우가 흔하며, 구체적인 내용은 4번 페이지에서 다룬다.

<aside>예시 — 교육용 로봇 콘텐츠 개발 흐름</aside>

**예시**: 아동 대상 교육용 로봇 콘텐츠를 만든다면, 먼저 대상 사용자에 맞는 UX와 접근성을 설계하고(2번), 학습 동기를 높이기 위한 게임화 요소를 적용한 뒤 실제 사용자 테스트로 효과를 검증하며(3번), 이 모든 상호작용 로직은 Unity3D 같은 게임 엔진으로 구현한다(4번).
