# Summary

CSRF(Cross-Site Request Forgery)는 로그인된 사용자가 **자신도 모르게 공격자가 의도한 요청을 정상 서버로 보내게** 만드는 공격으로, 스크립트를 실행시키는 [[XSS(Cross-Site Scripting)|XSS]]와 달리 이미 인증된 사용자의 권한을 그대로 악용한다.

# Notes

<aside>CSRF의 동작 방식</aside>

- 사용자가 정상 사이트에 로그인되어 있는 상태에서, 공격자가 만든 페이지(이메일 링크, 악성 사이트 등)를 열람
- 그 페이지에 숨겨진 요청(이미지 태그, 자동 제출 폼 등)이 사용자의 브라우저를 통해 **정상 사이트로 자동 전송**됨
- 브라우저는 해당 사이트의 인증 쿠키를 자동으로 함께 보내므로, 서버는 이 요청을 사용자 본인이 보낸 정상 요청으로 착각함

<aside>XSS와의 차이</aside>

XSS는 악성 스크립트를 실행시켜 직접 데이터를 탈취·조작하는 반면, CSRF는 스크립트 실행 없이 **이미 인증된 사용자의 권한으로 위조된 요청 자체**를 서버에 전달한다는 점이 다르다.

---

<aside>핵심 정리</aside>

- CSRF는 인증된 사용자의 권한을 이용해 위조된 요청을 서버로 보내게 만드는 공격이다
- CSRF 토큰 검증, 쿠키의 SameSite 속성이 기본 방어책이다
